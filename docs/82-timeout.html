timeout — Limiter le temps d'exécution d'une commande

Introduction

Vous êtes-vous déjà retrouvé avec un programme qui ne finit jamais ? Un script qui bloque ? Une commande réseau qui attend indéfiniment ? timeout est là pour ça : il permet de limiter le temps d'exécution d'une commande. Si elle dépasse la limite, timeout la termine automatiquement. C'est un outil indispensable pour éviter les blocages et gérer les processus qui prennent trop de temps.

Syntaxe de base

timeout [OPTIONS] DURÉE COMMANDE [ARGUMENTS]
  • DURÉE : temps maximum avant termination (en secondes par défaut)
  • COMMANDE : la commande à exécuter
  • ARGUMENTS : les arguments de la commande

Utilisation basique

Limiter à quelques secondes

# Timeout de 5 secondes sur une commande timeout 5 sleep 10 # sleep 10 sera arrêté après 5 secondes

Utiliser des unités de temps variées

# 2 minutes (2m) timeout 2m ma_commande # 1 heure (1h) timeout 1h script_long.sh # 30 secondes (par défaut, 30s ou 30) timeout 30 ping 192.168.1.1 # 1.5 secondes (avec décimales) timeout 1.5 curl http://example.com

Unités de temps disponibles

Signaux et comportement

Signal par défaut : SIGTERM

Par défaut, timeout envoie le signal SIGTERM pour terminer le processus. Si le processus ne s'arrête pas, il attend un court instant puis envoie SIGKILL pour forcer la termination.

# SIGTERM d'abord, puis SIGKILL si nécessaire timeout 5 curl http://example.com # Si curl ne répond pas en 5s → terminate

Envoyer un signal personnalisé

# Envoyer SIGINT (comme Ctrl+C) timeout -s INT 10 commande # Envoyer SIGKILL directement (plus brutal) timeout -s KILL 5 commande # Utiliser un signal par son nom timeout -s SIGUSR1 30 processus

Options utiles

--preserve-status

Retourne le code de sortie de la commande terminée par timeout comme code de sortie de timeout lui-même. Utile dans les scripts.

# Sans --preserve-status (par défaut) timeout 2 sleep 10 echo $? # Affiche 124 (timeout) # Avec --preserve-status timeout --preserve-status 2 sleep 10 echo $? # Affiche le code de sleep (124 ou 0)

--signal ou -s

Spécifie le signal à envoyer après la durée limite.

# Envoyer SIGKILL après 3 secondes timeout -s KILL 3 processus # Envoyer SIGINT après 10 secondes timeout -s INT 10 wget http://example.com

--kill-after ou -k

Définit un délai entre l'envoi du signal initial et SIGKILL. Le processus a ainsi le temps de s'arrêter proprement.

# Envoie SIGTERM, puis attend 2s, puis SIGKILL timeout -k 2 5 processus # Utile pour les scripts qui doivent nettoyer avant de mourir timeout -k 3 10 ./script_cleanup.sh

Afficher les détails avec --foreground

# Permet à timeout de fonctionner en premier plan timeout --foreground 5 curl http://example.com

Exemples pratiques

Limiter les requêtes réseau

# Timeout sur curl (10 secondes max) timeout 10 curl -O http://example.com/largefile.zip # Ping avec timeout timeout 5 ping -c 4 192.168.1.1 # SSH avec timeout timeout 30 ssh user@serveur "commande_lente"

Scripts et automation

# Dans un script : exécuter avec timeout #!/bin/bash if timeout 60 ./mon_script.sh; then echo "Script terminé avec succès" else code=$? if [ $code -eq 124 ]; then echo "Script trop long - timeout!" else echo "Script échoué avec code: $code" fi fi

Tests et débogage

# Tester si un service répond dans les 3 secondes timeout 3 nc -zv serveur:5432 && echo "Service accessible" # Tester une connexion avec timeout timeout 5 bash -c 'cat < /dev/null > /dev/tcp/serveur/port' && echo "Ouvert"

Loop avec timeout

# Réessayer une commande jusqu'à 3 fois, 10s par tentative for i in 1 2 3; do echo "Tentative $i..." if timeout 10 curl -s http://api.example.com/health; then echo "OK" break fi echo "Échec, nouvelle tentative..." sleep 5 done

Combiner avec d'autres outils

Avec xargs

# Appliquer un timeout à chaque commande cat serveur_list.txt | xargs -I {} timeout 5 ping -c 1 {} # Timeout sur des tâches parallèles echo -e "cmd1\ncmd2\ncmd3" | xargs -P 3 timeout 10

Avec find -exec

# Exécuter avec timeout via find find . -name "*.sh" -exec timeout 30 {} \; # Limiter le temps de chaque script find /scripts -type f -name "*.py" -exec timeout 60 python3 {} \;

Avec make

# Compiler avec timeout (éviter les builds infinies) timeout 300 make # Limiter la durée d'un build complexe timeout 600 make -j4

Scripts de surveillance avec timeout

Monitoring de service

#!/bin/bash # Vérifier si un service est joignable check_service() { local host=$1 local port=$2 local timeout_sec=5 timeout $timeout_sec bash -c "cat < /dev/null > /dev/tcp/$host/$port" 2>/dev/null return $? } # Utilisation if check_service "192.168.1.100" 443; then echo "Service UP" else echo "Service DOWN ou timeout" fi

Tâche cron avec timeout

# Dans /etc/crontab ou crontab -e # Exécuter un script toutes les heures avec timeout de 45 minutes 0 * * * * root timeout 2700 /opt/scripts/sauvegarde.sh # Explication : 2700 secondes = 45 minutes # Si la sauvegarde prend plus de 45min, elle est killée

Usage avancé

Timeout conditionnel

# Timeout seulement si la variable est définie TIMEOUT_VAL=${TIMEOUT:-30} timeout $TIMEOUT_VAL commande # Timeout dynamique basé sur une condition [ "$ENV" = "production" ] && T=60 || T=10 timeout $T ./deploy.sh

Pipeline avec timeout

# Timeout sur un pipeline entier timeout 30 sh -c 'long_running_command | another_command' # Utiliser un subshell timeout 15 $(cat large_file.csv | sort | uniq)

Environment timeout

# Définir un timeout par défaut via variable export COMMAND_TIMEOUT=60 # Utiliser dans les scripts timeout ${COMMAND_TIMEOUT} ./mon_script.sh # Modifier selon l'environnement [ "$NODE_ENV" = "test" ] && export COMMAND_TIMEOUT=300

Exercices pratiques

  1. Basique : Utilisez timeout pour limiter un sleep 20 à 3 secondes.
  2. Unité de temps : Créez une commande avec un timeout de 2 minutes sur un ping.
  3. Signal personnalisé : Utilisez -s KILL pour forcer l'arrêt d'une commande.
  4. Script : Écrivez un script qui exécute une commande avec un timeout et affiche si elle a réussi, échoué, ou été interrompue par timeout.
  5. Combinaison : Utilisez find avec -exec pour exécuter chaque script shell avec un timeout de 60 secondes.
  6. Loop : Créez une boucle qui réessaye une commande 3 fois, avec un timeout de 10 secondes par tentative.
  7. Monitoring : Créez un script de monitoring qui vérifie si un serveur est joignable dans les 5 secondes.
  8. Défi : Combinez timeout avec xargs pour tester la connectivité vers plusieurs serveurs avec un timeout de 3 secondes chacun.

Conclusion

timeout est un outil simple mais puissant qui peut vous sauver de nombreuses situations embarrassantes. Que ce soit pour éviter qu'un script ne bloque votre système, pour tester des services avec un délai maximal, ou pour gérer des tâches cron qui ne doivent pas dépasser un certain temps, timeout est votre allié. Pensez à l'utiliser régulièrement dans vos scripts et vos automatisations — c'est une bonne pratique qui évite bien des problèmes. Comme toujours sous Linux, combinez-le avec d'autres outils comme find, xargs ou vos scripts shell pour des solutions élégantes et robustes.
