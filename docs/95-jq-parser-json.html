Leçon 95 — jq — Parser et manipuler du JSON en ligne de commande

Qu'est-ce que jq ?

jq est un processeur léger et flexible pour JSON en ligne de commande. Il permet de lire, filtrer, transformer et formater des données JSON directement dans le terminal, sans avoir besoin d'écrire un script dans un langage de programmation.

JSON est omniprésent : APIs web, fichiers de configuration, logs structurés, output d'outils modernes. jq est devenu un outil indispensable pour tout administrateur ou développeur qui travaille avec ces données.

Installation

# Ubuntu / Debian
sudo apt install jq
# Fedora / RHEL / CentOS
sudo dnf install jq
# Arch Linux
sudo pacman -S jq

Vérifiez l'installation :

jq --version

Syntaxe de base

# Lire JSON depuis un fichier
jq '.clé' fichier.json
# Lire depuis un pipe (très courant)
curl -s https://api.exemple.com/data | jq '.'
# jq sans filtre affiche le JSON formaté
cat donnees.json | jq

Le filtre identity : .

Le point . désigne le filtre identity qui retourne le document entier. Utilisé seul, il affiche le JSON joliment formaté.

echo '{"nom": "Alice", "age": 30}' | jq .

Résultat :

{ code>
"nom": "Alice",
"age": 30
}

Accéder aux propriétés d'un objet

Utilisez la notation pointée pour accéder aux clés d'un objet.

# Données de test
echo '{"nom": "Bob", "email": "bob@exemple.com", "role": "admin"}' | jq '.nom'

Résultat :

"Bob"

Accéder à des propriétés imbriquées

echo '{"user": {"name": "Alice", "adress": {"city": "Genève"}}}}' | jq '.user.adress.city'

Résultat :

"Genève"

Accéder aux éléments d'un tableau

Les tableaux (arrays) s'indiquent avec []. Chaque élément est accessible par son index (0-based).

echo '["pomme", "banane", "cerise"]' | jq '.[0]'

Résultat :

"pomme"

Accéder à tous les éléments d'un tableau

echo '[1, 2, 3, 4, 5]' | jq '.[]'

Résultat :

1
2
3
4
5

Tranche de tableau

echo '[1, 2, 3, 4, 5]' | jq '.[1:3]'

Résultat : [2, 3] (éléments de l'index 1 à 3 exclus)

Exemples concrets avec des données réelles

1. Parser la sortie d'une API

# Requêter une API et extraire un champ
curl -s https://api.github.com/users/octocat | jq '.name'
# Extraire plusieurs champs
curl -s https://api.github.com/users/octocat | jq '{nom: .name, login: .login, followers: .followers}'

2. Travailler avec un fichier JSON

# fichier.json contient :
# {
# "employes": [
# {"nom": "Alice", "dept": "IT", "salaire": 75000},
# {"nom": "Bob", "dept": "RH", "salaire": 65000}
# ]
# }
# Extraire tous les noms
jq '.employes[].nom' fichier.json

3. Filtrer avec select

select permet de filtrer les éléments selon une condition.

echo '{"employes": [{"nom": "Alice", "dept": "IT"}, {"nom": "Bob", "dept": "RH"}, {"nom": "Claire", "dept": "IT"}]}' | jq '.employes[] | select(.dept == "IT")'

Résultat : les objets des employés du département IT.

4. Compter et agréger

# Compter le nombre d'éléments
echo '{"employes": [1, 2, 3]}' | jq '.employes | length'
# Compter les clés d'un objet
echo '{"a": 1, "b": 2}' | jq 'length'
# Additionner des valeurs
echo '[10, 20, 30]' | jq 'add'
# Trouver le minimum / maximum
echo '[3, 1, 4, 1, 5]' | jq 'min'
echo '[3, 1, 4, 1, 5]' | jq 'max'

Exemples pratiques

Transformer des données

# Ajouter une clé dérivée
echo '{"nom": "Alice", "age": 30}' | jq '. + {"majeur": (.age >= 18)}'
# Renommer une clé
echo '{"name": "Bob"}' | jq '{(.name | @text): "Bob"}'
# Convertir en CSV (simplifié)
echo '[{"nom": "Alice", "age": 30}, {"nom": "Bob", "age": 25}]' | jq -r '.[] | [.nom, .age] | @csv'

Travailler avec des tableaux

# Garder seulement les éléments qui satisfont une condition
echo '[1, 2, 3, 4, 5, 6]' | jq 'map(select(. >= 3))'
# Appliquer une transformation à chaque élément
echo '[1, 2, 3]' | jq 'map(. * 2)'
# Extraire une propriété de chaque élément
echo '[{"nom": "Alice"}, {"nom": "Bob"}]' | jq 'map(.nom)'

Travailler avec des chaînes

# Concaténer
echo '"Hello"' | jq '. + " World"'
# Mise en forme
echo '"hello"' | jq 'upcase'
# Interpolation (équivalent f-string)
echo '{"name": "Alice"}' | jq '"Bonjour \(.name) !"'

Options utiles

OptionRôle
-rRaw output : enlève les guillemets autour des chaînes
-cCompact : output sur une seule ligne (pas de formatage)
-nNull input : ne lit pas d'entrée, utile pour tester des expressions
-f fichierLire le filtre depuis un fichier
--arg k vPasser une variable shell comme chaîne
--argjson k vPasser une variable shell comme valeur JSON

Exemple avec --arg

# Utiliser une variable shell dans jq
FILTRE="admin"
cat users.json | jq --arg role "$FILTRE" '.users[] | select(.role == $role)'

Combiner jq avec d'autres outils

Avec curl et une API réelle

# Récupérer la liste des conteneurs Docker au format JSON
curl -s http://localhost:2375/containers/json | jq '.[].Names'
# Analyser des logs systemd au format JSON
journalctl -o json | jq '.PRIORITY, .MESSAGE' | head -20

Avec des fichiers de config

# Vérifier une clé dans un config.json
jq '.database.host' /etc/monapp/config.json
# Lister toutes les clés de premier niveau
jq 'keys' /etc/monapp/config.json

Avec grep et awk

# Filtrer puis extraire un champ précis
cat logs.json | jq -c '.[] | select(.niveau == "ERREUR")' | jq '.timestamp'
# Compter les occurrences
cat events.json | jq '.type' | sort | uniq -c

Mode interactif avec -n

Le mode -n (null input) permet de créer des données ou tester des expressions sans fichier d'entrée.

# Créer un objet
jq -n '{nom: "Test", valeur: 42}'
# Générer une séquence
jq -n 'range(5)'
# Calculer
jq -n '10 + 5'

Bonnes pratiques

  • Toujours utiliser -s (slurp) si vous recevez un JSON par ligne et voulez le traiter comme un tableau : curl -s api | jq -s '.'
  • Préférer -r pour extraire des valeurs brutes quand le résultat est une chaîne ou un nombre simple
  • Vérifier le type avec jq 'type' pour调试 les erreurs de filtre
  • Utiliser des fichiers de filtre (-f) pour les filtres complexes réutilisables
  • Combiner avec 2>/dev/null pour supprimer les messages d'erreur de jq

Exemple complet : pipeline de traitement d'API

#!/bin/bash
# Récupérer les 10 derniers commits d'un dépôt GitHub
REPO="$1"
curl -s "https://api.github.com/repos/$REPO/commits?per_page=10" | \
jq -r '.[] | "\(.commit.author.date | .[0:10]) - \(.commit.author.name) : \(.commit.message | split("\n")[0])"'

jq est l'outil de référence pour manipuler du JSON en ligne de commande. Que ce soit pour analyser des APIs, inspecter des fichiers de configuration au format JSON, ou traiter des logs structurés, il remplace avantageusement des combinations de grep, awk et sed pour tout ce qui touche au JSON.
