cmp — Comparaison binaire de fichiers octet par octet

La commande cmp est l'outil de comparaison de fichiers le plus fondamental sous Linux. Là où diff analyse le contenu textuel, cmp compare les fichiers octet par octet — sans se soucier du format. C'est l'outil idéal pour vérifier si deux fichiers sont strictement identiques, ou pour localiser la première différence entre deux fichiers binaires.

Syntaxe de base

cmp [OPTIONS] fichier1 fichier2

Options principales

OptionDescription
-cAffiche les octets qui diffèrent, en format texte (imprime le caractère)
-lAffiche tous les numéros d'octets et leurs valeurs qui diffèrent
-i NIgnore les N premiers octets de chaque fichier
-i N:MIgnore N octets dans fichier1 et M octets dans fichier2
-n NNe compare que les N premiers octets
-sMode silencieux : aucun affichage, code de retour seulement

Codes de retour

CodeSignification
0Les fichiers sont identiques
1Les fichiers diffèrent
2Erreur (fichier introuvable, permission refusée…)

Exemples concrets

Vérifier si deux fichiers sont identiques

cmp fichier1.txt fichier2.txt

Si les fichiers sont identiques, cmp ne renvoie rien (sortie silencieuse). Si des différences existent, la première est affichée :

fichier1.txt fichier2.txt differ: byte 10, line 1

Mode silencieux avec code de retour

Utile dans les scripts pour tester l'égalité de fichiers :

if cmp -s fichier1.txt fichier2.txt; then echo "Les fichiers sont identiques" else echo "Les fichiers diffèrent" fi

Lister toutes les différences avec -l

cmp -l fichier1.bin fichier2.bin

Chaque ligne affiche : numéro d'octet, valeur octale dans fichier1, valeur octale dans fichier2.

10 101 141 11 102 142 12 103 143

Ignorer les premiers octets

Pratique pour comparer des fichiers qui partagent un en-tête commun :

# Ignore les 64 premiers octets (en-tête) et compare le reste cmp -i 64 fichier1.bin fichier2.bin

Comparer seulement les N premiers octets

# Compare uniquement les 128 premiers octets cmp -n 128 fichier1.bin fichier2.bin

Voir le caractère qui diffère avec -c

cmp -c image1.png image2.png

Résultat possible :

image1.png image2.png differ: byte 25, file1 is 137 octal, file2 is 136 octal

Comparaison avec d'autres outils

Cas d'usage courants

Vérifier l'intégrité après une copie

# Comparer le fichier original et sa copie cmp -s document.pdf /mnt/backup/document.pdf && echo "Copie OK"

Détecter une corruption de fichier

cmp -l fichier.zip fichier.zip.corrompu | head -20

Comparer deux images ou fichiers binaires

cmp image1.png image2.png && echo "Images identiques" || echo "Images différentes"

Combiner avec find pour comparer un lot de fichiers

# Trouver les fichiers qui different entre deux repertoires diff -rq dir1 dir2 | while read line; do file1=$(echo "$line" | sed 's/Files \(.*\) and.*/\1/') file2=$(echo "$line" | sed 's/.*and \(.*\) differ/\1/') if [ -f "$file1" ] && [ -f "$file2" ]; then cmp -s "$file1" "$file2" || echo "Différent: $file1" fi done

Bonnes pratiques

  • Utilisez cmp -s dans les scripts pour un comportement prévisible (pas de sortie, juste un code de retour).
  • Pour les gros fichiers binaires, cmp est plus rapide que diff car il s'arrête à la première différence.
  • Combinez avec md5sum pour un contrôle d'intégrité rapide, puis cmp pour localiser la différence exacte.
  • L'option -i est très utile pour comparer des fichiers qui partagent un header (archives, images, exécutables).

Exercice pratique

  1. Créez deux fichiers texte et introduisez une petite différence dans le second :
echo "Bonjour le monde" > f1.txt echo "Bonjour la monde" > f2.txt
  1. Comparez-les avec cmp :
cmp f1.txt f2.txt
  1. Vérifiez avec l'option -c pour voir le caractère qui diffère :
cmp -c f1.txt f2.txt
  1. Vérifiez le code de retour :
cmp -s f1.txt f2.txt; echo $?

Le code 1 confirme que les fichiers diffèrent.

  1. Créez une copie identique et vérifiez que cmp ne trouve aucune différence :
cp f1.txt f3.txt cmp -s f1.txt f3.txt && echo "Fichiers identiques"

Résumé

cmp est l'outil de comparaison binaire le plus simple et le plus efficace. Il compare deux fichiers octet par octet et s'arrête à la première différence trouvée. C'est l'outil de choix pour vérifier rapidement si deux fichiers sont strictement identiques, sans se préoccuper du format ou du contenu textuel.
