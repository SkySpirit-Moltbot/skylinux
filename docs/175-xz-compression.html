xz — Compression moderne et performante

Introduction

xz est un outil de compression de fichiers qui utilise l'algorithme LZMA2. Il offre un excellent taux de compression, souvent supérieur à gzip et bzip2, tout en restant rapide et efficace en mémoire.

Les fichiers compressés avec xz portent l'extension .xz. C'est le format par défaut utilisé par de nombreuses distributions Linux pour leurs paquets et archives.

Syntaxe de base

xz [OPTIONS] [FICHIER...]

Sans option, xz compresse le fichier et le remplace par sa version compressée.

Options principales

OptionDescriptionExemple
-zCompresser (par défaut)xz -z fichier
-dDécompresser (équivalent à unxz)xz -d fichier.xz
-kGarder le fichier originalxz -k fichier
-fForcer l'écrasement du fichier de sortiexz -f fichier
-cÉcrire sur la sortie standardxz -c fichier > out.xz
-0 à -9Niveau de compression (0=rapide, 9=meilleur)xz -9 fichier
-eMode extrême (compression encore meilleure)xz -e -9 fichier
-T NNombre de threads (parallélisation)xz -T 4 fichier
-lLister les informations d'un fichier compresséxz -l fichier.xz

Exemples fondamentaux

1. Compresser un fichier

Compresser un fichier (le fichier original est remplacé) :

xz document.txt

Résultat : document.txt.xz

2. Décompresser un fichier

Restaurer le fichier original :

xz -d document.txt.xz

Ou simplement :

unxz document.txt.xz

3. Garder le fichier original

Avec l'option -k, le fichier source est conservé :

xz -k fichier_volumineux.log

4. Compression vers stdout

Envoyer le résultat compressé ailleurs sans modifier l'original :

xz -c fichier.txt > backup.xz

5. Décompression vers stdout

Afficher le contenu décompressé sans créer de fichier :

xz -d -c fichier.xz

Niveaux de compression

xz propose 10 niveaux de compression, de -0 (le plus rapide) à -9 (le plus compact). Le niveau par défaut est -6.

NiveauDescriptionUsage mémoire
-0Très rapide, compression faible~1 MB
-1Rapide~2 MB
-2~5 MB
-3~14 MB
-4~32 MB
-5~64 MB
-6Par défaut~64 MB
-7~256 MB
-8~512 MB
-9Meilleure compression~1 GB

Compression rapide

xz -0 fichier.log

Meilleure compression possible

xz -9e fichier.log

L'option -e (extreme) combine -9 avec des options supplémentaires pour un taux de compression encore meilleur, au prix d'un temps de traitement plus long.

Comparaison des niveaux

Exemple pour comparer les tailles obtenues :

ls -lh fichier
xz -0 fichier && ls -lh fichier.xz
xz -6 fichier && ls -lh fichier.xz
xz -9 fichier && ls -lh fichier.xz

Parallélisation avec -T

xz peut utiliser plusieurs cœurs de processeur pour accélérer la compression :

xz -T 4 gros_fichier.iso

Pour utiliser tous les cœurs disponibles automatiquement :

xz -T 0 gros_fichier.iso

Utiliser xz avec tar

La combinaison classique pour créer une archive compressée :

Créer une archive compressée

tar -cJf archive.tar.xz repertoire/

L'option J (avec tar) indique d'utiliser xz pour la compression.

Lister le contenu sans extraire

tar -tJf archive.tar.xz

Extraire une archive compressée

tar -xJf archive.tar.xz

Extraire vers un répertoire spécifique

tar -xJf archive.tar.xz -C /home/user/restaurer/

Variantes et outils associés

CommandeDescription
xzCompresseur principal

lzmaFormat LZMA classique (ancien)
xzcatDécompresser vers stdout (comme zcat)
xzcmpComparer deux fichiers xz compressés

xzcat — Lire sans décompresser

xzcat archive.tar.xz | tar -tf -

xzgrep — Rechercher dans un fichier compressé

xzgrep "erreur" journal.xz

Informations sur un fichier compressé

L'option -l affiche les détails d'un fichier .xz :

xz -l fichier.xz

Exemple de sortie :

Strms Blocks Compressed Uncompressed Ratio Check 1 1 1 234 567 B 10 000 000 B 0.124 CRC64

Décompression automatique

Si vous essayez de décompresser un fichier qui n'est pas au format xz, xz le détecte et ne fait rien (ou signale une erreur selon les options).

xz -d fichier_incorrect.xyz 2> /dev/null || echo "Format non supporté"

Script : compression avec choix du niveau

Voici un script utile pour compresser avec différents niveaux :

#!/bin/bash # Compresser un fichier avec choix du niveau FICHIER="$1" NIVEAU="${2:-6}" if [ -z "$FICHIER" ]; then echo "Usage: $0 [niveau 0-9]" exit 1 fi echo "Compression de $FICHIER au niveau $NIVEAU..." xz -"$NIVEAU" -k "$FICHIER" echo "Terminé !" ls -lh "${FICHIER}.xz"

xz vs gzip vs bzip2 vs zstd

FormatExtensionCompressionVitesseUsage
gzip.gzBonneTrès rapideUsage quotidien
bzip2.bz2Très bonneMoyenneFichiers texte
xz.xzExcellenteLenteArchives, paquets
zstd.zstTrès bonneTrès rapideSauvegardes

xz est particulièrement recommandé pour :

  • Les archives destinées à être distribuées (taille minimale)
  • Les paquets des distributions Linux
  • Les sauvegardes où l'espace de stockage compte
  • Les fichiers qui ne sont pas souvent décompressés

Bonnes pratiques

1. Compression normale (par défaut)

xz fichier.log

2. Compression maximale avec parallélisation

xz -9e -T 0 gros_fichier.iso

3. Compression rapide pour du temporaire

xz -0 -k fichier_temporaire.log

4. Archive complète avec tar

tar -cJf sauvegarde_$(date +%Y%m%d).tar.xz /home/user/documents/

5. Décompression et extraction simultanées

xz -d -c archive.tar.xz | tar -xf - -C /destination/

xz est un outil puissant qui offre d'excellents taux de compression pour les fichiers qui doivent être stockés ou distribués de manière efficace. Combinez-le avec tar pour créer des archives compressées modernes et compactes.
