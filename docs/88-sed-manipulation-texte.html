Leçon 88 : sed — Transformer du texte à la volée

Introduction

sed (Stream Editor) est un éditeur de texte non interactif qui permet de transformer du texte automatiquement. Il lit ligne par ligne, applique des transformations, et affiche le résultat. C'est l'outil idéal pour remplacer du texte dans des fichiers sans ouvrir d'éditeur.

Syntaxe de base

La syntaxe fondamentale de sed est simple :

sed 's/ancien/nouveau/' fichier

Cette commande remplace la première occurrence de "ancien" par "nouveau" sur chaque ligne.

Remplacer du texte

Remplacement simple

# Remplacer "foo" par "bar" dans un fichier sed 's/foo/bar/' fichier.txt
# Afficher le résultat sans modifier le fichier original sed 's/foo/bar/' fichier.txt

Par défaut, sed affiche le résultat à l'écran. Le fichier original n'est pas modifié.

Remplacer toutes les occurrences

Pour remplacer toutes les occurrences d'une chaîne sur chaque ligne (pas seulement la première), utilisez le flag g (global) :

# Remplace TOUTES les occurrences de "foo" par "bar" sed 's/foo/bar/g' fichier.txt

Remplacer uniquement la N-ième occurrence

# Remplace seulement la 2ème occurrence de chaque ligne sed 's/foo/bar/2' fichier.txt

Modifier le fichier directement

Pour enregistrer les modifications dans le fichier lui-même, utilisez l'option -i (in-place) :

# ATTENTION : modifie le fichier directement sed -i 's/ancien/nouveau/g' fichier.txt

Pour créer une sauvegarde avant modification, utilisez -i.bak :

# Crée fichier.txt.bak avant modification sed -i.bak 's/ancien/nouveau/g' fichier.txt

Adresses et plage de lignes

sed permet de n'appliquer une commande que sur certaines lignes :

Une ligne spécifique

# Remplace seulement sur la ligne 5 sed '5s/foo/bar/' fichier.txt

Plage de lignes

# Remplace de la ligne 10 à 20 sed '10,20s/foo/bar/' fichier.txt

Première et dernière ligne

# Première ligne seulement sed '1s/foo/bar/' fichier.txt # Dernière ligne seulement sed '$s/foo/bar/' fichier.txt

Modèles de lignes

# Lignes contenant "erreur" sed '/erreur/s/foo/bar/' fichier.txt

Supprimer des lignes

L'instruction d permet de supprimer des lignes :

# Supprimer la ligne 5 sed '5d' fichier.txt # Supprimer les lignes 10 à 20 sed '10,20d' fichier.txt # Supprimer les lignes vides sed '/^$/d' fichier.txt # Supprimer les lignes contenant "test" sed '/test/d' fichier.txt

Regex : expressions régulières

sed supporte les expressions régulières pour des remplacements puissants :

Caractères spéciaux

RegexSignification
.N'importe quel caractère
^Début de ligne
$Fin de ligne
[abc]Un caractère parmi a, b ou c
[0-9]Un chiffre
*Zéro ou plusieurs occurrences
\+Une ou plusieurs occurrences

Exemples avec regex

# Remplace les espaces multiples par un seul espace sed 's/ */ /g' fichier.txt # Supprime les espaces en fin de ligne sed 's/ *$//' fichier.txt # Ajoute "http://" au début des lignes sans protocole sed 's/^www\./http:\/\/www./' fichier.txt

Groupes de capture

Les parenthèses capturent du texte pour le réutiliser :

# Capture et réutilise (syntaxe GNU sed) sed -E 's/(foo)/\1-bar/' fichier.txt # Inverse deux mots séparés par un tiret echo "Jean-Pierre" | sed -E 's/([A-Za-z]+)-([A-Za-z]+)/\2-\1/'

Note : L'option -E active les regex étendues sur la plupart des systèmes.

Commandes multiples

Vous pouvez enchaîner plusieurs commandes avec -e :

# Enchaîne plusieurs substitutions sed -e 's/foo/bar/' -e 's/hello/world/' fichier.txt

Ou utiliser le point-virgule :

sed 's/foo/bar/; s/hello/world/' fichier.txt

Insertion et ajout

CommandeAction
i\Insérer avant la ligne
a\Ajouter après la ligne
c\Remplacer la ligne
# Insère "HEADER" avant la ligne 3 sed '3i\HEADER' fichier.txt # Ajoute "FOOTER" après chaque ligne contenant "END" sed '/END/a\FOOTER' fichier.txt

Exemples pratiques

Modifier des configurations

# Change le port dans un fichier de config sed -i 's/Port 22/Port 2222/' /etc/ssh/sshd_config # Active une ligne (décommente) sed -i 's/#ListenAddress/ListenAddress/' fichier.conf # Désactive une ligne (commente) sed -i 's/ListenAddress/#ListenAddress/' fichier.conf

Nettoyer du texte

# Supprime les lignes de commentaires sed '/^#/d' fichier.conf # Supprime les lignes vides sed '/^$/d' fichier.txt # Supprime les retours chariot Windows (^M) sed -i 's/\r$//' fichier.txt

Rename massif de fichiers

# Renomme tous les .txt en .md (via ls et sed) for f in *.txt; do mv "$f" "$(echo $f | sed 's/.txt$/.md/')" done

sed vs autres outils

OutilUsage
sedRemplacement de texte, substitutions simples
awkManipulation structurée, calcul, formatage
trTraduire/remplacer des caractères individuels

Bonnes pratiques

  • Testez toujours avec l'affichage standard avant d'utiliser -i
  • Utilisez -i.bak pour garder des sauvegardes
  • Annoncez les regex complexes avec -E (regex étendues)
  • Combinez avec grep pour traiter des lignes spécifiques

Exercice

Créez un fichier liste.txt avec plusieurs lignes contenant des adresses email. Utilisez sed pour :

  1. Remplacer "@domaine.com" par "@nouveau-domaine.com"
  2. Afficher seulement les lignes contenant "admin"
  3. Sauvegarder le résultat dans un nouveau fichier

Résumé

CommandeDescription
sed 's/a/b/'Remplace la première occurrence de a par b
sed 's/a/b/g'Remplace toutes les occurrences
sed -i 's/a/b/'Modifie le fichier directement
sed '5s/a/b/'Remplace seulement sur la ligne 5
sed '/mot/d'Supprime les lignes contenant "mot"
sed -E 's/(a)/\1/'Capture et réutilise

sed est un outil puissant pour automatiser les transformations de texte. Combiné avec des pipes, il devient un élément essentiel de votre boîte à outils Linux.
