date et strftime — Afficher et formater la date et l'heure

La commande date est un outil essentiel sous Linux. Elle permet d'afficher la date et l'heure actuelles, mais aussi de formater la sortie selon vos besoins, de calculer des dates, et d'utiliser le temps dans vos scripts Bash.

Afficher la date et l'heure actuelles

Sans option, date affiche la date et l'heure dans le format par défaut du système :

date

Résultat classique :

Thu Aug 13 08:00:00 UTC 2026

Formatage avec strftime

Le formatage se fait avec l'option +format. Le format est une chaîne contenant des séquences spéciales commençant par %.

Les séquences de format les plus utiles

SéquenceSignificationExemple
%YAnnée sur 4 chiffres2026
%mMois sur 2 chiffres08
%dJour du mois sur 2 chiffres13
%HHeure (00-23)08
%MMinutes (00-59)00
%SSecondes (00-59)00
%ANom complet du jourThursday
%aNom abrégé du jourThu
%BNom complet du moisAugust
%bNom abrégé du moisAug
%jJour de l'année (001-366)225
%uJour de la semaine (1=lundi, 7=dimanche)4
%VNuméro de semaine ISO33
%ZFuseau horaireUTC
%%Caractère pourcentage littéral%

Exemples concrets de formatage

# Format ISO classique date "+%Y-%m-%d" # → 2026-08-13
# Format français date "+%d/%m/%Y" # → 13/08/2026
# Date et heure complète date "+%A %d %B %Y à %H:%M:%S" # → Thursday 13 August 2026 à 08:00:00
# Horodatage (timestamp Unix) date "+%s" # → 1752480000
# Format compact pour les noms de fichiers date "+%Y%m%d_%H%M%S" # → 20260813_080000

Calculer des dates

Vous pouvez ajouter ou soustraire du temps avec l'option -d (ou --date).

# Demain date -d "tomorrow" "+%Y-%m-%d"
# Hier date -d "yesterday" "+%Y-%m-%d"
# Dans une semaine date -d "next week" "+%Y-%m-%d"
# Dans 3 mois date -d "3 months" "+%Y-%m-%d"
# Il y a 10 jours date -d "10 days ago" "+%Y-%m-%d"
# Date précise date -d "2026-12-25" "+%A" # → Friday

Utiliser date dans des scripts

Créer des noms de fichiers horodatés

#!/bin/bash # Sauvegarde avec horodatage sauvegarde="backup_$(date +%Y%m%d_%H%M%S).tar.gz" tar -czf "$sauvegarde" /home/user/documents echo "Sauvegarde créée : $sauvegarde"

Calculer le temps d'exécution d'un script

#!/bin/bash debut=$(date +%s) # Votre commande ici sleep 2 fin=$(date +%s) duree=$((fin - debut)) echo "Temps d'exécution : ${duree} secondes"

Log avec horodatage

#!/bin/bash log() { echo "[$(date +'%Y-%m-%d %H:%M:%S')] $*" >> /var/log/mon_script.log } log "Le service a démarré" log "Traitement terminé"

Afficher un timestamp lisible

Pour convertir un timestamp Unix en date lisible :

# Convertir un timestamp date -d @1752480000 # → Thu Aug 13 08:00:00 UTC 2026
# Avec formatage date -d @1752480000 "+%d/%m/%Y à %H:%M"

Définir la date et l'heure (root)

Pour modifier la date système (nécessite root) :

# Syntaxe : date MMDDhhmm[[CC]YY][.ss] # MM = mois, DD = jour, hh = heure, mm = minute # Exemple : 13 août 2026, 10h30 sudo date 081310302026

Attention : modifiez l'heure système uniquement sur un serveur ou machine locale, jamais à distance sans précaution.

Format UTC et fuseaux horaires

# Afficher en UTC date -u # Afficher pour un fuseau horaire spécifique TZ="America/New_York" date "+%H:%M"
