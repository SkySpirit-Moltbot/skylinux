Leçon 71 : find — Recherche avancée de fichiers

Introduction

La commande find est l'un des outils les plus puissants sous Linux pour rechercher des fichiers et des répertoires. Contrairement à locate qui utilise une base de données préconstruite, find effectue une recherche en temps réel dans le système de fichiers. Il permet de chercher des fichiers selon de nombreux critères : nom, type, taille, date de modification, permissions, etc.

Syntaxe de base

La syntaxe générale de find est :

find [chemin] [expression]
  • chemin : le répertoire de départ de la recherche (par défaut : répertoire courant)
  • expression : les critères de recherche et actions à effectuer

Recherche par nom

Recherche simple

Pour trouver tous les fichiers nommés " rapport.txt " dans le répertoire courant :

find . -name "rapport.txt"

Recherche avec joker

Pour trouver tous les fichiers se terminant par ".log" dans /var/log :

find /var/log -name "*.log"

Pour trouver tous les fichiers contenant "config" dans leur nom :

find /home -name "*config*"

Insensible à la casse

Utilisez -iname au lieu de -name pour une recherche insensible à la casse :

find . -iname "*.jpg"

Recherche par type

Vous pouvez rechercher selon le type de fichier :

OptionDescription
-type fFichiers réguliers
-type dRépertoires
-type lLiens symboliques
-type pTubes nommés (FIFO)
-type sSockets
# Trouver tous les répertoires nommés "backup" find /home -type d -name "*backup*" # Trouver tous les liens symboliques find /usr -type l

Recherche par taille

La recherche par taille utilise l'option -size :

SuffixeSignification
cOctets
kKilooctets
MMégaoctets
GGigaoctets
# Trouver les fichiers de plus de 100 Mo find /home -size +100M # Trouver les fichiers de moins de 1 Ko find . -size -1k # Trouver les fichiers entre 1 Mo et 10 Mo find . -size +1M -size -10M

Recherche par date

Modifié récemment

# Fichiers modifiés il y a moins de 7 jours find . -mtime -7 # Fichiers modifiés il y a exactement 3 jours find . -mtime 3 # Fichiers modifiés il y a plus de 30 jours find . -mtime +30

Accessed récemment

# Fichiers accédés il y a moins de 24h find . -atime -1 # Fichiers modifiés il y a moins de 1 heure find . -mmin -60

Recherche par permissions

# Fichiers accessibles par tous (777) find . -perm 777 # Fichiers writable par tous find . -perm -002 # Fichiers suid find /usr -perm /4000 2>/dev/null

Recherche par propriétaire

# Fichiers appartenant à l'utilisateur "david" find /home -user david # Fichiers belonging au groupe "www-data" find /var -group www-data

Combiner les critères

Vous pouvez combiner plusieurs critères avec les opérateurs logiques :

OpérateurDescription
-and ou -aLes deux conditions doivent être vraies
-or ou -oAu moins une condition doit être vraie
-not ou !Négation de la condition
# Fichiers .log de plus de 10 Mo modifiés il y a moins de 7 jours find /var/log -name "*.log" -size +10M -mtime -7 # Fichiers .conf OU .ini find /etc -name "*.conf" -o -name "*.ini" # Fichiers qui ne sont PAS des .log find /var -name "*.log" -not -name "*.gz"

Actions sur les résultats

Afficher les détails avec -ls

find . -name "*.txt" -ls

Exécuter une commande avec -exec

L'option -exec permet d'exécuter une commande sur chaque résultat trouvé. Le {} représente le fichier courant et \; termine la commande :

# Supprimer les fichiers .tmp de plus de 30 jours find /tmp -name "*.tmp" -mtime +30 -exec rm {} \; # Afficher les permissions de tous les fichiers .conf find /etc -name "*.conf" -exec ls -l {} \; # Compter les lignes de tous les .log find /var/log -name "*.log" -exec wc -l {} +

Confirmation avec -ok

L'option -ok fonctionne comme -exec mais demande une confirmation avant chaque exécution :

find . -name "*.bak" -ok rm {} \;

Supprimer avec -delete

# Supprimer directement les fichiers correspondants find /tmp -name "*.tmp" -type f -delete

Limiter la profondeur

# Explorer uniquement 2 niveaux de profondeur find . -maxdepth 2 -name "*.txt" # Commencer la recherche 2 niveaux plus bas find . -mindepth 3 -type d

Exemples pratiques complets

Nettoyer les fichiers temporaires

# Trouver et supprimer les fichiers de plus de 100 Mo non accédés depuis 90 jours find /tmp -type f -size +100M -atime +90 -exec rm {} \;

Trouver les fichiers en double

# Trouver les fichiers en double par nom (nécessite sort) find /home -type f -name "*.jpg" | sort | uniq -d

Archiver d'anciens fichiers

# Créer une archive des fichiers non accédés depuis 6 mois find /home -type f -atime +180 | xargs tar -czf backup_old.tar.gz

Sauvegarde de configuration

# Lister tous les fichiers de configuration modifiés récemment find /etc -name "*.conf" -mtime -7 -ls

Astuce : Pour accélérer les recherches sur de grands systèmes de fichiers, limitez la profondeur avec -maxdepth et spécifiez le chemin le plus précis possible. Combinez avec xargs pour traiter les résultats efficacement.

Résumé des options principales

OptionDescription
-nameRecherche par nom de fichier
-inameRecherche insensible à la casse
-typeRecherche par type (f, d, l...)
-sizeRecherche par taille
-mtimeRecherche par date de modification
-atimeRecherche par date d'accès
-mminRecherche par minutes de modification
-userRecherche par propriétaire
-groupRecherche par groupe
-permRecherche par permissions
-maxdepthLimite la profondeur de recherche
-mindepthIgnore les premiers niveaux
-execExécute une commande sur les résultats
-okExécute avec confirmation
-lsAffiche les détails
-deleteSupprime les fichiers trouvés

Conclusion

find est un outil extrêment puissant et versatile. Il permet de localiser n'importe quel fichier selon une grande variété de critères. Combiné avec -exec ou xargs, il devient un outil d'automatisation indispensable pour l'administration système. Prenez le temps de pratiquer ces différentes options pour maîtriser cette commande essentielle.
