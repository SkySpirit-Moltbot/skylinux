Leçon 90 - comm — Comparer deux fichiers ligne par ligne

La commande comm permet de comparer deux fichiers texte ligne par ligne. Elle affiche le résultat en trois colonnes : les lignes présentes uniquement dans le premier fichier, celles présentes uniquement dans le second, et celles communes aux deux. C'est un outil précis et puissant pour analyser les différences entre fichiers.

Principe de fonctionnement

Contrairement à diff qui montre les modifications à effectuer pour rendre les fichiers identiques, comm effectue une comparaison triée ligne par ligne et organise le résultat en trois colonnes clairement séparées par des tabulations.

Pour que comm fonctionne correctement, les deux fichiers doivent être triés au préalable. Si ce n'est pas le cas, vous pouvez utiliser l'option --check-order pour le détecter ou --nocheck-order pour ignorer ce requisito.

Syntaxe de base

comm [OPTIONS] FICHIER1 FICHIER2

Les trois colonnes de sortie

  • Colonne 1 : lignes présentes uniquement dans FICHIER1
  • Colonne 2 : lignes présentes uniquement dans FICHIER2
  • Colonne 3 : lignes communes aux deux fichiers

Options principales

OptionDescription
-1Supprimer la colonne 1 (uniquement fichier 1)
-2Supprimer la colonne 2 (uniquement fichier 2)
-3Supprimer la colonne 3 (lignes communes)
--check-orderVérifier que les fichiers sont triés
--nocheck-orderNe pas vérifier l'ordre de tri
--output-delimiter=STRUtiliser STR comme séparateur de colonnes
-z / --zero-terminatedUtiliser le caractère nul comme délimiteur de ligne

Exemples concrets

1. Comparaison basique

Créons deux fichiers pour illustrer le fonctionnement :

echo -e "banane\npomme\nraisin" > fruits1.txt
echo -e "banane\nfraise\npomme" > fruits2.txt
comm fruits1.txt fruits2.txt
# Sortie :
# (colonne 1) (colonne 2) (colonne 3)
banane
fraise
pomme pomme
raisin

Ici, banane et pomme sont communes aux deux fichiers (colonne 3), raisin n'existe que dans fruits1.txt (colonne 1) et fraise n'existe que dans fruits2.txt (colonne 2).

2. Afficher uniquement les lignes communes

Pour ne voir que ce qui est partagé entre les deux fichiers, supprimez les colonnes 1 et 2 :

comm -12 fruits1.txt fruits2.txt
# Sortie :
# banane
# pomme

3. Trouver les différences uniquement

Pour visualiser ce qui diffère entre les deux fichiers (lignes uniques à chacun), supprimez la colonne 3 :

comm -3 fruits1.txt fruits2.txt
# Sortie :
# raisin
# fraise

4. Comparer des fichiers déjà triés

Si vos fichiers sont déjà triés alphabétiquement, comm fonctionne directement :

comm fichier_trié1.txt fichier_trié2.txt

5. Comparer des fichiers non triés avec sort

Si vos fichiers ne sont pas triés, vous pouvez les trier à la volée avec un processus de substitution :

comm <(sort fichier1.txt) <(sort fichier2.txt)

Cas d'utilisation pratiques

Comparer deux sorties de commande

Vous pouvez comparer directement la sortie de deux commandes grâce aux processus de substitution :

comm <(ls /bin | sort) <(ls /usr/bin | sort)

Cela affiche les programmes présents uniquement dans /bin, ceux uniquement dans /usr/bin, et ceux présents dans les deux répertoires.

Trouver des utilisateurs uniques dans deux groupes

En combinant avec getent pour lister les utilisateurs de différents groupes :

comm -23 <(getent group sudo | cut -d: -f4 | tr ',' '\n' | sort) \
<(getent group admin | cut -d: -f4 | tr ',' '\n' | sort)

Cette commande affiche les utilisateurs présents uniquement dans le groupe sudo mais pas dans le groupe admin.

Analyser un fichier de configuration modifié

Pour voir exactement ce qui a changé entre deux versions d'un fichier de configuration :

comm -3 <(sort config.old) <(sort config.new)

Affiche chaque ligne qui diffère entre les deux versions, facilitant l'identification des modifications.

Format de sortie et séparateurs

Par défaut, comm utilise des tabulations pour séparer les colonnes. Vous pouvez personnaliser le séparateur avec l'option --output-delimiter :

comm --output-delimiter=" | " fichier1.txt fichier2.txt

Bonnes pratiques

  • Toujours trier avant : comm suppose des fichiers triés. Des fichiers non triés produisent des résultats incompréhensibles.
  • Combiner avec sort : utilisez les processus de substitution <() pour trier à la volée sans modifier les fichiers originaux.
  • Combiner les colonnes : les options -1, -2 et -3 peuvent se combiner pour ne garder que l'information qui vous intéresse.
  • Utiliser avec diff : comm montre les différences ligne par ligne, diff montre les modifications. Les deux sont complémentaires.

Résumé

CommandeRôle
comm fichier1 fichier2Comparaison complète en 3 colonnes
comm -12 f1 f2Lignes communes uniquement
comm -3 f1 f2Lignes différentes uniquement
comm <(sort f1) <(sort f2)Comparer des fichiers non triés

La commande comm est un outil précis pour analyser les différences entre deux fichiers triés. Sa sortie en trois colonnes distinctes facilite l'identification rapide de ce qui est partagé ou propre à chaque fichier. Combinée avec sort et les processus de substitution, elle devient un outil très puissant pour comparer n'importe quels fichiers texte.
