Leçon 163 : base64 — Encoder et décoder en Base64

Base64 est un système de numération utilisant 64 caractères (A-Z, a-z, 0-9, + et /) pour représenter des données binaires sous forme de texte. C'est extrêmement utile pour transmettre des données binaires dans des contexts textuels (emails, JSON, URLs, etc.).

Principe de base

Chaque groupe de 3 octets (24 bits) est converti en 4 caractères Base64. Si le dernier groupe contient moins de 3 octets, des caractères de remplissage (=) sont ajoutés.

CaractèreValeurCaractèreValeur
A - Z0 - 25a - z26 - 51
0 - 952 - 61+62
/63=Padding

Encoder un fichier ou du texte

Encoder depuis stdin

echo "Bonjour le monde !" | base64

Encoder un fichier

base64 fichier.png > fichier.b64

Encoder avec saut de ligne (RFC standard)

base64 -w 0 fichier.png

Décoder du Base64

Décoder depuis stdin

echo "Qm9uam91ciBsZSBtb25kZSAh" | base64 -d

Décoder un fichier Base64

base64 -d fichier.b64 > fichier_restored.png

Options utiles

OptionDescription
-dMode décodage
-w COLSLargeur des lignes (0 = pas de retour à la ligne)
-iIgnorer les caractères non-Base64 (valide aussi en décodage)
--wrap=COLSAlias de -w

Cas d'utilisation courants

Encoder une image pour JSON

base64 -w 0 image.png

Encoder une clé SSH publique pour l'ajouter à un serveur distant

cat ~/.ssh/id_rsa.pub | base64

Encoder un mot de passe pour un header HTTP

echo -n "utilisateur:motdepasse" | base64

Decoder et voir le résultat directement

echo "SGVsbG8gV29ybGQ=" | base64 -d && echo ""

Avec les pipes

Combiner Base64 avec d'autres outils pour des transformations puissantes :

# Encoder le contenu d'un fichier tar sans le nommer explicitement
tar cf - photos/ | base64 | wc -c
# Encoder et décoder en une seule commande (round-trip)
echo "Test" | base64 | base64 -d

Gestion des erreurs

Si le texte Base64 est corrompu, base64 -d le_signalera :

echo "Invalide!!!" | base64 -d 2>&& echo "OK" || echo "Erreur"

Bonnes pratiques

  • Utilisez -w 0 pour obtenir une sortie sur une seule ligne (idéal pour JSON, URLs, etc.)
  • Pour encoder des fichiers binaires, vérifiez toujours que le décodage produit le bon résultat avec une somme de contrôle
  • Combinez avec tr -d '\n' si vous avez besoin de supprimer tous les retours à la ligne
  • Pour les URLs,要考虑 использование URL-safe Base64 (заменяет + на - и / на _)

URL-safe Base64

Pour les URLs et noms de fichiers, remplacez les caractères spéciaux :

# Encoder en Base64 URL-safe
echo "données@sensibles/64" | base64 | tr '+/' '-_' | tr -d '='

Exercice pratique

  1. Créez un fichier texte avec echo "Linux c'est formidable !" > test.txt
  2. Encodez-le en Base64 : base64 test.txt
  3. Copiez la sortie Base64
  4. Décodez-la : echo "TGludXggYydlc3QgZm9ybWlkYWJsZSAhCg==" | base64 -d
  5. Vérifiez que le résultat correspond à l'original
