Leçon 106 : stat — Inspecter les fichiers en détail

La commande stat (pour status) affiche des informations complètes et détaillées sur un fichier ou un système de fichiers — bien plus que ce que ls -l ne montre. Elle révèle la taille exacte, les horodatages précis (accès, modification, changement), les permissions octopus, le numéro d'inode, et même le type de système de fichiers. C'est l'outil idéal quand vous avez besoin de détails forensiques sur un fichier.

Pourquoi utiliser stat plutôt que ls ?

ls -l vous donne un résumé rapide. stat vous donne tout le reste :

  • Les trois horodatages complets (accès, modification, changement)
  • La taille en octets exacte (pas arrondie)
  • Le numéro d'inode
  • Le nombre de liens durs
  • Le type de périphérique (pour les fichiers spéciaux)
  • Le type de système de fichiers
  • La taille de bloc utilisée

Syntaxe de base

stat [OPTIONS] fichier
stat [OPTIONS] fichier1 fichier2...
stat -f fichier # informations sur le système de fichiers (pas sur le fichier)

Sortie par défaut

Sans aucune option, stat affiche toutes les informations disponibles sur un fichier :

$ stat mon_fichier.txt
File: mon_fichier.txt
Size: 4096 Blocks: 8 IO Block: 4096 regular file
Device: 8h/8d Inode: 131076 Links: 1
Access: (0644/-rw-r--r--) Uid: ( 1000/ david) Gid: ( 1000/ david)
Access: 2026-07-15 08:00:00.000000000 +0200
Modify: 2026-07-10 14:30:00.000000000 +0200
Change: 2026-07-10 14:30:00.000000000 +0200
Birth: 2026-07-01 09:00:00.000000000 +0200

Les trois horodatages

Linux stocke trois dates pour chaque fichier. Comprendre la difference est essentiel :

atime — Access time

Dernier moment où le fichier a ete lu (acces au contenu). Se met a jour quand vous lisez le fichier avec cat, less, ou quand un programme y accede. Attention : sur certains systemes, l'acces au disque pour mettre a jour l'atime peut degrader les performances — c'est pourquoi noatime est souvent utilise sur les serveurs.

mtime — Modify time

Dernier moment où le contenu du fichier a ete modifie. Se met a jour quand vous editez et sauvegardez le fichier. C'est ce que ls -l affiche par defaut.

ctime — Change time

Dernier moment où les metadonnees du fichier ont change — c'est-a-dire tout sauf le contenu. Cela inclut les permissions, le proprietaire, le groupe, et aussi le fait de changer le contenu (car cela modifie aussi l'inode). Notez que ctime ne peut jamais reculer dans le temps — il ne fait que avancer.

Birth — Creation time

Date de creation du fichier. Cette information n'est pas toujours disponible — elle depend du systeme de fichiers. ext4 ne la stocke pas rellement (elle affiche "-" ou la repique du mtime), tandis que btrfs, XFS ou les systemes modernes la supportent correctement.

# Voir les trois horodatages clairement
stat -c "Access: %x | Modify: %y | Change: %z" fichier.txt

Formats personnalises avec -c

L'option -c (ou --format) permet de specifier exactement quelles informations vous voulez, dans le format que vous souhaitez. C'est particulierement utile dans les scripts.

Exemples pratiques de formats

# Taille en octets uniquement
stat -c "%s" fichier.txt
# Permissions numeriques
stat -c "%a" fichier.txt
# Exemple de sortie: 644
# Format compact: permissions | taille | date modification
stat -c "%A %s %y" fichier.txt
# Exemple de sortie: -rw-r--r-- 4096 2026-07-10 14:30:00
# Nom et inode
stat -c "Inode %i: %n" fichier.txt
# Horodatages en epoch (pour calcul)
stat -c "%Y" fichier.txt # mtime en epoch
stat -c "%X" fichier.txt # atime en epoch
# Format JSON (experimental,GNU stat)
stat --printf '{"name":"%n","size":%s,"mtime":%Y}' fichier.txt

Exemples pratiques

1. Comparer la taille reelle et l'espace disque utilise

# Taille reelle du fichier
stat -c "%s" fichier.txt
# Taille sur le disque (blocs * taille de bloc)
stat -c "%b * %B = %s octets sur le disque" fichier.txt
# Exemple: 8 * 512 = 4096 octets sur le disque

2. Trouver les fichiers recemment modifies

# Trouver les fichiers modifies dans les 24 dernieres heures
find . -type f -mtime 0 -exec stat --format="%Y %n" {} \; | \
awk '{if ($1 > systime() - 86400) print}'
# Lister par date de modification
ls -lt *.log | head -10
# Fichiers modifies aujourd'hui
find /var/log -type f -mtime 0 2>/dev/null

3. Verifier les permissions et proprietaire

# Afficher proprietaire et groupe
stat -c "%U:%G" fichier
# Verifier si un fichier est executable
[ $(stat -c "%a" script.sh) -ge 100 ] && echo "Executable" || echo "Non executable"
# Extraire uniquement les permissions numeriques
stat -c "%a" /etc/passwd

4. Traquer un fichier par son inode

# Trouver l'inode d'un fichier
stat -c "%i" fichier.txt
# Trouver tous les fichiers avec le meme inode (liens durs)
find . -inum 131076
# Compter les liens durs
stat -c "%h" fichier.txt

5. Utiliser avec des scripts Bash

# Verifier si un fichier a ete modifie depuis une date
#!/bin/bash
DATECIBLE="2026-07-01" # Date souhaitee
EPOCHCIBLE=$(date -d "$DATECIBLE" +%s)
for fichier in *.txt; do
MTIME=$(stat -c "%Y" "$fichier")
if [ "$MTIME" -gt "$EPOCHCIBLE" ]; then
echo "$fichier est plus recent que $DATECIBLE"
fi
done

6. Verifier un fichier avant installation

# Verifier un binaire avant de l'executer
stat -c "Type: %F | Taille: %s octets | Inode: %i" /usr/bin/python3
# Verifier si c'est un lien symbolique
stat -c "%F" /usr/bin/python3
# Si c'est un lien: symbolic link
# Sinon: regular file

stat -f — Informations sur le systeme de fichiers

L'option -f (ou --filesystem) affiche des informations sur le systeme de fichiers contenant le fichier, plutot que sur le fichier lui-meme :

$ stat -f /home
File: "/home"
ID: 0 Namelen: 255 Type: ext2/ext3
Block size: 4096 Fundamental block size: 4096
Blocks: Total: 2457923 Free: 1245678 Available: 1145678
Inodes: Total: 629144 Free: 612345

Travailler avec plusieurs fichiers

# Stat sur plusieurs fichiers
stat fichier1.txt fichier2.txt
# Format compact pour plusieurs fichiers (script)
stat -c "%n: %s octets" *.log
# Resumer la taille totale de tous les fichiers
stat -c "%s" *.txt | awk '{s+=$1} END {print "Total:", s, "octets"}'

Symbolic links (liens symboliques)

# Par defaut, stat suit le lien et affiche le fichier cible
stat lien_symbolique
# Pour voir les infos DU LIEN (pas de la cible)
stat -L lien_symbolique # Suit le lien (comportement par defaut)
# Verifier si un fichier est un lien symbolique
[ -L "$fichier" ] && echo "C'est un lien symbolique"
# Stat montre le type "symbolic link" si on ne dereference pas
stat -c "%F" lien_symbolique

Scripts pratiques

Script : Surveillance de modifications de fichiers

#!/bin/bash
# Surveiller si un fichier a ete modifie depuis la derniere verification
FICHIER="$1"
if [ -z "$FICHIER" ]; then
echo "Usage: $0 "
exit 1
fi
MTIME=$(stat -c "%Y" "$FICHIER")
MTIME_HUMAIN=$(stat -c "%y" "$FICHIER")
TAILLE=$(stat -c "%s" "$FICHIER")
EPOCH_AJOURD=HUI=$(date +%s)
DIFF=$((EPOCH_AUJOURD'HUI - MTIME))
echo "Fichier: $FICHIER"
echo "Taille: $TAILLE octets"
echo "Modifie le: $MTIME_HUMAIN"
if [ "$DIFF" -lt 3600 ]; then
echo "MODIFIE IL Y A $((DIFF / 60)) MINUTES"
elif [ "$DIFF" -lt 86400 ]; then
echo "Modifie il y a $((DIFF / 3600)) heures"
else
echo "Modifie il y a $((DIFF / 86400)) jours"
fi

Script : Lister les fichiers par age

#!/bin/bash
# Trier les fichiers par date de modification
echo "=== Fichiers tries par modification (recent -> ancien) ==="
for fichier in *; do
[ -e "$fichier" ] || continue
MTIME=$(stat -c "%Y" "$fichier")
echo "$MTIME $fichier"
done | sort -rn | while read epoch fichier; do
HUMAN=$(date -d "@$epoch" "+%Y-%m-%d %H:%M:%S")
printf "%-40s %s\n" "$fichier" "$HUMAN"
done

Script : Calculer l'espace total utilise par des fichiers

#!/bin/bash
# Calculer l'espace reel et l'espace disque pour des fichiers
TOTAL_OCTETS=0
TOTAL_BLOCS=0
TAILLE_BLOC=$(stat -c "%B" "${1:-.}") # Taille d'un bloc
for fichier in "$@"; do
if [ -e "$fichier" ]; then
OCTETS=$(stat -c "%s" "$fichier")
BLOCS=$(stat -c "%b" "$fichier")
TOTAL_OCTETS=$((TOTAL_OCTETS + OCTETS))
TOTAL_BLOCS=$((TOTAL_BLOCS + BLOCS))
fi
done
ESPACE_DISQUE=$((TOTAL_BLOCS * TAILLE_BLOC))
echo "Fichiers examines: $#"
echo "Taille totale (octets): $TOTAL_OCTETS"
echo "Espace sur disque: $ESPACE_DISQUE octets"

Cas d'utilisation courants

1. Verifier l'integrite d'un fichier de configuration

# Sauvegarder l'etat avant modification
stat -c "%Y %s %a" /etc/ssh/sshd_config > /root/sshd_config.avant
# Apres modification, comparer
stat -c "%Y %s %a" /etc/ssh/sshd_config > /root/sshd_config.apres
diff /root/sshd_config.avant /root/sshd_config.apres

2. Trouver les fichiers qui n'ont pas ete accedes depuis longtemps

# Fichiers non accedes depuis plus de 30 jours
find . -type f -atime +30 -exec stat --format="%n %x" {} \; | \
awk '{print $1, $2, $3}'

3. Verifier l'espace reel utilise vs taille apparente

# Un fichier de 1 octet occupe quand meme un bloc sur le disque
$ echo -n "a" > un_octet.txt
$ stat -c "Taille: %s octets | Blocs: %b | Espace disque: %b*%B=%d octets" un_octet.txt
Taille: 1 octets | Blocs: 8 | Espace disque: 8*512=4096 octets

Resume

La commande stat est l'outil ultime pour obtenir tous les details sur un fichier ou un systeme de fichiers. Elle depasse largement ce que ls peut offrir :

  • stat fichier — Afficher toutes les informations disponibles
  • stat -c "%s" fichier — Taille en octets uniquement
  • stat -c "%a" fichier — Permissions numeriques
  • stat -c "%Y" fichier — Modification time en epoch
  • stat -c "%i" fichier — Numero d'inode
  • stat -f fichier — Informations sur le systeme de fichiers
  • stat -c "%n: %s octets, modifie le %y" *.log — Format personnalise pour plusieurs fichiers
  • stat -c "%b * %B" fichier — Espace disque reel utilise

Dans les scripts de surveillance, de sauvegarde ou de diagnostic, stat est souvent preferable a parser la sortie de ls, car ses formats sont plus estables et plus facilement exploitables.
