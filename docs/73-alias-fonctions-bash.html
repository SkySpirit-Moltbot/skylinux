Leçon 73 : alias et fonctions Bash — Personnalisez votre terminal

1. Introduction

Vous tapez les mêmes commandes chaque jour ? ls -la, grep -r, git status ? Les alias et fonctions Bash sont là pour vous simplifier la vie en créant vos propres raccourcis et commandes personnalisées.

Les alias transforment les commandes complexes en frappes simples. Les fonctions Bash vont plus loin : elles permettent de créer de véritables programmes en ligne de commande.

2. Les alias — Raccourcis simples

Créer un alias

Un alias est simplement un nom qui remplace une commande (ou plusieurs commandes chainées).

# Syntaxe de base alias nom='commande'

Exemples classiques

# Raccourcis pour ls alias ll='ls -la' alias la='ls -A' alias l='ls -CF' # Raccourcis pour grep alias grep='grep --color=auto' alias fgrep='fgrep --color=auto' alias egrep='egrep --color=auto' # Mise à jour du système alias update='sudo apt update && sudo apt upgrade -y' # Afficher les ports en écoute alias ports='sudo lsof -i -P -n | grep LISTEN' # Accéder rapidement à mon projet alias proj='cd ~/projets/monapp && ls'

Alias avec paramètres

Un alias ne peut pas accepter d'arguments directement dans la definition. Pour cela, utilisez des fonctions Bash (section 4). Mais voici une astuce :

# Utiliser les arguments avec alias (via expansion de position) alias mongrep='grep' # Ensuite: mongrep "terme" fichier.txt — fonctionne mais limitatif # Pour desAlias qui acceptent des arguments, preferer les fonctions

3. Alias de sécurité et protection

# Protection contre les accidents alias rm='rm -i' # Confirmation avant suppression alias cp='cp -i' # Confirmation avant copie alias mv='mv -i' # Confirmation avant déplacement # Demande de confirmation pour détruire alias rmdir='rmdir -v' # Se protéger de soi-même alias shred='shred -uvz' # Effacement sécurisé avec verbose et zéro

4. Alias temporaires vs permanents

Alias temporaire (session actuelle)

# Créer un alias — fonctionne dans la session courante alias gs='git status' # Lister tous les alias actifs alias # Supprimer un alias (unexport) unalias gs # Supprimer tous les alias unalias -a

Alias permanent (fichier de configuration)

Ajoutez vos alias dans un fichier de démarrage pour qu'ils soient disponibles à chaque session :

# 1. Éditer le fichier .bashrc (valable pour Bash) nano ~/.bashrc # 2. Ajouter vos alias à la fin du fichier alias ll='ls -la' alias update='sudo apt update && sudo apt upgrade -y' alias grepc='grep --color=auto' # 3. Recharger sans redémarrer le terminal source ~/.bashrc # ou . ~/.bashrc # Pour Zsh (alternative à Bash) nano ~/.zshrc source ~/.zshrc

Pour les alias systeme (pour tous les utilisateurs), modifiez /etc/bash.bashrc ou créez un fichier dans /etc/profile.d/.

5. Fonctions Bash — Au-delà des alias

Les fonctions sont plus puissantes que les alias : elles peuvent accepter des arguments, contenir de la logique (boucles, conditions), et返回值.

Syntaxe de base

# Méthode 1 — mot-clé function (recommandé pour Bash moderne) function nom_fonction { # commandes return valeur # code de retour (0 = succès) } # Méthode 2 — syntaxe POSIX (compatible ksh, sh) nom_fonction() { # commandes } # Méthode 3 — sur une seule ligne (peu lisible) nom_fonction() { echo "Salut $1"; }

Arguments et variables spéciales

# VariablesSpeciales Bash # $1, $2, ... — Arguments positions (1er, 2e, etc.) # $@ — Tous les arguments comme liste # $# — Nombre d'arguments # $0 — Nom de la fonction ou du script # $? — Code de retour de la dernière commande function saluer { echo "Bonjour $1 ! Vous avez fourni $# arguments." } saluer Pierre # -> Bonjour Pierre ! Vous avez fourni 1 arguments. # Avec plusieurs arguments function afficher { echo "Args: $@" echo "Nombre: $#" } afficher un deux trois quatre # -> Args: un deux trois quatre # -> Nombre: 4

6. Exemples de fonctions pratiques

Créer un dossier et y entrer directement

# Sans cd dans la fonction, cd serait local à la fonction function mkcd { mkdir -p "$1" cd "$1" } # Utilisation : mkcd mon_projet # -> crée le dossier ET vous y place

Rechercher dans l'historique Git

function gch { if [ -z "$1" ]; then echo "Usage: gch (recherche dans les commits)" else git log --oneline --all --grep="$1" -n 20 fi } # Utilisation : gch "fix bug" # -> affiche les commits contenant "fix bug"

Extraire n'importe quelle archive

function extraire { if [ -f "$1" ]; then case "$1" in *.tar.bz2) tar xjf "$1" ;; *.tar.gz) tar xzf "$1" ;; *.tar.xz) tar xJf "$1" ;; *.bz2) bunzip2 "$1" ;; *.rar) unrar x "$1" ;; *.gz) gunzip "$1" ;; *.zip) unzip "$1" ;; *.7z) 7z x "$1" ;; *) echo "Format non supporté: $1" ;; esac else echo "Fichier non trouvé: $1" fi } # Utilisation : extraire archive.tar.gz extraire document.zip

Backup rapide avec timestamp

function backup { if [ -z "$1" ]; then echo "Usage: backup " return 1 fi if [ -e "$1" ]; then cp -r "$1" "${1}.bak-$(date +%Y%m%d-%H%M%S)" echo "Backup créé: ${1}.bak-$(date +%Y%m%d-%H%M%S)" else echo "Erreur: '$1' n'existe pas" return 1 fi } # Utilisation : backup projet/ # -> projet.bak-20260528-143052/

Vérifier si un port est ouvert

function port_check { if [ -z "$1" ] || [ -z "$2" ]; then echo "Usage: port_check " return 1 fi if timeout 2 bash -c "echo >/dev/tcp/$1/$2" 2>/dev/null; then echo "Port $2 sur $1 : OUVERT ✓" else echo "Port $2 sur $1 : FERMÉ ✗" fi } # Utilisation : port_check localhost 22 port_check example.com 443

7. Valeurs de retour et erreurs

# return — code de sortie (0 = succès, non-zero = erreur) function verifier_fichier { if [ -f "$1" ]; then echo "OK: $1 existe" return 0 else echo "ERREUR: $1 introuvable" return 1 fi } verifier_fichier /etc/passwd echo "Code retour: $?" # -> 0 verifier_fichier /inconnu.txt echo "Code retour: $?" # -> 1 # Tester le code de retour pour une condition if verifier_fichier /tmp/test.txt; then echo "Le fichier existe, on continue..." fi

8. Portée des variables

# Par défaut, les variables sont GLOBALES dans la fonction function test_portee { var_locale="je suis locale" var_globale="je suis globale" } test_portee echo $var_globale # -> je suis globale echo $var_locale # -> je suis locale (accessible!) # Pour une vraie variable locale : function test_local { local ma_variable="seulement dans cette fonction" echo $ma_variable } test_local echo $ma_variable # -> vide ! (n'existe pas en dehors)

9. Organiser vos fonctions dans des fichiers

# Créer un fichier de fonctions mkdir -p ~/.bash_functions # Ajouter dans ~/.bashrc : if [ -f ~/.bash_functions ]; then source ~/.bash_functions fi # Exemple: ~/.bash_functions/git-functions # ----- function gs { git status "$@"; } function ga { git add "$@"; } function gc { git commit -m "$1"; } function gp { git push "$@"; } function gl { git log --oneline -n 15; } function gco { git checkout "$1"; } function gstash { git stash "$@"; } # -----

Cette approche modulaire facilite la maintenance et le partage de vos fonctions entre machines.

10. Commandes utiles pour gérer alias et fonctions

# Lister tous les alias définis alias # Lister tous les alias contenant "git" alias | grep git # Voir le contenu d'une fonction (si définie) declare -f nom_fonction type nom_fonction # Lister toutes les fonctions définies declare -F # Supprimer un alias unalias nom_alias # Supprimer une fonction unset -f nom_fonction
