184. xxd — Visualiser et éditer en hexadécimal

Quand vous devez examiner le contenu brut d'un fichier — headers, données binaires, caractères invisibles — les éditeurs de texte classiques montrent leurs limites. xxd est l'outil idéal pour visualiser n'importe quel fichier en hexadécimal, et même pour créer des fichiers binaires à partir de texte.

Principe fondamental : hexadécimal vs texte

Chaque octet d'un fichier est représenté par un nombre hexadécimal (base 16) allant de 00 à ff (0 à 255 en décimal). xxd affiche trois colonnes :

  • Offset : la position du premier octet de la ligne (en hexadécimal)
  • Hexadécimal : les octets grouped par paires (16 octets par ligne)
  • Texte ASCII : la même donnée interpretée comme du texte lisible

Installation

xxd fait partie du paquet vim-common sur la plupart des distributions :

sudo apt install vim-common # Debian/Ubuntu
sudo dnf install vim-common # Fedora
sudo pacman -S vim # Arch

Vérifiez l'installation :

xxd --version

Affichage basique

Visualisez un fichier entier :

xxd fichier.bin

Exemple de sortie pour un fichier texte :

00000000: 4865 6c6c 6f20 776f 726c 6421 0a Hello world!.

Interprétation :

  • 00000000 = offset (position 0)
  • 4865 6c6c 6f20 776f 726c 6421 0a = octets en hexadécimal
  • Hello world!. = représentation ASCII (les points sont des caractères non imprimables)

Limiter le nombre d'octets affichés

Pour n'afficher que les N premiers octets :

xxd -l 32 fichier.bin

Pour n'afficher que les N derniers octets (skip + length) :

xxd -s 100 -l 32 fichier.bin

Depuis la fin du fichier avec un offset négatif :

xxd -s -64 fichier.bin # Les 64 derniers octets

Colonnes et format

Format par défaut (3 colonnes)

xxd fichier.txt

Format pure hexadécimal (sans ASCII)

xxd -p fichier.txt

Ce format est utile pour le piping et le traitement automatisé.

Format-postscript (compact)

xxd -ps fichier.txt

Format C array (pour inclure dans du code)

xxd -i fichier.bin

Produces output like:

unsigned char fichier_bin[] = { 0x48, 0x65, 0x6c, 0x6c, 0x6f, 0x20, 0x77, 0x6f, 0x72, 0x6c, 0x64, 0x21, 0x0a }; unsigned int fichier_bin_len = 13;

Créer un fichier binaire depuis hexadécimal

La vraie puissance de xxd : la conversion inverse. Pipez du hexadécimal vers xxd avec l'option -r (reverse) :

echo "48656c6c6f" | xxd -r -p > hello.bin
cat hello.bin # Affiche : Hello

Ou depuis un fichier hexadécimal :

xxd -r -p hexdump.txt > output.bin

Combiner lecture et écriture : édition inline

Pour modifier des octets spécifiques dans un fichier binaire, utilisez xxd avec un éditeur de texte :

xxd fichier.bin | sed 's/48656c6c6f/426974204d61/' | xxd -r > fichier_modifie.bin

Cette technique permet de faire des remplacements précis sans logiciel spécialisé.

Visualiser les caractères non imprimables

Quand xxd affiche des points (.), cela signifie que les octets correspondent à des caractères de contrôle ou non-ASCII. Voici les codes courants :

Analyser les headers de fichiers

MAGIC numbers courants

Chaque type de fichier a une signature hexadécimale caractéristique :

FichierSignature hexExplication
JPEGff d8 ffDébut d'une image JPEG
PNG89 50 4e 47"PNG" en ASCII, préfixé 0x89
PDF25 50 44 46"%PDF" en ASCII
ZIP50 4b 03 04"PK" (PKZip)
ELF (Linux)7f 45 4c 46".ELF" en ASCII
MP349 44 33"ID3" (tag metadata)

Vérifier le type réel d'un fichier

xxd image.jpg | head -3

Si le fichier est vraiment un JPEG, vous verrez ffd8ff au début. Si vous voyez autre chose, le fichier est peut-être corrompu ou mal nommé.

xxd vs hexdump vs od

Linux propose plusieurs outils d'affichage hexa. Voici leurs différences :

OutilCaractèreUsage typique
xxdFormat visuel 3 colonnes avec ASCIIDébogage, inspection manuelle
hexdump -CSimilaire à xxd, format canoniqueRemplacement standard BSD
od -A x -t x1zFormat octal par défaut, moins lisibleConversion octal/hex, compatibilité SysV

Pour une sortie similaire à xxd, utilisez :

hexdump -C fichier.bin | head -10

Exporter des données binaires dans un script

Parfois vous avez besoin d'encoder des données binaires dans un script shell. xxd + base64 peut aider :

# Encoder un fichier en base64 (sûr pour le texte) base64 fichier.bin > fichier.b64 # Decoder base64 -d fichier.b64 > fichier2.bin # Vérifier que c'est identique diff fichier.bin fichier2.bin && echo "OK"

Reconstruire un fichier depuis une capture

Si vous avez une capture d'écran ou un copier-coller d'une sortie hexadécimale, vous pouvez la reconvertir :

# Nettoyer la sortie xxd pour ne garder que l'hexadécimal xxd -p fichier.bin | tr -d '\n' | fold -w2 | while read b; do printf "\x$b"; done > fichier2.bin

Ou plus simplement avec xxd seul :

xxd -p fichier.bin | xxd -r -p > fichier2.bin

Atelier pratique : corriger un header PNG corrompu

Imaginons qu'un fichier PNG start par 89 50 4e 47 0d 0a 1a 0a (correct). Si vous observez :

xxd monimage.png | head -2
00000000: 8950 4e47 0a0a 1a0a ... PNG........

Le header est légèrement différent (0d0a devenu 0a0a). Pour le corriger :

# Créer un correctif cp monimage.png monimage_corrige.png # Remplacer les octets à l'offset 4-5 (0d0a -> 0d0a correct, ici juste pour l'exemple) xxd monimage_corrige.png | sed 's/0a0a 1a0a/0d0a 1a0a/' | xxd -r > monimage_fixed.png

Résumé des options principales

OptionDescription
xxd fichierAffichage par défaut (offset + hex + ASCII)
xxd -p fichierFormat pure hexadécimal continu
xxd -ps fichierFormat post-script compact
xxd -i fichierFormat tableau C (pour inclusion dans du code)
xxd -l N fichierLimiter à N octets
xxd -s N fichierCommencer à l'offset N
xxd -s -N fichierCommencer N octets avant la fin
xxd -r fichierMode reverse : convertir hex → binaire
xxd -c N fichierAfficher N octets par ligne (défaut 16)
xxd -g N fichierGrouper les octets par N (défaut 2)

Bonnes pratiques

  • Utilisez xxd | head pour éviter de saturer le terminal avec les gros fichiers
  • Pour les fichiers de plus de quelques Mo, privilégiez xxd -l 256 pour n'inspecter que le header
  • Combinez avec file pour une identification automatique avant xxd
  • La commande xxd -r est votre couteau suisse pour la conversion hex → binaire
  • N'hésitez pas à utiliser diff <(xxd f1) <(xxd f2) pour comparer deux fichiers binaires visuellement
