Leçon 131 - seq — Générer des suites de nombres

La commande seq (pour sequence) génère une suite de nombres entiers de manière simple et rapide. Que vous ayez besoin de créer une liste numérotée, d'itérer dans un script Bash, ou de générer des données de test, seq est l'outil idéal.

Principe de fonctionnement

seq prend en entrée un nombre de départ, un incrément optionnel, et un nombre de fin. Il affiche ensuite chaque nombre de la séquence sur une ligne distincte. Simple, efficace, et terriblement utile.

Syntaxe de base

seq [PREMIER] [INCRÉMENT] DERNIER

Options principales

OptionDescription
-f, --format=FORMATFormat de sortie (printf-style)
-s, --separator=CHAÎNESéparateur entre les nombres (défaut : \n)
-w, --equal-widthAlignement avec des zéros

Exemples concrets

1. Compter de 1 à un nombre donné

La forme la plus simple — compter de 1 jusqu'à une valeur :

seq 5
# Sortie :
# 1
# 2
# 3
# 4
# 5

2. Compter depuis un nombre précis

seq 3 7
# Sortie :
# 3
# 4
# 5
# 6
# 7

3. Compter avec un incrément personnalisé

Par défaut, l'incrément est 1. Vous pouvez le modifier :

seq 0 2 10
# Sortie : 0, 2, 4, 6, 8, 10
seq 10 -2 0
# Sortie : 10, 8, 6, 4, 2, 0

4. Compter à l'envers (décroissant)

seq 5 -1 1
# Sortie :
# 5
# 4
# 3
# 2
# 1

5. Utiliser un format personnalisé avec -f

Le format par défaut est %g (nombre simple). Vous pouvez utiliser un format printf :

seq -f "Fichier_%03g.txt" 1 3
# Sortie :
# Fichier_001.txt
# Fichier_002.txt
# Fichier_003.txt

6. Ajouter un préfixe avec %g

seq -f "Serveur %g" 1 3
# Sortie :
# Serveur 1
# Serveur 2
# Serveur 3

7. Utiliser un séparateur personnalisé avec -s

Par défaut, chaque nombre est sur une ligne. Vous pouvez changer le séparateur :

seq -s ", " 1 5
# Sortie : 1, 2, 3, 4, 5
seq -s " - " 1 3
# Sortie : 1 - 2 - 3

8. Nombres à largeur fixe avec -w

-w complète les nombres courts avec des zéros pour un affichage aligné :

seq -w 1 10
# Sortie :
# 01
# 02
# ...
# 10

seq dans les scripts Bash

1. Boucle for avec seq

Une utilisation classique dans les scripts :

for i in $(seq 1 5); do
echo "Traitement $i"
done
# Sortie :
# Traitement 1
# Traitement 2
# Traitement 3
# Traitement 4
# Traitement 5

2. Boucle avec incrément

for i in $(seq 0 10 50); do
echo "Étape $i"
done
# Sortie :
# Étape 0
# Étape 10
# Étape 20
# Étape 30
# Étape 40
# Étape 50

3. Générer des noms de fichiers numérotés

for i in $(seq -f "%03g" 1 10); do
touch "fichier_$i.txt"
done
# Crée fichier_001.txt, fichier_002.txt, ..., fichier_010.txt

4. Créer plusieurs répertoires

mkdir -p projet{$(seq -s "," 1 5)}
# Crée : projet1, projet2, projet3, projet4, projet5

5. Additionner une série de nombres

seq 1 100 | paste -s -d'+' | bc
# Sortie : 5050
# Calcule la somme des nombres de 1 à 100

Combinaisons utiles

1. Générer des lignes numérotées

seq 5 | while read n; do echo "Ligne $n"; done
# Sortie :
# Ligne 1
# Ligne 2
# Ligne 3
# Ligne 4
# Ligne 5

2. Créer une table de multiplication

for i in $(seq 1 10); do
echo "5 x $i = $((5 * i))"
done

3. Simuler des délais d'exécution

for i in $(seq 3 -1 1); do
echo "Redémarrage dans $i secondes..."
sleep 1
done

4. Itérer sur des ports

for port in $(seq 8000 8005); do
echo "Port : $port"
done
# Affiche : Port 8000, 8001, 8002, 8003, 8004, 8005

5. Générer des dates pour une plage

En combinaison avec date :

for i in $(seq 0 6); do
date -d "today + $i days" +"%A %d/%m"
done
# Affiche les 7 prochains jours

Bonnes pratiques

  • Préférer l'expansion de brace : pour des petites suites, {1..5} est plus rapide que $(seq 1 5)
  • Utiliser -f pour le formattage : -f permet de créer des nommages cohérents (zéros padded)
  • Combiner avec bc pour les calculs : seq | paste permet des calculs arithmétiques rapides
  • Éviter seq pour les grandes suites : pour des millions de lignes, considerer des alternatives comme yes ou des scripts optimisés

seq vs expansion de brace { }

Bash propose aussi les accolades pour les suites :

# Avec seq
for i in $(seq 1 5); do echo $i; done
# Avec brace expansion
for i in {1..5}; do echo $i; done
CaractéristiqueseqBrace expansion
VitesseLente (sous-processus)Rapide (natif Bash)
Incréments personnalisésOuiNon (incrément de 1)
DécroissantOuiOui ({5..1})
Format personnaliséOui (-f)Non

Résumé

CommandeDescription
seq NCompte de 1 à N
seq X YCompte de X à Y
seq X I YCompte de X à Y par pas de I
seq -f "fmt" X YCompte avec un format
seq -s "sep" X YUtilise sep comme séparateur
seq -w X YNombres à largeur fixe (padding)
seq X -1 YCompte à l'envers

seq est un outil simple mais puissant pour générer des suites de nombres. Que ce soit pour numérotées des fichiers, créer des boucles dans des scripts, ou générer des données de test, seq rend la tâche simple et lisible. Gardez-le sous la main : il vous fera gagner du temps bien plus souvent qu'on ne l'imagine.
