yes — Répéter du texte à l'infini

Introduction

La commande yes est l'une des plus simples d'Unix : elle affiche une chaîne de texte en boucle, sans jamais s'arrêter. Elle semble anodine, mais elle est incroyablement utile pour automatiser des réponses, tester des canaux, et alimenter des scripts en données répétitives.

Utilisation de base

Sans argument, yes affiche y en continu :

yes

Vous pouvez spécifier n'importe quel texte :

yes "oui"

Combiner yes avec d'autres commandes

Répondre automatiquement à une question

Quand un programme demande une confirmation, yes peut répondre pour vous :

yes | commande_interactive

Par exemple, pour supprimer plusieurs fichiers sans confirmation :

yes | rm -i *.log

Répondre "non" à tout

Vous pouvez aussi反向 — répondre non à chaque question :

yes n | commande_quelconque

Exemples pratiques

Créer un fichier avec des lignes répétées

yes "ligne de test" | head -20 > test.txt

Tester un pipe ou un canal

yes est parfait pour générer un flux de données continu et tester le comportement de vos scripts :

yes "donnee" | ./mon_script.sh

Combiner avec xargs

yes | xargs -n 1 echo "traitement"

Compter les répétitions avec head

Limitez le nombre de répétitions avec head :

yes " repetition " | head -5

Options principales

OptionDescription
--helpAfficher l'aide
--versionAfficher la version

Cas d'utilisation courants

Automatiser les réponses oui/non

Très utile dans les scripts d'installation ou de configuration :

yes | apt update && yes | apt upgrade

Générer du contenu pour des tests

Créer rapidement un fichier de test volumineux :

yes "donnee test" | head -100000 > gros_fichier.txt

Simulation de charge

Pour tester des scripts qui traitent des lignes en entrée :

yes "x" | while read line; do echo "traitement: $line"; done | head -10

Combiner avec d'autres outils

  • wc -l — Compter les lignes générées : yes | wc -l
  • sed — Modifier chaque ligne : yes | sed 's/y/OUI/g' | head -5
  • awk — Ajouter un numéro de ligne : yes | awk '{print NR, $0}' | head -5
  • grep — Filtrer les répétitions : yes | grep --line-buffered "y" | head -3

Arrêter yes

Par défaut, yes tourne indefiniment. Pour l'arrêter :

  • Ctrl + C — Interruption classique
  • Ctrl + D — Fin de fichier (envoie EOF au processus)
  • Piper vers head comme on l'a vu — le pipe se ferme quand head a lu assez de lignes

Bonnes pratiques

  • Utilisez toujours head ou une autre limite quand vous pipez vers un script ou un fichier pour éviter de saturer le système ou le disque
  • Préférez yes pour les réponses interactives dans les scripts d'automatisation
  • yes sans argument répond "y" — idéal pour les confirmations

Résumé

CommandeEffet
yesAffiche "y" en boucle infinie
yes "texte"Affiche "texte" en boucle infinie
yes | head -nAffiche n répétitions puis s'arrête
yes "oui" | commandeEnvoie des réponses automatiques à une commande

yes est simple mais puissant. Quelques lignes de répétition peuvent sauver un script d'automatisation !
