148 — fmt — Formater le texte en paragraphs

fmt est une commande simple mais puissante qui sert à formater du texte en paragraphs. Elle réaligne les lignes pour respecter une largeur maximale donnée, fusionne les lignes trop courtes et préserve les lignes vides. C'est l'outil idéal pour nettoyer du texte brut ou préparer des documents pour l'affichage.

1. Principe de base

fmt prend du texte en entrée et le redistribue en lignes d'une largeur maximale (par défaut 75 colonnes). Il ne tronque jamais les mots — il les redistribute intégralement en paragraphs.

Exemple le plus simple

echo "Un texte très espacé qui contient des mots avec des espaces multiples entre les mots" | fmt

Résultat : une ligne continue de maximum 75 caractères, avec un seul espace entre chaque mot.

2. Largeur de ligne personalisée

L'option -w (width) définit la largeur maximale de chaque ligne en caractères :

fmt -w 60 fichier.txt
cat fichier.txt | fmt -w 60

Ici, chaque ligne aura au maximum 60 caractères.

Quelques largeurs courantes

  • fmt -w 80 — largeur classique d'un terminal (80 colonnes)
  • fmt -w 72 — largeur traditionnelle pour les documents texte
  • fmt -w 40 — affichage étroit, utile pour les狭窄 displays

3. Largeur de point de rupture

L'option -p (point) permet de limiter la redistribution à des lignes commençant par un préfixe donné. Très utile pour formater du code ou des lignes avec des commentaires :

# Formater uniquement les lignes de commentaire cat script.sh | fmt -w 72 -p '#'

Seules les lignes commençant par # seront reformées ; les autres lignes restent intactes.

4. Mode coupe (crown)

Le mode -c (crown) preserve le style des paragraphs dont les deux premières lignes sont déjà formatées différemment du reste. Il ne reformate que le corps du texte, pas l'en-tête :

fmt -c texte.txt

Utile quand la première ligne d'un paragraphe est un titre ou une phrase d'accroche.

5. Mode trim (émondage)

L'option -t (trim) traite différemment la première ligne d'un paragraphe (qui est souvent en retrait) :

fmt -t texte.txt

La première ligne garde son retrait, les lignes suivantes sont reformées normalement.

6. Split only (division seule)

L'option -s (split-only) ne fusionne jamais les lignes — elle ne fait que couper les lignes trop longues :

fmt -s fichier.txt

Les lignes courtes restent courtes, seules les lignes dépassant la largeur sont coupées.

7. Options principales

OptionDescription
-w NLargeur maximale des lignes (défaut : 75)
-cMode crown : préserve le format de l'accroche
-tMode trim : traite différemment la première ligne
-sSplit-only : coupe mais ne fusionne jamais
-p PRENe reformate que les lignes commençant par PRE
-uEspacement uniforme (un espace entre mots, deux entre phrases)

8. Exemples concrets

Formater un fichier texte complet

fmt -w 80 fichier.txt > fichier_formate.txt

Nettoyer du texte depuis le presse-papiers

xclip -o | fmt -w 70 | xclip -i

Copie le contenu du presse-papiers, le formate à 70 colonnes et le remet dans le presse-papiers.

Préparer du texte pour un email

fmt -w 65 -u message.txt

L'option -u assure un espacement standard : un espace entre les mots, deux espaces après les points.

Formater uniquement les lignes de commentaires

grep '^#' script.sh | fmt -w 72

Couper les lignes trop longues sans fusionner

cat long_lines.txt | fmt -s -w 80

Combiner avec d'autres commandes

Formater la sortie d'une commande :

man bash | col -b | fmt -w 75

Ici on supprime les codes de formatage avec col -b, puis on formate le résultat.

Formater du Markdown pour le terminal

sed 's/^#.*//' README.md | fmt -w 75

Supprime les titres Markdown puis formate le reste du texte.

Réparer un fichier mal formaté

cat fichier_mal_formate.txt | tr -s ' ' | fmt -w 80

Élimine les espaces multiples puis formate proprement.

10. Erreurs fréquentes

  • Oublier -w et obtenir des lignes trop larges — La largeur par défaut de 75 caractères peut être insuffisante pour un terminal moderne. Spécifiez toujours la largeur souhaitée.
  • Utiliser fmt sur du code source — fmt fusionne les lignes, ce qui cassera la syntaxe. Utilisez fmt -s (split-only) pour du code.
  • Confondre avec fold — fold coupe brutalement à la colonne N, fmt redistribute inteligemment en paragraphs.
  • Utiliser fmt sur du Markdown — Il va redistribuer vos paragraphes et peut casser le formatage. Appliquez-le seulement au corps du texte, pas aux titres.

11. Bonnes pratiques

  • Pour du texte brut destiné à un terminal, utilisez fmt -w $(tput cols) pour adapter automatiquement à la largeur du terminal.
  • Pour des emails en texte brut, fmt -w 65 -u est le standard recommandé (65 colonnes, double espace après les phrases).
  • Dans un pipeline, fmt s'intercale bien entre sed et xclip ou less.
  • Pour formater du code, privilégiez fmt -s -w 80 pour couper sans jamais fusionner.
  • Quand vous préparez du texte pour le web, fmt -w 80 suivi d'un sed '/^$/d' produit un résultat propre.
