Leçon 144 : sleep — Créer des délais et pauses dans vos scripts

sleep est une commande fondamentale sous Linux qui suspend l'exécution pendant une durée précise. Bien qu'elle paraisse simple, elle est incontournable pour orchestrer des scripts, ajouter des temporisations, et gérer des boucles de retry.

Pourquoi sleep est essentiel

  • Scripts bash :espérer entre deux commandes
  • Boucles de retry : attendre qu'un service soit prêt
  • Délais visuels : ralentir l'affichage dans un script interactif
  • Crédibilité : simuler des opérations longues dans des démonstrations
  • Chronométrage : mesurer des durées ou créer des minuteurs

Syntaxe de base

sleep NOMBRE[SUFFIXE]...

Par défaut, le nombre est exprimé en secondes.

Installation

sleep fait partie du paquet coreutils et est installé par défaut sur toutes les distributions Linux. Aucune installation nécessaire.

Syntaxe des durées

sleep accepte différents suffixes pour exprimer la durée :

SuffixeUnitéExemple
sSecondes (défaut)sleep 5s
mMinutessleep 2m
hHeuressleep 1h
dJourssleep 1d
(aucun)Secondes (par défaut)sleep 5

Commandes fondamentales

Delai simple

# Attendre 5 secondes
sleep 5

Avec suffixe explicite

sleep 30s # 30 secondes
sleep 2m # 2 minutes
sleep 1h # 1 heure
sleep 1d # 1 jour

Delai fractionnel

sleep 0.5 # demi-seconde
sleep 0.1 # un dizieme de seconde
sleep 1.5 # une seconde et demie
sleep 2.5m # 2 minutes et demie

Delai compose

# Combiner plusieurs durees
sleep 1m 30s
sleep 2h 15m 10s

Exemples pratiques

Affichage avec delai

#!/bin/bash
# Afficher un message toutes les 2 secondes
for i in {1..5}; do
echo "Iteration $i"
sleep 2
done
echo "Termine !"

Minuteur dans le terminal

#!/bin/bash
# Minuteur de 10 secondes
secondes=10
while [ $secondes -gt 0 ]; do
echo -ne "Il reste $secondes secondes... \r"
sleep 1
secondes=$((secondes - 1))
done
echo -e "\nC'est parti !"

Boucle de retry

#!/bin/bash
# Attendre qu'un service soit operationnel
max_attentes=10
compteur=0
until curl -s http://localhost:8080/ready > /dev/null 2>&1; do
compteur=$((compteur + 1))
if [ $compteur -ge $max_attentes ]; then
echo "Le service n'est pas disponible apres $max_attentes tentatives"
exit 1
fi
echo "Attente du demarrage... ($compteur/$max_attentes)"
sleep 5
done
echo "Serviceopreationnel !"

Delai avant action

#!/bin/bash
# Demander confirmation avec delai d'expiration
echo "Voulez-vous continuer ? (o/n)"
read -t 10 reponse || reponse="timeout"
if [ "$reponse" = "timeout" ]; then
echo "Delai d'expiration dépassé. Continuation automatique..."
elif [ "$reponse" = "o" ] || [ "$reponse" = "O" ]; then
echo "Confirmation recue. Continuation..."
else
echo "Annulation."
exit 0
fi

Utilisation avec d'autres commandes

Simuler un traitement long

# Simuler un traitement de 3 secondes
echo "Traitement en cours..."
sleep 3
echo "Termine !"

Delai entre deux operations

# Creer un fichier, attendre, puis le copier
echo "Creation du fichier..."
echo "donnees" > /tmp/data.txt
sleep 2
cp /tmp/data.txt /tmp/backup.txt
echo "Sauvegarde effectuee."

Compte a rebours

#!/bin/bash
# Compte a rebours de 5 secondes
for i in 5 4 3 2 1; do
echo "$i..."
sleep 1
done
echo "Feu !"

Delai aleatoire

#!/bin/bash
# Attendre un temps aleatoire entre 1 et 5 secondes
delai=$((RANDOM % 5 + 1))
echo "Attente de $delai secondes..."
sleep $delai
echo "OK, on continue."

Daemon avec pause

#!/bin/bash
# Boucle infinie avec pause de 60 secondes
while true; do
echo "$(date) - Verification..."
# votre tache ici
sleep 60
done

Mesurer le temps avec sleep

Chronometrer une commande

# Mesurer le temps d'execution
debut=$(date +%s)
echo "Debut : $(date)"
# Votre commande
ls -la /
fin=$(date +%s)
duree=$((fin - debut))
echo "Fin : $(date)"
echo "Duree totale : ${duree}s"

Creer un minuteur

#!/bin/bash
# Minuteur pour une duree donnee
lecture() {
local t=$1
while [ $t -gt 0 ]; do
printf "\rTemps restant : %02d:%02d" $((t/60)) $((t%60))
sleep 1
t=$((t-1))
done
echo ""
echo "Temps ecoule !"
}
# Utilisation : ./minuteur.sh 300 (pour 5 minutes)
lecture ${1:-300}

Cas d'utilisation avances

Rate limiting simple

#!/bin/bash
# Limiter les requetes a 1 par seconde
derniere_requete=0
pour chaque_requete() {
maintenant=$(date +%s)
ecoule=$((maintenant - derniere_requete))
if [ $ecoule -lt 1 ]; then
sleep $((1 - ecoule))
fi
# ... votre logique ici
echo "Requete traitee"
derniere_requete=$(date +%s)
}

Progression bar

#!/bin/bash
# Barre de progression simple
total=20
for i in $(seq 1 $total); do
percent=$((i * 100 / total))
filled=$((i * 40 / total))
empty=$((40 - filled))
printf "\r[%${filled}s%${empty}s] %3d%%" | tr ' ' '=' | tr ' ' '-'
sleep 0.1
done
echo ""

Integration avec cron

Delai au demarrage d'un script cron

#!/bin/bash
# Dans un script lance par cron, eviter le demarrage simultane
# Attendre un delai aleatoire pour eviter la surcharge
sleep $((RANDOM % 300)) # 0 a 5 minutes
# Puis le reste du script
/opt/mon-script.sh

Bonnes pratiques

  • Utilisez des suffixes explicites (5s, 2m) pour la lisibilité
  • Pour les boucles, commencez avec des délais courts et augmentez si nécessaire
  • Backoff exponentiel : pour les retries, augmentez le délai à chaque tentative
  • Des délais de 0.1s sont utiles pour les boucles de progression
  • Combiner avec read -t : timeout sur les entrées utilisateur
  • Dans les scripts critiques, ajoutez des logs avant/après les sleep

Résumé

sleep est une commande simple mais puissante. Elle suspend l'exécution pour une durée précise et s'intègre naturellement dans les scripts bash pour orchestrer des délais, des retries, des minuteurs, et des boucles de progression. Combinez-la avec des boucles, des conditions, et des compteurs pour créer des scripts robustes et temporisés.
