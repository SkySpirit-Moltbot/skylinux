basename et dirname — Extraire le nom et le répertoire d'un chemin

Quand vous travaillez avec des chemins de fichiers en Bash, il est souvent utile d'en extraire une partie précise : le nom du fichier seul, ou le répertoire parent. C'est exactement ce que font basename et dirname.

Qu'est-ce que basename ?

basename extrait le dernier élément d'un chemin. Si vous lui donnez un chemin complet de fichier, il retourne simplement le nom du fichier (sans le répertoire qui le contient).

Utilisation basique

basename /home/utilisateur/documents/rapport.pdf

Résultat :

rapport.pdf

Supprimer une extension

Vous pouvez demander à basename de retirer une extension précise grâce à l'option -s (suffix) :

basename -s .pdf /home/utilisateur/documents/rapport.pdf

Résultat :

rapport

Autre méthode avec basename suivi du suffixe en argument :

basename /home/utilisateur/documents/rapport.pdf .pdf

Résultat :

rapport

Qu'est-ce que dirname ?

dirname fait l'inverse de basename : il retourne la partie répertoire du chemin, c'est-à-dire tout ce qui précède le dernier /.

Utilisation basique

dirname /home/utilisateur/documents/rapport.pdf

Résultat :

/home/utilisateur/documents

Cas particulier

Si le chemin ne contient qu'un nom de fichier sans répertoire, dirname retourne . :

dirname rapport.pdf

Résultat :

.

Combiner basename et dirname

Ensemble, ils permettent de分解 un chemin complet en ses deux parties :

chemin="/home/utilisateur/documents/rapport.pdf" echo "Chemin complet : $chemin" echo "Répertoire : $(dirname "$chemin")" echo "Nom du fichier : $(basename "$chemin")"

Résultat :

Chemin complet : /home/utilisateur/documents/rapport.pdf Répertoire : /home/utilisateur/documents Nom du fichier : rapport.pdf

Utiliser basename dans des scripts

basename est très utile dans les scripts pour :

Créer des noms de fichiers temporaires

# Extraire le nom sans extension nom_fichier=$(basename "$fichier" .pdf) echo "Base : $nom_fichier"

Générer des noms de sauvegarde

# Créer une sauvegarde : fichier.bak fichier="/home/utilisateur/data.csv" bak="${fichier}.bak" cp "$fichier" "$bak" echo "Sauvegarde créée : $bak"

Afficher le nom du script

# Dans un script nom_script=$(basename "$0") echo "Ce script s'appelle : $nom_script"

Traiter plusieurs chemins

Avec l'option -a (multiple), vous pouvez traiter plusieurs chemins à la fois :

# basename sur plusieurs fichiers basename -a /home/user/a.txt /home/user/b.txt /home/user/c.txt

Résultat :

a.txt b.txt c.txt

Et avec -z, les résultats sont séparés par des caractères nuls (utile avec xargs -0) :

basename -z /home/user/a.txt /home/user/b.txt

Exercices pratiques

Exercice 1

Quel résultat donne cette commande ?

basename /var/log/syslog

Exercice 2

Écrivez une commande qui affiche le répertoire parent de /etc/nginx/nginx.conf.

Exercice 3

Dans un script, extrayez le nom du fichier sans son extension à partir de /home/david/photos/vacances.jpg.

Exercice 4

Comment afficher simultanément le répertoire et le nom de fichier de /opt/projet/code/main.py en une seule ligne ?

Solutions

Solution 1

syslog

Solution 2

dirname /etc/nginx/nginx.conf

Résultat : /etc/nginx

Solution 3

basename -s .jpg /home/david/photos/vacances.jpg

Résultat : vacances

Solution 4

chemin="/opt/projet/code/main.py" echo "Répertoire : $(dirname "$chemin")" echo "Fichier : $(basename "$chemin")"

Conclusion

basename et dirname sont deux outils simples mais essentiels pour manipuler les chemins de fichiers. Ils s'utilisent partout : dans les scripts Bash, les commandes en ligne, ou combinés avec d'autres outils comme find, cp ou mv. Leur maîtrise rend la gestion des fichiers beaucoup plus fluide.
