Leçon 129 : htop — Surveillance interactive des processus

Introduction

htop est un visualiseur de processus interactif en temps réel. Contrairement à top, il offre une interface plus intuitive, colorée, et permet de naviguer et manipuler les processus avec les touches du clavier.

C'est l'outil de surveillance incontournable pour quiconque administre un serveur ou souhaite comprendre ce qui se passe sur sa machine Linux.

Installation

# Ubuntu / Debian sudo apt install htop # Fedora / CentOS / RHEL sudo dnf install htop # Arch Linux sudo pacman -S htop # Vérifier l'installation htop --version

Lancement

# Lancement simple htop # Avec un_pid spécifique en surbrillance htop -d PID # Mode lecture seule (sans modification possible) htop -s

L'interface d'htop

Les zones de l'écran

ZoneDescription
Barre supérieureCPU (par cœur), RAM, Swap, nombre de tâches, charge système, uptime
Zone centraleListe des processus triés (par défaut par CPU)
Barre des minimiseursRaccourcis clavier disponibles
Barre inférieureCommandes principales (F1-F10)

La barre supérieure

De gauche à droite, la barre affiche :

  • CPU : utilisation par cœur (barres colorées)
  • MEM : mémoire vive utilisée / totale
  • SZW : swap utilisé / total
  • Tasks : nombre total de processus
  • Load average : charge système (1, 5, 15 min)
  • Uptime : temps depuis le dernier démarrage

Navigation et interaction

Raccourcis clavier essentiels

ToucheAction

Tri et affichage

Changer le tri

Appuyez sur >< (touches Shift + point-virgule) ou utilisez M, N, P :

ToucheTri par
MMémoire (Memory)
PProcesseur (CPU)
TTemps (Time)
NPID (numéro de processus)

Vue en arbre

La vue en arbre montre les relations parent-enfant entre processus :

# Dans htop, appuyez sur 't' pour basculer en mode arbre

Exemple de sortie en arbre :

systemd─┬─sshd───sshd───bash ├─nginx───nginx───php-fpm └─dockerd───containerd───sh

Recherche et filtrage

Rechercher un processus

Appuyez sur / et tapez le nom du processus :

# Appuyez sur /, puis tapez 'nginx' # htop surligne tous les processus contenant 'nginx'

Filtrer par nom

Appuyez sur Ctrl+f pour filtrer :

# Affiche uniquement les processus contenant 'firefox' # (après avoir appuyé sur Ctrl+f et tapé 'firefox')

Filtrer par utilisateur

Appuyez sur u et choisissez un utilisateur :

# Affiche uniquement les processus de l'utilisateur 'www-data' # Utile pour isoler les processus d'un service web

Signaux et actions

Envoyer un signal à un processus

Sélectionnez un processus et appuyez sur k :

SignalNuméroEffet
SIGTERM15Demande d'arrêt élégant (par défaut)
SIGKILL9Arrêt forcé immédiat
SIGSTOP19Suspendre le processus
SIGCONT18Reprendre un processus suspendu

Exemple concret

# 1. Lancez un processus en arrière-plan sleep 300 & # 2. Ouvrez htop htop # 3. Trouvez le processus 'sleep' # 4. Appuyez sur 'k' # 5. Choisissez SIGTERM (15) pour arrêter proprement # 6. Ou SIGKILL (9) pour forcer l'arrêt

Personnalisation

Configurer htop

Appuyez sur F2 (Setup) pour accéder aux options :

  • Display options : afficher/masquer les colonnes, les couleurs
  • Columns : ajouter ou retirer des colonnes (PID, USER, PRI, NI, etc.)
  • Meters : configurer la barre supérieure (CPU, RAM, Swap, etc.)
  • Colors : choisir un thème de couleurs

Colonnes utiles à ajouter

Dans Setup → Columns, ajoutez :

ColonneDescription
PIDNuméro unique du processus
PPIDPID du processus parent
USERPropriétaire du processus
PRIPriorité réelle
NIValeur nice
CMDCommande complète
CWDRépertoire de travail

Fichier de configuration

La configuration est sauvegardée dans ~/.config/htop/htoprc :

# Exemple de configuration minimale [settings] delay=15 sort_key=PERCENT_CPU sort_direction=1 [colors] scheme=0 [meters] CPU=1,1,1 Memory=1,1,1 Swap=1,1,1 Tasks=1,1,1 Uptime=1,1,1

htop en ligne de commande

Options non-interactives

# Afficher les processus d'un utilisateur htop -u www-data # Démarrer avec un tri par mémoire htop -s PERCENT_MEM # Rafraîchir toutes les secondes (par défaut : 10) htop -d 1 # Mode compact (moins de détails) htop -C # Afficher uniquement les processus actifs htop --user=root --no-unicode

Combiner avec d'autres outils

# Capturer la sortie de htop dans un fichier (non interactif) htop -b -n 1 > etat_systeme.txt # Explication : # -b : mode batch (non interactif) # -n 1 : une seule itération # Redirection vers un fichier pour l'archiver

Exemples pratiques

Surveiller un service spécifique

# Lancer htop filtré sur nginx htop -u www-data # Dans htop : # 1. Appuyez sur / et tapez 'nginx' # 2. Observez la charge CPU et mémoire de chaque worker

Identifier un processus qui mange la RAM

# Lancer htop trié par mémoire htop -s PERCENT_MEM # Les processus les plus gourmands apparaissent en haut # Cliquez sur M pour forcer le tri par mémoire

Diagnostiquer une charge élevée

# 1. Lancez htop htop # 2. Observez la barre CPU - si tous les cœurs sont à 100% : # 3. Triez par CPU (P ou M) # 4. Identifiez le processus responsable # 5. Cliquez sur le processus # 6. Appuyez sur 's' pour voir les fichiers ouverts (strace léger)

Arrêter proprement plusieurs processus

# 1. Lancez htop htop # 2. Appuyez sur 't' pour la vue en arbre # 3. Trouvez le processus parent (ex: un script Python) # 4. Sélectionnez-le et appuyez sur 'k' # 5. Envoyez SIGTERM (15) - tue aussi les processus enfants

Surveiller les threads d'un processus

# 1. Lancez un processus multi-threadé (ex: Firefox) firefox & # 2. Lancez htop htop # 3. Appuyez sur 'H' pour afficher les threads # 4. Chaque thread apparaît comme une ligne séparée # 5. Identifiez les threads qui consomment le plus

Bonnes pratiques

  • Utilisez htop au quotidien plutôt que top — plus ergonomique
  • Familiarisez-vous avec les raccourcis clavier (M, P, t, u)
  • Surveillez régulièrement la RAM avec M pour détecter les fuites mémoire
  • Combinez avec htop -b -n 1 pour capturer l'état dans un script
  • Personnalisez vos colonnes pour votre usage (dev, sysadmin, etc.)
  • Installez btop pour une expérience encore plus moderne

htop est l'outil de surveillance de processus le plus complet et agréable à utiliser. Que ce soit pour diagnostiquer un serveur lent, identifier un processus gourmand, ou simplement explorer ce qui tourne sur votre machine, htop rend la tâche intuitive et efficace.
