Leçon 89 : comm — Comparer deux fichiers ligne par ligne

Introduction

La commande comm permet de comparer deux fichiers texte ligne par ligne et d'afficher les différences de manière structurée. Contrairement à diff qui montre les modifications, comm sépare clairement les lignes uniques à chaque fichier et celles communes aux deux.

Syntaxe de base

comm [OPTIONS] FICHIER1 FICHIER2

Sortie en trois colonnes

Par défaut, comm affiche trois colonnes :

  • Colonne 1 : Lignes présentes uniquement dans le premier fichier
  • Colonne 2 : Lignes présentes uniquement dans le second fichier
  • Colonne 3 : Lignes communes aux deux fichiers

Exemple simple

Créons deux fichiers pour tester :

# Fichier A
echo -e "pomme\nbanane\ncerise\ndatte" > fichier_a.txt
# Fichier B
echo -e "banane\ncerise\nfigue\nraisin" > fichier_b.txt

Comparons les deux fichiers :

comm fichier_a.txt fichier_b.txt

Résultat :

pomme          ← colonne 1 : seulement dans A
        figue  ← colonne 2 : seulement dans B
        raisin ← colonne 2 : seulement dans B
banane         ← colonne 3 : dans les deux
cerise         ← colonne 3 : dans les deux
datte          ← colonne 1 : seulement dans A

Options principales

-1 : Supprimer la colonne 1

comm -1 fichier_a.txt fichier_b.txt

Affiche uniquement les colonnes 2 et 3 (lignes uniques à B + lignes communes).

-2 : Supprimer la colonne 2

comm -2 fichier_a.txt fichier_b.txt

Affiche uniquement les colonnes 1 et 3 (lignes uniques à A + lignes communes).

-3 : Supprimer la colonne 3

comm -3 fichier_a.txt fichier_b.txt

Affiche uniquement les colonnes 1 et 2 (lignes uniques à A ou B, sans les communes).

-12 : Afficher seulement les lignes uniques

comm -12 fichier_a.txt fichier_b.txt

N'affiche que les lignes qui n'existent que dans un seul des deux fichiers (sans les communes).

Comparaison avec fichiers triés

comm exige que les fichiers soient triés pour fonctionner correctement. Si vos fichiers ne sont pas triés, vous devez les trier d'abord :

comm <(sort fichier_a.txt) <(sort fichier_b.txt)

Exemples pratiques

Trouver les différences entre deux configurations

# Comparer deux fichiers de config
comm -3 <(sort /etc/passwd.old) <(sort /etc/passwd.new)

Voir uniquement ce qui a été ajouté

# Ajouter -2 pour voir seulement ce qui est nouveau dans le second fichier
comm -12 <(sort ancien.txt) <(sort nouveau.txt)

Identifier les lignes supprimées

# Lignes uniquement dans le premier fichier
comm -23 <(sort fichier1.txt) <(sort fichier2.txt)

Tableau récapitulatif des options

OptionDescription
-1Supprimer la colonne 1 (lignes uniques au fichier 1)
-2Supprimer la colonne 2 (lignes uniques au fichier 2)
-3Supprimer la colonne 3 (lignes communes)
--check-orderVérifier que le fichier est correctement trié
--nocheck-orderNe pas vérifier l'ordre de tri
--output-delimiter=XUtiliser X comme séparateur de colonnes

Combinaison avec d'autres commandes

Compter les différences

# Compter les lignes uniques à chaque fichier
comm -12 <(sort a.txt) <(sort b.txt) | wc -l

Fusionner avec extraction

# Obtenir uniquement les lignes communes triées
comm -12 <(sort liste1.txt) <(sort liste2.txt) | sort

Conclusion

comm est un outil puissant pour comparer des fichiers texte triés. Sa sortie en trois colonnes permet de visualiser clairement les différences et les similitudes entre deux fichiers. Combiné avec le tri et d'autres commandes Unix, il devient un outil indispensable pour la gestion et la comparaison de données.
