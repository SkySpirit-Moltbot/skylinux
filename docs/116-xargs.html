Leçon 116 : xargs — Construire des commandes à partir de résultats

xargs est un outil qui lit des données (depuis l'entrée standard ou un fichier) et les transforme en arguments pour une autre commande. C'est le pont idéal entre les commandes qui produisent du texte et celles qui attendent des arguments. Sans xargs, beaucoup de chaînes de commandes puissantes seraient impossibles.

Le problème que xargs résout

Imaginons que vous vouliez supprimer tous les fichiers .tmp trouvés par find. Vous pourriez croire que ceci fonctionne :

find /tmp -name "*.tmp" | rm

Mais rm ne lit pas l'entrée standard. Elle attend des arguments explicites. C'est là qu'intervient xargs :

find /tmp -name "*.tmp" | xargs rm

xargs reçoit les lignes de find et les passe comme arguments à rm.

Syntaxe de base

commande_source | xargs commande_cible

Chaque ligne résultat de commande_source devient un argument de commande_cible.

Exemples concrets

Supprimer des fichiers par leur contenu

# Trouver les fichiers contenant "error" et les supprimer
grep -rl "error" /var/log/ | xargs rm

Créer des archives à partir d'une liste de fichiers

# Archiver tous les fichiers .txt du répertoire courant
ls *.txt | xargs tar -czf archive.tar.gz

Compter les lignes de plusieurs fichiers

find /home -name "*.log" | xargs wc -l

Équivalent à : wc -l fichier1.log fichier2.log fichier3.log ...

Créer des répertoires à partir d'une liste

# Lire les noms de la liste.txt et créer chaque répertoire
cat liste.txt | xargs mkdir

La commande -I : remplacement de placeholder

Par défaut, xargs place les arguments en fin de commande. Parfois, vous voulez les insérer au milieu ou utiliser plusieurs fois le même argument. L'option -I définit un placeholder.

find . -name "*.txt" | xargs -I {} mv {} /home/user/docs/

{} est remplacé par chaque chemin de fichier. La commande mv est exécutée séparément pour chaque fichier (par défaut).

Autre exemple avec -I

# Copier chaque image en备份
ls *.jpg | xargs -I {} cp {} {}.bak

Utiliser un autre placeholder

# Créer un fichier .md et un .txt pour chaque nom
cat noms.txt | xargs -I @ sh -c 'touch @.md && touch @.txt'

Exécution parallèle avec -P

Par défaut, xargs exécute les commandes séquentiellement. L'option -P permet de paralléliser.

# Compresser 4 fichiers simultanément
ls *.log | xargs -P 4 gzip

Cela compressera jusqu'à 4 fichiers en même temps, ce qui accélère considérablement le traitement sur les machines multi-cœurs.

Combiner -I et -P

find . -name "*.png" | xargs -I {} -P 4 convert {} -resize 800x600 {}

Limiter le nombre d'arguments par commande : -n

-n 1 force xargs à exécuter la commande cible avec un seul argument à la fois. C'est utile quand la commande cible ne supporte pas plusieurs arguments.

# Exporter chaque variable individuellement
cat variables.env | xargs -n 1 export
# Importer chaque clé SSH séparément
ssh-add -l | grep " RSA" | xargs -n 1 ssh-add -d

Combiner -n et -P pour un contrôle fin

# 2 arguments par commande, jusqu'à 3 processus parallèles
cat fichiers.txt | xargs -n 2 -P 3 commande

Interaction avec find

find et xargs fonctionnent très bien ensemble. Par défaut, find utilise des sauts de ligne, ce qui pose problème si les noms contiennent des espaces. two solutions :

Solution 1 : find -print0 et xargs -0

find /home -name "*.txt" -print0 | xargs -0 rm

-print0 sépare les résultats par un caractère nul (\0) au lieu d'un retour à la ligne. xargs -0 lit ces séparateurs nuls. Gère les noms avec espaces ou caractères spéciaux.

Solution 2 : find -exec avec ;

find /home -name "*.txt" -exec rm {} \;

Cette approche exécute rm pour chaque fichier individuellement. xargs est généralement plus rapide car il группирует les arguments.

Afficher la commande avant de l'exécuter : --verbose / -t

# Voir exactement quelles commandes seront exécutées
echo "fichier1.txt fichier2.txt" | xargs -t rm
rm fichier1.txt fichier2.txt

Très utile pour vérifier avant de lancer, surtout avec des commandes destructives.

Ne rien exécuter : --empty-verbose / --dry-run

Pas de flag dry-run natif, mais combinez -t avec une cible inoffensive :

find . -name "*.tmp" | xargs -t echo "Suppression:"

Combiner avec des compteurs

# Numéroter chaque fichier pour le traitement
ls *.mp3 | nl | xargs -I {} sh -c 'echo "Piste {}"'

Protéger contre l'injection

Si les noms de fichiers peuvent contenir des caractères dangereux, combinez toujours find -print0 et xargs -0.

find /uploads -type f -print0 | xargs -0 -I {} chmod 644 {}

Tableau récapitulatif des options principales

OptionDescription
-0Séparateur nul (pour utiliser avec find -print0)
-I {}Placeholder remplacé par chaque argument
-n NMaximum N arguments par commande
-P NExécuter jusqu'à N processus en parallèle
-tAfficher la commande avant de l'exécuter
-pDemander confirmation avant chaque exécution
-rNe rien faire si l'entrée est vide

Exemple avancé : pipeline complet

# 1. Trouver les fichiers.log de plus de 7 jours
# 2. Les compresser en parallèle (max 4)
# 3. Compter les lignes de chaque archive
find /var/log -name "*.log" -mtime +7 -print0 | \
xargs -0 -P 4 gzip && \
find /var/log -name "*.log.gz" | xargs -P 4 zcat | wc -l

Résumé

  • xargs transforme l'entrée standard en arguments pour une autre commande.
  • -I {} insère les arguments à un endroit précis de la commande.
  • -n 1 passe un seul argument par exécution.
  • -P N parallélise jusqu'à N processus.
  • -0 avec find -print0 gère les noms avec espaces.
  • -t affiche les commandes avant exécution (debug).
