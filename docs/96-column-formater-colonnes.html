column — Formater du texte en colonnes

Introduction

La commande column est un outil puissant pour formater du texte en colonnes nettes et lisibles. Elle prend en entrée un texte tabulé ou délimité et le réorganise en colonnes bien alignées, comme un tableau.

C'est particulièrement utile pour afficher des sorties de commandes comme ls, des fichiers CSV simples, ou toute donnée texte structurée.

Syntaxe de base

column [OPTIONS] [FICHIER]

Exemples fondamentaux

1. Formater la sortie de ls

Quand vous listez des fichiers, la sortie peut être désordonnée. column l'organise :

ls -l /etc | tail -n +2 | awk '{print $9, $5}' | column -t

Explication :

  • ls -l liste les fichiers avec détails
  • awk '{print $9, $5}' extrait le nom (colonne 9) et la taille (colonne 5)
  • column -t formate en colonnes alignées

2. Formater un fichier délimité par des tabs

cat fichier.txt | column -t

3. Spécifier le séparateur

Par défaut, column utilise les tabs comme séparateurs. Pour un CSV (virgule) :

column -t -s ',' fichier.csv

Le flag -s définit le séparateur de champs.

4. Spécifier les colonnes

Laisser column calculer automatiquement le nombre de colonnes :

column -t -c 80 mon_fichier.txt

Le flag -c définit la largeur totale en caractères.

Options principales

OptionDescription
-tCrée une table : détermine automatiquement le nombre de colonnes
-s SEPSpécifie le séparateur de colonnes (défaut : tab)
-c NLimite la sortie à N caractères de large
-o SEPSpécifie le séparateur de sortie entre colonnes
-xRemplit les colonnes horizontalement avant verticalement

Exemples pratiques détaillés

Formater /etc/passwd

cat /etc/passwd | column -t -s ':'

Ceci affiche le fichier /etc/passwd avec les champs alignés par colonnes, en utilisant les deux-points comme séparateur.

Créer un tableau lisible depuis une sortie arbitraire

echo -e "Nom\tAge\tVille\nAlice\t30\tGenève\nBob\t25\tZurich" | column -t

Résultat :

Nom    Age  Ville
Alice  30   Genève
Bob    25   Zurich

Remplissage horizontal avec -x

seq 12 | column -x -t

Avec -x, les nombres sont d'abord remplis horizontalement (ligne par ligne), puis verticalement.

Utiliser un séparateur de sortie personnalisé

echo -e "a\tb\tc\n1\t2\t3" | column -t -o " | "

Les colonnes seront séparées par | au lieu d'espaces.

Combiner avec d'autres commandes

Avec grep pour filtrer et formater

ps aux | grep python | column -t

Avec find pour lister les fichiers

find . -type f -name "*.txt" -printf "%f\t%s\n" | column -t

Avec df pour un affichage propre

df -h | tail -n +2 | awk '{print $1, $2, $5}' | column -t

Formatage de fichiers CSV simples

Pour un fichier CSV avec des virgules comme séparateur :

column -t -s ',' fichier.csv

Note : pour des CSV complexes avec des virgules dans les champs, utilisez plutôt csvtool ou awk.

Limites de column

  • Ne gère pas les données avec des séparateurs dans les champs (guillemets imbriqués)
  • Le texte trop long est tronqué ou dépasse selon les cas
  • Moins puissant que awk pour la transformation de données complexes

Bonnes pratiques

  • Utilisez -t systématiquement pour obtenir un formatage en tableau
  • Combinez avec awk pour préparer les données avant le formatage
  • Pour des rapports plus complexes, pensez à column dans un script Bash avec redirection vers un fichier

Résumé

CommandeUsage
column -t fichierFormater en colonnes alignées
column -t -s ',' fichier.csvFormater un CSV avec virgule comme séparateur
cat fichier | column -tFormater depuis l'entrée standard
column -x -tRemplir horizontalement avant verticalement
column -c 80Limiter à 80 caractères de large

column est un outil simple mais efficace pour rendre n'importe quelle sortie texte lisible en quelques secondes. Ajoutez-le à votre boîte à outils pour formatter rapidement vos données !
