Leçon 87 : expr — Calcul et évaluation d'expressions

Introduction

expr est un outil polyvalent qui évalue des expressions en ligne de commande. Il peut effectuer des calculs arithmétiques sur des entiers, manipuler des chaînes de caractères, et tester des conditions. Bien que Bash dispose désormais de l'arithmétique intégrée ($(( ))), expr reste utile dans les scripts portables et pour la correspondance de motifs avec les expressions régulières.

Calculs arithmétiques

Les quatre opérations de base

expr 10 + 5
expr 10 - 5
expr 10 \* 5
expr 10 / 5

Attention : le signe * doit être échappé avec \ car il a une signification spéciale dans le shell.

Exemple concret

expr 25 + 10 # → 35
expr 100 - 37 # → 63
expr 7 \* 8 # → 56
expr 100 / 4 # → 25
expr 10 % 3 # → 1 (modulo : reste de la division)

Dans un script Bash

#!/bin/bash # Calcul du périmètre et de l'aire d'un rectangle largeur=8 hauteur=5 perimetre=$(expr $largeur + $largeur + $hauteur + $hauteur) aire=$(expr $largeur \* $hauteur) echo "Rectangle : $largeur x $hauteur" echo "Périmètre : $perimetre" echo "Aire : $aire"

Précautions avec les espaces

expr nécessite des espaces entre les opérandes et les opérateurs. Ces commandes échoueront :

expr 10+5 # ERREUR : 10+5 est interprété comme une chaîne
expr 10 +5 # ERREUR : espace manquant
expr 10 + 5 # OK : résultat = 15

Comparaisons et conditions

Opérateurs de comparaison

OpérateurSignificationRetourne
=Égal1 si vrai, 0 si faux
!=Différent1 si vrai, 0 si faux
>Supérieur1 si vrai, 0 si faux
>=Supérieur ou égal1 si vrai, 0 si faux
<Inférieur1 si vrai, 0 si faux
<=Inférieur ou égal1 si vrai, 0 si faux
expr 10 = 10 # → 1 (vrai)
expr 10 != 5 # → 1 (vrai)
expr 7 \> 3 # → 1 (vrai)
expr 7 \<= 3 # → 0 (faux)

Note : les signes > et < doivent être échappés dans le shell.

Exemple : tester une valeur

#!/bin/bash note=85 if [ $(expr $note \>= 60) -eq 1 ]; then echo "Réussite ! Note : $note/100" else echo "Échec. Note insuffisante : $note/100" fi

En combinant dans un test

Le résultat de expr peut servir dans un test :

test $(expr 10 > 5) -eq 1 && echo "Oui, 10 est plus grand que 5"
if expr "$nom_utilisateur" = "admin" \> /dev/null; then echo "Bienvenue, administrateur !" fi

Manipulation de chaînes

Longueur d'une chaîne

expr length "Bonjour" # → 7
expr length "Linux c'est bien" # → 16

Sous-chaîne (substr)

expr substr "Bonjour" 1 4 # → Bonj (depuis position 1, 4 caractères)
expr substr "Bonjour" 3 4 # → njou (depuis position 3, 4 caractères)
expr substr "Linux" 2 3 # → inu

La position commence à 1, pas à 0.

Index — Trouver un caractère

expr index "Linux" x # → 3 (x trouvé en position 3)
expr index "Bonjour" o # → 2 (premier 'o' en position 2)
expr index "Linux" z # → 0 (non trouvé)

Extrait — Prendre des caractères depuis le début

expr match "Ubuntu" 'U.*' # → 6 (toute la chaîne)
expr match "Ubuntu" 'U' # → 1 (le 'U' seul)
expr match "Ubuntu" '[A-Z].*' # → 6 (majuscule suivie de n'importe quoi)

Exemple : valider un nom d'utilisateur

#!/bin/bash nom="JeanDupont" # Vérifier que le nom contient uniquement des lettres if [ $(expr match "$nom" '^[A-Za-z]*$') -eq $(expr length "$nom") ]; then echo "Nom valide : $nom" else echo "Nom invalide : $nom (caractères non autorisés)" fi

Correspondance de motifs avec regex

L'opérateur match

expr "bonjour" : 'bon' # → 3 (longueur de la correspondance)
expr "bonjour" : 'xxx' # → 0 (pas de correspondance)
expr "fichier.txt" : '.*\.txt' # → 11 (correspondance de l'extension)

Capturer une partie du motif

Utilisez des parenthèses dans le motif pour capturer une partie :

expr "ubuntu-22.04" : '\(ubuntu\)' # → ubuntu (la partie entre parenthèses)
expr "fichier.zip" : '\(.*\)\.zip' # → fichier (tout avant .zip)
expr "192.168.1.1" : '\([0-9]*\)\.[0-9]*\.[0-9]*\.[0-9]*' # → 192 (le premier nombre avant le premier point)

Exemple : vérifier un numéro de téléphone

#!/bin/bash tel="079 123 45 67" # Format suisse : 079 XXX XX XX if expr "$tel" : '^[0-9][0-9][0-9] [0-9][0-9][0-9] [0-9][0-9] [0-9][0-9]$' \> /dev/null; then echo "Numéro valide : $tel" else echo "Format invalide" fi

Exemple : extraire l'extension d'un fichier

#!/bin/bash fichier="document.pdf" extension=$(expr "$fichier" : '.*\.\([a-zA-Z0-9]*\)') echo "Extension : $extension" # → pdf

Utilisation dans des scripts

Incrémenter une variable

#!/bin/bash compteur=0 # Incrémenter compteur=$(expr $compteur + 1) echo "Compteur : $compteur" # → 1 compteur=$(expr $compteur + 1) echo "Compteur : $compteur" # → 2 compteur=$(expr $compteur + 1) echo "Compteur : $compteur" # → 3

Calcul avec des variables

#!/bin/bash prix_unitaire=19.90 quantite=3 remise=10 # Prix avant remise sous_total=$(expr $prix_unitaire \* $quantite) # Montant de la remise (en pourcents) montant_remise=$(expr $sous_total \* $remise / 100) # Prix final prix_final=$(expr $sous_total - $montant_remise) echo "Sous-total : $sous_total" echo "Remise ($remise%) : -$montant_remise" echo "Prix final : $prix_final"

Vérifier si un nombre est pair ou impair

#!/bin/bash nombre=${1:-42} if [ $(expr $nombre % 2) -eq 0 ]; then echo "$nombre est pair" else echo "$nombre est impair" fi

Calculer une factorielle

#!/bin/bash # Factorielle de n n=${1:-5} resultat=1 while [ $n -gt 1 ]; do resultat=$(expr $resultat \* $n) n=$(expr $n - 1) done echo "Factorielle : $resultat"

Boucle avec expr pour l'itération

#!/bin/bash # Afficher les 5 premières puissances de 2 i=0 while [ $i -le 10 ]; do puissance=$(expr 2 \*\* $i) echo "2^$i = $puissance" i=$(expr $i + 1) done

Recommandation

  • Utilisez $(( )) pour l'arithmétique simple dans les scripts Bash.
  • Utilisez expr pour les expressions régulières, la manipulation de chaînes, ou quand la portabilité POSIX est requise.

Exercice pratique

Créez un script qui :

  1. Demande à l'utilisateur de saisir son année de naissance
  2. Calcule son âge avec expr
  3. Vérifie si l'âge est majeur (18 ans ou plus) avec expr
  4. Affiche un message approprié

Correction

#!/bin/bash # Exercice : calcul de l'âge et vérification de majorité read -p "Votre année de naissance : " annee_naissance # Obtenir l'année courante annee_courante=$(date +%Y) # Calculer l'âge age=$(expr $annee_courante - $annee_naissance) # Vérifier la majorité (expr retourne 1 si la comparaison est vraie) est_majeur=$(expr $age \>= 18) echo "" echo "Année de naissance : $annee_naissance" echo "Âge actuel : $age ans" if [ $est_majeur -eq 1 ]; then echo "Vous êtes majeur." else echo "Vous êtes mineur." fi

Conclusion

expr est un outil classique du monde Unix, à la fois calculatrice, manipulateur de chaînes et moteur d'expressions régulières. Si Bash moderne a rendu certaines de ses fonctionnalités redondantes ($(( )) pour l'arithmétique, ${#var} pour la longueur), expr reste irremplaçable pour la correspondance de motifs POSIX et la manipulation de chaînes portable. Dans un script portable ou pour traiter des motifs complexes, expr reste un allié précieux.
