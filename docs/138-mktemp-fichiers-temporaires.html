mktemp — Fichiers et répertoires temporaires sécurisés

Quand un script a besoin de stocker des données intermédiaires, la pire approche est d'utiliser un nom fixe comme /tmp/mon_fichier.txt. Ce fichier peut déjà exister, appartenir à un autre processus, ou pire — créer une faille de sécurité. La commande mktemp génère des noms de fichiers et répertoires temporaires avec des noms aléatoires et uniques, impossibles à deviner. C'est l'outil de référence pour tout script qui manipule des données temporaires.

Le problème des fichiers temporaires

La méthode naïve (à éviter)

# NE PAS FAIRE — Problèmes de sécurité et de concurrence echo "donnees" > /tmp/temp.txt

Plusieurs processus lancés simultanément vont se marcher sur les pieds. Pire : un attaquant peut prédire le nom du fichier et y écrire des données malveillantes avant votre script.

La bonne approche

mktemp
# Résultat : /tmp/tmp.R7xNk2h3m # Le nom est aléatoire, imprévisible, et le fichier n'existe pas encore

Créer un fichier temporaire

Usage de base

mktemp

Par défaut, mktemp crée un fichier vide et affiche son chemin. Le nom contient tmp. suivi de 10 caractères aléatoires.

Utiliser le résultat directement

TMPFILE=$(mktemp) echo "Contenu temporaire" > "$TMPFILE" cat "$TMPFILE" rm -f "$TMPFILE"

La syntaxe $(mktemp) capture le chemin généré dans une variable pour l'utiliser ensuite.

Avec un suffixe personnalisé

Vous pouvez ajouter une extension pour identifier le type de fichier :

mktemp --suffix=.txt
# Résultat : /tmp/tmp.K8mNp2x4.txt

Avec un préfixe personnalisé

mktemp /tmp/monapp-XXXXXX
# Résultat : /tmp/monapp-aB3kLm7 # Les X sont remplacés par des caractères aléatoires

Le nombre de X détermine le niveau d'aléatoire : au moins 3 X sont requis. Plus il y en a, plus le nom est imprévisible.

Créer un répertoire temporaire

L'option -d

mktemp -d
# Résultat : /tmp/tmp.R9pLw3k1m

Avec -d, mktemp crée un répertoire au lieu d'un fichier. C'est idéal quand votre script a besoin de stocker plusieurs fichiers temporaires ensemble.

Exemple concret

TMPDIR=$(mktemp -d) echo "Fichier 1" > "$TMPDIR/fichier1.txt" echo "Fichier 2" > "$TMPDIR/fichier2.txt" ls -la "$TMPDIR" rm -rf "$TMPDIR"

rm -rf supprime le répertoire et tout son contenu en une seule commande.

Mode一点的 : suffixe de sécurité

Vérifier que le fichier n'existait pas avant

Par défaut, mktemp crée le fichier/répertoire et garantit qu'il n'existait pas avant. Si pour une raison obscure le nom généré existait déjà, mktemp échoue avec une erreur — il ne remplace jamais un fichier existant.

# Sans l'option -u, mktemp crée réellement le fichier TMPFILE=$(mktemp) ls -l "$TMPFILE" # -rw------- 1 user user 0 ... /tmp/tmp.Xy7k2m9p

Mode "dry-run" avec -u

L'option -u génère le nom sans créer le fichier. Utile pour tester ou quand vous voulez créer le fichier vous-même :

mktemp -u
# Résultat : /tmp/tmp.M3nR8pQ5k # Le fichier n'est PAS créé sur le disque

Template de nom personnalisé

Le dernier argument non-optionnel de mktemp est un template. Il doit contenir au moins 3 X qui seront remplacés par le générateur aléatoire.

Exemples de templates

TemplateExemple de résultat
tmp.XXXXXXtmp.aB3kL9
/tmp/monapp-XXXX/tmp/monapp-xK9m
donnees-XXXXXX.csvdonnees-7nLpQr.csv
XXXXXXXXXXXXR9mXk3pL7nQr

Gestion des erreurs

Vérifier le retour de mktemp

Si mktemp ne peut pas créer le fichier (permissions, disque plein), il renvoie un code d'erreur non nul. Toujours vérifier :

TMPFILE=$(mktemp) || { echo "Erreur: impossible de créer le fichier temporaire"; exit 1; } echo "OK, fichier créé : $TMPFILE"

Nettoyage automatique avec trap

Dans un script qui peut être interrompu (Ctrl+C), les fichiers temporaires doivent être supprimés même en cas d'erreur :

#!/bin/bash TMPFILE=$(mktemp) || exit 1 TMPDIR2=$(mktemp -d) || { rm -f "$TMPFILE"; exit 1; } # Supprimer automatiquement en cas d'interruption ou de sortie trap 'rm -f "$TMPFILE"; rm -rf "$TMPDIR2"' EXIT INT TERM # ... votre code ici ... exit 0 # Le trap s'exécute automatiquement à la sortie du script

trap garantit que les fichiers sont supprimés quel que soit le moyen de sortie du script — succès, erreur, ou interruption par l'utilisateur.

Cas d'utilisation courants

1. Télécharger et traiter des données

TMPFILE=$(mktemp --suffix=.csv) curl -s "https://api.exemple.com/export" -o "$TMPFILE" python3 traitement.py "$TMPFILE" rm -f "$TMPFILE"

2. Comparer deux fichiers avec un fichier intermédiaire

TMPDIFF=$(mktemp) diff fichier1.txt fichier2.txt > "$TMPDIFF" || true # || true car diff retourne 1 si des différences sont trouvées cat "$TMPDIFF" rm -f "$TMPDIFF"

3. Stocker des données de session

SESSION_DIR=$(mktemp -d) echo "Session de travail : $SESSION_DIR" # Stocker les fichiers de travail temporairement echo "donnees" > "$SESSION_DIR/etat.txt" # ... utiliser les fichiers ... rm -rf "$SESSION_DIR"

4. Stocker des logs temporaires pour un script

LOG=$(mktemp --suffix=.log) mon_script.sh 2>&1 | tee "$LOG" echo "=== Log sauvegardé dans $LOG ==="

TMPDIR et les variables d'environnement

Par défaut, mktemp utilise /tmp. Vous pouvez changer ce comportement avec la variable TMPDIR :

TMPDIR="$HOME/tmp" mktemp
# Résultat : /home/user/tmp/tmp.K9mNp3x

Dans un script, vous pouvez aussi créer ~/tmp au préalable :

mkdir -p "$HOME/tmp" TMPFILE=$(TMPDIR="$HOME/tmp" mktemp)

mktemp vs alternatives

MéthodeProblème
echo "x" > /tmp/tempNom prévisible, risque de collision
/tmp/temp.$Toujours prévisible
mktempNoms aléatoires, sécurisés, uniques
tempfileObsolète, moins sécurisé que mktemp

tempfile est une commande historique plus ancienne. mktemp est la solution moderne recommandée sur toutes les distributions Linux.

mktemp est une commande simple mais indispensable. Dès que votre script a besoin d'un espace temporaire, c'est toujours la solution à adopter. Elle élimine les risques de collision et de sécurité liés aux noms de fichiers temporaires fixes, et combinée avec trap, elle garantit un nettoyage parfait même en cas d'interruption.
