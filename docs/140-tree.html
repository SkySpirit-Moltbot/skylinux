tree — Afficher une arborescence de répertoires

Vous connaissez ls pour lister les fichiers, mais quand les répertoires deviennent profonds, il est difficile de s'y retrouver. tree affiche la structure complète d'un répertoire sous forme d'arborescence visuelle — bien plus lisible qu'une longue liste de ls -R.

Installation

tree n'est pas toujours installé par défaut. Sur Debian/Ubuntu :

sudo apt install tree

Sur Fedora/RHEL :

sudo dnf install tree

Sur Arch Linux :

sudo pacman -S tree

Syntaxe de base

tree [OPTIONS] [RÉPERTOIRE]

Sans argument, tree affiche l'arborescence du répertoire courant.

Exemples fondamentaux

Arborescence simple

$ tree
.
├── documents
│ ├── rapport.pdf
│ └── notes.txt
├── images
│ ├── photo1.jpg
│ └── photo2.png
└── projet
├── src
│ ├── main.c
│ └── utils.c
└── Makefile

Limiter la profondeur

L'option -L contrôle la profondeur de l'affichage :

# Afficher uniquement 1 niveau de profondeur
$ tree -L 1
.
├── documents
├── images
└── projet
# Afficher 2 niveaux maximum
$ tree -L 2
.
├── documents
│ ├── rapport.pdf
│ └── notes.txt
├── images
│ ├── photo1.jpg
│ └── photo2.png
└── projet
├── src
└── Makefile

Options utiles

Afficher les fichiers cachés

$ tree -a

Types de fichiers

-p affiche les permissions et -s affiche la taille des fichiers :

$ tree -p -s
.
[drwxr-xr-x] documents
├── [-rw-r--r--] 4096 rapport.pdf
└── [-rw-r--r--] 512 notes.txt

Filtrer par extension

-P filtre les fichiers par motif (pattern) :

# Afficher uniquement les fichiers .txt
$ tree -P "*.txt"
.
├── documents
│ └── notes.txt
└── projet
└── README.txt

-I exclut les fichiers correspondant au motif :

# Exclure node_modules et .git
$ tree -I "node_modules|.git"

Trier la sortie

# Trier par nom (défaut)
$ tree --sort=name
# Trier par taille (décroissant)
$ tree -sh --sort=size
.
├── [drwxr-xr-x 4.0K] projet
├── [drwxr-xr-x 2.0K] documents
└── [drwxr-xr-x 1.0K] images

Afficher le nombre de fichiers par répertoire

$ tree
$ tree

Sortie vers un fichier

Redirigez la sortie vers un fichier pour garder une trace de l'arborescence :

$ tree -o arborescence.txt
# Version ASCII (compatible partout)
$ tree -o arborescence.txt --charset=ascii

Utiliser avec d'autres commandes

Combiner avec find

# Afficher l'arborescence complète du système de fichiers
$ tree -L 3 /home/utilisateur

Combiner avec grep

# Trouver un fichier dans l'arborescence
$ tree | grep "config"
│ └── config.json

Exclure certains répertoires

# Exclure plusieurs patterns
$ tree -I "node_modules|.git|dist|build" -L 3

Options avancées

Afficher les liens symboliques

# Les liens symboliques sont affichés différemment
$ tree -L 2 -p -s
.
[drwxr-xr-x] 4096 .
├── [lrwxrwxrwx] 4096 lien -> cible

Couleur selon le type

# Activer les couleurs (par défaut si terminal le supporte)
$ tree -C
# Désactiver les couleurs
$ tree -n

Format JSON

# Sortie en JSON (avec jq pour parser)
$ tree -J /home/user | jq '.'

Exercices pratiques

Exercice 1 : Explorer son répertoire personnel

# Voir la structure de base sans les fichiers cachés
$ tree -L 2 $HOME

Exercice 2 : Trouver les gros fichiers

# Lister les fichiers triés par taille
$ tree -s -h --sort=size | head -20

Exercice 3 : Vérifier un projet

# Voir la structure d'un projet sans les dépendances
$ cd /home/user/projet
$ tree -I "node_modules|.git|vendor|__pycache__" -L 3

Conclusion

tree est l'outil idéal pour visualiser rapidement la structure d'un projet ou d'un répertoire. Que ce soit pour comprendre l'organisation d'un code source, retrouver un fichier perdu dans une arborescence profonde, ou simplement partager une vue d'ensemble de vos dossiers, tree rend tout cela simple et visuel. Combinez-le avec les options de filtrage pour ne voir que ce qui vous intéresse.
