factor — Décomposer les nombres en facteurs premiers

Sous Linux, même les mathématiques font partie du terminal. La commande factor permet de décomposer n'importe quel nombre entier en ses facteurs premiers. C'est un outil simple mais fascinant, utile pour la cryptographie, l'éducation, ou simplement pour satisfaire sa curiosité mathématique.

Syntaxe de base

La syntaxe de factor est des plus simples :

factor [NOMBRE...]

Si aucun nombre n'est fourni, factor attend une entrée depuis l'entrée standard (stdin).

Exemples fondamentaux

Décomposer un nombre

$ factor 12
12: 2 2 3

Le nombre 12 se décompose en 2 × 2 × 3.

Décomposer plusieurs nombres

$ factor 15 21 84
15: 3 5
21: 3 7
84: 2 2 3 7

Décomposition d'un nombre premier

$ factor 17
17: 17

Les nombres premiers n'ont qu'eux-mêmes comme facteur (sauf 1).

Utilisation avancée

Avec des boucles

# Décomposer les 10 premiers nombres
$ for i in {1..10}; do factor $i; done
1:
2: 2
3: 3
4: 2 2
5: 5
6: 2 3
7: 7
8: 2 2 2
9: 3 3
10: 2 5

Depuis un fichier

# Créer un fichier avec des nombres
$ echo -e "100\n256\n1024" > nombres.txt
$ factor $(cat nombres.txt)
100: 2 2 5 5
256: 2 2 2 2 2 2 2 2
1024: 2 2 2 2 2 2 2 2 2 2

Dans un script

#!/bin/bash
# Vérifier si un nombre est premier
is_prime() {
local n=$1
local factors=$(factor $n | awk '{print NF}')
# Un nombre premier n'a qu'un seul facteur (lui-même)
if [ $factors -eq 1 ]; then
return 0 # true
else
return 1 # false
fi
}
# Test
for num in 7 15 23 100; do
if is_prime $num; then
echo "$num est premier"
else
echo "$num n'est pas premier"
fi
done

Exercices pratiques

Exercice 1 : Trouver le PGCD

Le Plus Grand Commun Diviseur (PGCD) de deux nombres peut être trouvé en décomposant les deux et en multipliant les facteurs communs.

# 48 = 2⁴ × 3
# 18 = 2 × 3²
# PGCD = 2 × 3 = 6
$ factor 48
48: 2 2 2 2 3
$ factor 18
18: 2 3 3

Exercice 2 : Compter les facteurs

$ factor 360
360: 2 2 2 3 3 5
# 360 = 2³ × 3² × 5

Exercice 3 : Trouver le PPCM

Le Plus Petit Commun Multiple (PPCM) utilise les facteurs avec l'exposant maximal.

# 12 = 2² × 3
# 18 = 2 × 3²
# PPCM = 2² × 3² = 36

Limites de factor

factor a quelques limites à connaître :

  • Taille des nombres : sur les systèmes 64 bits, les nombres supérieurs à 2⁶³ peuvent ne pas être traités correctement.
  • Performance : la factorisation de très grands nombres (plus de 20 chiffres) peut être très lente.
  • Nombres négatifs : factor ne gère pas les nombres négatifs.
  • Nombres décimaux : seuls les entiers sont acceptés.

Combiner avec d'autres commandes

# Générer et factoriser une séquence de nombres
$ seq 1 20 | xargs factor
1:
2: 2
3: 3
...
20: 2 2 5
# Compter le nombre de facteurs
$ factor 1000 | awk '{print "Nombre de facteurs:", NF-1}'
Nombre de facteurs: 4
# Formater joliment la sortie
$ factor 1234567890
1234567890: 2 3 3 5 3607 3803

Conclusion

Bien que factor soit une commande simple, elle révèle la beauté des mathématiques derrière les nombres. Que ce soit pour vérifier qu'un nombre est premier, comprendre la structure d'un nombre, ou simplement s'amuser avec les mathématiques, factor est un outil étonnamment utile à avoir dans sa boîte à outils Linux.
