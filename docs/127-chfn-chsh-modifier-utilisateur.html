Leçon 127 : chfn et chsh — Modifier les informations utilisateur

Introduction

Sous Linux, chaque compte utilisateur dispose d'informations complémentaires au simple nom de login : le nom complet, le bureau, le téléphone, etc. Les commandes chfn (change finger) et chsh (change shell) permettent de modifier ces informations directement depuis le terminal.

Ces commandes agissent sur le fichier /etc/passwd et sont particulièrement utiles sur les systèmes multi-utilisateurs ou les serveurs où vous souhaitez maintenir un annuaire précis des utilisateurs.

La commande chfn

chfn modifie les champs d'information personnelle d'un utilisateur dans /etc/passwd. Ces informations sont parfois affichées par la commande finger (d'où le nom).

Syntaxe de base

chfn [options] [utilisateur]

Modifier les informations de l'utilisateur courant

chfn

Sans argument, chfn demande交互式 les nouvelles valeurs pour chaque champ :

Nom complet []: Jean Dupont Bureau []: Atelier B Téléphone professionnel []: 021 123 45 67 Téléphone personnel []: 079 123 45 67

Modifier un champ précis

# Modifier le nom complet chfn -f "Marie Martin" utilisateur # Modifier le bureau chfn -o "Bureau 204" utilisateur # Modifier le téléphone professionnel chfn -p "021 987 65 43" utilisateur # Modifier le téléphone personnel chfn -h "079 555 33 22" utilisateur

Options principales de chfn

OptionDescription
-f, --full-nameDéfinir le nom complet
-o, --officeDéfinir le bureau ou le service
-p, --office-phoneDéfinir le téléphone professionnel
-h, --home-phoneDéfinir le téléphone personnel
-u, --helpAfficher l'aide
-v, --versionAfficher la version

La commande chsh

chsh modifie le shell de connexion d'un utilisateur. C'est le programme qui s'exécute automatiquement lors de l'ouverture d'une session terminal.

Syntaxe de base

chsh [options] [utilisateur]

Voir le shell actuel

# Pour l'utilisateur courant chsh -l

Cette commande liste les shells disponibles dans /etc/shells.

Modifier son propre shell

# Passer à zsh chsh -s /bin/zsh # Passer à fish chsh -s /usr/bin/fish # Passer à bash (chemin complet) chsh -s /bin/bash

Modifier le shell d'un autre utilisateur

Il faut être root :

sudo chsh -s /bin/zsh utilisateur

Options principales de chsh

OptionDescription
-s, --shellDéfinir le nouveau shell
-l, --list-shellsLister les shells disponibles
-u, --helpAfficher l'aide
-v, --versionAfficher la version

Vérifier les modifications

Après modification, vous pouvez vérifier les changements de plusieurs manières :

Avec id

id utilisateur

Avec getent

getent passwd utilisateur

Avec finger (si installé)

finger utilisateur

La commande finger affiche les informations définies par chfn.

Shells disponibles

Le fichier /etc/shells liste les shells autorisés sur le système :

cat /etc/shells

Exemple de sortie :

/bin/sh /bin/bash /bin/rbash /bin/zsh /usr/bin/zsh /usr/bin/fish /bin/dash

Cas pratiques

Créer un compte avec un shell spécifique

# Créer l'utilisateur avec zsh comme shell par défaut sudo useradd -m -s /bin/zsh nouvelutilisateur # Ou modifier après création sudo chsh -s /bin/zsh nouvelutilisateur

Configurer les informations complètes d'un nouvel employé

# Définir toutes les informations en une seule commande sudo chfn -f "Sophie Müller" -o "Développement" -p "021 111 22 33" -h "079 444 55 66" sophie

Restreindre un utilisateur à un shell limité

Pour un utilisateur qui ne doit exécuter qu'un programme spécifique (compte de service) :

# Donner un shell restreint comme /usr/sbin/nologin sudo chsh -s /usr/sbin/nologin compte-service

Les shells comme /usr/sbin/nologin ou /bin/false empêchent la connexion interactive.

Difference entre /etc/passwd et /etc/shadow

Il est important de comprendre où sont stockées ces informations :

FichierContenuAccessible en lecture
/etc/passwdNom, UID, GID, shell, infos chfnTous les utilisateurs
/etc/shadowMot de passe chiffréRoot uniquement

Bonnes pratiques

  • Utilisez sudo pour modifier les comptes d'autres utilisateurs.
  • Vérifiez toujours que le shell choisi existe dans /etc/shells avant d'appliquer chsh.
  • Un shell erroné peut bloquer la connexion d'un utilisateur. En cas de problème, utilisez le mode single-user pour corriger.
  • Documentez le shell attribué à chaque utilisateur dans un registre pour faciliter l'administration.
  • Pour les comptes de service, privilégiez /usr/sbin/nologin plutôt qu'un shell interactif.

Résumé

CommandeUsageExemple
chfnModifier les informations personnelleschfn -f "Nouveau Nom" user
chshModifier le shell de connexionchsh -s /bin/zsh

Ces deux commandes font partie des outils essentiels pour l'administration des comptes utilisateurs sous Linux. Elles permettent de maintenir un annuaire précis et d'adapter l'environnement de chaque utilisateur selon ses besoins.
