Leçon 71 : useradd, usermod et groupadd — Créer et gérer les comptes

1. Introduction

Sous Linux, la gestion des utilisateurs et des groupes se fait principalement avec quelques commandes dédiées. useradd crée un compte utilisateur, usermod le modifie, et groupadd crée des groupes. Ces commandes sont les outils de base de tout administrateur système.

Ces commandes nécessitent les droits root (ou sudo). Une mauvaise manipulation peut verrouiller l'accès au système — teste toujours sur un compte secondaire avant de modifier root.

2. Créer un utilisateur avec useradd

Syntaxe de base

sudo useradd [options] nom_utilisateur

Exemple simple

sudo useradd -m alice

L'option -m (ou --create-home) crée automatiquement le répertoire personnel /home/alice.

Options courantes

OptionDescription
-mCrée le répertoire personnel
-d /cheminSpécifie un répertoire personnel personnalisé
-s /bin/bashDéfinit le shell par défaut
-c "Nom Complet"Ajoute un commentaire (nom complet)
-G groupesListe de groupes secondaires (séparés par des virgules)
-e YYYY-MM-DDDate d'expiration du compte
-u UIDForce un UID spécifique
-p motdepasseDéfinit un mot de passe (déconseillé — utilise plutôt passwd)

Exemple complet

sudo useradd -m -s /bin/bash -c "Alice Dupont" -G sudo,www-data alice

Cet exemple crée l'utilisateur alice avec son home, bash, le commentaire "Alice Dupont", et les groupes secondaires sudo et www-data.

3. Définir ou changer le mot de passe

Après création, il faut assigner un mot de passe :

sudo passwd alice

Le système demandera d'entrer et de confirmer le nouveau mot de passe.

4. Modifier un utilisateur avec usermod

Syntaxe de base

sudo usermod [options] nom_utilisateur

Ajouter un utilisateur à un groupe

sudo usermod -aG groupe nom_utilisateur

L'option -aG (append + Group) ajoute l'utilisateur à un groupe sans le retirer des groupes auxquels il appartient déjà. Sans -a, l'utilisateur perdrait tous ses autres groupes.

Autres options courantes

OptionDescription
-l nouveau_nomRenomme le compte utilisateur
-d /nouveau/homeChange le répertoire personnel
-mDéplace le contenu de l'ancien home vers le nouveau (avec -d)
-s /bin/nouveau_shellChange le shell par défaut
-LVerrouille le compte (ajoute ! devant le mot de passe)
-UDéverrouille le compte
-e YYYY-MM-DDModifie la date d'expiration
-u UIDChange l'UID de l'utilisateur

Exemples pratiques

# Renommer un compte sudo usermod -l nouveau_nom ancien_nom # Changer le shell sudo usermod -s /bin/zsh alice # Ajouter un groupe (sans perdre les autres) sudo usermod -aG docker alice # Verrouiller un compte sudo usermod -L alice # Déverrouiller un compte sudo usermod -U alice

5. Créer et gérer des groupes avec groupadd

Créer un groupe

sudo groupadd nom_groupe

Options utiles

OptionDescription
-g GIDForce un GID spécifique
-rCréer un groupe système (GID < 1000)

Ajouter ou retirer des membres d'un groupe

# Ajouter un utilisateur à un groupe sudo gpasswd -a alice developpeurs # Retirer un utilisateur d'un groupe sudo gpasswd -d alice developpeurs # Définir l'administrateur d'un groupe sudo gpasswd -A alice developpeurs

6. Supprimer un utilisateur ou un groupe

# Supprimer un utilisateur (sans supprimer son home) sudo userdel alice # Supprimer un utilisateur ET son répertoire personnel sudo userdel -r alice # Supprimer un groupe sudo groupdel nom_groupe

Avant de supprimer un utilisateur, pense à vérifier quels fichiers lui appartiennent et à les transférer ou les archiver. Utilise find / -uid UID -ls pour les retrouver.

7. Vérifier et lister

# Lister tous les utilisateurs getent passwd # Lister tous les groupes getent group # Voir les groupes d'un utilisateur groups alice # Voir l'UID et les groupes d'un utilisateur id alice

Sortie de id alice

uid=1001(alice) gid=1001(alice) groupes=1001(alice),27(sudo),33(www-data)
  • uid : l'identifiant utilisateur
  • gid : le groupe primaire
  • groupes : le groupe primaire + les groupes secondaires

8. Fichiers de référence

Chaque commande modifie des fichiers système clés :

FichierRôle
/etc/passwdInformations sur les comptes (login, UID, GID, home, shell)
/etc/shadowMots de passe chiffrés (accessible uniquement par root)
/etc/groupListe des groupes et de leurs membres
/etc/gshadowMots de passe de groupes (rarement utilisé)

9. Script d'exemple : créer un compte utilisateur complet

#!/bin/bash # Créer un compte utilisateur avec Everything configuré NOM=$1 if [ -z "$NOM" ]; then echo "Usage: $0 nom_utilisateur [groupes,separés,par,virgules]" exit 1 fi GROUPES=${2:-""} echo "Création de l'utilisateur : $NOM" sudo useradd -m -s /bin/bash -c "$NOM" $NOM if [ -n "$GROUPES" ]; then echo "Ajout aux groupes : $GROUPES" sudo usermod -aG $GROUPES $NOM fi echo "Définition du mot de passe..." sudo passwd $NOM echo "Compte $NOM créé avec succès." echo " UID : $(id -u $NOM)" echo " Groupes : $(groups $NOM)"

10. Exercices pratiques

1. **Créer un utilisateur** — Crée un utilisateur testuser avec -m -s /bin/bash, puis définis-lui un mot de passe.

2. **Groupes** — Crée un groupe developpeurs et ajoute testuser à ce groupe avec -aG.

3. **Vérifier** — Utilise id testuser et groups testuser pour vérifier les groupes.

4. **Modifier** — Change le shell de testuser en /bin/zsh avec usermod.

5. **Nettoyer** — Supprime testuser et le groupe developpeurs que tu as créés.
