curl et wget — Télécharger depuis le terminal

Les commandes curl et wget sont deux outils essentiels pour télécharger des fichiers et interroger des API depuis le terminal. wget brille par sa simplicité pour les téléchargements récursifs, tandis que curl excelle dans l'interaction avec les API et le transfert de données arbitraires.

wget — Téléchargement simple et récursif

Téléchargement basique

# Télécharger un fichier unique
wget https://example.com/fichier.zip
# Télécharger avec un nom personnalisé
wget -O mon_fichier.zip https://example.com/fichier.zip

Options courantes de wget

OptionDescription
-O nomDéfinir le nom du fichier de sortie
-cReprendre un téléchargement interrompu (continue)
-qMode silencieux (pas de sortie)
-vMode verbeux
-bPasser en arrière-plan après le démarrage
--limit-rate=500kLimiter la vitesse de téléchargement (500 Ko/s)
-rTéléchargement récursif
-npNe pas remonter dans les répertoires parents
-l 5Profondeur de récursion (5 niveaux)

Reprendre un téléchargement interrompu

# Télécharger avec reprise automatique
wget -c https://example.com/gros_fichier.tar.gz

Téléchargement récursif d'un site

# Télécharger un site web entier (à utiliser responsibly)
wget -r -l 2 -np https://example.com/docs/
# Limiter la profondeur et le taux de téléchargement
wget -r -l 3 --limit-rate=200k https://example.com/site/

Télécharger plusieurs fichiers avec une liste

# Créer un fichier avec les URLs
echo -e "https://example.com/fichier1.zip\nhttps://example.com/fichier2.zip" > urls.txt
# Télécharger tous les fichiers de la liste
wget -i urls.txt

curl — Transfert de données多功能

Téléchargement basique

# Télécharger et afficher la sortie dans le terminal
curl https://example.com/fichier.zip
# Télécharger et sauvegarder dans un fichier
curl -o mon_fichier.zip https://example.com/fichier.zip
# Télécharger en utilisant le nom original du fichier
curl -O https://example.com/fichier.zip

Options courantes de curl

OptionDescription
-o fichierSauvegarder la sortie dans un fichier nommé
-OUtiliser le nom de fichier original du serveur
-LSuivre les redirections HTTP
-IAfficher uniquement les en-têtes HTTP
-sMode silencieux (sans barre de progression ni erreurs)
-SAfficher les erreurs même en mode silencieux
-vMode verbeux (afficher les en-têtes)
-X méthodeDéfinir la méthode HTTP (GET, POST, PUT, DELETE...)
-d donnéesEnvoyer des données (pour POST)
-H "En-tête: valeur"Ajouter un en-tête HTTP personnalisé
-u utilisateur:mdpAuthentification basique
-kIgnorer les erreurs de certificat SSL
--limit-rate 500kLimiter la vitesse de transfert

Interagir avec les API REST

Requêtes GET simples

# Obtenir une réponse JSON d'une API
curl https://api.exemple.com/utilisateurs
# Suivre les redirections et mode silencieux
curl -Ls https://api.exemple.com/donnees

Envoyer des données avec POST

# Envoyer un JSON POST
curl -X POST https://api.exemple.com/utilisateurs \
-H "Content-Type: application/json" \
-d '{"nom": "Alice", "email": "alice@example.com"}'
# Envoyer des données de formulaire
curl -X POST https://form.exemple.com/submit \
-d "nom=Alice" -d "message=Bonjour"

Utiliser des en-têtes personnalisés

# Ajouter des en-têtes personnalisés
curl -H "Authorization: Bearer TOKEN_SECRET" \
-H "Accept: application/json" \
https://api.exemple.com/profil

Authentification

# Authentification basique HTTP
curl -u admin:password https://api.exemple.com/admin
# Token Bearer (JWT)
curl -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
https://api.exemple.com/secure

Télécharger avec reprise et limitation

# wget : reprendre un téléchargement interrompu
wget -c https://example.com/gros_fichier.tar.gz
# curl : télécharge et affiche la progression
curl -L -C - -o sortie.tar.gz https://example.com/gros_fichier.tar.gz
# Limiter le débit à 500 Ko/s
wget --limit-rate=500k https://example.com/fichier.zip
curl --limit-rate 500k -O https://example.com/fichier.zip

Inspecter les en-têtes HTTP

# Afficher uniquement les en-têtes de réponse
curl -I https://example.com
# Afficher les en-têtes avec la réponse complète
curl -i https://example.com
# Vérifier les en-têtes avec wget
wget -S https://example.com 2>&1 | head -20

FTP — Téléchargement depuis un serveur de fichiers

# Télécharger un fichier via FTP anonyme
wget ftp://ftp.exemple.com/fichier.zip
# FTP avec authentification
wget --user=monuser --password=monmdp ftp://ftp.exemple.com/fichier.zip
# Avec curl
curl -u monuser:monmdp -O ftp://ftp.exemple.com/fichier.zip

Combiner avec d'autres outils

Télécharger et décompresser en une ligne

# Télécharger et extraire directement
wget -qO- https://example.com/archive.tar.gz | tar xz
# Télécharger via curl et pipe vers tar
curl -Ls https://example.com/archive.tar.gz | tar xz

Télécharger et traiter avec jq

# Télécharger un JSON et l'afficher joliment
curl -s https://api.exemple.com/utilisateurs | jq '.'
# Extraire une valeur spécifique
curl -s https://api.exemple.com/utilisateurs/1 | jq -r '.email'

Envoyer un fichier sur un serveur

# Upload avec curl
curl -X PUT -T mon_fichier.zip https://upload.exemple.com/receive
# Upload multipart/form-data
curl -F "fichier=@rapport.pdf" https://upload.exemple.com/upload

Bonnes pratiques

  • Choisissez wget pour les téléchargements de fichiers uniques ou récursifs — il reprend automatiquement les téléchargements interrompus
  • Choisissez curl pour interagir avec les API REST, envoyer des données ou tester des endpoints
  • Utilisez -s (curl) ou -q (wget) dans les scripts pour éviter le bruit dans les logs
  • Combinez -L avec curl pour suivre automatiquement les redirections
  • Pour les serveurs avec des certificats auto-signés, utilisez -k avec curl (avec précaution)
  • Protégez vos tokens et mots de passe — évitez de les mettre en clair dans les commandes visibles
