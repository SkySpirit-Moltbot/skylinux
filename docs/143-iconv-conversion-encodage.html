Leçon 143 : iconv — Convertir l'encodage des caractères

iconv est un outil en ligne de commande pour convertir des fichiers texte entre différents encodages de caractères. Indispensable pour manipuler d'anciens fichiers ou échanger des données avec des systèmes utilisant des encodages différents.

Pourquoi iconv est essentiel

  • Problèmes d'accents : caractères mal affichés (�, Ã©, etc.)
  • Fichiers legacy : documents anciens créés sous Windows ou Latin-1
  • Compatibilité : convertir entre UTF-8, ISO-8859-1, Windows-1252, etc.
  • Scriptable : automatiser la conversion massive de fichiers

Syntaxe de base

iconv [option] [-f encodage_source] [-t encodage_cible] [fichier]

Installation

iconv fait partie de la glibc et est installé par défaut sur la plupart des distributions Linux. Vérifiez sa présence :

which iconv
iconv --version

Si absent, installez le paquet glibc ou libc-bin.

Commandes fondamentales

Conversion simple

# Convertir un fichier Latin-1 vers UTF-8
iconv -f ISO-8859-1 -t UTF-8 fichier_latin1.txt > fichier_utf8.txt

Écrire dans un fichier directement

# Avec redirection (écrase le fichier original)
iconv -f Windows-1252 -t UTF-8 entree.txt -o sortie.txt
# Remplacer le fichier en place (via fichier temporaire)
iconv -f ISO-8859-1 -t UTF-8 ancien.txt > temporaire.txt && mv temporaire.txt ancien.txt

Convertir et afficher

# Afficher le résultat dans le terminal (sans fichier de sortie)
iconv -f Windows-1252 -t UTF-8 document_windows.txt

Détecter l'encodage automatiquement

# Linux : utiliser enca (si installé)
sudo apt install enca
enca -L french fichier_mystere.txt
# Ou avec uchardet (détection par Mozilla)
sudo apt install uchardet
uchardet fichier_mystere.txt

Cas pratiques

Conversion de fichiers CSV Windows

# Fichier CSV Windows (Windows-1252) vers UTF-8
iconv -f Windows-1252 -t UTF-8 donnees_windows.csv > donnees_utf8.csv

Conversion de logs systèmes anciens

# Log en Latin-1 vers UTF-8
iconv -f ISO-8859-1 -t UTF-8 /var/log/old_system.log -o /var/log/old_system_utf8.log

Préparer un fichier pour le web

# Convertir en UTF-8 sans BOM (recommandé pour le web)
iconv -f ISO-8859-1 -t UTF-8//TRANSLIT page_latin1.html > page_utf8.html
# ou avec suppression des caractères non convertibles
iconv -f ISO-8859-1 -t UTF-8//IGNORE ancien.html > nouveau.html

Options avancées

Translittération (//TRANSLIT)

Remplace les caractères non convertibles par des近似 caractères相似 :

# Les caractères accentués sont Approximés
iconv -f ISO-8859-1 -t ASCII//TRANSLIT texte_accentue.txt
# é -> e, ç -> c, ñ -> n

Ignorer les caractères non convertibles (//IGNORE)

# Supprime silencieusement les caractères problématiques
iconv -f UTF-8 -t ASCII//IGNORE fichier.txt > resultat.txt

Combiner les options

# TRANSLIT d'abord, puis IGNORE pour le reste
iconv -f Windows-1252 -t UTF-8//TRANSLIT//IGNORE fichier.txt

Conversion par lot

Plusieurs fichiers avec une boucle

# Convertir tous les fichiers .txt d'un répertoire
for fichier in *.txt; do
iconv -f ISO-8859-1 -t UTF-8 "$fichier" -o "${fichier%.txt}_utf8.txt"
done

Renommer et convertir

# Convertir et remplacer (avec backup)
for f in *.csv; do
cp "$f" "$f.bak"
iconv -f Windows-1252 -t UTF-8 "$f.bak" > "$f"
rm "$f.bak"
done

Conversion récursive

# Trouver et convertir tous les .txt d'un dossier
find /home/docs -name "*.txt" -exec sh -c '
iconv -f ISO-8859-1 -t UTF-8 "$1" > "$1.tmp" && mv "$1.tmp" "$1"' _ {} \;

Convertir avec dos2unix (encodage + fins de ligne)

Pour les fichiers Windows, vous pourriez aussi vouloir corriger les fins de ligne :

# dos2unix convertit aussi l'encodage si nécessaire
sudo apt install dos2unix
# Convertir fins de ligne Windows (CRLF) -> Unix (LF)
dos2unix fichier_windows.txt
# Avec conversion d'encodage simultanée
iconv -f Windows-1252 -t UTF-8 fichier.txt | dos2unix > resultat.txt

Encodages et diagnostics

Détecter l'encodage actuel

# Voir l'encodage actuel du système
locale
# Exemple: LANG=fr_CH.UTF-8
# Examiner les premiers octets d'un fichier binaire
hexdump -C fichier.txt | head
# ou
file fichier.txt

Vérifier la conversion

# Vérifier qu'un fichier est bien en UTF-8
file -i fichier_utf8.txt
# Affiche: fichier_utf8.txt: text/plain; charset=utf-8
# Vérifier qu'il n'y a plus de caractères non-ASCII problématiques
iconv -f UTF-8 -t UTF-8 fichier.txt > /dev/null && echo "UTF-8 valide"

Exemples intégrés

Script de migration massif

#!/bin/bash
# Conversion récursive de ISO-8859-1 vers UTF-8
find /home/data -type f \( -name "*.txt" -o -name "*.csv" -o -name "*.html" \) | while read fichier; do
# Vérifier si le fichier contient des caractères Latin-1
if iconv -f ISO-8859-1 -t UTF-8 "$fichier" > /dev/null 2>&1; then
echo "Conversion : $fichier"
iconv -f ISO-8859-1 -t UTF-8 "$fichier" > "${fichier}.utf8"
mv "${fichier}.utf8" "$fichier"
else
echo "Problème : $fichier"
fi
done

Pipeline avec curl

# Télécharger une page et convertir son encodage
curl -s "http://example.com/page.php" | iconv -f ISO-8859-1 -t UTF-8 > page_utf8.html

Bonnes pratiques

  • Toujours garder un backup avant conversion massive
  • Vérifiez l'encodage source avant de convertir (file, uchardet)
  • UTF-8 est le standard moderne — convertissez tout vers UTF-8
  • Évitez UTF-8 avec BOM pour les fichiers texte Linux (cause des erreurs)
  • Utilisez //TRANSLIT pour garder le texte lisible quand des caractères manquent
  • Scripts de conversion : loggez les fichiers traités pour audit

Résumé

iconv est l'outil indispensable pour gérer les problèmes d'encodage sous Linux. Que ce soit pour convertir d'anciens fichiers Windows-1252 ou Latin-1 vers UTF-8, iconv offre une solution simple et scriptable pour tous vos besoins de conversion de caractères.
