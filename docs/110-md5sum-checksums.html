Leçon 110 : md5sum, sha256sum et les checksums — Vérifier l'intégrité des fichiers

Quand vous téléchargez un fichier sur Internet — une image ISO, un logiciel, une archive — comment être sûr qu'il n'a pas été corrompu pendant le téléchargement, ou pire, qu'il n'a pas été modifié par un attaquant ? La réponse se trouve dans les checksums (ou sommes de contrôle). Ce sont des empreintes numériques uniques générées à partir du contenu d'un fichier. Linux fournit plusieurs outils pour calculer et vérifier ces empreintes : md5sum, sha256sum, et d'autres. Dans cette leçon, vous apprendrez à les utiliser pour garantir l'intégrité de vos fichiers.

Qu'est-ce qu'un checksum ?

Un checksum est le résultat d'une fonction mathématique (algorithme de hachage) appliquée au contenu d'un fichier. Le même fichier produit toujours le même hash. Si le fichier change, même d'un seul bit, le hash change complètement. Cela permet de détecter n'importe quelle modification, corruption ou manipulation.

Les algorithmes les plus courants :

AlgorithmeLongueur du hashUsage recommandé
md5sum32 caractères hexLegacy, vérifications rapides (non sécurisé)
sha256sum64 caractères hexRecommandé pour la plupart des usages
sha512sum128 caractères hexHaute sécurité
b2sum64 caractères hexBLAKE2, rapide et sécurisé

Calculer un checksum

md5sum

La commande md5sum calcule l'empreinte MD5 d'un fichier :

# Calculer le hash MD5 d'un fichier
md5sum fichier.iso
d41d8cd98f00b204e9800998ecf8427e fichier.iso

Le format de sortie est simple : le hash suivi du nom du fichier.

sha256sum

Pour un hash plus fiable et sécurisé, utilisez sha256sum :

# Calculer le hash SHA-256 d'un fichier
sha256sum fichier.iso
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855 fichier.iso

Vérifier plusieurs fichiers

Vous pouvez calculer le hash de plusieurs fichiers en une seule commande :

# Hash de plusieurs fichiers
sha256sum fichier1.txt fichier2.txt archive.tar.gz
a1b2c3d4... fichier1.txt
e5f6g7h8... fichier2.txt
i9j0k1l2... archive.tar.gz

Calculer le hash depuis stdin

Vous pouvez aussi calculer le hash d'une chaîne de texte ou d'un flux :

# Hash d'une chaîne de texte
echo -n "Bonjour" | sha256sum
18ea9307cf35c1e3dfa6f1a6e0c1e9f16c3e8a7d5b9f2c4e6a8d0c2b4e6f8a0c -

L'argument -n est important : il retire le retour à la ligne ajouté par echo, sinon le hash serait différent.

Vérifier l'intégrité d'un fichier

Comparaison manuelle

La méthode la plus simple est de comparer visuellement le hash calculé avec le hash attendu (publié sur le site de téléchargement) :

# Vous calculez
sha256sum ubuntu-22.04.iso
b54e9e4c6e2a7f8d1c3b5a9e2d4f6a8b0c2e4f6a8b0c2e4f6a8b0c2e4f6a8b0 ubuntu-22.04.iso
# Sur le site officiel, vous lisez :
# SHA256: b54e9e4c6e2a7f8d1c3b5a9e2d4f6a8b0c2e4f6a8b0c2e4f6a8b0c2e4f6a8b0

Si les deux correspondent, le fichier est intact. Sinon, il a été corrompu ou modifié.

Vérification automatisée avec un fichier .sha256

Quand vous téléchargez un fichier, son hash officiel est souvent fourni dans un fichier séparé (par exemple fichier.iso.sha256). Pour vérifier automatiquement :

# Créer un fichier de hash (exemple)
sha256sum ubuntu-22.04.iso > ubuntu-22.04.iso.sha256
# Vérifier à partir du fichier de hash
sha256sum -c ubuntu-22.04.iso.sha256
ubuntu-22.04.iso: OK

L'option -c (check) lit le fichier de hash et compare chaque hash avec le fichier correspondant. Si tout va bien, vous obtenez OK. Si le fichier a changé, vous verrez ÉCHEC ou FAILED.

Créer un fichier de hash pour plusieurs fichiers

Pour vérifier un ensemble de fichiers, vous pouvez créer un fichier listant tous les hashes :

# Générer un fichier contenant les hashes de tous les fichiers du répertoire
sha256sum * > checksums.sha256
# Vérifier tous les fichiers d'un coup
sha256sum -c checksums.sha256
fichier1.txt: OK
fichier2.txt: OK
archive.tar.gz: OK

Utiliser md5sum pour des проверки (legacy)

Bien que MD5 soit considéré comme cryptographiquement faible pour la sécurité, il reste utilisé pour des vérifications de corruption rapide. Le principe est identique :

# Créer un fichier de hash MD5
md5sum photo.jpg musique.mp3 > backup.md5
# Vérifier
md5sum -c backup.md5
photo.jpg: OK
musique.mp3: OK

Bonnes pratiques

Toujours vérifier après téléchargement

C'est une habitude essentielle, surtout pour les fichiers sensibles :

  • Images ISO de systèmes d'exploitation
  • Logiciels téléchargés depuis des sites tiers
  • Archives contenant des données importantes
  • Fichiers reçus par email ou transfert réseau

Utiliser SHA-256 de préférence

Bien que md5sum soit plus rapide, sha256sum offre une bien meilleure garantie de sécurité. Pour les fichiers importants, SHA-256 ou SHA-512 sont recommandés.

Protéger le fichier de hash

Si vous publiez un hash, faites-le sur le même canal que le fichier ou via un canal sécurisé (HTTPS). Sinon, un attaquant pourrait modifier le fichier ET le hash.

Combiner avec GPG pour une sécurité maximale

Les checksums garantissent l'intégrité, mais pas l'authenticité. Pour vérifier que c'est bien l'auteur officiel qui a signé le fichier, utilisez GPG avec une signature numérique.

Exercice pratique

Pour vous familiariser avec les checksums, essayez cet exercice :

# 1. Créez un fichier texte
echo "Mon fichier de test" > test.txt
# 2. Calculez son hash SHA-256
sha256sum test.txt
# 3. Modifiez légèrement le fichier
echo "Mon fichier de test." > test.txt
# 4. Calculez à nouveau le hash
sha256sum test.txt
# 5. Comparez : les hash sont différents, même avec un seul point ajouté !

Vous constaterez que le hash change complètement, même pour un changement minime. C'est précisément ce qui rend les checksums si fiables pour détecter n'importe quelle modification.

Conclusion

Les checksums sont un outil fondamental pour quiconque manipule des fichiers importants sous Linux. Que ce soit pour vérifier l'intégrité d'un téléchargement, valider une sauvegarde ou s'assurer qu'un fichier n'a pas été modifié, md5sum, sha256sum et leurs variantes offrent une solution simple, rapide et efficace. Prenez l'habitude de vérifier vos fichiers critiques — c'est une bonne pratique qui peut vous éviter bien des ennuis.
