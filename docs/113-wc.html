Leçon 113 : wc — Compter lignes, mots et caractères

Quand vous avez besoin de savoir combien de lignes contient un fichier, combien de mots dans un texte, ou la taille exacte en caractères d'une sortie, wc (word count) est l'outil parfait. Simple, rapide et souvent utilisé dans les pipes, wc fait partie de ces commandes essentielles que tout utilisateur Linux devrait connaître. Dans cette leçon, vous apprendrez toutes ses options et des combinaisons pratiques.

Introduction à wc

wc signifie word count (compteur de mots). Par défaut, il affiche trois informations :

  • Le nombre de lignes
  • Le nombre de mots
  • Le nombre d'octets (caractères)

C'est une commande présente sur tous les systèmes Unix/Linux depuis les origines, grâce à son utilité dans les scripts et les tubes (pipes).

Utilisation de base

Compter un fichier entier

wc fichier.txt

Résultat :

125 892 5214 fichier.txt
# Lignes Mots Octets

Compter plusieurs fichiers

wc fichier1.txt fichier2.txt fichier3.txt

Résultat :

125 892 5214 fichier1.txt
78 456 2890 fichier2.txt
203 1348 8104 fichier3.txt
406 2696 16208 total

Compter depuis stdin (pipe)

cat fichier.txt | wc

Ou encore plus simplement avec une redirection :

wc < fichier.txt

Les options principales

-l : Compter uniquement les lignes

L'option la plus utilisée. Nombreux sont les cas où seule la nombre de lignes importe :

wc -l fichier.txt
# 125 fichier.txt

Exemples pratiques :

# Compter le nombre de connexions SSH actives
who | wc -l
# Compter le nombre de paquets installés
dpkg -l | wc -l
# Compter le nombre de lignes dans un log
wc -l /var/log/syslog
# Compter le nombre de fichiers dans un répertoire
ls -1 | wc -l

-w : Compter uniquement les mots

wc -w fichier.txt
# 892 fichier.txt

Utile pour analyser la taille d'un texte :

# Compter les mots d'un article
wc -w article.txt
# Compter les mots dans toutes les pages HTML
cat *.html | wc -w

-c : Compter uniquement les octets

wc -c fichier.txt
# 5214 fichier.txt

Affiche la taille exacte du fichier en octets (indépendamment du contenu).

-m : Compter uniquement les caractères

Similar à -c mais prend en compte les caractères multi-octets (comme les accents UTF-8) :

wc -m fichier.txt

Sur un fichier avec des caractères accentués, -c et -m peuvent donner des résultats différents.

-L : Afficher la longueur de la ligne la plus longue

wc -L fichier.txt
# 78

Cette option affiche la longueur (en caractères) de la ligne la plus longue du fichier. Très utile pour :

  • Déterminer la largeur d'affichage nécessaire
  • Valider des formats avec des limites de longueur
  • Optimiser l'affichage dans un terminal

Exemples pratiques en combinaison

Compter des lignes avec grep

# Compter le nombre d'erreurs dans un log
grep "ERROR" /var/log/syslog | wc -l
# Compter le nombre de lignes contenant "TODO" dans du code
grep -r "TODO" src/ | wc -l
# Compter le nombre de fichiers d'un type précis
find . -name "*.py" | wc -l

Compter le nombre de processus

# Nombre total de processus
ps aux | wc -l
# Nombre de processus d'un utilisateur
ps -u $USER | wc -l

Compter des utilisateurs ou connexions

# Nombre d'utilisateurs sur le système
cat /etc/passwd | wc -l
# Nombre de connexions SSH actives
who | wc -l

Analyser du code

# Nombre de lignes dans un fichier source
wc -l main.py
# Total de lignes de code dans un projet
find . -name "*.py" -exec cat {} + | wc -l
# Nombre de fonctions dans un fichier
grep -c "def " fichier.py

Combiner wc avec d'autres outils

Tri par nombre de lignes

# Lister les fichiers par nombre de lignes (du plus grand au plus petit)
wc -l *.txt | sort -rn
# Exclure le total et trier
wc -l *.txt | grep -v total | sort -rn

Statistiques avec awk

# Additionner toutes les lignes de plusieurs fichiers
cat *.log | wc -l
# Moyenne de mots par ligne
awk '{mots+=$2; lignes++} END {print mots/lignes}' <(wc -l *.txt)

Utiliser avec xargs

# Compter les lignes de tous les fichiers txt
find . -name "*.txt" | xargs wc -l
# Version sûre (gère les espaces dans les noms)
find . -name "*.txt" -print0 | xargs -0 wc -l

Formats de sortie personnalises

Ajouter le nom du fichier

Par défaut, wc affiche le nom du fichier. Pour un affichage plus propre :

# Format : "nombre_lignes fichier"
wc -l fichier.txt
# 125 fichier.txt

Sans nom de fichier (pour les pipes)

# pipe | wc -l n'affiche pas le nom
cat fichier.txt | wc -l
# 125

Formatage avec printf

# Format personnalisé
printf "Lignes: %s\n" "$(wc -l < fichier.txt)"
# Utiliser dans un script
#!/bin/bash
nb_lignes=$(wc -l < "$1")
echo "Le fichier $1 contient $nb_lignes lignes"

Les limites de wc

  • Ne compte pas les lignes vides correctement si le fichier ne se termine pas par un retour à la ligne (la dernière ligne sans \n n'est pas comptée)
  • Les performances peuvent être meilleures avec wc -l qu'avec grep -c car wc utilise une méthode plus directe
  • Pour les très gros fichiers, wc -l est plus rapide que charger tout le fichier en mémoire

Scripts pratiques avec wc

Script : vérifier la taille d'un projet

#!/bin/bash
echo "=== Statistiques du projet ==="
echo ""
echo "Lignes de code par langage:"
find . -name "*.py" 2>/dev/null | xargs wc -l | tail -1
find . -name "*.js" 2>/dev/null | xargs wc -l | tail -1
find . -name "*.html" 2>/dev/null | xargs wc -l | tail -1
echo ""
echo "Total fichiers:"
find . -type f | wc -l

Script : surveillance de log

#!/bin/bash
LOG="/var/log/syslog"
avant=$(wc -l < "$LOG")
sleep 60
apres=$(wc -l < "$LOG")
echo "Lignes ajoutées en 1 minute: $((apres - avant))"

Résumé des options

Conclusion

wc est une commande simple mais puissante, indispensable dans la boîte à outils de tout utilisateur Linux. Que ce soit pour analyser du code, surveiller des logs, ou compter des éléments dans un système, wc s'intègre parfaitement dans les tubes (pipes) avec d'autres commandes. N'oubliez pas l'option -l qui est de loin la plus utilisée au quotidien.
