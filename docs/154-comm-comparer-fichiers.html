Leçon 154 : comm — Comparer deux fichiers ligne par ligne

La commande comm permet de comparer deux fichiers triés ligne par ligne. Elle affiche le résultat en trois colonnes : les lignes présentes uniquement dans le premier fichier, celles présentes uniquement dans le second, et celles communes aux deux. C'est un outil puissant pour identifier les différences entre fichiers triés.

Syntaxe de base

comm [OPTIONS] FICHIER1 FICHIER2

Important : comm exige que les deux fichiers soient triés. Si ce n'est pas le cas, vous devez les trier d'abord avec sort.

Exemple simple

Créons deux fichiers pour illustrer le fonctionnement de comm :

# Fichier 1
pomme
banane
cerise
# Fichier 2
banane
cerise
dattes

La commande comm fichier1.txt fichier2.txt produit :

pomme
banane
cerise
dattes

Interprétation des colonnes

ColonneContenuExemple
1ère colonneLignes uniquement dans le fichier 1pomme
2ème colonneLignes uniquement dans le fichier 2dattes
3ème colonneLignes communes aux deux fichiersbanane, cerise

Options principales

-1, -2, -3 : Masquer les colonnes

Vous pouvez masquer une ou plusieurs colonnes pour n'afficher que ce qui vous intéresse :

# Masquer la colonne 1 : afficher uniquement ce qui est dans fichier2 et commun
comm -1 fichier1.txt fichier2.txt
# Masquer les colonnes 1 et 2 : afficher uniquement les lignes communes
comm -12 fichier1.txt fichier2.txt
# Masquer la colonne 3 : afficher uniquement les différences
comm -3 fichier1.txt fichier2.txt

-i : Comparaison insensible à la casse

Par défaut, comm fait la distinction entre majuscules et minuscules. L'option -i permet d'ignorer la casse :

comm -i fichier1.txt fichier2.txt

--output-delimiter=CHAÎNE : Personnaliser les séparateurs

Par défaut, les colonnes sont séparées par des tabulations. Vous pouvez personnaliser ces séparateurs :

# Remplacer les tabulations par des chaînes vides (pas de séparateur visible)
comm --output-delimiter='' fichier1.txt fichier2.txt
# Utiliser des séparateurs personnalisés
comm --output-delimiter='A: ' --output-delimiter='B: ' --output-delimiter='AB: ' fichier1.txt fichier2.txt

Cas d'utilisation pratiques

Trouver les lignes communes à deux fichiers

comm -12 liste1.txt liste2.txt

Cette commande est très utile pour trouver les éléments communs entre deux listes, par exemple les utilisateurs présents dans deux groupes.

Trouver les différences entre deux fichiers

comm -3 fichier1.txt fichier2.txt

Cela affiche les lignes qui diffèrent entre les deux fichiers, en masquant les lignes communes.

Comparer des fichiers déjà triés

Si vos fichiers sont déjà triés, vous pouvez les comparer directement :

# Fichiers déjà triés
comm fichier1_trie.txt fichier2_trie.txt

Combiner avec sort pour des fichiers non triés

# Trier puis comparer (via process substitution)
comm <(sort fichier1.txt) <(sort fichier2.txt)

Identifier les lignes uniques

Pour trouver les lignes présentes uniquement dans le premier fichier :

comm -23 <(sort fichier1.txt) <(sort fichier2.txt)

Pour les lignes uniquement dans le second fichier :

comm -13 <(sort fichier1.txt) <(sort fichier2.txt)

Comparaison avec diff

commdiff
Compare des fichiers triésCompare des fichiers quel qu'ils soit
Résultat en 3 colonnesRésultat en format patch/unifié
Indique l'appartenance exacteIndique les modifications ligne par ligne
Plus rapide sur de gros fichiers triésPlus détaillé pour les modifications

Utilisez comm pour des comparaisons simples de listes triées, et diff pour des comparaisons plus détaillées de fichiers texte.

Exemple concret : comparer des listes d'utilisateurs

Imaginez que vous avez deux fichiers contenant des noms d'utilisateurs et que vous voulez savoir :

  • Quels utilisateurs sont dans les deux fichiers
  • Quels utilisateurs sont uniquement dans le premier
  • Quels utilisateurs sont uniquement dans le second
# admin_groupe1.txt contient : alice, bob, charlie
# admin_groupe2.txt contient : bob, charlie, david
comm <(sort admin_groupe1.txt) <(sort admin_groupe2.txt)
# Résultat :
# alice (colonne 1 : uniquement dans groupe1)
# bob (colonne 3 : dans les deux)
# charlie (colonne 3 : dans les deux)
# david (colonne 2 : uniquement dans groupe2)

Bonnes pratiques

  • Toujours trier vos fichiers avant d'utiliser comm
  • Utiliser comm -12 pour trouver rapidement les éléments communs
  • Combiner avec sort -u si vous voulez éliminer les doublons avant comparaison
  • Pour des fichiers volumineux, comm est plus efficace que diff
