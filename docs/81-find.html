find — Rechercher des fichiers comme un détective

Introduction

find est l'un des outils les plus puissants sous Linux. Il permet de rechercher des fichiers et répertoires selon de nombreux critères : nom, type, taille, date de modification, permissions, propriétaire, et bien plus encore. Contrairement à locate qui utilise une base de données pré-construite, find explore le système de fichiers en temps réel — ce qui le rend précis mais potentiellement plus lent sur de grands volumes.

Syntaxe de base

find [répertoire] [critères] [actions]
  • répertoire : où commencer la recherche (par défaut : répertoire courant)
  • critères : les conditions de recherche
  • actions : que faire avec les résultats

Recherche par nom

Recherche simple

# Rechercher un fichier par son nom exact find . -name "rapport.txt" # Rechercher sans distinction majuscules/minuscules find . -iname "Rapport.txt" # Rechercher tous les fichiers .txt find . -name "*.txt" # Rechercher tous les fichiers .txt (sans casse) find . -iname "*.txt" # Rechercher dans un répertoire spécifique find /home/david -name "*.pdf"

Utilisation de regex

# Utiliser des expressions régulières find . -regex ".*\.\(txt\|csv\)" # Regex insensible à la casse find . -iregex ".*\.\(txt\|csv\)" # Chercher des fichiers commençant par "config" find . -regex ".*/config[^/]*$"

Recherche par type

# Rechercher des fichiers réguliers (-type f) find . -type f -name "*.log" # Rechercher des répertoires (-type d) find . -type d -name "backup" # Rechercher des liens symboliques (-type l) find . -type l # Rechercher des fichiers spéciaux (blocs, caractères) find /dev -type b # périphériques bloc find /dev -type c # périphériques caractère

Recherche par taille

# Fichiers de plus de 100 Mo find . -type f -size +100M # Fichiers de moins de 1 Ko find . -type f -size -1k # Fichiers de taille exacte (ici 512 octets) find . -type f -size 512c # Fichiers entre 10 et 100 Mo find . -type f -size +10M -size -100M

Recherche par date

Date de modification (-mtime)

# Modifiés il y a exactement 2 jours find . -type f -mtime 2 # Modifiés il y a moins de 7 jours find . -type f -mtime -7 # Modifiés il y a plus de 30 jours find . -type f -mtime +30 # Dans les 24 dernières heures find . -type f -mtime 0 # Dans les 5 dernières minutes find . -type f -mmin -5

Date d'accès (-atime)

# Accédés il y a moins de 7 jours find . -type f -atime -7 # Jamais accédés depuis 90 jours find . -type f -atime +90 # Accédés dans les 10 dernières minutes find . -type f -amin -10

Date de changement de statut (-ctime)

# Propriétés modifiées il y a plus de 7 jours find . -type f -ctime +7 # Combiner avec taille pour trouver gros fichiers récents find . -type f -mtime -7 -size +100M

Recherche par permissions

# Fichiers权限 777 find . -type f -perm 777 # Fichiers exécutables find . -type f -perm /111 # Fichiers writable par tous find . -type f -perm -002 # Fichiers SETUID find /usr -type f -perm -4000 # Fichiers SETGID find /usr -type f -perm -2000

Recherche par propriétaire

# Fichiers appartenant à root find . -type f -user root # Fichiers belonging à l'utilisateur david find /home -type f -user david # Répertoires belonging au groupe www-data find . -type d -group www-data # Fichiers ni belonging à root ni à david find . -type f ! -user root ! -user david

Actions sur les résultats

-print (action par défaut)

# Afficher les chemins complets find . -name "*.txt" -print # Supprimer le -print (c'est la valeur par défaut) find . -name "*.txt"

-ls (afficher comme ls -l)

# Afficher les détails des fichiers trouvés find . -name "*.log" -ls # Exemple de sortie : # 4194305 124 -rw-r--r-- 1 david staff 63421 Jun 5 08:00 app.log

-exec (exécuter une commande)

# Exécuter une commande pour chaque résultat find . -name "*.bak" -exec rm {} \; # Utiliser + pour grouper les appels (plus efficace) find . -name "*.bak" -exec rm {} + # Confirmer avant suppression find . -name "*.bak" -exec rm -i {} \; # Afficher les permissions avec ls find . -type f -perm -4000 -exec ls -l {} \;

-delete (supprimer directement)

# Supprimer directement les fichiers trouvés find . -name "*.tmp" -delete # ATTENTION : tester d'abord avec -print find . -name "*.tmp" -print # voir ce qui serait supprimé find . -name "*.tmp" -delete # puis supprimer

Combiner avec xargs

# Utiliser xargs pour traiter les résultats find . -name "*.log" | xargs wc -l # Avec xargs et delimiteur nul (gestion des noms spéciaux) find . -name "*.txt" -print0 | xargs -0 rm # Limiter le nombre d'arguments par commande find . -name "*.log" | xargs -n 5 rm

Exclure des répertoires

# Ignorer un répertoire spécifique find . -path "./node_modules" -prune -o -name "*.js" -print # Ignorer plusieurs répertoires find . \( -path "./node_modules" -o -path "./.git" \) -prune -o -name "*.js" -print # Exclure par type (plus simple) find . -name "*.js" ! -path "./node_modules/*" # Exclure plusieurs patterns find . -name "*.log" ! -path "./var/log/*"

Limiter la profondeur

# Limiter à 2 niveaux de profondeur find . -maxdepth 2 -name "*.txt" # Commencer la recherche à partir du 2e niveau find . -mindepth 2 -type f # Chercher exactement à 3 niveaux de profondeur find . -mindepth 3 -maxdepth 3 -name "*.conf" # Trouver les fichiers dans les 3 premiers niveaux find . -maxdepth 3 -type f

Recherches avancées combinées

Trouver les gros fichiers recently modifiés

# Fichiers > 100 Mo modifiés il y a moins de 7 jours find . -type f -size +100M -mtime -7 # Logs de plus de 1 Go find /var/log -type f -size +1G -name "*.log" # Images modifiées récemment find . -type f \( -iname "*.jpg" -o -iname "*.png" \) -mtime -30

Trouver des fichiers par extension et agir

# Compter les fichiers par type find . -type f -name "*.py" | wc -l find . -type f -name "*.js" | wc -l # Trouver et archiver find /backup -name "*.tar.gz" -mtime +30 -exec tar -czf old_backups.tar.gz {} + # Trouver et compresser find /var/log -type f -name "*.log" -mtime +7 -exec gzip {} \;

Nettoyage intelligent

# Supprimer les fichiers vides find . -type f -empty -delete # Supprimer les fichiers temporaires de plus de 7 jours find /tmp -type f -name "*.tmp" -mtime +7 -delete # Trouver les doublons (par taille et nom) find . -type f -name "*.jpg" -exec ls -l {} \; | sort -k5 -n # Lister les 10 plus gros fichiers find . -type f -exec du -h {} + | sort -rh | head -10

Exemples pratiques du quotidien

Gestion des logs

# Trouver tous les fichiers .log find /var/log -name "*.log" # Fichiers log de plus de 100 Mo find /var/log -type f -name "*.log" -size +100M # Nettoyer les vieux logs (> 30 jours) find /var/log -name "*.log" -mtime +30 -delete # Lister les logs par date de modification find /var/log -name "*.log" -mtime -7 -ls

Gestion des sauvegardes

# Trouver les sauvegardes récentes find /backup -name "*.tar.gz" -mtime -7 # Trouver les anciennes sauvegardes (> 90 jours) find /backup -name "*.bak" -mtime +90 # Lister les sauvegardes triées par taille find /backup -type f -name "*.gz" -exec du -h {} \; | sort -h

Recherche de code

# Trouver tous les fichiers Python find . -name "*.py" # Trouver les fichiers avec un nom précis find . -name "config*" -type f # Exclure node_modules et .git find . -name "*.js" ! -path "*/node_modules/*" ! -path "*/.git/*" # Trouver les fonctions dans des fichiers find . -name "*.sh" -exec grep -l "^function" {} \;

Sécurité système

# Trouver les fichiers SETUID find /usr -type f -perm -4000 2>/dev/null # Trouver les fichiers world-writable find / -type f -perm -002 ! -path "/proc/*" 2>/dev/null # Trouver les fichiers sans propriétaire find /home -type f -nouser 2>/dev/null # Trouver les fichiers sans groupe find /home -type f -nogroup 2>/dev/null

Erreurs communes à éviter

Toujours tester avant de supprimer

# AVANT de supprimer : toujours faire un -print d'abord find /tmp -name "*.tmp" -mtime +7 -print # montre ce qui serait supprimé find /tmp -name "*.tmp" -mtime +7 -delete # puis supprimer # Utiliser -ok pour confirmer chaque action find . -name "*.bak" -ok rm {} \; # Répondra y/n pour chaque fichier

Gestion des noms avec espaces

# Utiliser -print0 avec xargs -0 pour gérer les espaces find . -name "*.txt" -print0 | xargs -0 wc -l # Ou utiliser -exec avec {} \; find . -name "*.txt" -exec wc -l "{}" \;

Attention aux guillemets

# Les guillemets protègent les wildcards du shell find . -name "*.txt" # correct : cherche *.txt find . -name *.txt # FAUX : le shell expansion # Pour les variables, utiliser les guillemets extension=".txt" find . -name "$extension" # correct

Exercice pratique

  1. Recherche basique : Trouvez tous les fichiers .conf dans le répertoire /etc.
  2. Par taille : Trouvez les fichiers de plus de 50 Mo dans votre répertoire personnel.
  3. Par date : Listez les fichiers modifiés dans les 7 derniers jours dans /var/log.
  4. Nettoyage : Créez une commande pour trouver et lister (sans supprimer) tous les fichiers .tmp de plus de 7 jours dans /tmp.
  5. Actions : Utilisez -exec pour afficher les permissions de tous les fichiers exécutables dans /usr/bin.
  6. Exclusion : Trouvez tous les fichiers .py en excluant le répertoire node_modules et __pycache__.
  7. Profondeur : Listez les fichiers à exactement 3 niveaux de profondeur dans votre home directory.
  8. Défi : Créez une commande pour trouver tous les fichiers .log de plus de 100 Mo, modifiés il y a plus de 30 jours, et affichez-les avec -ls.

Conclusion

find est un outil extrêément puissant et flexible. Sa syntaxe peut sembler complexe au début, mais une fois comprise, elle devient indispensable au quotidien. La clé est de commencer par des recherches simples et d'ajouter progressivement des critères. N'oubliez jamais de tester avec -print avant d'utiliser -delete ou -exec rm — la prudence est votre meilleure alliée. Avec find, vous avez littéralement le pouvoir de retrouver n'importe quel fichier sur votre système Linux.
