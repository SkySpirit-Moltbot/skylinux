xargs — Construire et exécuter des commandes à partir de résultats

Introduction

La commande xargs est un outil puissant qui permet de transformer le résultat d'une commande en arguments pour une autre. Elle fait le lien entre les commandes qui produisent du texte et celles qui attendent des paramètres.

En d'autres termes : xargs lit des données depuis l'entrée standard et les convertit en arguments pour une commande. C'est le ciment qui relie les outils Unix entre eux.

Syntaxe de base

commande | xargs commande2

xargs prend chaque ligne de l'entrée standard et la passe comme argument à commande2.

Exemples fondamentaux

1. Supprimer des fichiers trouvés

Trouver et supprimer tous les fichiers .log :

find /var/log -name "*.log" | xargs rm

Ici, find liste les fichiers, et xargs les convertit en arguments pour rm.

2. Créer des fichiers

Créer plusieurs fichiers à partir d'une liste :

echo "fichier1.txt fichier2.txt fichier3.txt" | xargs touch

3. Lister les permissions

Voir les permissions de tous les fichiers trouvés :

find . -type f | xargs ls -l

Utilisation avancée

Limiter le nombre d'arguments

Par défaut, xargs passe le maximum d'arguments possible. Pour limiter :

echo "1 2 3 4 5 6" | xargs -n 2 echo "Lot"

Résultat :

Lot 1 2 Lot 3 4 Lot 5 6

Remplacement de placeholder avec -I

L'option -I {} permet d'insérer les arguments à n'importe quelle position :

find . -name "*.txt" | xargs -I {} cp {} /sauvegardes/{}.bak

Chaque fichier sera copié avec l'extension .bak ajoutée.

Traitement parallèle avec -P

Pour accélérer le traitement sur plusieurs cœurs :

cat urls.txt | xargs -P 4 -I {} curl -O {}

Télécharger 4 fichiers simultanément.

Gestion des espaces et caractères spéciaux

Pour les noms de fichiers avec des espaces, combinez avec find -print0 :

find /data -name "*.txt" -print0 | xargs -0 rm

Le caractère nul \0 comme délimiteur évite les problèmes avec les espaces.

Combiner avec grep

Rechercher dans plusieurs fichiers

grep -rl "erreur" . | xargs grep -l "critical"

Trouve les fichiers contenant "erreur", puis filtre ceux contenant aussi "critical".

Compter les occurrences

find . -name "*.py" | xargs grep -c "TODO" | xargs -I {} echo "{} occurrences"

Exemples pratiques complets

Archiver des fichiers modifiés récemment

find /home -mtime -7 | xargs tar -czf backup-semaine.tar.gz

Modifier les permissions de fichiers trouvés

find . -name "*.sh" | xargs chmod 755

Envoyer un mail pour chaque ligne d'un fichier

cat utilisateurs.txt | xargs -I {} mail -s "Rapport" {} < rapport.txt

Renommer des fichiers en masse

ls *.JPG | xargs -n 1 -I {} mv {} {/.}.jpg

Convertit les .JPG en .jpg (minuscules).

Nettoyer les logs de plus de 30 jours

find /var/log -name "*.log" -mtime +30 | xargs rm -f

xargs vs boucle for

La même opération peut souvent être faite avec une boucle for :

# Avec xargs find . -name "*.tmp" | xargs rm
# Avec une boucle for for f in $(find . -name "*.tmp"); do rm "$f"; done

Avantages de xargs :

  • Plus court et lisible
  • Gestion automatique du maximum d'arguments par commande
  • Support du parallélisme avec -P
  • Meilleure gestion des noms de fichiers spéciaux

Mode interactif avec -p

Pour vérifier chaque action avant execution :

find . -name "*.bak" | xargs -p rm

Affichera chaque commande avec confirmation (o/n).

Debug avec -t

Pour voir exactement quelles commandes seront exécutées :

echo "fichier1 fichier2" | xargs -t cp -v /destination/

xargs est un outil essentiel pour chaîner les commandes sous Linux. Il transforme les résultats textuels en actions concrètes, permettant des pipelines puissants et efficaces.
