Leçon 105 : zcat, bzcat et xzcat — Lire les fichiers compressés sans les décompresser

Vous avez un fichier compressé et vous voulez simplement voir son contenu, sans créer de copie décompressée sur le disque ? Les commandes zcat, bzcat et xzcat sont exactement faites pour cela. Elles lisent des fichiers compressés et sortent leur contenu décompressé sur la sortie standard — sans toucher au fichier original.

Pourquoi utiliser ces commandes ?

Les fichiers journaux Linux sont souvent compressés pour économiser de l'espace. Par exemple, les vieux logs dans /var/log se retrouvent compressés en .gz, .bz2 ou .xz. Vous ne voulez pas les décompresser à chaque fois pour lire quelques lignes. Ces outils permettent de lire directement le contenu compressé.

Autre cas courant : vous recevez un fichier de logs compressé par email ou téléchargement. Au lieu de le décompresser, de le lire, puis de le supprimer, vous pouvez simplement l'afficher directement.

Les trois variantes

CommandeFormat compresséCompressionDécompresse aussi
zcat.gzgzipzcat = gzcat
bzcat.bz2bzip2bzcat = bzless
xzcat.xzxzxzcat = unxz
lzcat.lzlzmalzcat = unlzma
zstdcat.zstzstandardunzstd

Syntaxe de base

zcat [OPTIONS] fichier.gz
bzcat [OPTIONS] fichier.bz2
xzcat [OPTIONS] fichier.xz

Ces commandes n'ont pas besoin de l'option -d pour décompresser — elles décompressent par défaut quand le fichier a l'extension reconnue.

Exemples fondamentaux

1. Lire un fichier .gz directement

# Lire un journal compressé
zcat /var/log/syslog.1.gz
# Lire un ancien log rotatif
zcat /var/log/dmesg.0.gz

2. Lire un fichier .bz2

# Lire un log compressé avec bzip2
bzcat /var/log/alternatives.log.2.bz2
# Lire un fichier source compressé
bzcat projet.tar.bz2 | tar -tvf -

3. Lire un fichier .xz

# Lire un log compressé avec xz
xzcat /var/log/journal/system.journal.1.xz
# Extraire directement depuis un .tar.xz
xzcat archive.tar.xz | tar -xvf -

Combiner avec grep et less

Rechercher dans un fichier compressé

# Chercher "erreur" dans un log compressé
zcat fichier.log.gz | grep "erreur"
# Avec awk, compter les occurrences
zcat syslog.1.gz | awk '/ssh/ {count++} END {print count}'

Voir les dernières lignes d'un fichier compressé

# Dernières 20 lignes d'un .gz
zcat /var/log/auth.log.2.gz | tail -20
# combiner avec head
bzcat logs.tar.bz2 | tar -xOf - log.txt | head -50

Utiliser avec less (version compressée)

# less pour naviguer dans un fichier compressé
zless fichier.log.gz
# Équivalent de less pour bzip2
bzless fichier.log.bz2
# Équivalent de less pour xz
xzless fichier.log.xz

Utiliser avec les pipes

Décompresser et compter les lignes

# Compter les lignes d'un fichier compressé
zcat log.gz | wc -l
# Compter les lignes avec bzip2
bzcat log.bz2 | wc -l

Combiner plusieurs fichiers compressés

# Lire plusieurs fichiers compressés à la suite
zcat syslog.1.gz syslog.2.gz | grep "erreur"
# Avec joker (tous les .gz)
zcat /var/log/syslog*.gz | grep "echec"

Décompresser et extraire depuis une archive tar compressée

# Lister le contenu d'un tar.gz sans extraire
zcat archive.tar.gz | tar -tvf -
# Extraire un fichier précis d'un tar.bz2
bzcat backup.tar.bz2 | tar -xvf - fichier.txt
# Extraire un fichier précis d'un tar.xz
xzcat backup.tar.xz | tar -xvf - config.conf

Options utiles

-f : Forcer si le fichier n'a pas l'extension reconnue

# Décompresser même si le fichier n'a pas l'extension .gz
zcat -f fichier_sans_extension

-k : Garder le fichier compressé (mode cat)

Bien que zcat ne décompresse pas par défaut (il envoie vers stdout), cette option existe pour d'autres outils de décompression.

# Décompresser en gardant l'original
gunzip -k fichier.gz
bzip2 -k fichier.bz2
xz -k fichier.xz

-N : Afficher le numéro de ligne

# Avec numérotation des lignes
zcat log.gz | cat -n

-h : Afficher l'aide

zcat -h
bzcat --help
xzcat --help

Cas d'utilisation courants

1. Explorer les logs Apache/Nginx compressés

# Trouver les erreurs 500 dans les logs Apache
zcat /var/log/apache2/access.log.1.gz | grep "500"
# Compter les erreurs par IP
zcat /var/log/apache2/error.log.1.gz | awk '{print $NF}' | sort | uniq -c

2. Rechercher dans les logs système rotatifs

# Chercher une connexion SSH échouée dans plusieurs logs
zcat /var/log/auth.log*.gz | grep "Failed password"
# Voir les connexions du jour dans tous les logs (compressés et non)
zcat -f /var/log/auth.log.1.gz | grep "session opened"

3. Analyser d'anciens logs compressés

# Compter les lignes par jour dans un log compressé
zcat syslog.2.gz | awk '{print $1, $2}' | sort | uniq -c
# Extraire les erreurs critiques
bzcat messages.1.bz2 | grep -i "critical\|alert\|emergency"

4. Transformer un fichier compressé en non-compressé

# Décompresser vers un nouveau fichier
zcat fichier.gz > fichier_decompresse.txt
# Alternative :
gunzip -c fichier.gz > fichier_decompresse.txt

Scripts pratiques

Script : Rechercher dans tous les logs compressés

#!/bin/bash
# Rechercher un motif dans tous les logs (compressés ou non)
if [ -z "$1" ]; then
echo "Usage: $0 [fichier.log*]"
exit 1
fi
MOTIF="$1"
shift
LOG_PATTERN="${*:-/var/log/syslog*}"
zcat -f $LOG_PATTERN | grep "$MOTIF"

Script : Compter les lignes par type de compression

#!/bin/bash
# Compter les lignes de plusieurs fichiers compressés
count_lines() {
local file="$1"
local count
case "$file" in
*.gz) count=$(zcat "$file" 2>/dev/null | wc -l);;
*.bz2) count=$(bzcat "$file" 2>/dev/null | wc -l);;
*.xz) count=$(xzcat "$file" 2>/dev/null | wc -l);;
*.zst) count=$(zstdcat "$file" 2>/dev/null | wc -l);;
*) count=$(wc -l < "$file");;
esac
echo "$count $file"
}
export -f count_lines
ls /var/log/*.gz /var/log/*.bz2 /var/log/*.xz 2>/dev/null | \
xargs -I {} bash -c 'count_lines "{}"'

Script : Lister le contenu d'archives compressées

#!/bin/bash
# Lister le contenu d'une archive tar sans l'extraire
list_archive() {
local archive="$1"
echo "=== Contenu de $archive ==="
case "$archive" in
*.tar.gz|*.tgz)
zcat "$archive" | tar -tvf -
;;
*.tar.bz2)
bzcat "$archive" | tar -tvf -
;;
*.tar.xz)
xzcat "$archive" | tar -tvf -
;;
*.zip)
unzip -l "$archive"
;;
*)
echo "Format non supporté"
;;
esac
}
list_archive "$1"

Résumé

Les commandes zcat, bzcat et xzcat permettent de lire le contenu de fichiers compressés sans les décompresser sur le disque. Elles sont indispensables pour analyser les logs système rotatifs et travailler avec des archives compressées.

  • zcat fichier.gz — lire un fichier gzip compressé
  • bzcat fichier.bz2 — lire un fichier bzip2 compressé
  • xzcat fichier.xz — lire un fichier xz compressé
  • zcat -f fichier — forcer la décompression sans extension
  • zcat fichier.gz | grep motif — rechercher dans un log compressé
  • zcat archive.tar.gz | tar -xvf - — extraire depuis un tar.gz sans décompresser avant
  • zless fichier.gz — naviguer interactivement dans un fichier compressé
  • zcat fichier.gz > nouveau.txt — convertir en fichier non compressé

Associées à grep, awk, sort ou tar, ces commandes permettent de traiter des téraoctets de logs compressés sans jamais toucher au fichier original.
