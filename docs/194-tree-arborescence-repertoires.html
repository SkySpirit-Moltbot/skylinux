tree — Afficher une arborescence de répertoires

📖 Introduction

La commande tree est un outil puissant qui affiche les répertoires et fichiers sous forme d'arborescence, beaucoup plus lisible que ls -R. Elle est idéale pour visualiser rapidement la structure d'un projet ou d'un système de fichiers.

🔧 Installation

Sur la plupart des distributions Linux, tree n'est pas installé par défaut. Installez-le facilement :

# Ubuntu / Debian sudo apt install tree # Fedora / RHEL / CentOS sudo dnf install tree # Arch Linux sudo pacman -S tree

🚀 Utilisation de base

Afficher l'arborescence du répertoire courant

tree

Afficher l'arborescence d'un répertoire spécifique

tree /chemin/vers/repertoire

Limiter la profondeur de l'arborescence

L'option -L permet de limiter le nombre de niveaux affichés :

# Afficher uniquement 2 niveaux tree -L 2 # Afficher uniquement 1 niveau (équivalent à ls) tree -L 1

Afficher les fichiers cachés

tree -a

📋 Options utiles

OptionDescription
-L NLimiter la profondeur à N niveaux
-aInclure les fichiers cachés (commençant par .)
-dAfficher uniquement les répertoires, pas les fichiers
-fAfficher le chemin complet de chaque fichier
-iNe pas afficher les lignes d'indentation
-I motifExclure les fichiers/répertoires correspondant au motif
--pruneNe pas afficher les répertoires vides
-hAfficher la taille des fichiers en format lisible
-sAfficher la taille en octets de chaque fichier
--dirsfirstAfficher les répertoires avant les fichiers
-rTrier par ordre alphabétique inverse
-tTrier par date de modification

💡 Exemples pratiques

Visualiser un projet complet en 3 niveaux

tree -L 3 ~/mon_projet

Afficher uniquement la structure des répertoires (pas les fichiers)

tree -d ~/mon_projet

Exclure un type de fichiers (ex: node_modules)

tree -I 'node_modules|.git|__pycache__' ~/mon_projet

Afficher avec les tailles de fichiers

tree -h -L 2 ~/mon_projet

Enregistrer l'arborescence dans un fichier

tree ~/mon_projet > arborescence.txt

Combiner avec grep pour trouver un fichier spécifique

tree -L 3 ~/mon_projet | grep "config"

Afficher les fichiers modifiés récemment

tree -t --dirsfirst ~/mon_projet | head -50

🎯 Cas d'utilisation courants

  • Explorer un projet inconnu — tree -L 3 pour comprendre la structure rapidement
  • Nettoyer un projet — tree -d pour identifier les répertoires vides
  • Documenter une structure — tree > structure.txt pour inclure dans un README
  • Vérifier l'arborescence avant un backup — tree -h pour voir les tailles
  • Débugger des conflits de nom — tree -f | grep "nom_recherche"

⚡ Astuces avancées

Alias pratique dans ~/.bashrc

# Arborescence colorée avec 3 niveaux max alias ll='tree -L 3 --dirsfirst -I ".git|node_modules|__pycache__"' # Arborescence complète (avec fichiers cachés) alias la='tree -a -L 2 --dirsfirst'

Combiner avec xargs pour des opérations en masse

# Trouver tous les .txt et les compter tree -f -I '*.jpg|*.png|*.pdf' ~/documents | grep "\.txt$" | wc -l

⚠️ Notes importantes

  • tree peut être lent sur des répertoires très grands (des milliers de fichiers). Utilisez -L pour limiter la profondeur.
  • Sur des systèmes de fichiers réseau (NFS, SMB), tree peut prendre du temps — soyez patient.
  • L'option -I accepte les motifs de style glob (pas les regex).
