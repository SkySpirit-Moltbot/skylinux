shuf — Générer de l'aléatoire en ligne de commande

📖 Introduction

La commande shuf (pour shuffle, soit mélangé en français) permet de générer des permutations aléatoires à partir d'une entrée. C'est l'outil idéal pour mélanger des lignes, sélectionner aléatoirement des éléments ou produire des nombres dans un ordre imprévisible.

Très utile pour les scripts de test, les tirages au sort, ou la sélection aléatoire de données.

🔧 Syntaxe de base

shuf [OPTIONS] [FICHIER] echo "élément1 élément2 élément3" | shuf

🎲 Utilisations courantes

Générer une permutation de nombres

# Générer les nombres de 1 à 10 dans un ordre aléatoire shuf -i 1-10 # Résultat possible : # 7 # 3 # 10 # 1 # 5 # 9 # 2 # 8 # 4 # 6

Mélanger les lignes d'un fichier

# Mélanger toutes les lignes shuf liste.txt # Mélanger et afficher le résultat à l'écran shuf /etc/passwd | head -5

Sélectionner N éléments aléatoirement

L'option -n (pour head count) limite la sortie aux N premières lignes :

# Sélectionner 3 lignes au hasard shuf -n 3 liste.txt # Choisir 5 nombres entre 1 et 50 shuf -i 1-50 -n 5 # Résultat possible : # 23 # 7 # 41 # 15 # 38

🎯 Options principales

OptionDescriptionExemple
-i MIN-MAXGénérer des nombres dans cet intervalleshuf -i 1-100
-n NLimiter la sortie à N lignesshuf -n 5
-eLes arguments sont les éléments à traitershuf -e rouge vert bleu
-o FICHIERÉcrire le résultat dans un fichiershuf -o resultat.txt
-rRépétition possible (tirage avec remise)shuf -r -n 10

💡 Exemples pratiques

Tirage au sort simple

# Avec des mots-clés shuf -e "Pierre" "Paul" "Jacques" "Marie" "Lucie" # Résultat : une personne est tirée au hasard shuf -e "Pierre" "Paul" "Jacques" | head -1

Sélectionner un fichier aléatoire

# Choisir une image au hasard dans un dossier ls ~/Images/*.jpg | shuf -n 1 # Définir un fond d'écran aléatoire (script) FOND=$(ls ~/Images/wallpapers/*.jpg | shuf -n 1) gsettings set org.gnome.desktop.background picture-uri "file://$FOND"

Créer un mot de passe aléatoire

# Générer un mot de passe de 16 caractères cat /dev/urandom | tr -dc 'a-zA-Z0-9' | fold -w 16 | shuf -n 1 # Version plus lisible avec shuf uniquement printf '%s\n' {a..z} {A..Z} {0..9} | shuf -r -n 16 | tr -d '\n' echo

Échantillonnage pour les tests

# Prendre 10% des lignes au hasard TOTAL=$(wc -l < donnees.csv) TAILLE=$((TOTAL / 10)) shuf -n $TAILLE donnees.csv > echantillon.csv # Sélectionner 20% des utilisateurs pour un test A/B getent passwd | shuf -n $(( $(getent passwd | wc -l) * 20 / 100 ))

Mélanger un playlist (exemple)

# Créer une playlist dans un ordre aléatoire ls ~/Musique/*.mp3 | shuf > playlist_melangee.m3u # Jouer la musique dans un ordre aléatoire (avec mplayer) shuf -e ~/Musique/*.mp3 | xargs mplayer

Répétition avec -r (tirage avec remise)

# Générer 10 nombres entre 1 et 6 (comme un dé) shuf -i 1-6 -r -n 10 # Résultat possible : # 3 # 6 # 1 # 6 # 2 # 4 # 6 # 3 # 1 # 5 # Simuler 100 lancers de pièce shuf -e "Pile" "Face" -r -n 100 | sort | uniq -c

📂 Écrire le résultat dans un fichier

# Méthode 1 : redirection shuf -i 1-100 > resultat.txt # Méthode 2 : option -o shuf -i 1-100 -o resultat.txt # Les deux sont équivalentes

🔗 Combiner avec d'autres commandes

Pipeline classique

# Prendre les 5 dernières lignes, puis en choisir 2 au hasard tail -20 /var/log/syslog | shuf -n 2 # Mélanger puis exécuter shuf -e "apt update" "apt upgrade" "reboot" | xargs -I {} sh -c '{}'

Dans un script Bash

#!/bin/bash # Script : sélection aléatoire d'un serveur SERVEURS=( "serveur1.exemple.com" "serveur2.exemple.com" "serveur3.exemple.com" "serveur4.exemple.com" ) # Choisir un serveur au hasard serveur=$(printf '%s\n' "${SERVEURS[@]}" | shuf -n 1) echo "Connexion au serveur : $serveur" ssh "$serveur"

Avec xargs

# Appliquer une commande à 3 fichiers choisis au hasard ls *.log | shuf -n 3 | xargs -I {} gzip {} # Exécuter un backup sur 2 machines aléatoires parmi une liste cat serveurs.txt | shuf -n 2 | xargs -I {} ssh {} "backup.sh"

⚠️ Différence entre shuf et sort -R

La commande sort -R existe aussi pour mélanger, mais voici les différences :

Aspectshufsort -R
PerformancePlus rapide et prévisiblePlus lent sur grands fichiers
Répétition possibleOui, avec -rNon
Sélection aléatoire (head)Fiables avec -nbiaisé car le tri est aléatoire
Standard POSIXNon (GNU coreutils)Non (GNU extension)

Pour la sélection aléatoire, shuf -n est toujours plus fiable que sort -R | head.

🎓 Cas d'utilisation réels

  • Tests automatisés — Exécuter des tests dans un ordre aléatoire pour détecter les dépendances cachées
  • Monte-Carlo — Générer des simulations aléatoires en batch
  • jeux — Tirages, dés, sélection aléatoire
  • ML / Data Science — Créer des jeux de données de test/validation
  • Rotation — Alterner des tâches ou serveurs de manière équilibrée

📝 Résumé des options

shuf [OPTIONS] -e, --echo Traiter les arguments comme des lignes d'entrée -i, --input-range=MIN-MAX Intervalle de nombres (ex: 1-100) -n, --head-count=NOMBRE Nombre de lignes à输出 -o, --output=FICHIER Écrire dans un fichier -r, --repeat Autoriser la répétition (tirage avec remise) -z, --zero-terminated Séparateur nul au lieu de newline

⚡ Astuces

Sélectionner un élément parmi N

# Une seule ligne au hasard shuf -n 1 fichier.txt # Équivalent à : head -$((RANDOM % $(wc -l < fichier.txt) + 1)) fichier.txt | tail -1

Graines aléatoires (reproductibilité)

Bien que shuf ne supporte pas nativement une graine (seed), vous pouvez utiliser RANDOM de Bash pour des cas simples :

# Fixer la graine pour des tests reproductibles RANDOM=42 shuf -e un deux trois quatre cinq
