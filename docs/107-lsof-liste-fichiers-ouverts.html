Leçon 107 : lsof — Lister les fichiers ouverts

La commande lsof (List Open Files) est un outil essentiel pour comprendre ce que le système fait à tout moment. Elle affiche la liste de tous les fichiers ouverts par tous les processus en cours d'exécution. Sous Linux, presque tout est un fichier : les fichiers ordinaires, les répertoires, les tubes (pipes), les sockets réseau, et même les périphériques. lsof vous permet de répondre à des questions comme :

  • Quel processus accède à un fichier précis ?
  • Quel processus écoute sur un port réseau ?
  • Pourquoi un système de fichiers ne peut-il pas être démonté ?
  • Combien de fichiers un processus a-t-il ouverts ?

Installation

lsof est généralement préinstallé sur la plupart des distributions Linux. S'il ne l'est pas :

# Ubuntu / Debian
sudo apt install lsof
# Fedora / RHEL / CentOS
sudo dnf install lsof
# Arch Linux
sudo pacman -S lsof

Syntaxe de base

lsof [OPTIONS]
lsof [OPTIONS] fichier # fichiers ouverts par un fichier precis
lsof -c processus # fichiers ouverts par un processus
lsof -i [protocole:port] # fichiers ouverts reseau
lsof -u utilisateur # fichiers ouverts par un utilisateur

Sortie par defaut

Lancez lsof sans arguments pour voir TOUS les fichiers ouverts par TOUS les processus (attention : liste très longue) :

$ lsof
COMMAND PID USER FD TYPE DEVICE SIZE/OFF NODE NAME
systemd 1 root cwd DIR 253,1 4096 131073 /
systemd 1 root rtd DIR 253,1 4096 131073 /
systemd 1 root txt REG 253,1 1594480 526259 /lib/systemd/systemd
systemd 1 root mem REG 253,1 226960 395949 /lib/x86_64-linux-gnu/libpthread.so.0
systemd 1 root 0u CHR 1,3 0t0 12736 /dev/null
systemd 1 root 1u CHR 1,3 0t0 12736 /dev/null
systemd 1 root 2u CHR 1,3 0t0 12736 /dev/null
sshd 1234 root 3u IPv4 18745 0t0 TCP *:22 (LISTEN)
nginx 2345 root 6u IPv4 23456 0t0 TCP *:80 (LISTEN)

Decryptage des colonnes

ColonneSignification
COMMANDNom de la commande (processus)
PIDNumero du processus (Process ID)
USERProprietaire du processus
FDDescripteur de fichier (0=entree, 1=sortie, 2=erreur, etc.) + mode (r=read, w=write, u=rw)
TYPEType du fichier (REG=fichier normal, DIR=repertoire, CHR=peripherique caractere, FIFO=tube, IPv4/IPv6=socket reseau)
DEVICEPeripherique (majeur/mineur)
SIZE/OFFTaille du fichier ou decalage
NODENumero d'inode (ou protocole pour les sockets)
NAMENom du fichier ou adresse reseau

Filtrer par fichier

Trouver quel processus utilise un fichier

C'est l'utilisation la plus courante : vous voulez savoir quel processus empêche le démontage d'un système de fichiers ou bloque un fichier :

# Trouver les processus qui utilisent un fichier precis
lsof /home/david/document.txt
# Trouver les processus qui utilisent un repertoire
lsof /var/log
# Trouver les processus qui utilisent un systeme de fichiers (pourquoi umount echoue)
lsof +D /mnt/disque-externe
# +D explore recursivement tous les sous-repertoires

Trouver tous les fichiers ouverts dans un repertoire

# Lister tous les fichiers ouverts dans un repertoire (sans recursion)
lsof +d /var/log
# Tous les fichiers ouverts dans /home (recursif)
lsof +D /home
# Attention: peut etre lent sur de gros repertoires

Filtrer par processus

Par nom de commande

# Tous les fichiers ouverts par nginx
lsof -c nginx
# Par plusieurs commandes (commence par)
lsof -c ssh
# Affiche ssh, sshd, ssh-agent...
# Exclure une commande
lsof -c nginx -c ^systemd

Par PID

# Fichiers ouverts par un processus precis
lsof -p 1234
# Par plusieurs PIDs
lsof -p 1234,5678,9012
# Exclure un processus
lsof -p ^1234
# Affiche tout SAUF le processus 1234

Compter les fichiers ouverts par processus

# Compter combien de fichiers chaque processus a ouverts
lsof -c nginx | awk 'NR>1 {print $1}' | sort | uniq -c | sort -rn
# Nombre total de fichiers ouverts par un processus
lsof -c nginx | wc -l
# Limiter la sortie aux fichiers reguliers (pas les sockets, pipes...)
lsof -c nginx -a -d ^FD

Filtrer par utilisateur

# Tous les fichiers ouverts par un utilisateur
lsof -u david
# Plusieurs utilisateurs
lsof -u david -u root
# Exclure un utilisateur
lsof -u ^root
# Tous les fichiers ouverts SAUF par root

lsof et le reseau

Trouver les connexions reseau ouvertes

# Toutes les connexions reseau actives
lsof -i
# Simplement les ports en ecoute (LISTEN)
lsof -i -sTCP:LISTEN
# Connexions etablies
lsof -i -sTCP:ESTABLISHED

Par protocole

# Uniquement IPv4
lsof -i 4
# Uniquement IPv6
lsof -i 6
# Par protocole TCP ou UDP
lsof -i tcp
lsof -i udp

Par port ou plage de ports

# Qui ecoute sur le port 80 ?
lsof -i :80
# Qui utilise le port 443 ?
lsof -i :443
# Plusieurs ports
lsof -i :80 -i :443 -i :22
# Plage de ports
lsof -i :1-1024

Par adresse

# Connexions vers un hote precis
lsof -i @serveur.example.com
# Connexions depuis une IP locale
lsof -i @192.168.1.10

Combiner les filtres

Utiliser -a pour combiner (AND)

# Utilisateur ET port
lsof -u david -a -i :80
# Affiche les fichiers reseau de david sur le port 80
# Commande ET fichier
lsof -c nginx -a /var/log/nginx/access.log
# Quel processus nginx accede a ce log ?

Exclure avec ^

# Tous les fichiers SAUF ceux de root
lsof -u ^root
# Tous SAUF les processus root SUR le port 22
lsof -u ^root -i :22

Exemples pratiques

1. Pourquoi umount echoue ?

Le cas classique : vous voulez démonter un disque externe mais le système refuse :

$ sudo umount /mnt/disque-externe
umount: /mnt/disque-externe: target is busy.
# Trouver ce qui utilise ce point de montage
$ sudo lsof +D /mnt/disque-externe
COMMAND PID USER FD TYPE DEVICE SIZE/OFF NODE NAME
bash 1234 david cwd DIR 8,17 4096 1234 /mnt/disque-externe
vim 2345 david 4r REG 8,17 8192 2345 /mnt/disque-externe/notes.txt
# Vous pouvez maintenant tuer les processus ou fermer les fichiers

2. Quel processus ecoute sur un port ?

# Equivalent de "quel process sur port 3306 ?"
$ lsof -i :3306
COMMAND PID USER FD TYPE DEVICE SIZE/OFF NODE NAME
mysqld 2345 mysql 19u IPv4 45678 0t0 TCP *:3306 (LISTEN)
# Tous les services en ecoute
lsof -i -sTCP:LISTEN

3. Verifier les connexions d'un utilisateur

# Toutes les connexions reseau d'un utilisateur
lsof -u david -i
# Connections SSH actives d'un utilisateur
lsof -u david -i :22 -a -sTCP:ESTABLISHED

4. Surveillance en temps reel

# Actualiser toutes les 2 secondes
watch -n 2 'lsof -i :80'
# Surveiller les nouveaux fichiers ouverts par un processus
lsof -c nginx -r 2
# -r : mode repeat toutes les 15s (par defaut)
# -r2 : toutes les 2 secondes

5. Trouver les fichiers supprimes mais encore ouverts

Un cas très utile : un fichier supprimé mais toujours utilisé par un processus (souvent un logrotate qui a rotate mais pas reload) :

# Fichiers supprimes (deleted) mais toujours ouverts
lsof +L1
# Pour un processus precis
lsof -p 1234 +L1
# Recuperer l'espace disque en relancant le service
# (ferme les fichiers supprimes encore ouverts)

6. Voir les pipes et tubes nommes

# Fichiers de type FIFO (tubes)
lsof -F
# Tous les types de fichiers non-reguliers
lsof -e /var/run

Options utiles

OptionDescription
-nNe pas resolver les noms d'hotes (plus rapide)
-PNe pas resolver les numeros de port en noms (http, ssh...)
-FFormat de sortie machine (pour parser)
+D repertoireExplorer recursivement un repertoire
+d repertoireLister les fichiers dans le repertoire (non recursif)
-aCombiner les criteres avec ET
-c cmdFiltrer par commande (commencant par)
-p pidFiltrer par PID
-u userFiltrer par utilisateur
-i [criteria]Filtrer par interface reseau
+L1Afficher les fichiers supprimes encore ouverts
-NLister les fichiers NFS sans verifier le serveur
-r[s]Mode repeat toutes les s secondes (defaut 15)

Scripts pratiques

Script : Alerte si un port est deja utilise

#!/bin/bash
# Verifier si un port est deja en cours d'utilisation
PORT="${1:-8080}"
RESULT=$(lsof -i :$PORT -sTCP:LISTEN 2>/dev/null)
if [ -n "$RESULT" ]; then
echo "ERREUR: Le port $PORT est deja utilise :"
echo "$RESULT"
exit 1
else
echo "Port $PORT est libre, vous pouvez demarrer votre service."
exit 0
fi

Script : Liberer les fichiers supprimes encore ouverts

#!/bin/bash
# Trouver et liberer l'espace des fichiers supprimes encore ouverts
echo "=== Fichiers supprimes mais encore ouverts ==="
lsof +L1
echo ""
echo "Espace total bloques (octets):"
lsof +L1 2>/dev/null | awk 'NR>1 {s+=$7} END {print s}'
echo ""
echo "Pour liberer: redemarrez le service concerne ou tuez le processus."
echo "Exemple: sudo systemctl restart nginx"

Script : Compteur de fichiers ouverts par utilisateur

#!/bin/bash
# Compter les fichiers ouverts par chaque utilisateur
echo "=== Fichiers ouverts par utilisateur ==="
lsof -n -P | awk 'NR>1 {print $3}' | sort | uniq -c | sort -rn
echo ""
echo "=== Limite utilisateur (ulimit -n) ==="
for user in $(lsof -n -P | awk 'NR>1 {print $3}' | sort -u); do
limite=$(su -s /bin/bash "$user" -c "ulimit -n" 2>/dev/null)
echo "$user: $limite fichiers max"
done

Script : Surveillance d'acces a un fichier

#!/bin/bash
# Surveiller qui accede a un fichier en temps reel
FILE="$1"
if [ -z "$FILE" ]; then
echo "Usage: $0 "
exit 1
fi
echo "Surveillance de $FILE (Ctrl+C pour arreter)..."
while true; do
clear
date
lsof "$FILE"
sleep 2
done

lsof vs autres commandes

CommandeCe qu'elle montreQuand l'utiliser
lsofTous les fichiers ouverts par tous les processusOutil generaliste, diagnostic systeme
ssSockets reseau (plus moderne que netstat)Connexions reseau rapide
netstatConnexions reseau et tables de routageCompatibilite, informations plus larges
fuserProcessus utilisant un fichier ou point de montageIdentique mais plus leger
/proc/*/fdDescripteurs de fichiers par processusInspection directe sans lsof

Cas d'utilisation courants

1. Preparer une migration de service

# Identifier tous les fichiers ouverts par un service avant arret
lsof -c nginx | awk '{print $NF}' | sort -u | grep -v '^$'
# Verifier que le service a bien libere tous les fichiers
systemctl stop nginx && sleep 2 && lsof -c nginx

2. Diagnostic de performance

# Verifier si un processus ouvre trop de fichiers
lsof -p 1234 | wc -l
# Comparer avec la limite syste
cat /proc/sys/fs/file-max
ulimit -n

3. Securite : detection d'anomalies

# Verifier les connexions depuis un compte utilisateur suspect
lsof -u www-data -i
# Trouver les processus qui ecoutent sur des ports non attendus
lsof -i -sTCP:LISTEN | grep -v -E ':(22|80|443|25|53):'

Resume

lsof est un outil de diagnostic incontournable pour tout administrateur Linux. Il révèle tout ce qui est ouvert sur votre système :

  • lsof — Lister tous les fichiers ouverts (sortie très longue)
  • lsof fichier — Qui utilise ce fichier précis ?
  • lsof +D /repertoire — Tous les fichiers dans un répertoire (récursif)
  • lsof -c nginx — Tous les fichiers ouverts par nginx
  • lsof -u david — Tous les fichiers d'un utilisateur
  • lsof -i :80 — Qui utilise le port 80 ?
  • lsof -i -sTCP:LISTEN — Tous les ports en écoute
  • lsof +L1 — Fichiers supprimés mais encore ouverts
  • lsof -p 1234 — Tous les fichiers d'un processus précis
  • lsof -u david -a -i :443 — Combinaison de filtres (ET)

Maitriser lsof vous permet de diagnostiquer rapidement les problèmes de fichiers verrouillés, les services qui ne s'arrêtent pas proprement, les démontages qui échouent, et les connexions réseau suspectes.
