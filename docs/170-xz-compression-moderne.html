xz — Compression moderne et performante

La commande xz est un outil de compression de nouvelle génération. Il utilise l'algorithme LZMA2 et offre un excellent taux de compression, souvent supérieur à gzip et bzip2, tout en restant rapide et efficace en mémoire. C'est le format de compression recommandé pour l'archivage moderne sous Linux.

Compression de base

Compresser un fichier

Pour compresser un fichier avec xz, utilisez simplement :

# Compresser un fichier (remplace le fichier original par fichier.xz)
xz monfichier.txt
# Le fichier devient monfichier.txt.xz

Par défaut, xz supprime le fichier original après compression réussie.

Décompresser un fichier

# Décompresser (restaure le fichier original)
xz -d monfichier.txt.xz
# Alternative avec uname (unarchive)
unxz monfichier.txt.xz

Conserver le fichier original

Utilisez l'option -k (keep) pour garder le fichier source :

# Compresser sans supprimer l'original
xz -k monfichier.txt
# Décompresser sans supprimer l'archive
xz -d -k archive.tar.xz

Les niveaux de compression

xz offre 9 niveaux de compression (de -0 à -9). Plus le niveau est élevé, plus la compression est forte, mais plus le temps de traitement augmente.

NiveauDescriptionUtilisation typique
-0Compression rapide (équivalent gzip -1)Transferts temporaires
-1Très rapideQuand la vitesse prime
-2Rapide (équivalent gzip -6 par défaut)Usage courant
-3ÉquilibréBon compromis
-4BonUsage courant
-5Très bonRecommandé par défaut
-6Excellent (défaut)Archives importantes
-7Très excellentArchives longue durée
-8Quasi optimalCompression maximale
-9Compression maximaleRares cas spéciaux
# Compression ultra-rapide (niveau 0)
xz -0 gros_fichier.bin
# Compression maximale (niveau 9)
xz -9 gros_fichier.bin
# Niveau 7 (entre -6 et -9)
xz -7 -k archive_backup.sql

Comparaison des niveaux

# Tester différents niveaux sur un fichier de 100 Mo
time xz -0 fichier.img # Très rapide : ~0.5s
time xz -6 fichier.img # Équilibré : ~3s
time xz -9 fichier.img # Lent : ~15s, mais plus petit

Compression avec tar

xz se combine parfaitement avec tar pour créer des archives compressées :

# Créer une archive .tar.xz (syntaxe moderne)
tar -cJf archive.tar.xz /chemin/vers/dossier
# Créer une archive .tar.xz (syntaxe alternative)
tar -caf archive.tar.xz /chemin/vers/dossier
# Décompresser et extraire une archive .tar.xz
tar -xJf archive.tar.xz
# Lister le contenu sans extraire
tar -tJf archive.tar.xz

Note : L'option -J (avec J majuscule) indique à tar d'utiliser xz comme format de compression.

Options utiles

-v : mode verbose (afficher la progression)

# Afficher des détails pendant la compression
xz -v fichier.txt
# Sortie : fichier.txt.xz (4.2 Mo → 1.1 Mo, 73.8% compression)

-l : lister les informations d'une archive compressée

# Voir les détails sans décompresser
xz -l archive.tar.xz

Tester l'intégrité

# Vérifier qu'un fichier compressé n'est pas corrompu
xz -t archive.tar.xz

Compresser plusieurs fichiers

# Compresser plusieurs fichiers individuellement
xz fichier1.txt fichier2.txt fichier3.txt
# Résultats : fichier1.txt.xz, fichier2.txt.xz, fichier3.txt.xz

Compression récursive

# Compresser tous les fichiers .log dans un répertoire
find /var/log -name "*.log" -print0 | xargs -0 xz
# Compresser tous les fichiers d'un dossier
find /backup -type f -print0 | xargs -0 xz

Format .xz vs autres formats

Comparaison rapide

FormatCompressionVitesseUsage
gzip (.gz)BonneTrès rapideFichiers temporaires, logs
bzip2 (.bz2)Très bonneMoyenneArchives classiques
xz (.xz)ExcellenteRapideArchives modernes, sources Linux
zstd (.zst)Très bonneTrès rapideBackup, compression en temps réel

Pourquoi xz est utilisé pour les sources Linux ?

Le kernel Linux et beaucoup de projets open source distributes leurs archives en .tar.xz car :

  • Compression supérieure à gzip et bzip2
  • Décompression rapide
  • Format libre et bien maintenu
  • Supporte des fichiers volumineux (plus de 4 Go)

Exemple : télécharger les sources du kernel

# wget ou curl pour télécharger une archive xz
wget https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.8.tar.xz
# Vérifier l'empreinte (sha256sum)
sha256sum linux-6.8.tar.xz
# Extraire directement avec tar
tar -xJf linux-6.8.tar.xz

Gestion de la mémoire

xz peut utiliser beaucoup de RAM selon le niveau de compression. Vous pouvez limiter cela :

# Limiter l'utilisation mémoire à 64 Mo
xz -M 64 fichier.img
# Afficher la mémoire utilisée
xz -vv fichier.txt

Sur les systèmes avec peu de RAM, privilégiez les niveaux -0 à -3.

xz dans les scripts

Compression automatique

#!/bin/bash
# Compresser tous les logs de plus de 7 jours
find /var/log -name "*.log" -mtime +7 -print0 | \
xargs -0 -I {} sh -c 'xz {} && echo "Compressé: {}"'

Sauvegarde avec horodatage

#!/bin/bash
# Créer une sauvegarde compressée
DATE=$(date +%Y%m%d_%H%M%S)
tar -cJf /backup/donnees_$DATE.tar.xz /home/user/documents
echo "Sauvegarde créée : donnees_$DATE.tar.xz"

Nettoyage des archives anciennes

#!/bin/bash
# Supprimer les archives xz de plus de 30 jours
find /backup -name "*.xz" -mtime +30 -delete
echo "Archives anciennes supprimées"

Bonnes pratiques

  • Utilisez -k pour garder les originaux jusqu'à vérification
  • Préférez -6 (défaut) pour un bon équilibre compression/vitesse
  • Pour des sauvegardes fréquentes, utilisez -3 (rapide)
  • Pour des archives de distribution, utilisez -9 (compression maximale)
  • Vérifiez toujours avec xz -t après compression critique

Conclusion

xz est l'outil de compression moderne par excellence sous Linux. Plus efficace que gzip et bzip2, il est devenu le standard pour la distribution de logiciels et d'archives. Maîtrisez les niveaux de compression et combinez-le avec tar pour créer des archives compactes et fiables.
