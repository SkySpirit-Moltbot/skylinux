set — Contrôler le comportement du Shell Bash

📖 Introduction

La commande set est un builtin Bash qui permet de modifier le comportement du shell et de ses scripts. Elle contrôle notamment la gestion des erreurs, l'expansion des motifs, l'historique, et bien plus encore.

Chaque option activée par set change la façon dont le shell interprète les commandes. C'est un outil puissant pour écrire des scripts robustes ou déboguer des comportements étranges.

🔧 Syntaxe de base

# Activer des options set -option # Désactiver des options set +option # Activer plusieurs options set -euo pipefail # Afficher toutes les options actives set -o

⚡ Options les plus utiles

-e : Arrêter sur la première erreur

L'option -e (pour exit on error) fait quitter le script dès qu'une commande retourne un code de sortie non nul :

#!/bin/bash set -e echo "Début du script" fichier_inexistant.txt # Cette commande échoue → le script s'arrête ici echo "Cette ligne ne sera jamais atteinte"

Cette option est recommandée pour tout script de production. Elle empêche le script de continuer quand quelque chose se passe mal.

-u : Détecter les variables non définies

L'option -u (pour undefined) génère une erreur quand une variable non définie est utilisée :

#!/bin/bash set -u echo "Bienvenue $nom_utilisateur" # Si $nom_utilisateur n'existe pas → erreur # Sans set -u, cela afficherait simplement une chaîne vide sans avertissement

-o pipefail : Garder le code de retour du pipeline qui échoue

Par défaut, le code de retour d'un pipeline est celui de la dernière commande. pipefail retourne le code de la première commande qui échoue :

# Sans pipefail : le code de retour est celui de grep (0 si trouvé) commande | grep pattern echo "Code: $?" # Affiche 0 même si commande échoue # Avec pipefail : le code de retour est celui de la commande qui échoue set -o pipefail commande | grep pattern echo "Code: $?" # Affiche le vrai code d'erreur de commande

-x : Mode débogage (trace)

L'option -x affiche chaque commande avant son exécution, avec les valeurs des variables substituées :

#!/bin/bash set -x nom="Alice" age=30 echo "Bonjour $nom, vous avez $age ans" # Sortie affichée : # + nom=Alice # + age=30 # + echo 'Bonjour Alice, vous avez 30 ans' # Bonjour Alice, vous avez 30 ans

-v : Afficher les lignes lues

L'option -v affiche chaque ligne du script telle qu'elle est lue par le shell, avant expansion :

#!/bin/bash set -v echo "Test $HOME" # Affiche : # echo "Test $HOME" # Test /home/utilisateur

💡 Combinaison recommandée pour les scripts robustes

La combinaison set -euo pipefail est devenue un standard dans l'écriture de scripts Bash professionnels :

#!/bin/bash # Mode strict : arrêt sur erreur ou variable non définie set -euo pipefail # Variables obligatoires : "${NOM_FICHIER:?Erreur: NOM_FICHIER doit être défini}" : "${TAILLE_MAX:?Erreur: TAILLE_MAX doit être défini}" echo "Traitement de $NOM_FICHIER (max: $TAILLE_MAX octets)" # ... suite du script

Explication détaillée

  • -e : Le script s'arrête dès qu'une commande échoue
  • -u : Le script s'arrête si une variable n'est pas définie
  • -o pipefail : Un pipeline retourne le code d'erreur réel, pas juste celui de la dernière commande

🔄 Activer et désactiver

On peut activer une option avec - et la désactiver avec + :

#!/bin/bash set -e # Activer : quitter sur erreur commandé_risqué # Si échec → arrêt set +e # Désactiver : continuer même en cas d'erreur commandé_risqué # Si échec → on continue set -e # Réactiver echo "Fin du script"

🛠️ Options interactives du shell

Ces options sont surtout utiles dans un shell interactif ou dans le ~/.bashrc :

Options d'historique

# Ne pas enregistrer de commande en double dans l'historique set -o histappend # Ignorer les doublons dans l'historique HISTCONTROL=ignoredups # Ignorer les commandes commençant par un espace HISTCONTROL=ignorespace # Ignorer les deux HISTCONTROL=ignoreboth

Options de correction

# Activer la correction orthographique des commandes shopt -s cdspell # Compléter les chemins même avec des fautes de frappe shopt -s nocaseglob

🔍 shopt : d'autres options du shell

La commande shopt (shell options) permet d'activer des options supplémentaires que set ne couvre pas :

# Voir toutes les options et leur état shopt # Activer une option shopt -s nom_option # Désactiver une option shopt -u nom_option # Options utiles shopt -s histappend # Ajouter à l'historique au lieu de l'écraser shopt -s checkwinsize # Mettre à jour LINES et COLUMNS après resize shopt -s cmdhist # Garder les commandes multi-lignes comme une entrée shopt -s dotglob # Inclure les fichiers cachés dans les expansions * shopt -s nullglob # Remplacer les patterns sans correspondance par rien shopt -s nocaseglob # Expansion insensible à la casse

⚠️ Pièges courants

set -e dans une fonction qui retourne explicitement

#!/bin/bash set -e ma_fonction() { return 1 # set -e ne quitte pas ici si c'est explicite } ma_fonction # Ne quitte PAS car return est explicite echo "On continue"

set -e avec les条件 ternaires

#!/bin/bash set -e # L'opérateur || est souvent utilisé pour éviter set -e commande || true # Continue même en cas d'échec commande || : # Équivalent (null command) # Mais prudence avec les pipes : commande1 | commande2 # Si commande1 échoue mais commande2 réussit → code = 0 sans pipefail

set -u vs variables tableaux

#!/bin/bash set -u tableau=([0]="a" [2]="c") # Note : l'index 1 n'existe pas echo "${tableau[0]}" # OK : "a" echo "${tableau[1]}" # ERREUR avec set -u (même si le tableau existe) echo "${tableau[@]}" # OK : affiche "a c"

🎯 Débogage avec set

Débogage ciblé avec un sous-shell

#!/bin/bash set -euo pipefail echo "Début" # Déboguer seulement cette partie ( set -x resultat=$((calcul_complexe)) echo "Résultat: $resultat" ) echo "Suite du script"

Débogage depuis la ligne de commande

# Lancer un script en mode trace bash -x mon_script.sh # Lancer en mode noexec (vérifier la syntaxe) bash -n mon_script.sh # Lancer avec exit on error bash -e mon_script.sh

ISET bash pour le débogage

On peut activer le mode trace seulement pour certaines fonctions :

#!/bin/bash set -euo pipefail fonction_complexe() { set -x # ... code complexe ... result=$((a + b * c)) set +x # Désactiver le trace echo "Résultat: $result" } echo "Début" fonction_complexe echo "Fin"
