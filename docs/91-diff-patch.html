Leçon 91 — diff et patch — Comparer et appliquer des différences

Qu'est-ce que diff et patch ?

diff analyse deux fichiers et affiche les différences ligne par ligne. patch utilise le fichier de différences généré par diff pour reconstruire le fichier modifié à partir de l'original. Ce tandem est essentiel pour comparer des versions, appliquer des modifications et collaborer sur du code.

Syntaxe de base de diff

diff [OPTIONS] FICHIER1 FICHIER2

Formats de sortie

1. Format normal (par défaut)

Le format le plus simple, avec des symboles intuitifs :

diff fichier_original.txt fichier_modifie.txt
SymboleSignification
<Ligne présente uniquement dans le premier fichier
>Ligne présente uniquement dans le second fichier
1c1Ligne 1 du fichier 1 changée en ligne 1 du fichier 2
3d2Ligne 3 supprimée, il faudrait insérer ligne 2 après
2a3Ligne 2 ajoutée, correspond à la nouvelle ligne 3

2. Format unifié (le plus courant)

Le format recommandé pour la plupart des usages, avec le contexte visible :

diff -u fichier_original.txt fichier_modifie.txt
--- fichier_original.txt 2026-06-15 10:00:00.000000000 +0200
+++ fichier_modifie.txt 2026-06-15 10:05:00.000000000 +0200
@@ -1,3 +1,4 @@
ligneinchangée
-ligne supprimée
+nouvelle ligne ajoutée
autre ligneinchangée

3. Format side-by-side (côte à côte)

Pour une comparaison visuelle facilitée :

diff -y fichier_original.txt fichier_modifie.txt
SymboleSignification
|Ligne modifiée
<Ligne uniquement dans le fichier de gauche
>Ligne uniquement dans le fichier de droite

Options utiles de diff

OptionDescription
-u NAfficher N lignes de contexte autour des modifications
-rComparer les répertoires récursivement
-iIgnorer la casse (majuscules/minuscules)
-wIgnorer les espaces blancs
-BIgnorer les lignes vides
-qAfficher seulement si les fichiers diffèrent
-sIndiquer quand les fichiers sont identiques
-NTraiter les fichiers absents comme vides

Générer un fichier patch

Pour sauvegarder les différences dans un fichier (patch) :

diff -u fichier_original.txt fichier_modifie.txt > modifications.patch

Pour comparer des répertoires entiers :

diff -ruN repertoire_original/ repertoire_modifie/ > modifications.patch

Appliquer un patch avec patch

La commande patch applique les modifications contenues dans un fichier patch :

patch -p1 < modifications.patch

L'option -p1 retire le premier niveau de répertoire des chemins du patch. Cela permet d'appliquer le patch depuis n'importe quel répertoire.

Exemples concrets

1. Comparer deux fichiers texte

# Fichier original
echo -e "ligne 1\nligne 2\nligne 3" > original.txt
# Fichier modifié
echo -e "ligne 1\nligne 2 modifié\nligne 3\nligne 4" > modifie.txt
# Comparer
diff -u original.txt modifie.txt

2. Générer un patch pour un projet

# Depuis la racine du projet
diff -ruN projet_v1/ projet_v2/ > corrections.patch
# Vérifier le contenu du patch
cat corrections.patch

3. Appliquer un patch

# Depuis le répertoire contenant le projet
patch -p1 < corrections.patch
# Vérifier que ça a fonctionné
diff -rq projet_v1/ projet_v2/

4. Annuler un patch (reverse)

Pour revenir en arrière et还原 le fichier original :

patch -R < corrections.patch

5. Comparer deux répertoires

diff -rq repertoire1/ repertoire2/

L'option -q affiche uniquement les fichiers qui diffèrent, sans le détail des modifications.

6. Ignorer les espaces et la casse

diff -uwB fichier1.txt fichier2.txt

Combine les options -w (espaces), -u (unifié) et -B (lignes vides) pour une comparaison plus souple.

Utiliser diff avec Git

Git utilise en interne un format similaire à diff pour afficher les modifications :

# Voir les modifications non commitées
git diff
# Voir les modifications d'un fichier précis
git diff -- fichier.txt
# Comparer avec une version antérieure
git diff HEAD~3 -- fichier.txt
# Générer un patch à partir des modifications
git diff > modifications.patch

Bonnes pratiques

  • Toujours utiliser le format unifié (-u) : plus lisible et standardisé
  • Inclure du contexte (-u 3 ou plus) : facilite la compréhension des modifications
  • Vérifier avant d'appliquer : lisez le patch avant d'utiliser patch
  • Sauvegarder : appliquez le patch sur une copie du projet d'abord
  • Utiliser -N pour les répertoires : traite les fichiers absents comme vides, utile pour les nouveaux fichiers
  • Combiner avec git : Git facilite la gestion des patchs et l'historique

Résumé

CommandeRôle
diff -u f1 f2Comparer deux fichiers en format unifié
diff -rq d1 d2Comparer deux répertoires rapidement
diff -ruN d1 d2 > patch.diffGénérer un patch pour un répertoire
patch -p1 < patch.diffAppliquer un patch
patch -R < patch.diffAnnuler un patch

diff et patch forment un tandem puissant pour comparer des fichiers, suivre les modifications et partager des correctifs. Leur format unifié est devenu un standard dans le monde du développement logiciel.
