Leçon 133 - tr — Transformer du texte caractère par caractère

La commande tr (pour translate ou translate characters) est un outil minuscule mais extrê

La commande tr (pour translate) effectue des transformations de texte caractère par caractère. Contrairement à sed qui opère sur des motifs, tr travaille directement sur les caractères — substitution, suppression, compression — de manière بسيطة et très rapide. C'est l'outil idéal pour nettoyer des données, convertir des majuscules/minuscules, ou supprimer les espaces indésirables.

Principe de fonctionnement

tr lit depuis l'entrée standard et transforme chaque caractère selon les règles que vous spécifiez. Il ne lit jamais de fichier directement — toujours via un pipe. C'est simple, efficace, et souvent plus rapide que sed pour des transformations caractère par caractère.

Syntaxe de base

tr [OPTIONS] ENSEMBLE1 [ENSEMBLE2]

Options principales

OptionDescription
-d, --deleteSupprimer les caractères de l'ensemble, sans les remplacer
-c, --complementUtiliser le complémentaire de l'ensemble (tout EXCEPTER)
-s, --squeeze-repeatsCompresser les caractères répétés en un seul
-t, --truncate-set1Tronquer l'ensemble 1 à la longueur de l'ensemble 2

Ensembles spéciaux

EnsembleSignification
a-zToutes les lettres minuscules
A-ZToutes les lettres majuscules
0-9Tous les chiffres
[:alpha:]Toutes les lettres (majuscules et minuscules)
[:lower:]Lettres minuscules
[:upper:]Lettres majuscules
[:digit:]Chiffres
[:space:]Espaces blancs (espace, tab, newline)
[:alnum:]Lettres et chiffres
[:punct:]Caractères de ponctuation

Exemples concrets

1. Convertir en minuscules

echo "BONJOUR TOUT LE MONDE" | tr 'A-Z' 'a-z'
# bonjour tout le monde

La forme POSIX (plus portable) utilise les classes :

echo "BONJOUR TOUT LE MONDE" | tr '[:upper:]' '[:lower:]'
# bonjour tout le monde

2. Convertir en majuscules

echo "linux est formidable" | tr 'a-z' 'A-Z'
# LINUX EST FORMIDABLE

3. Supprimer des caractères

L'option -d supprime simplement les caractères spécifiés :

echo "hello world" | tr -d ' '
# helloworld

Supprimer tous les chiffres :

echo "abc123def456" | tr -d '0-9'
# abcdef

Supprimer les espaces et tabulations :

echo -e "hello world\n\t avec\ttab" | tr -d ' \t'
# helloworld
# avectab

4. Remplacer un caractère par un autre

Chaque caractère de l'ensemble 1 est remplacé par le caractère correspondant de l'ensemble 2 :

echo "bonjour" | tr 'o' '0'
# b0nj0ur

Le remplacement est ordinal — le 1er caractère de l'ensemble 1 devient le 1er de l'ensemble 2, etc. :

echo "abcdef" | tr 'ace' 'XYZ'
# XbYdZf (a→X, c→Y, e→Z)

5. Compresser les caractères répétés

L'option -s réduit les suites de caractères identiques en un seul :

echo "hellooo world" | tr -s ' '
# hellooo world

Compresser tous les espaces (y compris tabs) :

echo -e "un espace\t\tde\t\t\t\tlà" | tr -s '[:space:]'
# un espace de là

6. Supprimer les lignes vides

Combinez -s et -d pour supprimer les nouvelles lignes consécutives :

cat fichier_avec_lignes_vides.txt | tr -s '\n'

7. Utiliser le complémentaire (-c)

-c inverse l'ensemble — vous ciblez tout CE QUE vous ne spécifiez PAS :

# Garder seulement les lettres (supprimer tout le reste)
echo "abc123def!@#" | tr -cd '[:alpha:]'
# abcdef

Ou garder chiffres et lettres (nettoyer une chaîne) :

echo "Prix: 49.99 € (TVA incluse)" | tr -cd '[:alnum:].'
# Prix49.99

8. Nettoyer un numéro de téléphone

echo "+41 (0)79 456-96-45" | tr -cd '0-9'
# 410794569645

9. Convertir les sauts de ligne en espaces

cat fichier_multiligne.txt | tr '\n' ' '

Puis supprimer les espaces multiples en complément :

cat fichier_multiligne.txt | tr '\n' ' ' | tr -s ' '

10. Changer la casse de manière sélective

Transformer les voyelles en majuscules (et laisser les autres caractères intacts) :

echo "bonjour monde" | tr 'aeiou' 'AEIOU'
# bOnjOUr mOndE

11. Supprimer les caractères non imprimables

# Supprimer tous les caractères de contrôle (sauf newline)
cat fichier_binaire.txt | tr -cd '[:print:]\n'

12. Créer une liste alphabétique triée

Combinez tr avec sort pour nettoyer avant de trier :

echo -e "Banane\nAbricot\ncerise\nDATE" | tr 'A-Z' 'a-z' | sort
# abricot
# banane
# cerise
# date

Cas d'usage réels

1. Normaliser un fichier CSV (séparateurs)

# Remplacer les points-virgules par des virgules
cat donnees.csv | tr ';' ','

2. Mettre en majuscules un fichier entier

cat monfichier.txt | tr 'a-z' 'A-Z' > monfichier_MAJ.txt

3. Supprimer les retours chariot Windows (^M)

Très utile après un transfert de fichier depuis Windows :

# Supprimer les ^M (retours chariot \r)
cat fichier_windows.txt | tr -d '\r'
# Ou
cat fichier_windows.txt | dos2unix 2>/dev/null || tr -d '\r'

4. Convertir des tabs en espaces

cat fichier_tab.txt | tr '\t' ' ' > fichier_espace.txt

5. Compter les caractères uniques

En combinant avec sort et uniq :

echo "hello world" | tr -s ' ' '\n' | sort | uniq -c
# 1 h
# 1 o
# 1 w
# 2 l
# 1 d
# 1 e
# 1 r

6. Générer un mot de passe aléatoire

# 16 caractères aléatoires alphanumériques
< /dev/urandom tr -dc 'a-zA-Z0-9' | head -c 16; echo
# Ex: k8LmN2pQ9xR3vT7w

7. Compter le nombre de mots

echo "un deux trois quatre cinq" | tr ' ' '\n' | wc -l
# 5

tr vs sed vs awk — Quand utiliser quoi ?

OutilForceUsage idéal
trSimple, rapide, caractère par caractèreSubstitutions simples, suppression, casse
sedMotifs Regex, substitutions complexesRemplacer des mots, des motifs, du texte
awkTraitement de colonnes, logique complexeCalculs, filtres avancés, structures de données

Bonnes pratiques

  • Utilisez les classes POSIX ([:alpha:], [:digit:]) plutôt que a-z — plus portable et plus lisible
  • Utilisez toujours des quotes autour des arguments pour éviter l'expansion du shell
  • Combinez avec -s pour éviter les caractères répétés après substitution
  • Pour les fichiers, pipez avec cat : cat fichier | tr ...
  • Attention aux ensembles de tailles différentes : si l'ensemble 1 est plus long, les caractères surnuméraires sont supprimés

tr est un outil de transformation de texte caractère par caractère. Bien qu'il soit simple, il est extrêmement puissant pour nettoyer des données, convertir des formats, ou préparer du texte pour un traitement ultérieur. Sa rapidité en fait un choix privilégié dans les pipelines et les scripts shell. Gardez-le sous le coude — il simplifie bien des tâches du quotidien.
