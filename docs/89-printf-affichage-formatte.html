Leçon 89 : printf — Affichage formaté en Bash

Qu'est-ce que printf ?

printf est une commande qui permet d'afficher du texte formaté dans le terminal. Contrairement à echo, printf offre un contrôle précis sur le format d'affichage : nombres décimaux, zéros de remplissage, alignement, retour à la ligne, etc.

Il fonctionne comme la fonction printf() du langage C, ce qui le rend très puissant pour les scripts Bash.

Syntaxe de base

printf "format" [arguments...]

Le format définit comment afficher les arguments. Les séquences les plus courantes :

SéquenceSignification
\nSaut de ligne
\tTabulation
%sChaîne de caractères
%dNombre entier (décimal)
%fNombre à virgule flottante
%02dEntier sur 2 chiffres, avec zéros
%-10sChaîne alignée à gauche sur 10 caractères
%05.2fFlottant sur 5 caractères, 2 décimales

Exemples concrets

1. Affichage simple avec saut de ligne

printf "Bonjour le monde !\n"

Contrairement à echo, printf n'ajoute pas de retour à la ligne automatique. Il faut le préciser avec \n.

2. Afficher des variables

nom="Alice" printf "Bienvenue, %s !\n" "$nom"

Résultat : Bienvenue, Alice !

3. Formater des nombres

printf "Le résultat est : %d\n" 42 printf "Pi vaut : %.4f\n" 3.14159265

Résultat :

Le résultat est : 42 Pi vaut : 3.1416

4. Alignement et padding

printf "%-10s %05d\n" "Alice" 42 printf "%-10s %05d\n" "Bob" 7

Résultat :

Alice 00042 Bob 00007

%-10s = texte aligné à gauche sur 10 caractères. %05d = nombre sur 5 chiffres avec zéros de remplissage.

5. Tableau formaté

printf "%-15s %-10s %s\n" "Nom" "Statut" "Score" printf "%-15s %-10s %s\n" "Alice" "Actif" "1500" printf "%-15s %-10s %s\n" "Bob" "Inactif" "980"

Idéal pour afficher des tableaux dans vos scripts.

Dans les scripts Bash

printf est particulièrement utile dans les scripts pour créer des sorties formées et professionnelles.

#!/bin/bash nom=$1 score=$2 printf "══════════════════════════════\n" printf " Rapport de l'utilisateur\n" printf "══════════════════════════════\n" printf "Nom : %-20s\n" "$nom" printf "Score : %05d points\n" "$score" printf "Date : %s\n" "$(date '+%Y-%m-%d %H:%M:%S')" printf "══════════════════════════════\n"

Différence entre echo et printf

Caractéristiqueechoprintf
Retour à la ligneAutomatiqueManuel (\n)
FormatageBasiqueAvancé et précis
NombresTexte brutFormat décimal, flottant
PortabilitéMoins portableTrès portable (style C)

Exercices pratiques

Exercice 1

Utilisez printf pour afficher votre nom avec 20 caractères de large, aligné à droite.

Exercice 2

Créez un script qui affiche la date du jour au format JJ/MM/AAAA en utilisant printf.

Exercice 3

Affichez un tableau de 3 colonnes (Nom, Âge, Ville) avec 3 entrées, en alignant proprement les colonnes.

Résumé

  • printf offre un contrôle précis du format d'affichage
  • Les séquences comme %s, %d, %f remplacent les variables
  • \n est nécessaire pour le retour à la ligne
  • Les options de padding (%05d, %-10s) permettent un alignement parfait
  • Plus portable et puissant que echo pour les scripts professionnels
