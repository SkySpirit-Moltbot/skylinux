mtree — Vérifier l'intégrité des fichiers et répertoires

mtree est un outil puissant permet de vérifier l'intégrité des fichiers et répertoires. Il génère une spécification (ou "spec") d'un répertoire, puis permet de vérifier si des changements sont survenus : fichiers modifiés, supprimés, ou permissions changées.

Installation

mtree fait partie des utilitaires système sur la plupart des distributions Linux. Sous Debian/Ubuntu :

sudo apt install mtree

Sous Red Hat/CentOS :

sudo yum install mtree-nox11

Ou installez le package mtree-netbsd selon votre distribution.

Principe de fonctionnement

mtree fonctionne en deux étapes :

  1. Génération : créer un fichier de spécification (spec) qui contient les empreintes et attributs de chaque fichier
  2. Vérification : comparer l'état actuel contre cette spécification

Générer une spécification

Commande de base

Pour créer une spécification d'un répertoire, utilisez mtree -c :

mtree -c -K md5ormd5 -p /home/david/documents > ~/documents.mtree

Explication :

  • -c : créer une spécification (spec)
  • -K md5ormd5 : inclure les empreintes MD5 (ou SHA256)
  • -p /home/david/documents : le répertoire à analyser
  • > ~/documents.mtree : sauvegarder dans un fichier

Types d'empreintes disponibles

OptionDescription
md5ormd5Empreinte MD5 (si disponible)
sha256Empreinte SHA-256
sha512Empreinte SHA-512
rmd160Empreinte RIPEMD-160

Inclure les permissions et attributs

Par défaut, mtree vérifie le type de fichier, le propriétaire, les permissions et le nombre de liens. Vous pouvez spécifier les éléments à vérifier avec -K :

mtree -c -K md5ormd5,cksum,owner,group,mode,nlink -p /home/david/documents > ~/documents.mtree

Ou de manière plus concise en spécifiant les clés ignorées avec -k :

mtree -c -k md5 -p /home/david/documents > ~/documents.mtree

Vérifier l'intégrité

Une fois la spécification créée, vous pouvez vérifier si des changements sont survenus :

mtree -f ~/documents.mtree -p /home/david/documents

Si tout est intact, vous n'aurez aucune sortie. Si des écarts sont détectés :

.J./home/david/documents/rapport.pdf modification time Fri Jun 20 14:30:00 2025 -> Tue Jul 28 09:15:00 2026 size 10240 -> 11520

Exemple de sortie avec erreur

Quand un fichier a été modifié, mtree affiche les différences :

documents/archive.zip modification time Wed Jan 15 10:00:00 2026 -> Thu Feb 20 11:30:00 2026 documents/notes.txt missing

Options de vérification utiles

Vérifier sans les timestamps

Les timestamps changent souvent naturellement. Pour ne vérifier que le contenu :

mtree -f ~/documents.mtree -p /home/david/documents -e -k md5
  • -e : ignorer les fichiers manquants dans le répertoire cible
  • -k md5 : vérifier uniquement l'empreinte MD5

Mode silencieux (quiet)

Pour ne voir que les erreurs sans les statistiques :

mtree -f ~/documents.mtree -p /home/david/documents -q

Le code de retour indique le résultat :

  • 0 : tout estOK
  • 1 : des écarts ont été détectés
  • 2 : une erreur s'est produite

Mettre à jour une spécification

Si vous avez fait des modifications légitimes et voulez mettre à jour la spec :

mtree -c -K md5ormd5 -p /home/david/documents > ~/documents.mtree

Ou en utilisant la redirection pour remplacer la spécification existante :

mtree -c -K md5ormd5 -p /home/david/documents | tee ~/documents.mtree

Utiliser mtree pour la sécurité

Vérifier un répertoire système critique

Vous pouvez créer une spécification d'un répertoire système et la vérifier régulièrement :

# Créer la spécification sudo mtree -c -K md5ormd5,cksum,owner,group,mode,nlink -p /etc > /root/etc.mtree # Vérifier périodiquement sudo mtree -f /root/etc.mtree -p /etc

Automatiser avec cron

Créez un script de vérification automatique :

#!/bin/bash # Script de vérification d'intégrité SPEC="/root/etc.mtree" RESULT=$(mtree -f "$SPEC" -p /etc 2>&1) if [ -n "$RESULT" ]; then echo "ALERTE: Des changements ont été détectés dans /etc" | mail -s "mtree alert" admin@exemple.com echo "$RESULT" >> /var/log/mtree.log fi

Planifier avec cron

Ajoutez ceci dans la crontab :

0 3 * * * /usr/local/bin/check-integrity.sh

Format du fichier de spécification

Un fichier .mtree est un fichier texte lisible :

# mtree specification . type=dir time=1627459200.0 mode=755 owner=root group=root ./subdir type=dir time=1627459200.0 mode=755 owner=root group=root ./fichier.txt size=1024 md5digest=a1b2c3d4e5f6... mode=644 owner=david group=david ./archive.zip size=5242880 md5digest=f6e5d4c3b2a1... mode=600 owner=david group=david

Spécifier les mots-clés (keywords)

Les mots-clés définissent ce qui sera vérifié. Syntaxe avec -K :

KeywordDescription

md5Empreinte MD5
sha256Empreinte SHA-256
sha512Empreinte SHA-512
ripemd160Empreinte RIPEMD-160
sizeTaille du fichier en octets
modePermissions du fichier
ownerPropriétaire du fichier
groupGroupe du fichier
nlinkNombre de liens physiques

Exercices pratiques

Exercice 1

Créez une spécification de votre répertoire /tmp/test_mtree avec des empreintes MD5, puis vérifiez-la.

Exercice 2

Modifiez un fichier dans le répertoire de l'exercice 1, puis lancez la vérification. Observez la sortie.

Exercice 3

Créez une spécification de /etc qui vérifie uniquement les permissions et le propriétaire (sans empreintes).

Exercice 4

Écrivez un script qui vérifie automatiquement l'intégrité de /var/www chaque jour à 4h du matin.

Solutions

Solution 1

# Créer le répertoire de test mkdir -p /tmp/test_mtree echo "fichier test" > /tmp/test_mtree/test.txt # Créer la spécification mtree -c -K md5 -p /tmp/test_mtree > /tmp/test.mtree # Vérifier mtree -f /tmp/test.mtree -p /tmp/test_mtree

Solution 2

# Modifier le fichier echo "contenu modifié" >> /tmp/test_mtree/test.txt # Vérifier à nouveau mtree -f /tmp/test.mtree -p /tmp/test_mtree

Résultat attendu : affichage des différences de taille et d'empreinte MD5.

Solution 3

sudo mtree -c -k mode,owner,group -p /etc > /root/etc-perms.mtree

Solution 4

Créez le script /usr/local/bin/check-www.sh :

#!/bin/bash SPEC="/root/www.mtree" RESULT=$(mtree -f "$SPEC" -p /var/www 2>&1) if [ -n "$RESULT" ]; then echo "Changements détectés dans /var/www:" | tee -a /var/log/www-integrity.log echo "$RESULT" >> /var/log/www-integrity.log fi

Ajoutez dans la crontab :

0 4 * * * /usr/local/bin/check-www.sh

Conclusion

mtree est un outil simple mais efficace pour vérifier l'intégrité des fichiers. Il est particulièrement utile pour :

  • Détecter des modifications non autorisées sur des fichiers critiques
  • Valider l'intégrité d'une installation après une mise à jour
  • Vérifier que des sauvegardes sont intactes
  • Surveiller des répertoires sensibles comme /etc ou /var/www

Bien qu'il soit moins complet que des outils comme tripwire ou AIDE, sa simplicité et sa disponibilité native en font un excellent choix pour des vérifications ponctuelles ou automatisées avec cron.
