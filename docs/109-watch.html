Leçon 109 : watch — Exécuter une commande périodiquement

La commande watch est un outil simple mais puissant qui permet d'exécuter une commande périodiquement et d'afficher son résultat en temps réel dans le terminal. C'est l'outil idéal pour surveiller l'évolution de données système : l'utilisationCPU, la mémoire, l'espace disque, les connexions réseau, ou encore la progression d'une opération longue. Au lieu de répéter manuellement une commande avec Entrée, watch le fait pour vous, avec un rafraîchissement configurable.

Syntaxe de base

watch [options] commande

Par défaut, watch exécute la commande toutes les 2 secondes et efface l'écran entre chaque exécution pour ne montrer que le résultat свежий. L'affichage est actualisé automatiquement, ce qui permet de voir les changements en temps réel.

# Surveiller l'utilisation de la memoire (par defaut, 2 secondes)
watch free -h
# Surveiller les processus les plus consommateurs CPU
watch ps aux --sort=-%cpu | head -10

Options principales

OptionDescriptionExemple
-n <sec>Intervalle de rafraîchissement en secondeswatch -n 5
-dSurligne les différences entre les affichageswatch -d
-d=<type>Type de surlignage : cumulative (cumulé) ou highlight (ponctuel)watch -d=cumulative
-tMasque l'en-tête avec la date et la commandewatch -t
-bÉmet un signal sonore si la commande retourne une erreurwatch -b
-eQuitte si la commande échouewatch -e
-gQuitte quand la sortie changewatch -g

Exemples concrets d'utilisation

1. Surveiller l'espace disque

# Rafraichi toutes les 5 secondes, differences surlignees
watch -n 5 -d df -h
# Surveiller un repertoire specifique (evolution de la taille)
watch -n 10 du -sh /var/log

2. Surveiller les processus actifs

# Voir les processus en temps reel (comme top, mais rafraichi)
watch -n 1 ps aux --sort=-%cpu | head -15
# Surveiller les connexions reseau actives
watch -n 2 ss -tunap

3. Surveiller un fichier qui grandit

# Suivre la taille d'un fichier en train de telecharger/copier
watch -n 2 ls -lh /chemin/vers/fichier.tgz
# Compter les lignes d'un fichier de log qui s'allonge
watch -n 5 wc -l /var/log/syslog

4. Surveiller les services systemd

# Verifier l'etat d'un service en temps reel
watch -n 1 systemctl status nginx
# Surveiller tous les services en etat failed
watch -n 3 systemctl --failed

5. Surveiller les connexions utilisateurs

# Qui est connecte au serveur ?
watch -n 5 who
# Nombre de connexions SSH actives
watch -n 2 "ss -tn | grep ':22' | wc -l"

Option -d : Surligner les différences

L'option -d est particulièrement utile pour visualiser instantanément ce qui change. Par défaut, elle surligne uniquement les caractères qui ont changé. Avec -d=cumulative, elle surligne aussi toutes les valeurs qui ont changé depuis la première exécution — idéal pour suivre l'évolution d'un compteur ou d'un graphique.

# Surlignage simple des changements
watch -d free -h
# Surlignage cumulatif : tout ce qui a change reste surligne
watch -d=cumulative "df -h | grep '/dev/sda'"

Combiner watch avec des pipes

watch transmet la commande telle quelle au shell. Pour utiliser des pipes (|) ou des redirections, il est recommandé d'entourer la commande de guillemets pour que le pipe soit interprété correctement par watch et non par le shell parent.

# Compter les lignes d'un fichier toutes les secondes
watch -n 1 'wc -l /var/log/syslog'
# Surveiller l'etat de la memoire avec un tri
watch -n 3 'free -m | grep Mem | awk "{print \$3/\$2 * 100}"'
# Surveiller le nombre de fichiers dans un repertoire
watch -n 10 'ls /tmp | wc -l'

Cas d'usage pratiques

1. Suivre la progression d'un téléchargement

# Si wget ou curl ecrit dans un fichier, surveillez sa taille
watch -n 2 'ls -lh /var/cache/telechargement/fichier.iso'

2. Vérifier la disponibilité d'un serveur

# Surveiller la latence ping (Ctrl+C pour arreter)
watch -n 1 'ping -c 1 8.8.8.8 | grep "time="'
# Surveiller si un port est ouvert
watch -n 5 'nc -zv example.com 443 2>&1 | grep succeeded'

3. Surveiller les ressources d'un conteneur Docker

# Statistiques en temps reel d'un conteneur
watch -n 2 docker stats --no-stream mon-conteneur
# Lister les conteneurs actifs et leurs etats
watch -n 5 docker ps

4. Surveiller un build ou une compilation

# Suivre la taille du repertoire de build
watch -n 5 'du -sh build/'
# Surveiller l'apparition de fichiers de sortie
watch -n 3 'ls -lt /chemin/build/*.o 2>/dev/null | head -5'

5. Quitter automatiquement quand quelque chose se produit

L'option -g est très utile dans les scripts : elle fait quitter watch dès que la sortie change. Combiné avec une commande qui vérifie une condition, cela permet d'attendre un événement précis.

# Attendre que le fichier existe, puis quitter
watch -g 'ls /chemin/vers/fichier-attendu.txt' && echo "Fichier pret!"
# Attendre que le processus se termine
watch -g 'pgrep -f "make build" >/dev/null || echo "termine"'

Options avancées

-b : Émettre un signal sonore

# Beep quand la commande echoue
watch -b 'nc -zv serveur.example.com 22'

-e : Quitter sur erreur

# Quitter des que systemctl echoue (service arrete)
watch -e 'systemctl is-active mon-service'

-t : Masquer l'en-tête

Par défaut, watch affiche un en-tête avec la date, l'intervalle et la commande. L'option -t supprime cet en-tête pour un affichage plus compact, utile quand on veut capturer la sortie ou l'intégrer dans un script.

# Affichage compact sans en-tete
watch -t 'uptime'

Combiner avec d'autres outils

Avec un script de surveillance personnalisé

#!/bin/bash
# Script personnel de surveillance systeme
watch -n 5 '
echo "=== SYSTEME ===" && uptime
echo ""
echo "=== CPU / MEMOIRE ===" && top -bn1 | head -5
echo ""
echo "=== DISQUE ===" && df -h /
echo ""
echo "=== RESEAU ===" && ss -tun | wc -l && echo "connexions actives"
'

Avec un filtre en temps réel

# Filtrer la sortie de ps toutes les secondes
watch -n 1 'ps aux | grep python | grep -v grep'

Différences entre watch, top et tmux

OutilUsage principalAvantage clé
watchRépéter n'importe quelle commandeUniversel, fonctionne avec tout
top / htopSurveillance système dédiéeTri interactif, multiple par processus
tmux (leçon 27)Sessions persistantesPlusieurs terminals en un
screen (leçon 84)Sessions persistantesCompatible, large support

watch se distingue par sa simplicité : il n'a pas besoin d'une interface interactive. Vous pouvez l'utiliser dans un script, dans un pipe, ou en arrière-plan via nohup (leçon 59). Il est idéal pour surveiller l'évolution d'une commande simple ou combiner plusieurs outils sans la surcharge d'une interface complète.

Récapitulatif

# Syntaxe de base
watch commande # toutes les 2 secondes
watch -n 5 commande # toutes les 5 secondes
watch -d commande # surligner les differences
watch -d=cumulative commande # surlignage cumule
watch -t commande # sans en-tete
watch -g commande # quitter quand la sortie change
watch -e commande # quitter si erreur
watch -b commande # beep si erreur

watch est un outil minimaliste mais terriblement efficace. Son principal atout est sa polyvalence : elle fonctionne avec n'importe quelle commande, sans configuration ni interface complexe. Pour la surveillance en temps réel d'un serveur ou le suivi d'une opération longue, watch est souvent la solution la plus rapide à mettre en place.
