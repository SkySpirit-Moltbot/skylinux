Leçon 150 : lsof — Lister les fichiers ouverts

Sur un système Linux, chaque fichier, dossier, socket ou tube possède un descripteur de fichier. lsof (List Open Files) permet de voir exactement quels fichiers sont ouverts par quels processus. C'est un outil essentiel pour le diagnostic et la sécurité.

Installation

lsof est généralement préinstallé. Si ce n'est pas le cas :

# Debian/Ubuntu sudo apt install lsof # Fedora/RHEL sudo dnf install lsof # Arch Linux sudo pacman -S lsof

Syntaxe de base

lsof [options]

Options principales

OptionDescription
-aCombine les critères avec ET (AND)
-c processusAffiche les fichiers ouverts par un processus précis
-u utilisateurAffiche les fichiers ouverts par un utilisateur précis
-p PIDAffiche les fichiers ouverts par un PID précis
-i [46][protocol][@hostname][:service]Affiche les fichiers réseau (sockets)
-nN'affiche pas les noms d'hôtes (plus rapide)
-PN'affiche pas les noms de ports (plus rapide)
+D répertoireAffiche tous les fichiers ouverts dans un répertoire et ses sous-répertoires
-tAffiche uniquement les PID (pour scripting)
-iVoir les connexions réseau actives

Exemples pratiques

1. Voir tous les fichiers ouverts

lsof

Sans argument, lsof affiche TOUS les fichiers ouverts par TOUS les processus. La sortie est longue et détaillée.

2. Fichiers ouverts par un utilisateur

lsof -u ubuntu

3. Fichiers ouverts par un processus spécifique

lsof -c sshd

4. Connexions réseau actives

lsof -i

Affiche toutes les connexions réseau (TCP, UDP). Pour filtrer par type :

# TCP uniquement lsof -i tcp # UDP uniquement lsof -i udp # Un port précis lsof -i :80 # Connexions établies (established) lsof -i -sTCP:ESTABLISHED

5. Fichiers ouverts par un processus spécifique (par PID)

lsof -p 1234

6. Trouver quel processus utilise un port

# Trouver le processus qui utilise le port 443 lsof -i :443 # Trouver le processus qui utilise le port 22 lsof -i :22

7. Fichiers ouverts dans un répertoire

lsof +D /home

+D explore récursivement. Utile pour trouver quels processus accèdent à un dossier.

8. Combiner les critères (ET)

# Fichiers réseau ouverts par l'utilisateur root ET le processus sshd lsof -a -u root -c sshd -i

9. Trouver les fichiers supprimés mais encore ouverts

C'est un cas très courant ! Un fichier supprimé mais toujours utilisé par un processus prend de la place sur le disque.

lsof +L1

+L1 affiche les fichiers avec un lien-count de 1 ou moins (donc supprimés mais ouverts).

10. Exclure un utilisateur

# Tous les fichiers SAUF ceux de root lsof -u ^root

11. Mode silencieux (PID uniquement)

# Pour scripting — obtenir juste les PID lsof -t -i :8080

12. Affichage optimisé (plus rapide)

# Sans résolution DNS et sans conversion des ports en noms lsof -n -P

Comprendre la sortie de lsof

ColonneDescription
COMMANDNom du processus
PIDIdentifiant du processus
USERPropriétaire du processus
FDDescripteur de fichier (r=read, w=write, u=read+write)
TYPEType (REG=fichier régulier, DIR=répertoire, CHR=périphérique, FIFO=tube…)
DEVICEPériphérique (majeur, mineur)
SIZE/OFFTaille ou offset du fichier
NODENuméro d'inœud (inode)
NAMEChemin du fichier ou adresse réseau

Cas d'utilisation courants

Diagnostic : processus qui utilise un port

# Vous obtenez "Address already in use" ? lsof -i :3000 # Affiche le processus qui bloque le port 3000

Diagnostic : espace disque occupé malgré la suppression

# Un fichier a été supprimé mais prend toujours de la place ? lsof +L1 # Affiche les fichiers supprimés mais encore ouverts # Pour libérer : redémarrez le processus concerné

Diagnostic : activité réseau suspecte

# Voir toutes les connexions réseau lsof -i -n -P # Connexions sur un port précis lsof -i :443 # Vérifier les processus qui écoutent (LISTEN) lsof -i -sTCP:LISTEN

Sécurité : vérifier les accès à un répertoire

# Qui accède au répertoire /etc ? lsof +D /etc

Scripting : tuer tous les processus d'un utilisateur

# Obtenir les PID et les tuer kill $(lsof -t -u utilisateur) # Équivalent à : pkill -u utilisateur

Résumé

lsof est un outil puissant pour comprendre quels processus utilisent quels fichiers et connexions réseau. Ses utilisations les plus courantes sont le diagnostic de ports bloqués, la détection de fichiers supprimés encore ouverts, et l'investigation réseau.

CommandeUsage
lsofTous les fichiers ouverts
lsof -i :portProcessus utilisant un port
lsof -c nomFichiers d'un processus
lsof -u userFichiers d'un utilisateur
lsof +D /dirFichiers dans un répertoire
lsof +L1Fichiers supprimés encore ouverts
