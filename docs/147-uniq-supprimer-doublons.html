147 — uniq — Supprimer ou compter les doublons

uniq est une commande qui permet de supprimer ou de compter les lignes consécutives identiques dans un fichier ou un flux. Elle est très souvent utilisée en combinaison avec sort pour traiter des données triées et en extraire des informations utiles.

1. Principe fondamental

La chose la plus importante à comprendre est que uniq ne fonctionne que sur des lignes consécutives identiques. Si votre fichier contient :

pomme banane pomme cerise pomme

uniq seul ne supprimera aucun doublon car les "pomme" ne sont pas consécutifs. Il faut d'abord trier le fichier.

2. Utilisation de base

Supprimer les doublons

sort fichier.txt | uniq

Cela affiche chaque ligne unique, triée par ordre alphabétique.

Variante équivalente

sort -u fichier.txt

L'option -u de sort fait exactement la même chose en une seule commande. C'est une question de préférence et de lisibilité.

3. Compter les occurrences

L'option -c (count) affiche le nombre de fois que chaque ligne apparaît :

sort fichier.txt | uniq -c

Résultat :

3 pomme 1 banane 2 cerise

Le chiffre apparaît en début de ligne, suivi d'un espace, puis de la ligne elle-même.

4. Ne garder que les lignes dupliquées

Parfois on veut voir uniquement les valeurs qui apparaissent plusieurs fois. On utilise -d (duplicated) :

sort fichier.txt | uniq -d

Seules les lignes qui apparaissent au moins deux fois de suite sont affichées.

5. Ne garder que les lignes uniques (apparaissant une seule fois)

L'option -u (unique) affiche les lignes qui n'apparaissent qu'une seule fois :

sort fichier.txt | uniq -u

6. Comparer deux fichiers

uniq peut comparer deux fichiers déjà triés avec l'option - pour l'entrée standard :

comm -12 <(sort fichier1.txt) <(sort fichier2.txt)

Pour utiliser uniq en combinaison avec deux fichiers triés séparément :

cat <(sort fichier1.txt) <(sort fichier2.txt) | uniq -d

Affiche les lignes présentes dans les deux fichiers.

7. Options utiles

OptionDescription
-cCompte les occurrences de chaque ligne
-dN'affiche que les lignes dupliquées (apparaissant au moins 2 fois)
-uN'affiche que les lignes uniques (apparaissant une seule fois)
-iIgnore la casse (minuscules/majuscules équivalentes)
-w NNe compare que les N premiers caractères de chaque ligne
-f NIgnore les N premiers champs de chaque ligne
-s NIgnore les N premiers caractères de chaque ligne

8. Exemples concrets

Trouver les IP qui accèdent le plus à un serveur

grep "GET /api" /var/log/nginx/access.log \ | cut -d' ' -f1 \ | sort \ | uniq -c \ | sort -rn \ | head -10

Cette chaîne de commandes est très classique : on filtre les lignes pertinentes, on extrait le champwanted (ici l'adresse IP), on trie, on compte les occurrences, puis on trie par nombre décroissant pour voir les IP les plus fréquentes.

Trouver les erreurs les plus fréquentes dans les logs

grep "ERROR" /var/log/syslog \ | cut -d' ' -f5- \ | sort \ | uniq -c \ | sort -rn \ | head -20

Lister les utilisateurs connectés (sans doublons)

who | cut -d' ' -f1 | sort | uniq

Comparer deux listes et voir les différences

Éléments présents dans liste1.txt mais pas dans liste2.txt :

comm -23 <(sort liste1.txt) <(sort liste2.txt)

Éléments présents dans les deux listes :

comm -12 <(sort liste1.txt) <(sort liste2.txt)

Ignorer la casse avec -i

sort fichier.txt | uniq -ic

Compte les occurrences en ignorant les différences entre minuscules et majuscules.

Comparer uniquement les premiers caractères avec -w

sort fichier.txt | uniq -cw 3

Ne compare que les 3 premiers caractères de chaque ligne.

Ignorer les premiers champs avec -f

Utile quand chaque ligne a un préfixe (comme un compteur ou un horodatage) :

sort fichier.txt | uniq -f 1

Ignore le premier champ (séparé par des espaces) pour la comparaison.

9. Erreurs fréquentes

  • Oublier de trier avant uniq — C'est l'erreur la plus courante. uniq ne détecte que les doublons consécutifs. Sans tri, il ne se passera rien.
  • Confondre sort -u et sort | uniq — Ils sont équivalents pour supprimer les doublons, mais uniq offre des options supplémentaires comme -c et -d qui n'existent pas dans sort.
  • Utiliser uniq seul pour "nettoyer" un fichier — S'il n'est pas trié, les doublons resteront. Toujours trier d'abord.

10. Bonnes pratiques

  • Combinez toujours sort et uniq dans le bon ordre : sort | uniq, jamais l'inverse.
  • Pour des fichiers volumineux, sort peut être lent. Utilisez sort -u en une seule passe si vous n'avez pas besoin des comptages.
  • Quand vous analysez des logs, chainez grep | cut | sort | uniq -c | sort -rn pour obtenir un classement par fréquence très rapidement.
  • Pour des comparaisons entre fichiers, comm est souvent plus lisible que uniq avec des fichiers concaténés.
