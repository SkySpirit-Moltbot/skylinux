fzf — Fuzzy Finder, recherche floue en ligne de commande

Introduction

fzf (fuzzy finder) est un outil de recherche floue ultra-rapide et interactif pour le terminal. Il vous permet de filtrer rapidement des fichiers, du texte, des commandes, et bien plus encore — le tout avec une interface visuelle élégante. C'est l'un des outils les plus appréciés des utilisateurs Linux avancés.

Installation

fzf est généralement disponible dans les dépôts de la plupart des distributions :

# Debian/Ubuntu sudo apt install fzf # Fedora sudo dnf install fzf # Arch Linux sudo pacman -S fzf # macOS brew install fzf

Après l'installation, activez les raccourcis clavier intégrés :

# Ajoutez cette ligne à votre ~/.bashrc ou ~/.zshrc eval "$(fzf --bash)"

Principe de base

fzf fonctionne sur le principe de la recherche floue (fuzzy search) : il trouve des correspondances même si vous ne tapez pas le texte exact. Par exemple, "lnx" trouvera "linux".

Syntaxe simple

fzf

Sans argument, fzf lit depuis l'entrée standard (stdin) et affiche une interface interactive. Tapez pour filtrer, Entrée pour sélectionner, Ctrl+C pour quitter.

Recherche de fichiers

La commande la plus courante avec fzf est de combiner find ou fd avec fzf pour trouver des fichiers visuellement :

# Rechercher des fichiers dans le répertoire courant find . -type f | fzf # Avec preview (aperçu du contenu) fzf --preview 'cat {}'

Avec fd (plus rapide que find)

fd est un alternative moderne à find, souvent utilisée avec fzf :

# Rechercher avec fd fd --type f | fzf # Aperçu avec bat ( coloration syntaxique) fzf --preview 'bat --color=always {}'

Raccourcis clavier intégrés

Quand eval "$(fzf --bash)" est activé, ces raccourcis deviennent disponibles :

RaccourciAction
Ctrl+TOuvrir fzf pour sélectionner un fichier
Ctrl+RRechercher dans l'historique des commandes
Alt+C cd vers le répertoire sélectionné (fuzzy directory navigation)

Ctrl+T — Sélection de fichiers

Appuyez sur Ctrl+T n'importe où dans le terminal. Une fenêtre fzf apparaît pour sélectionner un fichier dont le chemin sera inséré sur la ligne de commande :

# Après Ctrl+T, le chemin s'insère automatiquement cat [fichier_sélectionné]

Ctrl+R — Historique des commandes

Ctrl+R ouvre fzf pour parcourir votre historique bash. Plus besoin de faire défiler avec les flèches :

# Appuyez sur Ctrl+R et tapez pour filtrer history | grep commande

Alt+C — Navigation dans les répertoires

Alt+C (ou Esc+C) ouvre fzf pour sélectionner un répertoire et exécute un cd directement :

# Navigation rapide entre répertoires cd /home/user/projets # Devient : Alt+C puis taper "pro" puis Entrée

Options utiles

OptionDescription
--height=30%Hauteur de la fenêtre fzf (en pourcentage)
--preview 'cmd'Affiche un aperçu du fichier sélectionné
--multiPermet la sélection multiple (Tab pour ajouter)
--nth=2..Ignorer les premiers champs dans la recherche
--reverseAffichage inversé (résultats en haut)
--bind 'key:action'Lier des touches à des actions personnalisées

Combiner fzf avec d'autres commandes

Ouvrir un fichier avec $EDITOR

# Ouvrir le fichier sélectionné avec vim vim $(fzf) # Ou plus safely fzf --preview 'bat --color=always {}' | xargs $EDITOR

Se déplacer vers un dépôt git

# cd vers un projet dans ~/projets cd ~/projets && cd $(find . -type d -name ".git" | sed 's/.git$//' | fzf)

Sélection multiple avec --multi

# Sélectionner plusieurs fichiers avec Tab fzf --multi | xargs rm -i # Copier plusieurs fichiers fzf --multi | xargs cp -t /destination/

Filtrer la sortie d'une commande

# Lister les processus et filtrer ps aux | fzf # Lister les connexions et filtrer ss -tuln | fzf

Preview (aperçu) des fichiers

L'option --preview affiche le contenu du fichier surligné pendant la navigation :

# Aperçu basique fzf --preview 'cat {}' # Aperçu avec coloration syntaxique (via bat) fzf --preview 'bat --color=always --style=numbers --line-range=:500 {}' # Limiter la hauteur de l'aperçu fzf --height=40% --preview 'bat --color=always {}'

Preview d'images dans le terminal

Si vous utilisez un terminal compatible (iTerm2, kitty, etc.), vous pouvez même prévisualiser des images :

# Installer chafa pour les images dans le terminal sudo apt install chafa # Prévisualiser des images fzf --preview 'chafa {}'

Recherche dans le contenu des fichiers

Combinez fzf avec grep, rg (ripgrep) ou ag (the silver searcher) pour rechercher dans le contenu :

# Rechercher un texte dans les fichiers rg --files-with-matches "motif" | fzf # Avec ripgrep et sélection rg -l "fonction" | fzf --preview 'bat --color=always {}'

fzf-tmux — Version tmux

Si vous utilisez tmux, fzf-tmux lance fzf dans un panneau tmux plutôt que dans le terminal :

# Installer fzf-tmux (souvent inclus avec fzf) fzf-tmux # Ou avec options fzf-tmux -d 50% # Panneau en bas, 50% de hauteur

Variables d'environnement utiles

Configurez le comportement par défaut de fzf via des variables :

# Ajoutez à ~/.bashrc ou ~/.zshrc export FZF_DEFAULT_COMMAND='fd --type f' export FZF_CTRL_T_COMMAND="$FZF_DEFAULT_COMMAND" export FZF_ALT_C_COMMAND='fd --type d .' export FZF_DEFAULT_OPTS='--height=40% --layout=reverse --border'

Exemples pratiques complets

Recherche de fichiers avec aperçu

fzf --height=50% \ --layout=reverse \ --border \ --preview 'bat --color=always {}' \ --bind 'ctrl-/:toggle-preview'

Kill process interactif

ps aux | fzf --multi | awk '{print $2}' | xargs kill

Switch entre branches git

git checkout $(git branch | fzf)

Sélection de variables d'environnement

env | fzf

Recherche fuzzy dans man

man fzf # La documentation officielle de fzf

Intégration avec vim/neovim

fzf s'intègre parfaitement avec vim via le plugin fzf.vim (si vous utilisez un plugin manager) :

:FZF " Ouvre fzf pour rechercher des fichiers :Files " Alias pour FZF :Ag [pattern] " Recherche avec ripgrep

Bonnes pratiques

  • Activez toujours eval "$(fzf --bash)" pour profiter des raccourcis globaux
  • Combinez fzf avec fd et bat pour une expérience optimale
  • Utilisez --multi pour la sélection multiple quand c'est nécessaire
  • Personnalisez les options par défaut via FZF_DEFAULT_OPTS
  • Créez des alias pour vos combinaisons favorites
