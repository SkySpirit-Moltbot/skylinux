watch — Exécuter une commande périodiquement

Introduction

La commande watch permet d'exécuter une commande Linux de manière répétée et d'afficher le résultat en temps réel dans votre terminal. C'est l'outil idéal pour surveiller l'évolution d'un processus, d'un fichier, ou de n'importe quelle sortie de commande sans avoir à la relancer manuellement.

Utilisation de base

La syntaxe simple de watch :

watch commande

Par exemple, pour surveiller l'espace disque toutes les 2 secondes :

watch df -h

Par défaut, watch actualise l'affichage toutes les 2 secondes. Le résultat s'affiche dans tout l'écran du terminal, et l'écran est nettoyé avant chaque nouvelle exécution.

Options principales

OptionDescription
-n secondesIntervalle entre chaque exécution (par défaut : 2 secondes)
-dMettre en surbrillance les différences entre deux exécutions
-d=cumulativeAccumuler les différences au fil du temps
-tMasquer l'en-tête avec la commande et l'intervalle
-bÉmettre un signal sonore si la commande échoue
-eArrêter watch si la commande échoue
-gQuitter quand la sortie change

Exemples pratiques

Surveiller la mémoire disponible

watch free -h

Observer l'espace disque

watch df -h

Surveiller les processus d'un utilisateur

watch ps aux | grep username

Vérifier le contenu d'un répertoire

watch ls -la /chemin/vers/repertoire

Surveiller le nombre de connexions actives

watch 'netstat -an | grep :80 | wc -l'

Surveiller les connexions réseau actives

watch ss -tunapl

Mode différences avec -d

L'option -d est particulièrement utile pour visualiser ce qui change entre deux exécutions. Les différences sont mises en surbrillance en couleur :

watch -d df -h

Pour conserver l'historique des différences (cumulative) :

watch -d=cumulative df -h

Intervalle personnalisé

Modifiez l'intervalle avec l'option -n (en secondes) :

watch -n 5 df -h # toutes les 5 secondes
watch -n 0.5 ps aux # toutes les demi-secondes
watch -n 60 'command' # chaque minute

Quitter automatiquement avec -g

L'option -g permet de quitter watch dès que la sortie change. Très utile pour attendre un événement précis :

watch -g ls -l /chemin/vers/fichier

Cas d'utilisation courants

  • Attendre qu'un fichier apparaisse : watch -g ls -l /chemin/fichier && echo "Fichier détecté !"
  • Attendre qu'un service démarre : watch -g systemctl status mon-service

Combiner avec d'autres outils

Avec tail pour surveiller les logs en temps réel

watch -n 1 tail -20 /var/log/syslog

Avec grep pour filtrer en temps réel

watch -n 2 'ps aux | grep python | grep -v grep'

Avec des Scripts Bash

Vous pouvez exécuter des scripts plus complexes :

watch -n 5 './mon_script.sh'

Arrêter watch

Pour quitter watch à tout moment :

  • Ctrl + C — Interruption classique
  • Ctrl + Z — Suspendre watch (puis kill %1 pour tuer)

Masquer l'en-tête avec -t

Si vous souhaitez un affichage plus compact sans la barre de titre :

watch -t df -h

Bonnes pratiques

  • Utilisez des intervalles plus longs pour les commandes coûteuses en ressources
  • Combinez avec -d pour visualiser rapidement les changements
  • Utilisez -g pour attendre un événement précis sans surveillance permanente
  • Évitez les intervalles inférieurs à 0.1 seconde sauf nécessité absolue

Cas d'utilisation avancés

Surveiller plusieurs commandes avec un script

watch -n 2 'echo "=== CPU ===" && top -bn1 | head -5 && echo "=== MEMOIRE ===" && free -h'

Surveiller les modifications de fichiers

watch -d=cumulative 'find /tmp -type f | wc -l'

Attendre qu'un serveur soit joignable

watch -g 'nc -z localhost 8080 && echo "OK"'

Résumé

CommandeEffet
watch cmdExécute cmd toutes les 2 secondes
watch -n 5 cmdExécute cmd toutes les 5 secondes
watch -d cmdMet en surbrillance les différences
watch -g cmdQuitte quand la sortie change
watch -t cmdMasque l'en-tête

watch est un outil simple mais puissant pour toute surveillance en temps réel depuis le terminal. Combinez-le avec les autres commandes Linux pour créer des tableaux de bord personnalisés directement dans votre console.
