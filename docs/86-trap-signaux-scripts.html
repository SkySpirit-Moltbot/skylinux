trap — Intercepter et gérer les signaux dans les scripts Bash

Introduction

Quand vous exécutez un script Bash, le système peut à tout moment lui envoyer des signaux : interruption par Ctrl+C, fermeture du terminal, réception d'une requête d'arrêt... Sans gestion, le script s'interrompt brutalement et peut laisser des fichiers temporaires, des processus ou des connexions en état incohérent.

trap est la commande qui permet d'intercepter ces signaux et d'exécuter du code en réponse — nettoyer des fichiers, fermer des connexions, sauvegarder un état. C'est un outil indispensable pour écrire des scripts robustes et professionnels.

Comprendre les signaux

Qu'est-ce qu'un signal ?

Un signal est un message envoyé par le noyau ou un autre processus à un processus. Il indique un événement — interruption, erreur, demande d'arrêt — et le processus peut choisir de l'ignorer, de le capturer ou de laisser le comportement par défaut s'appliquer.

Signaux capturables vs non capturables

# Signaux que vous POUVEZ capturer avec trap : # SIGINT (2), SIGHUP (1), SIGTERM (15), SIGQUIT (3), SIGTSTP (20) # SIGUSR1 (10), SIGUSR2 (12), SIGEXIT (0) # Signaux que vous NE POUVEZ PAS capturer : # SIGKILL (9) → tue immédiatement, aucun interception possible # SIGSTOP (19) → suspend immédiatement, aucun interception possible # En résumé : trap ne fonctionne pas avec les signaux qui forcent # l'arrêt ou la suspension immédiate du processus

La commande trap — Les bases

Syntaxe fondamentale

# Syntaxe de trap trap 'commandes' signaux # Exemple simple trap 'echo "Signal reçu !"' SIGINT # Signaux multiples trap 'cleanup' SIGINT SIGTERM SIGHUP # Exécuter plusieurs commandes trap 'echo "Interruption"; exit 1' SIGINT # Signaux nommés ou numériques (équivalents) trap 'echo "Ctrl+C"' 2 # 2 = SIGINT trap 'echo "Ctrl+C"' SIGINT # équivalent

Capturer un signal

#!/bin/bash # script-test-trap.sh echo "Mon script est en cours... (Ctrl+C pour tester)" echo "PID : $$" # Intercepter SIGINT (Ctrl+C) trap 'echo ""; echo "Signal SIGINT capturé ! Le script continue..."' SIGINT # Intercepter la fin du script trap 'echo "Le script se termine."' EXIT # Boucle infinie pour garder le script actif while true; do sleep 1 done

Capturer plusieurs signaux

#!/bin/bash # multi-signaux.sh # Capturer plusieurs signaux avec une seule commande trap 'echo "Signal capturé à $(date '+%H:%M:%S')"' SIGINT SIGTERM SIGHUP echo "En cours... PID : $$" echo "Testez :" echo " Ctrl+C → SIGINT" echo " kill $$ → SIGTERM" echo " kill -HUP $$ → SIGHUP" echo "" # Boucle de démonstration compteur=0 while true; do echo "Compteur : $compteur" sleep 2 ((compteur++)) done

Ignorer un signal

# Ignorer un signal : utiliser '' (chaîne vide) trap '' SIGINT # Ce script ne peut PAS être interrompu par Ctrl+C echo "Ce script est protégé contre Ctrl+C" while true; do sleep 1 done # Pour protéger contre plusieurs signaux : trap '' SIGINT SIGTERM SIGHUP # ATTENTION : seul root ou le propriétaire du processus # peut envoyer un signal après l'avoir ignoré

trap pour le nettoyage (cleanup)

Nettoyage de fichiers temporaires

#!/bin/bash # cleanup-example.sh # Créer des fichiers temporaires TEMP_FILE1=$(mktemp) TEMP_FILE2=$(mktemp) TEMP_DIR=$(mktemp -d) echo "Fichiers temporaires créés." echo "TEMP_FILE1 : $TEMP_FILE1" echo "TEMP_FILE2 : $TEMP_FILE2" echo "TEMP_DIR : $TEMP_DIR" # Fonction de nettoyage cleanup() { echo "" echo "=== Nettoyage en cours ===" rm -f "$TEMP_FILE1" "$TEMP_FILE2" rm -rf "$TEMP_DIR" echo "Fichiers temporaires supprimés." } # Intercepter tous les signaux importants + sortie normale trap cleanup EXIT INT TERM HUP # Corps du script echo "Traitement en cours..." sleep 5 echo "Traitement terminé." # Sortie normale (EXIT déclenchera cleanup)

Nettoyage avec message d'erreur

#!/bin/bash # cleanup-error.sh TEMP_FILE=$(mktemp) # Fonction de nettoyage cleanup() { local exit_code=$? echo "" echo "=== Nettoyage ===" if [ -f "$TEMP_FILE" ]; then rm -f "$TEMP_FILE" echo "Fichier temporaire supprimé." fi if [ $exit_code -ne 0 ]; then echo "Le script s'est terminé avec une erreur (code $exit_code)." fi echo "Nettoyage terminé." } trap cleanup EXIT # Exemple de travail echo "Travail en cours..." sleep 3 # Décommenter pour simuler une erreur : # exit 1 echo "Travail terminé avec succès." exit 0

trap pour la gestion des erreurs

Arrêt automatique en cas d'erreur

#!/bin/bash # erreur-auto.sh # Activer le mode erreur : exit immédiatement si une commande échoue set -e # Fonction appelée quand une commande échoue (ERR) handle_error() { local line_no=$1 echo "ERREUR à la ligne $line_no. Commande échouée." exit 1 } # Intercepter le signal ERR (sortie sur erreur) trap 'handle_error $LINENO' ERR echo "Étape 1..." sleep 1 echo "Étape 2..." sleep 1 echo "Étape 3..." exit 1 # Ce script échouera ici echo "Cette ligne ne sera jamais atteinte."

Gestion centralisée des erreurs

#!/bin/bash # gestion-erreurs.sh # Activer les options de sécurité set -euo pipefail # Variables pour le suivi ERROR_LOG="/tmp/script-errors.log" # Fonction de gestion d'erreur gestion_erreur() { local exit_code=$? local line=$1 echo "==================================" echo "ERREUR détectée !" echo "Date : $(date)" echo "Ligne : $line" echo "Code sortie: $exit_code" echo "Commande : ${BASH_COMMAND}" echo "==================================" # Logger l'erreur echo "$(date '+%Y-%m-%d %H:%M:%S') | Ligne $line | Code $exit_code | ${BASH_COMMAND}" >> "$ERROR_LOG" # Nettoyage rm -f /tmp/script-temp-* exit $exit_code } # Intercepter ERR (commande échouée) et EXIT (fin du script) trap 'gestion_erreur $LINENO' ERR trap 'echo "Script terminé à $(date)." >> /tmp/script.log' EXIT # Corps du script echo "Début du traitement..." mkdir -p /tmp/script-temp-$$ cd /tmp/script-temp-$$ sleep 1 echo "Étape 1 réussie." sleep 1 echo "Étape 2 réussie." echo "Script terminé proprement."

Debugger avec trap

#!/bin/bash # debug-trap.sh # Afficher chaque commande avant exécution set -x # Trap DEBUG : appelé avant chaque commande debug_trace() { echo ">>> $(date '+%H:%M:%S') | Exécution : ${BASH_COMMAND}" } trap debug_trace DEBUG # Trap EXIT : à la fin trap 'echo "=== Fin du script ==="; echo "Lignes exécutées : $LINENO"' EXIT # Corps du script a=5 b=3 result=$((a + b)) echo "Résultat : $result" sleep 1 echo "Script terminé."

Script serveur basique avec trap

Arrêt en cours..." echo "$(date) : Serveur arrêté" >> "$LOG_FILE" rm -f "$PID_FILE" exit 0 } # Installer les handlers trap arreter SIGINT SIGTERM SIGHUP # Démarrer demarrer # Boucle principale while true; do sleep 1 done

Déployer et tester

# Lancer le serveur en arrière-plan bash serveur.sh & SERVER_PID=$! echo "Serveur démarré avec PID : $SERVER_PID" sleep 2 # Envoyer SIGTERM (équivalent à kill normal) kill $SERVER_PID sleep 1 cat /tmp/serveur.log

Script de téléchargement avec trap

#!/bin/bash # telechargement.sh — Téléchargement avec gestion d'interruption URL="${1:-}" OUTPUT="${2:-fichier.zip}" if [ -z "$URL" ]; then echo "Usage : $0 " exit 1 fi PARTIAL_FILE="${OUTPUT}.part" FINAL_FILE="$OUTPUT" # Fonction de nettoyage cleanup() { echo "" echo "=== Interruption détectée ===" if [ -f "$PARTIAL_FILE" ]; then echo "Fichier partiel conservé : $PARTIAL_FILE" echo "Relancez pour reprendre le téléchargement." fi } # Capturer les signaux trap cleanup EXIT INT TERM # Vérifier si le fichier existe déjà (reprise) if [ -f "$FINAL_FILE" ]; then echo "Le fichier existe déjà. Utilisation de curl -C - pour reprendre..." curl -L -C - -o "$FINAL_FILE" "$URL" else curl -L -o "$PARTIAL_FILE" "$URL" mv "$PARTIAL_FILE" "$FINAL_FILE" fi echo "Téléchargement terminé : $FINAL_FILE"

trap et fonctions

Définir le trap dans une fonction

#!/bin/bash # trap-dans-fonctions.sh # Fonction qui configure son propre trap operation_sensible() { local temp_file=$(mktemp) # Trap local à cette fonction local_cleanup() { echo "Nettoyage local..." rm -f "$temp_file" } trap local_cleanup EXIT echo "Opération en cours dans la fonction..." sleep 3 # Si le fichier n'est plus nécessaire, on peut réinitialiser le trap rm -f "$temp_file" trap - EXIT # Réinitialiser le trap } # Fonction principale main() { echo "Début du programme." # Configurer un trap global global_cleanup() { echo "Nettoyage global du programme." } trap global_cleanup EXIT operation_sensible echo "Suite du programme..." sleep 2 echo "Fin du programme." } main

Passer des arguments à trap

#!/bin/bash # trap-avec-args.sh # Fonction qui utilise une variable externe traitement() { local nom_fichier="$1" cleanup() { echo "Nettoyage de $nom_fichier" # Supprimer uniquement si le fichier est incomplet [ -f "${nom_fichier}.tmp" ] && rm -f "${nom_fichier}.tmp" } trap cleanup EXIT INT TERM echo "Traitement de $nom_fichier..." touch "${nom_fichier}.tmp" sleep 3 mv "${nom_fichier}.tmp" "$nom_fichier" echo "Terminé." } # Traiter plusieurs fichiers for fichier in fichier1.txt fichier2.txt fichier3.txt; do traitement "$fichier" done

Exemples concrets

Base de données avec transactions

#!/bin/bash # database-transaction.sh — Transactions avec trap DB_FILE="/tmp/mabase.db" BACKUP_FILE="/tmp/mabase.backup" TEMP_FILE="/tmp/mabase.tmp" # Initialiser la base init_db() { echo "ID,NOM,EMAIL" > "$DB_FILE" echo "1,Alice,alice@example.com" >> "$DB_FILE" echo "2,Bob,bob@example.com" >> "$DB_FILE" } # Rollback en cas d'erreur rollback() { echo "" echo "=== ROLLBACK ===" if [ -f "$BACKUP_FILE" ]; then cp "$BACKUP_FILE" "$DB_FILE" echo "Base restaurée depuis la sauvegarde." fi [ -f "$TEMP_FILE" ] && rm -f "$TEMP_FILE" [ -f "$BACKUP_FILE" ] && rm -f "$BACKUP_FILE" } # Nettoyage final cleanup() { [ -f "$TEMP_FILE" ] && rm -f "$TEMP_FILE" echo "Nettoyage terminé." } # Installer les traps trap rollback EXIT trap 'rollback; exit 130' INT TERM trap cleanup EXIT # Corps du script init_db cp "$DB_FILE" "$BACKUP_FILE" echo "Base initiale :" cat "$DB_FILE" # Simuler une transaction echo "Ajout d'un nouvel enregistrement..." echo "3,Charlie,charlie@example.com" > "$TEMP_FILE" cat "$DB_FILE" >> "$TEMP_FILE" mv "$TEMP_FILE" "$DB_FILE" echo "" echo "Base après transaction :" cat "$DB_FILE" # Supprimer le backup si tout s'est bien passé rm -f "$BACKUP_FILE" echo "Transaction validée."

Installation avec rollback

#!/bin/bash # installation.sh — Installation avec rollback INSTALL_DIR="/opt/monapp" CONFIG_FILE="/etc/monapp.conf" SERVICE_NAME="monapp" rollback() { echo "" echo "=== ROLLBACK - Annulation de l'installation ===" [ -d "$INSTALL_DIR" ] && rm -rf "$INSTALL_DIR" [ -f "$CONFIG_FILE" ] && rm -f "$CONFIG_FILE" systemctl stop "$SERVICE_NAME" 2>/dev/null || true systemctl disable "$SERVICE_NAME" 2>/dev/null || true echo "Rollback terminé." } install() { echo "Installation de MonApp..." mkdir -p "$INSTALL_DIR" echo "# Configuration" > "$CONFIG_FILE" echo "version=1.0" >> "$CONFIG_FILE" echo "Installation des fichiers..." sleep 1 echo "Configuration du service..." sleep 1 echo "Activation du service..." sleep 1 echo "Installation terminée avec succès." } # Trap principal trap 'rollback; exit 1' ERR INT TERM HUP install

Bonnes pratiques

  • Utilisez toujours EXIT pour le nettoyage : trap cleanup EXIT se déclenche à la fin du script, que l'arrêt soit normal ou anormal.
  • Combinez EXIT avec les signaux : trap 'cleanup; exit 1' INT TERM pour un nettoyage complet en cas d'interruption.
  • Ne capturez pas SIGKILL ni SIGSTOP : ces signaux ne peuvent pas être interceptés, c'est intentionnel.
  • Protégez les scripts critiques : trap '' SIGINT SIGTERM rend un script immunisé aux interruptions — à utiliser avec prudence.
  • Utilisez $LINENO pour le debugging : dans une fonction d'erreur, $LINENO indique la ligne exacte du problème.
  • Vérifiez l'état avant de nettoyer : dans les fonctions cleanup, vérifiez si les fichiers existent avant de les supprimer.
  • Configurez trap au début du script : avant toute opération qui pourrait être interrompue.
  • Documentez vos traps : un commentaire au-dessus de chaque trap explique son but.

Conclusion

trap est l'outil qui transforme un script fragile en un script robuste. Il permet de capturer les signaux système — Ctrl+C, kill, fermeture du terminal — et d'exécuter du code de nettoyage en réponse. Le pattern le plus courant combine trap cleanup EXIT INT TERM pour un nettoyage fiable quel que soit le mode de fin du script. Pour la gestion d'erreurs, trap handle_error ERR intercepte chaque commande qui échoue. Ces techniques sont la base des scripts professionnels en Bash.
