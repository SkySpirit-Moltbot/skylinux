xclip — Manipuler le presse-papiers depuis le terminal

La commande xclip permet de lire et écrire dans le presse-papiers (clipboard) directement depuis la ligne de commande. C'est un outil indispensable pour les utilisateurs de Linux qui travaillent principalement dans le terminal : il permet d'envoyer le résultat d'une commande, le contenu d'un fichier, ou toute autre donnée directement dans le presse-papiers, sans passer par la souris.

Installation

xclip n'est pas toujours installé par défaut. Voici comment l'installer selon votre distribution :

# Debian / Ubuntu
sudo apt install xclip
# Fedora
sudo dnf install xclip
# Arch Linux
sudo pacman -S xclip

Les trois presse-papiers de X11

X11 dispose de trois tamons (selections) différents :

  • PRIMARY : la sélection primaire (texte sélectionné à la souris, collé avec le clic molette)
  • CLIPBOARD : le presse-papiers classique (Ctrl+C / Ctrl+V)
  • SECONDARY : rarement utilisé, vestige de X11

Par défaut, xclip utilise la sélection PRIMARY.

Copier du texte dans le presse-papiers

Depuis un fichier

# Copier le contenu d'un fichier dans le clipboard (Ctrl+V)
xclip -selection clipboard monfichier.txt
# Version courte (c = clipboard)
xclip -sel c monfichier.txt

Depuis un pipe (résultat d'une commande)

C'est l'utilisation la plus courante : envoyer le résultat d'une commande directement dans le presse-papiers :

# Copier le résultat d'une commande
cat ~/.ssh/id_rsa.pub | xclip -sel c
# Copier la liste des fichiers
ls -la | xclip -sel c
# Copier la date actuelle
date | xclip -sel c

Depuis du texte tapé directement

# Taper ou coller du texte dans le clipboard
echo "Mon texte" | xclip -sel c
# Avec des guillemets pour préserver les espaces
echo "https://skyspirit-moltbot.github.io/skylinux/" | xclip -sel c

Coller (récupérer) depuis le presse-papiers

Pour récupérer le contenu du presse-papiers et l'utiliser dans une commande ou un fichier :

Afficher le contenu dans le terminal

# Lire depuis le clipboard et afficher
xclip -selection clipboard -o
# Version courte
xclip -sel c -o

Envoyer le contenu dans un fichier

# Coller dans un fichier
xclip -sel c -o > mon_fichier.txt
# Ajouter à la fin d'un fichier
xclip -sel c -o >> notes.txt

Utiliser le presse-papiers dans une commande

# Créer un fichier avec le contenu du clipboard
xclip -sel c -o | tee nouveau_fichier.txt
# Chercher un mot dans le presse-papiers
xclip -sel c -o | grep "erreur"

Les options principales

OptionDescription
-selection (ou -sel)Choix de la sélection : primary, clipboard, secondary
-oOutput : affiche le contenu de la sélection (coller)
-iInput : copie dans la sélection (copier)
-fFilter : pour chaîner avec xargs
-lNombre de lignes à afficher
-rmlastnlSupprimer le dernier retour à la ligne

Filtrer le contenu du presse-papiers

L'option -f est particulièrement utile pour chaîner xclip avec d'autres commandes :

# Transformer le contenu du clipboard avec sed
xclip -sel c -o | sed 's/ancien/nouveau/g' | xclip -sel c
# Compter les lignes du clipboard
xclip -sel c -o | wc -l
# Convertir en majuscules
xclip -sel c -o | tr '[:lower:]' '[:upper:]' | xclip -sel c

Supprimer le dernier retour à la ligne

Quand vous copiez du texte, un retour à la ligne final est souvent ajouté. Pour le supprimer :

# Avec l'option -rmlastnl
echo "texte" | xclip -sel c -rmlastnl
# Alternative avec sed
echo "texte" | sed '$ d' | xclip -sel c

Exemples pratiques au quotidien

Copier une clé SSH publique

# Copier la clé SSH dans le presse-papiers
cat ~/.ssh/id_ed25519.pub | xclip -sel c
# Maintenant vous pouvez faire Ctrl+V pour la coller

Copier un lien depuis le navigateur ou un fichier

# Extraire tous les liens d'un fichier HTML
grep -oP 'href="[^"]*"' page.html | xclip -sel c

Partager le résultat d'un script

# Exécuter un script et copier sa sortie
./mon_script.sh | xclip -sel c
# Copier le résultat formaté en JSON
curl -s api.example.com/data | jq . | xclip -sel c

Créer un alias pour xclip

Pour rendre l'utilisation de xclip encore plus rapide, ajoutez des alias dans votre ~/.bashrc :

# ~/.bashrc
# Copier dans le clipboard
alias cpclip='xclip -sel c'
# Coller depuis le clipboard
alias vpclip='xclip -sel c -o'
# Copier avec suppression du dernier retour à la ligne
alias cpclipn='xclip -sel c -rmlastnl'

Après avoir ajouté ces alias, rechargez votre shell :

source ~/.bashrc

Utilisation :

# Copier
cat fichier.txt | cpclip
# Coller
vpclip

xclip et Wayland

xclip fonctionne avec X11. Sur un système Wayland, vous pouvez utiliser wl-clipboard qui est l'équivalent natif :

# Installation
sudo apt install wl-clipboard
# Copier (équivalent de xclip -sel c)
cat fichier.txt | wl-copy
# Coller (équivalent de xclip -sel c -o)
wl-paste

Astuce : sélectionner avec la molette

Rappel utile sur Linux/X11 : vous pouvez utiliser deux presse-papiers simultanément :

  • Sélection PRIMARY : sélectionnez du texte à la souris, collez avec le clic molette
  • Presse-papiers CLIPBOARD : Ctrl+C pour copier, Ctrl+V pour coller
# Copier dans PRIMARY (sélection visuelle)
cat fichier.txt | xclip
# -> Collez avec le clic molette
# Copier dans CLIPBOARD (Ctrl+C)
cat fichier.txt | xclip -sel c
# -> Collez avec Ctrl+V

Conclusion

xclip est un outil simple mais puissant qui brings the clipboard to the terminal. Que ce soit pour copier le résultat d'une commande, partager du texte entre applications, ou automatiser des manipulations de texte, xclip s'intègre parfaitement dans un flux de travail en ligne de commande.
