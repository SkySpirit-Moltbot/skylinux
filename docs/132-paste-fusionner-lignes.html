Leçon 132 - paste — Fusionner des lignes de fichiers

La commande paste fait l'inverse de ce que vous pourriez attendre : au lieu de coller du texte bout à bout (comme cat), elle juxtapose des lignes provenant de différents fichiers ou flux, les unes à côté des autres, séparées par un caractère personnalisable. C'est l'outil idéal pour assembler des colonnes, créer des tableaux, ou fusionner des données tabulaires.

Principe de fonctionnement

paste lit simultanément une ligne de chaque fichier passé en argument, et les affiche séparées par une tabulation (par défaut). Si un fichier a plus de lignes que l'autre, les lignes restantes sont affichées normalement. C'est simple, rapide, et souvent bien plus pratique que，写 du code.

Syntaxe de base

paste [OPTIONS] FICHIER...

Options principales

OptionDescription
-d, --delimiters=LISTECaractères séparateurs (au lieu de tabulation)
-s, --serialColler un fichier à la fois (toutes ses lignes sur une seule)
-Lire depuis l'entrée standard (pipe)

Exemples concrets

1. Fusionner deux fichiers ligne par ligne

Créons d'abord deux fichiers simples pour illustrer :

echo -e "Alice\nBob\nCharlie" > prenoms.txt
echo -e "25\n30\n35" > ages.txt

Puis fusionnons-les :

paste prenoms.txt ages.txt
# Sortie :
# Alice 25
# Bob 30
# Charlie 35

Par défaut, paste utilise la tabulation comme séparateur. Le résultat est une juxtaposition colonne par colonne.

2. Utiliser un séparateur personnalisé

L'option -d permet de choisir un ou plusieurs caractères séparateurs :

paste -d ":" prenoms.txt ages.txt
# Sortie :
# Alice:25
# Bob:30
# Charlie:35

3. Plusieurs séparateurs en alternance

Vous pouvez spécifier plusieurs caractères qui seront utilisés en alternance :

paste -d " | " prenoms.txt ages.txt prenoms.txt
# Sortie :
# Alice | 25 | Alice
# Bob | 30 | Bob
# Charlie | 35 | Charlie

4. Fusionner plus de deux fichiers

paste accepte un nombre illimité de fichiers :

echo -e "75001\n75002\n75003" > cp.txt
paste prenoms.txt ages.txt cp.txt
# Sortie :
# Alice 25 75001
# Bob 30 75002
# Charlie 35 75003

5. Mode série avec -s

L'option -s改变了行为 : au lieu de lire plusieurs fichiers en parallèle, elle lit chaque fichier entièrement et place toutes ses lignes sur une seule ligne, séparées par le délimiteur :

paste -s prenoms.txt
# Sortie :
# Alice Bob Charlie

Avec un séparateur personnalisé :

paste -s -d "," prenoms.txt
# Sortie :
# Alice,Bob,Charlie

6. Lire depuis l'entrée standard

Le tiret - représente l'entrée standard. Très utile dans un pipeline :

echo -e "Pierre\nJean\nMarie" | paste - ages.txt
# Sortie :
# Pierre 25
# Jean 30
# Marie 35

7. Créer un fichier CSV simple

paste -d "," prenoms.txt ages.txt cp.txt > data.csv
cat data.csv
# Sortie :
# Alice,25,75001
# Bob,30,75002
# Charlie,35,75003

Combinaisons puissantes

1. Avec cut pour créer un tableau

paste + cut = manipulation de tableaux complète :

# Extraire deux colonnes d'un fichier et les combiner
cut -f1 fichier.tsv > col1.txt
cut -f3 fichier.tsv > col3.txt
paste col1.txt col3.txt

2. Ajouter une colonne de numéros de ligne

seq 1 3 | paste - prenoms.txt
# Sortie :
# 1 Alice
# 2 Bob
# 3 Charlie

3. Créer une liste avec bullets

echo -e "Tâche 1\nTâche 2\nTâche 3" | paste -d " → " - <(echo "")
# Ou plus simplement :
echo -e "Tâche 1\nTâche 2\nTâche 3" | cat -n | paste - -

4. Transposer un fichier (lignes → colonnes)

En combinant -s avec un séparateur newline :

cat prenoms.txt
# Alice
# Bob
# Charlie
paste -s -d "\t" prenoms.txt
# Alice Bob Charlie

Pour transposer un fichier tabulaire complet (lignes ↔ colonnes), combinez avec datamash si disponible :

sudo apt install datamash
datamash transpose < fichier.txt

5. Assembler des résultats de commande

paste -d ":" <(whoami) <(date +%Y-%m-%d) <(hostname)
# Sortie :
# alice:2026-08-10:monserveur

6. Créer des en-têtes pour un rapport

echo -e "Colonne A\nLigne 1\nLigne 2" > colA.txt
echo -e "Colonne B\nVal 1\nVal 2" > colB.txt
echo -e "Nom\tScore" | paste - colA.txt colB.txt

Cas d'usage réels

1. Fusionner des exports de bases de données

Si vous avez deux exports CSV (sans header) :

paste -d "," clients_noms.csv clients_adresses.csv > clients_full.csv

2. Préparer un mailing

paste -d "," destinataires.csv modele_mail.csv

3. Créer un fichier de configuration

paste clés.txt valeurs.txt | sed 's/\t/=/'
# Cle1=Valeur1
# Cle2=Valeur2

4. Comparer visuellement deux listes

paste liste1.txt liste2.txt | column -t
# Affiche les deux listes côte à côte pour comparaison

pwd vs cut vs paste

CommandeRôleDirection
cutExtraire des colonnesVerticale (réduire)
pasteFusionner des colonnesHorizontale (assembler)
catConcaténer bout à boutVerticale (empiler)

Bonnes pratiques

  • Toujours vérifier le nombre de lignes : si les fichiers n'ont pas le même nombre de lignes, les lignes surnuméraires sont affichées seules
  • Utiliser des chemins absolus pour éviter les ambiguïtés dans les scripts
  • Combiner avec column -t pour formater joliment le résultat
  • Protéger les noms spéciaux avec des quotes si vos fichiers contiennent des espaces

Résumé

CommandeDescription
paste f1 f2Fusionne f1 et f2 ligne par ligne (tabulation)
paste -d "," f1 f2Utilise la virgule comme séparateur
paste -s f1Toutes les lignes de f1 sur une seule ligne
cmd | paste - f1Combine sortie de cmd avec f1
paste f1 f2 | column -tFormate en colonnes alignées
paste -s -d "\t" fTranspose les lignes en colonnes

paste est un outil souvent oublié mais terriblement utile. Qu'il s'agisse de fusionner des exports CSV, de créer des tableaux lisibles, ou d'assembler des résultats de commandes dans un script, paste fait le travail simplement et efficacement. Gardez-le dans votre boîte à outils — vous le sortirez plus souvent que vous ne le pensez.
