Leçon 155 : time — Mesurer le temps d'exécution des commandes

La commande time permet de mesurer le temps qu'une commande met à s'exécuter. Elle affiche trois types de mesures : le temps réel (wall clock time), le temps CPU utilisateur et le temps CPU système. C'est un outil essentiel pour optimiser les performances de vos scripts et commandes.

Syntaxe de base

time [OPTIONS] COMMANDE

time affiche ses résultats après l'exécution de la commande. Le format de sortie peut varier selon que vous utilisez le built-in Bash ou le binaire /usr/bin/time.

Exemple simple

time sleep 2

Résultat typique (bash built-in) :

real 0m2.003s
user 0m0.001s
sys 0m0.000s

Comprendre les trois temps

TempsSignificationExemple
realTemps total écoulé (horloge murale)Temps perceptible par l'utilisateur
userTemps CPU en mode utilisateurCalcul pur par le programme
sysTemps CPU en mode systèmeAppels système (lecture fichier, etc.)

La somme de user et sys représente le temps CPU total. Si real est nettement supérieur à cette somme, cela signifie que le programme a passé du temps à attendre (I/O, réseau, sommeil).

Le binaire /usr/bin/time

Il existe deux versions de time : le built-in Bash (intégré au shell) et le binaire système /usr/bin/time. Le binaire offre plus d'options.

Specifier le binaire systeme

/usr/bin/time sleep 2

Options du binaire /usr/bin/time

-v : Sortie détaillée

/usr/bin/time -v ls /usr

Cette commande affiche un rapport complet incluant :

  • Temps d'exécution (réel, utilisateur, système)
  • Mémoire maximale utilisée
  • Nombre de fautes de page
  • Swaps
  • Signaux reçus
  • Code de sortie

-p : Format POSIX portable

/usr/bin/time -p sleep 1

Résultat :

real 1.00
user 0.00
sys 0.00

-o fichier : Rediriger la sortie vers un fichier

/usr/bin/time -o /tmp/mon_temps.txt ls /home

La sortie de time est écrite dans le fichier, tandis que la sortie de la commande va sur la sortie standard.

-a : Ajouter au fichier (sans écraser)

/usr/bin/time -a -o /tmp/mon_temps.txt ls /var

-f format : Format personnalise

Vous pouvez définir votre propre format avec des variables :

/usr/bin/time -f "Temps réel: %E\nMémoire max: %M Ko" ls /etc
Option de formatDescription
%ETemps réel (format HH:MM:SS)
%eTemps réel en secondes
%UTemps utilisateur en secondes
%STemps système en secondes
%MMémoire maximale en Ko
%xCode de sortie
%CCommande et ses arguments

Exemples pratiques

Comparer deux methodes

# Méthode 1 : boucle while
time while read line; do echo "$line"; done < fichier.txt
# Méthode 2 : cat
time cat fichier.txt

Mesurer un script complet

time ./mon_script.sh

Mesurer une commande avec des arguments

/usr/bin/time -v find /home -name "*.log" 2>/dev/null

Benchmark d'une commande repetee

for i in {1..5}; do /usr/bin/time -f "%e" -o /tmp/bench.txt -a ls /usr; done
echo "Temps moyen:"; awk '{s+=$1; c++} END {print s/c}' /tmp/bench.txt

Rediriger la sortie de la commande (sans polluer)

(time ls -R /usr) 2> /tmp/time_output.txt

Capturer le resultat de time dans une variable

Avec Bash, vous pouvez capturer le résultat de time dans une variable en utilisant les parenthèses :

# Capturer la sortie stderr de time
output=$( { time sleep 1; } 2>&1 )
echo "$output"

Utilisation dans un script

#!/bin/bash
# Fonction pour chronométrer une commande
chrono() {
debut=$(date +%s)
"$@"
fin=$(date +%s)
echo "Durée: $((fin - debut)) secondes"
}
# Utilisation
chrono wget -q https://example.com

Interpretation des resultats

real > user + sys

Le programme a attendu (I/O lent, réseau, sommeil, locks). C'est normal pour des commandes comme sleep ou wget.

user + sys ≈ real

Le programme est CPU-bound. Il utilise intensivement le processeur. Potentiellement optimisable.

real >> user + sys (souvent)

Programme très lent en I/O ou qui attend beaucoup. Peut indiquer un goulot d'étranglement.

time avec pipeline

time fonctionne aussi avec les pipes :

time ls -la /usr | sort -k5 -n | head -20

Le chronométrage couvre l'ensemble du pipeline, du début à la fin.

time dans un sous-shell

Pour chronométrer un pipeline entier et l'afficher correctement :

# Utiliser les accolades pour grouper
{ time ls -la /usr; } 2>&1 | tail -5

Bonnes pratiques

  • Utilisez /usr/bin/time -v pour des mesures détaillées
  • Répétez les mesures plusieurs fois pour tenir compte des variations
  • Mesurez dans des conditions similaires (charge système, cache, etc.)
  • Utilisez -o pour rediriger les résultats vers un fichier de log
  • Comparez toujours avec un point de référence avant d'optimiser
