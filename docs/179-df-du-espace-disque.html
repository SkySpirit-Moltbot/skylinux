df et du — Gérer l'espace disque

Sous Linux, surveiller l'espace disque est une tâche essentielle pour tout administrateur ou utilisateur. Deux commandes permettent de répondre à cette problématique : df pour voir l'espace disponible sur les systèmes de fichiers, et du pour analyser l'espace occupé par les fichiers et répertoires. Dans cette leçon, vous apprendrez à les maîtriser.

1. df — Espace disque disponible

La commande df (disk free) affiche l'espace disque utilisé et disponible sur tous les systèmes de fichiers montés.

Utilisation de base

df

Par défaut, df affiche les tailles en blocs de 1 Ko, ce qui rend la lecture difficile. Utilisez l'option -h pour un format lisible par l'humain :

df -h

Résultat typique :

Sys. de fichiers Taille Utilisé Dispo Uti% Monté sur /dev/sda1 50G 23G 27G 46% / tmpfs 2.0G 0 2.0G 0% /dev/shm /dev/sdb1 200G 85G 115G 43% /mnt/backup

Options utiles de df

OptionDescription
df -hTailles en format lisible (Ko, Mo, Go)
df -aAffiche tous les systèmes de fichiers, y compris ceux de 0 bloc
df -TAffiche le type de système de fichiers (ext4, xfs, tmpfs…)
df -iAffiche l'utilisation des inodes au lieu des blocs
df -h /homeInformation uniquement pour le point de montage /home
df -BGArrondit à la Gio (utile pour des valeurs exactes)

Comprendre les colonnes

  • Sys. de fichiers — Le périphérique ou label du système de fichiers
  • Taille — Capacité totale
  • Utilisé — Espace déjà alloué
  • Dispo — Espace restant disponible
  • Uti% — Pourcentage d'utilisation (un indicateur d'alerte à surveiller)
  • Monté sur — Le point de montage

Alertes automatiques

Pour trouver rapidement les partitions proches de 90% d'utilisation :

df -h | awk 'NR>1 && int($5) >= 90 {print $0}'

Ou avec un affichage plus propre :

df -h --output=source,size,used,avail,pcent,target -l | awk 'NR>1 && int($5) >= 80'

2. du — Espace utilisé par les fichiers

La commande du (disk usage) calcule et affiche l'espace disque utilisé par les fichiers et répertoires.

Utilisation de base

du

Sans argument, du affiche l'espace utilisé par chaque fichier et sous-répertoire dans le répertoire courant — ce qui peut être très long. Mieux vaut utiliser -h :

du -h

Voir uniquement le total d'un répertoire

Pour connaître la taille totale d'un répertoire sans le détail de chaque sous-dossier :

du -sh /var/log

Résultat :

1.2G /var/log

L'option -s (summary) affiche uniquement le total, et -h rend le résultat lisible.

Voir les plus gros répertoires

Pour trouver les répertoires qui consomment le plus d'espace, triez par taille :

du -h / | sort -rh | head -20

Ou pour un répertoire précis, trié par taille décroissante :

du -sh /home/* | sort -rh

Options utiles de du

OptionDescription
du -hFormat lisible (Ko, Mo, Go)
du -shSummary uniquement — taille totale du répertoire
du -aAffiche les fichiers individuels en plus des répertoires
du -d NLimite l'affichage à N niveaux de profondeur (profondeur = N)
du --max-depth=1N'affiche que le premier niveau de sous-répertoires
du -cAffiche un total à la fin
du -BMAffiche les tailles en Mio arrondis
du -s --exclude="*.log"Exclut les fichiers correspondant au motif
du --apparent-sizeCalcule la taille apparente (contenu réel du fichier)

Exemples pratiques

Voir la taille des sous-répertoires directs de /home :

du -sh /home/*

Voir les 10 plus gros fichiers dans /var/log :

du -ah /var/log | sort -rh | head -10

Limiter à 2 niveaux de profondeur :

du -h --max-depth=2 /

Exclure un type de fichier :

du -sh --exclude="*.tmp" /tmp

3. Cas pratiques combinés

Trouver ce qui remplit le disque

Quand le disque est plein et que vous ne savez pas pourquoi, une approche systématique fonctionne le mieux :

# Étape 1 : voir les partitions df -h # Étape 2 : voir les gros répertoires à la racine sudo du -sh /* 2>/dev/null | sort -rh | head -10 # Étape 3 : creuser dans le plus gros répertoire sudo du -sh /var/* 2>/dev/null | sort -rh | head -10

Nettoyer les anciens journaux

Identifier les gros fichiers de log et leur ancienneté :

find /var/log -name "*.gz" -o -name "*.old" | xargs du -h 2>/dev/null | sort -rh

Puis supprimer les logs de plus de 30 jours :

sudo find /var/log -name "*.log" -mtime +30 -exec rm -v {} \;

Surveillance d'un serveur

Créer un petit script de surveillance :

#!/bin/bash # Alerte si une partition dépasse 85% df -h | awk 'NR>1 && int($5) >= 85 { print "ALERTE: " $6 " est à " $5 " sur " $1 }'

4. ncdu — une alternative graphique

Si du est trop statique, ncdu (NCurses Disk Usage) offre une interface interactive et naviguer dans les répertoires. Installez-le et utilisez-le ainsi :

sudo apt install ncdu # Debian/Ubuntu sudo dnf install ncdu # Fedora sudo pacman -S ncdu # Arch ncdu /

Naviguez avec les flèches, entrez dans un dossier avec Entrée, remontez avec .., et supprimez avec d.

5. Résumé

CommandeUsage
df -hEspace disque disponible sur toutes les partitions
df -h /point/montEspace pour une partition précise
du -sh /dirTaille totale d'un répertoire
du -h --max-depth=1Tailles du premier niveau de sous-répertoires
du -ah /dir | sort -rh | headLes fichiers et répertoires les plus gros
ncdu /dirInterface interactive pour explorer l'espace disque

df répond à la question "où en est mon disque ?", tandis que du répond à "qu'est-ce qui prend tant de place ?". Les deux sont indispensables pour maintenir un système en bonne santé.
