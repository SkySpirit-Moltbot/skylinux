Leçon 66 : wc — Compter lignes, mots et caractères

wc (word count) est l'outil de statistiques le plus simple et le plus utilisé du shell.

1. Utilisation de base

# Compter tout : lignes, mots, octets wc mon_fichier.txt # → 150 1200 8500 mon_fichier.txt # ↑ ↑ ↑ # lignes mots octets # Seulement les lignes wc -l mon_fichier.txt # Seulement les mots wc -w mon_fichier.txt # Seulement les caractères wc -m mon_fichier.txt # Seulement les octets wc -c mon_fichier.txt

2. Cas pratiques du quotidien

# Combien de fichiers dans un dossier ? ls | wc -l # Combien de processus ? ps aux | wc -l # Combien d'utilisateurs ont un compte ? wc -l /etc/passwd # Combien de lignes de code dans un projet ? find . -name "*.py" | xargs wc -l # Total global find . -name "*.py" | xargs wc -l | tail -1 # Compter les occurrences d'un mot grep "erreur" /var/log/syslog | wc -l # Taille totale des .log find /var/log -name "*.log" | xargs wc -c | tail -1

3. Différence entre -c et -m

# -c = octets (bytes) # -m = caractères (UTF-8, un caractère peut valoir plusieurs octets) echo "ça" | wc -c # → 4 (c=1, ¸=2, a=1, \n=1) echo "ça" | wc -m # → 3 (ç=1, a=1, \n=1)

4. Dans un script

#!/bin/bash nb_lignes=$(wc -l < fichier.txt) echo "Le fichier contient $nb_lignes lignes" if [ "$nb_lignes" -gt 1000 ]; then echo "Gros fichier détecté !" fi

5. Exercices pratiques

1. **Base** — Compte les lignes, mots et caractères d'un fichier

2. **Dossier** — Compte combien de fichiers .sh sont dans /usr/bin

3. **Logs** — Compte le nombre de lignes contenant "error" dans /var/log/syslog

4. **Projet** — Compte les lignes de tous les .md de ton dossier courant
