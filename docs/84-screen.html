screen — Gestionnaire de sessions terminal persistantes

Introduction

Vous êtes connecté en SSH à un serveur et vous lancez un téléchargement qui prendra 2 heures. Que se passe-t-il si votre connexion coupe ? Le processus meurt. screen résout ce problème : c'est un multiplexeur de terminal qui garde vos sessions actives même si vous vous déconnectez. Vous pouvez vous reconnecter plus tard et retrouver votre session exactement où vous l'avez laissée.

screen est préinstallé sur beaucoup de distributions Linux. Il est l'alternative historique à tmux (vu en leçon 27). Si tmux n'est pas disponible, screen reste un excellent choix.

Installation

# Debian / Ubuntu sudo apt install screen # Fedora / CentOS / RHEL sudo dnf install screen # Arch Linux sudo pacman -S screen # Vérifier que screen est installé screen --version

Démarrer une session screen

Créer une nouvelle session

# Lancer screen (crée une nouvelle session) screen # Lancer screen avec un nom personnalisé screen -S mon_serveur # Lancer screen avec un titre descriptif screen -S "backup-server" # Le titre apparaît dans la liste des sessions

Comprendre screen dès le départ

# Quand screen démarre, vous voyez un écran vide (ou un shell) # Tout semble normal... mais vous êtes dans une session screen ! # Pour confirmer, faites : echo $TERM # Affiche : screen (indique que vous êtes dans screen) # ou tapez : screen -v # GNU Screen 4.08.00 (protocol version 4)

Les commandes de base dans screen

Le préfixe Ctrl+A

Toutes les commandes de screen commencent par Ctrl+A, suivi d'une lettre ou d'une touche. Cela signifie : maintenez Ctrl, appuyez sur A, puis relâchez et tapez la commande.

# Syntaxe générale : # Ctrl+A puis d → Détacher la session # Ctrl+A puis c → Créer une nouvelle fenêtre # Ctrl+A puis n → Fenêtre suivante # Ctrl+A puis p → Fenêtre précédente # Ctrl+A puis " → Liste des fenêtres # Ctrl+A puis k → Tuer la fenêtre actuelle

Détacher et rattacher

# Se détacher (sortir de screen sans fermer la session) # Depuis inside screen : Ctrl+A puis d # Vous revenez au terminal normal # La session screen continue en arrière-plan ! # Rattacher à une session existante screen -r # Si plusieurs sessions existent, choisir laquelle screen -ls # Lister les sessions # There are several suitable screens: # 1652.backup-server (Detached) # 1687.monitor (Attached) screen -r 1652 # Rattacher par PID screen -r backup-server # Rattacher par nom # Rattacher en mode lecture seule (ne pas interferer) screen -r -d 1652 # Rattacher, détacher d'abord si quelqu'un d'autre est connecté

Créer plusieurs fenêtres

# Depuis inside screen : # Créer une nouvelle fenêtre Ctrl+A puis c # Passer à la fenêtre suivante Ctrl+A puis n # Passer à la fenêtre précédente Ctrl+A puis p # Lister toutes les fenêtres (interface interactive) Ctrl+A puis " # Choisir une fenêtre par numéro Ctrl+A puis " puis 0, 1, 2... # Sauter à la fenêtre 3 directement Ctrl+A puis 3

Fenêtre historique (scrollback)

# Activer le mode copie/scroll Ctrl+A puis [ # Navigation en mode copie : # Flèches haut/bas → Défiler # Page Up/Down → Défiler par page # q → Quitter le mode copie # Chercher dans l'historique (mode copie) # / → Rechercher vers le bas # ? → Rechercher vers le haut # n → Prochain résultat # N → Résultat précédent

Copier-coller

# Entrer en mode copie Ctrl+A puis [ # Positionner le curseur, puis : # Espace → Commencer la sélection # Entrer → Finir la sélection (copie) # Coller le texte copié Ctrl+A puis ] # Alternative : sélection à la souris (si activé)

Fermer et tuer

# Tuer la fenêtre actuelle (confirmation) Ctrl+A puis K # Puis taper "y" pour confirmer # Tuer toutes les fenêtres et quitter screen Ctrl+A puis \ # Quitter screen normalement (ferme la session) exit # Quand la dernière fenêtre est fermée, screen se ferme

Gérer plusieurs sessions

Lister les sessions

# Voir toutes les sessions screen screen -ls # Exemple de sortie : # There are screens on: # 1652.backup-server (Detached) # 1687.monitor (Attached) # 1892.download (Detached) # 3 Sockets in /run/screens/S-david. # Chaque session a : # - Un PID (1652, 1687, 1892) # - Un nom (backup-server, monitor, download) # - Un état (Detached = inactive, Attached = en cours d'utilisation)

Créer une session nommée

# Créer une session avec nom explicite screen -S travaux # Utile pour identifier rapidement : screen -S serveur-web screen -S backup-nocturne screen -S monitoring # Se rattacher plus tard par nom screen -r serveur-web

Partager une session (screen partagé)

# Mode multi-utilisateur (avancé) # Activer le mode multi-display sur la session Ctrl+A puis :multiuser on # Donner l'accès à un autre utilisateur chmod 755 /run/screens/S-david # L'autre utilisateur peut se rattacher en lecture seule screen -r nom_session -t 0 # Mode lecture seule (l'autre voit mais ne peut pas taper) screen -r -x # Session partagée (les deux voient et tapent) # Les deux utilisateurs font : screen -x nom_session # Les deux voient la même chose en temps réel

Envoyer des commandes à une session détachée

# Envoyer une commande à une session screen sans s'attacher screen -S nom_session -X stuff 'ls -la\n' # Envoyer un texte brut (sans Enter) screen -S nom_session -X stuff 'echo test' # Plus complexe : utiliser -X eval screen -S nom_session -X eval "stuff 'exit'\n" # Alternative : créer un script pour envoyer des commandes # screen -S nom_session -X exec ...

Configuration de screen

Le fichier ~/.screenrc

# Créer ou éditer le fichier de configuration nano ~/.screenrc # Exemple de configuration basique : startup_message off # Pas de message de bienvenue defscrollback 1000 # 1000 lignes d'historique hardstatus alwayslastline # Barre de statut en bas hardstatus string '%{= kG}%?%-Lw%?%{r}(%{g}%n%f %t%?}%?%{r})%?%{g}%?%+Lw%?%? %{g}%?%{y}:%{g} %c:%s %{g}' # Active les raccourcis Ctrl+L pour effacer l'écran bind l stuff ^L

Barre de statut (hardstatus)

# ~/.screenrc avec barre de statut utile # Afficher la liste des fenêtres en bas hardstatus alwayslastline hardstatus string '%{= kW}%-Lw%{?nw}%?%{r}(%{g}%n%f %t%?}%?%{r})%{w}%?%{g}%+Lw%?%{w}%? %=%{g} %c:%s %d/%m' # Résultat visuel : # 0$bash 1$top 2$logs 3$vim 14:30: 08/06 # another bar style : hardstatus string ' %`%{= kw}%-w+ %{= kw}%n*%t%{= kw}%+w %= %{= kR}%?%F%{.kw} [%?] %?%{.kw}%c:%s%?%?%{= kR} [%S] %?%?%{.kw}%-w%?%{r}%n%f %t%?%{w}%?%+w %='

Raccourcis personnalisés

# ~/.screenrc # Définir F1 pour créer une nouvelle fenêtre bindkey "^[O5P" screen bindkey -k F1 screen # Définir F2 pour lister les fenêtres bindkey -k F2 windowlist # Raccourci pour se détacher rapidement bind d detach bind D lock # Split-screen (diviser l'écran) bind | split -v # Split vertical bind S split # Split horizontal bind Q only # Fermer les splits bind Tab focus # Basculer entre splits # Copier-coller bind ] paste .

Configuration avancée

# ~/.screenrc - configuration complète # ---Général--- startup_message off # Pas de message au démarrage msgwait 2 # Message de statut pendant 2 secondes nethack on # Interface plus lisible (style jeu) # ---Apparence--- shell -bash # Utiliser bash defshell -bash caption always "%{= wb}%?%-Lw%?%{r}(%{g}%n%f %t%?}%?%{r})%?%{g}%+Lw%?%? %{g}%=%{y} %c:%s %{w}%?%?%{y}:%{g} %d/%m%?" # ---Comportement--- autodetach on # Détacher automatiquement à la déconnexion wrap on # Les lignes longues continuent sur la ligne suivante idle 300 lockscreen # Verrouiller après 5 min d'inactivité

Split-screen dans screen

Diviser l'écran

# Depuis inside screen : # Diviser horizontalement (crée une région au-dessus) Ctrl+A puis S # Diviser verticalement (crée une région à gauche) Ctrl+A puis | # Basculer entre les régions Ctrl+A puis Tab # Fermer la région actuelle Ctrl+A puis X # Toutes les régions = splitter pour créer un layout # Commencer avec | (vertical) # Puis Tab puis créer une fenêtre dans la nouvelle région

Travailler avec les splits

# Créer un layout à 3 panneaux : # 1. Ctrl+A | → Split vertical # 2. Ctrl+A Tab → Aller dans le nouveau panneau # 3. Ctrl+A c → Créer une fenêtre dans ce panneau # 4. Ctrl+A Tab → Revenir au panneau gauche # 5. Ctrl+A S → Split horizontal # 6. Ctrl+A Tab → Aller en bas # 7. Ctrl+A c → Créer une fenêtre en bas # Naviguer entre les régions Ctrl+A Tab # Redimensionner une région Ctrl+A :resize 20 # Fixer la taille à 20 lignes Ctrl+A :resize +5 # Ajouter 5 lignes Ctrl+A :resize -5 # Retirer 5 lignes

Configuration des splits

# ~/.screenrc pour les splits # Layout par défaut avec splits layout save default # Sauvegarder le layout layout new # Créer un nouveau layout layout select 0 # Utiliser le layout 0 # Raccourcis pour les splits bind s split # Split horizontal bind v split -v # Split vertical bind t focus # Aller à la région du haut bind b focus # Aller à la région du bas

Utiliser screen dans un script

Lancer une commande dans screen

# Lancer une commande sans interaction (session detached) screen -dmS test_session "sleep 10; echo 'Terminé'" # -d : lancer en mode détaché # -m : forcer la création d'une nouvelle session # -S : nommer la session # Vérifier que la session existe screen -ls | grep test_session

Script de surveillance

#!/bin/bash # Script : lancer un processus en arrière-plan avec screen SESSION="backup-$(date +%Y%m%d-%H%M)" COMMAND="tar -czf /backup/data.tar.gz /home/data && echo 'Backup terminé' | mail admin@example.com" # Créer la session screen -dmS "$SESSION" bash -c "$COMMAND" # Attendre un peu et vérifier sleep 2 screen -ls | grep "$SESSION" # Voir les logs en temps réel screen -r "$SESSION"

Démarrer plusieurs processus

#!/bin/bash # Lancer plusieurs services dans des sessions screen services=("apache" "mysql" "redis" "nginx") base_port=3000 for i in "${!services[@]}"; do name="${services[$i]}" port=$((base_port + i)) # Créer une session par service screen -dmS "$name" bash -c "echo 'Démarrage $name sur port $port'; sleep infinity" done echo "Sessions créées :" screen -ls

Dépannage

Session coincée ou écran noir

# Si screen ne répond plus # Forcer la déconnexion Ctrl+A puis :quit # Ou depuis un autre terminal : screen -S nom_session -X quit # Si le terminal est coincé, forcer kill kill -9 $(screen -ls | grep nom_session | awk -F. '{print $1}')

Impossible de se rattacher

<
# Vérifier l'état de la session screen -ls # Si "Attached" mais personne n'est connecté : # Forcer le détachement screen -d nom_session # Puis se rattacher screen -r nom_session # Si la session est vraiment corrompue : # Rattacher en mode lecture seule screen -r -p 0 nom_session # Et tuer la session si nécessaire screen -S nom_session -X quit

screen ne répond plus au préfixe

# Si Ctrl+A ne fonctionne pas : # 1. Vérifier que le terminal n'est pas en mode brut # Taper : exit (ou Ctrl+D) pour quitter # 2. Si screen est coincé, utiliser le fallback : # Ctrl+A puis Ctrl+\ (forcer quit) # Ou : Ctrl+Z (mettre en arrière-plan, puis kill) # 3. Depuis un autre terminal : screen -S nom_session -X quit # 4. Redémarrer une nouvelle session screen -R

Récupérer après une déconnexion SSH

# Connexion a été coupée, sessions perdues ? # Vérifier si screen tourne encore ps aux | grep screen # Lister les sessions screen persistantes screen -ls # Si une session existe en état "Detached", se rattacher screen -r nom_session # Si l'état est "Dead" : # Nettoyer la session morte screen -wipe # Créer une nouvelle session et continuer screen -S nouvelle_session

Bonnes pratiques

  • Nommez vos sessions : screen -S projet_x pour les retrouver facilement
  • Vérifiez avant de fermer : screen -ls pour voir les sessions actives
  • Utilisez le scrollback : Ctrl+A [ pour naviguer dans l'historique
  • Configurez ~/.screenrc : personalisez la barre de statut et les raccourcis
  • Intégration scripts : utilisez screen -dmS pour lancer des tâches en arrière-plan
  • Nettoyez les sessions mortes : screen -wipe régulièrement

Exercices pratiques

  1. Premier screen : Lancez screen -S test, tapez quelques commandes, puis détachez-vous avec Ctrl+A d. Rattachez-vous avec screen -r test.
  2. Multi-fenêtres : Dans screen, créez 3 fenêtres avec Ctrl+A c. Naviguez entre elles avec Ctrl+A n et Ctrl+A p. Listez-les avec Ctrl+A ".
  3. Scrollback : Lancez history ou ls -la /, puis utilisez Ctrl+A [ pour naviguer dans l'historique. Quittez avec q.
  4. Session persistente : Créez une session, lancez sleep 60, détachez, kill le terminal, rouvrez un terminal, et rattachez-vous. Le sleep devrait toujours tourner.
  5. Script screen : Créez un script qui lance 3 sessions screen nommées (serveur1, serveur2, serveur3), chacune exécutant une commande différente.
  6. Configuration : Créez un fichier ~/.screenrc avec une barre de statut montrant l'heure et la date.
  7. Défi : Créez un script de surveillance qui lance un processus long dans screen, et envoie un email quand il se termine.

Conclusion

screen est votre allié pour garder des sessions actives en permanence. Que vous bossiez sur un serveur distant, lanciez des processus longs, ou partagiez une session avec un collègue, screen assure la persistance. Combinez-le avec les autres leçons : ssh (leçon 12) pour la connexion distante, cron (leçon 13 ou 79) pour les tâches planifiées, et tmux (leçon 27) si vous préférez une alternative plus moderne. Une session screen bien gérée peut tourner des semaines, voire des mois, sans intervention.
