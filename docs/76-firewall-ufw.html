UFW — Le pare-feu simple sous Linux

Introduction

Un pare-feu est votre première ligne de défense sur un système Linux. Il contrôle quels paquets réseau peuvent entrer ou sortir de votre machine. ufw (Uncomplicated Firewall) est l'outil simplifié fourni par défaut sur Ubuntu et de nombreuses distributions Linux pour gérer iptables sans complexité.

Si iptables est puissant mais difficile à maîtriser, ufw offre une interface simple et lisible pour configurer votre pare-feu en quelques minutes.

Vérifier et installer UFW

Vérifier le statut

Pour voir si UFW est installé et son état actuel :

sudo ufw status

Si UFW n'est pas installé, installez-le avec :

sudo apt update sudo apt install ufw

Activer et désactiver le pare-feu

Activer UFW

Pour activer le pare-feu (bloquera tout le trafic entrant non autorisé) :

sudo ufw enable

Un message d'avertissement peut apparaître, indiquant que cela pourrait perturber les connexions SSH existantes. Si vous êtes connecté en SSH, pensez à autoriser ce trafic avant d'activer !

Désactiver UFW

sudo ufw disable

Cette commande désactive complètement le pare-feu. À utiliser avec précaution sur un serveur exposé.

Réinitialiser UFW

Si vous avez fait une erreur de configuration et voulez recommencer à zéro :

sudo ufw reset

Cela réinitialise UFW à son état par défaut (inactif, avec les règles par défaut).

Autoriser et bloquer le trafic

Règles de base

Autoriser le trafic SSH

TRÈS IMPORTANT : avant d'activer UFW sur un serveur avec SSH, assurez-vous d'autoriser SSH sous peine de vous verrouiller dehors !

sudo ufw allow ssh

Ou en spécifiant le port directement :

sudo ufw allow 22/tcp

Autoriser le trafic HTTP et HTTPS

Pour un serveur web, autorisez les ports 80 (HTTP) et 443 (HTTPS) :

sudo ufw allow http sudo ufw allow https

Ou en utilisant les ports directement :

sudo ufw allow 80/tcp sudo ufw allow 443/tcp

Autoriser un port spécifique

Pour autoriser le trafic sur un port donné :

sudo ufw allow 8080

Bloquer le trafic entrant

Pour bloquer tout le trafic entrant (par défaut, UFW bloque tout sauf le trafic autorisé explicitement) :

sudo ufw default deny incoming

Autoriser tout le trafic sortant

sudo ufw default allow outgoing

Créer des règles plus spécifiques

Autoriser depuis une adresse IP spécifique

Pour autoriser les connexions entrantes depuis une adresse IP précise :

sudo ufw allow from 192.168.1.100

Autoriser depuis une IP vers un port spécifique

Autoriser l'accès au port 3306 (MySQL) uniquement depuis le réseau local :

sudo ufw allow from 192.168.1.0/24 to any port 3306

Bloquer une IP ou un réseau

Pour bloquer une adresse IP spécifique :

sudo ufw deny from 192.168.1.50

Pour bloquer tout un réseau :

sudo ufw deny from 192.168.0.0/24

Autoriser une plage de ports

Pour autoriser une plage de ports (par exemple 6000-6010) :

sudo ufw allow 6000:6010/tcp

Règles pour les applications nommées

Certaines applications enregistrement leur profil UFW. Vous pouvez les autoriser par nom :

sudo ufw app list

Par exemple, pour Nginx :

sudo ufw allow 'Nginx Full'

Supprimer des règles

Afficher les règles avec leurs numéros

sudo ufw status numbered

Vous verrez une liste numérotée des règles actives :

Status: active To Action From -- ------ ---- [ 1] 22/tcp ALLOW IN Anywhere [ 2] 80/tcp ALLOW IN Anywhere [ 3] 443/tcp ALLOW IN Anywhere

Supprimer une règle par numéro

Pour supprimer la règle numéro 2 :

sudo ufw delete 2

Supprimer une règle par sa définition

Pour supprimer une règle comme "allow http" :

sudo ufw delete allow http

Gérer les connexions établies

Autoriser les connexions sortantes correspondantes

Pour que UFW suive automatiquement les connexions établies (pour que les réponses aux requêtes sortantes soient autorisées) :

sudo ufw allow out state ESTABLISHED,RELATED

Logging

Activer ou désactiver les logs

Pour activer les logs de pare-feu (niveau basique) :

sudo ufw logging on

Pour un niveau plus détaillé :

sudo ufw logging low # Faible volume de logs sudo ufw logging medium # Volume moyen sudo ufw logging high # Volume élevé (avec détails de chaque paquet)

Pour désactiver les logs :

sudo ufw logging off

Les logs sont écrits dans /var/log/ufw.log. Vous pouvez les consulter avec :

sudo tail -f /var/log/ufw.log

Configuration pour des cas courants

Serveur web (Apache/Nginx)

sudo ufw default deny incoming sudo ufw allow ssh sudo ufw allow 80/tcp sudo ufw allow 443/tcp sudo ufw enable

Serveur mail (SMTP, IMAP, POP3)

sudo ufw default deny incoming sudo ufw allow ssh sudo ufw allow 25/tcp # SMTP sudo ufw allow 465/tcp # SMTPS sudo ufw allow 587/tcp # Submission sudo ufw allow 993/tcp # IMAPS sudo ufw allow 995/tcp # POP3S sudo ufw enable

PostgreSQL

sudo ufw default deny incoming sudo ufw allow ssh sudo ufw allow from 192.168.1.0/24 to any port 5432 sudo ufw enable

Vérifier la configuration complète

Voir toutes les règles

sudo ufw status verbose

Ce mode affiche des détails supplémentaires comme les politiques par défaut, les logs actifs, et l'interface par laquelle UFW surveille le trafic.

Créer un fichier de configuration

UFW peut être configuré via un fichier texte situé en /etc/ufw/ufw.conf :

sudo nano /etc/ufw/ufw.conf

Contenu typique :

# Configure UFW ENABLED=yes DEFAULT_INPUT_POLICY="DROP" DEFAULT_OUTPUT_POLICY="ACCEPT" DEFAULT_FORWARD_POLICY="DROP" DEFAULT_APPLICATION_POLICY="SKIP" MANAGE_BUILTINS=no IPT_MODULES="nf_conntrack_ftp nf_nat_ftp nf_conntrack_netbios_ns"

Exercice pratique

  1. Vérifiez l'état de UFW : lancez sudo ufw status verbose pour voir la configuration actuelle.
  2. Créez une configuration serveur SSH : activez UFW, bloquez tout le trafic entrant par défaut, autorisez SSH uniquement.
  3. Testez le blocage : ajoutez une règle pour bloquer une IP de test (la vôtre ou une IP de votre réseau local) et vérifiez le comportement.
  4. Configurez pour un serveur web complet : activez UFW, bloquez le trafic entrant non explicite, et configurez-le pour un serveur Nginx avec SSH.
  5. Supprimez une règle : utilisez sudo ufw status numbered, puis supprimez une règle par son numéro.
  6. Consultation des logs : activez le logging et examinez /var/log/ufw.log pour voir les paquets bloqués.

Conclusion

ufw est l'outil idéal pour sécuriser votre système Linux sans affronter la complexité de iptables. En quelques commandes, vous pouvez configurer un pare-feu fonctionnel qui bloquera le trafic non autorisé tout en laissant passer vos services légitimes. N'oubliez jamais d'autoriser SSH avant d'activer le pare-feu sur un serveur distant, sous peine de perdre l'accès à votre machine !
