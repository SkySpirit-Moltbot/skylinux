fmt — Formater le texte en paragraphs

Introduction

La commande fmt est un outil simple mais puissant pour reformater les paragraphes de texte. Elle ajuste automatiquement la largeur des lignes, fusionne les lignes trop courtes et répartit le texte pour qu'il soit plus lisible.

fmt est particulièrement utile pour nettoyer du texte brut, formater des fichiers de configuration, ou préparer du contenu pour l'affichage dans un terminal.

Syntaxe de base

fmt [OPTIONS] [FICHIER]

Si aucun fichier n'est spécifié, fmt lit depuis l'entrée standard.

Options principales

OptionDescriptionExemple
-w NLargeur maximale des lignes (défaut : 75)fmt -w 60
-sNe pas fusionner les lignes, juste casser les trop longuesfmt -s
-uEspacement uniforme (une espace entre mots, deux entre phrases)fmt -u
-tMode tagéré (première ligne indentée)fmt -t
-cConserver l'indentation des lignes suivantes (crown margin)fmt -c

Exemples fondamentaux

1. Formatage standard

Formater un fichier avec la largeur par défaut (75 caractères) :

fmt fichier.txt

2. Largeur personnalisée

Limiter les lignes à 60 caractères :

fmt -w 60 fichier.txt

3. Lire depuis un pipe

Formater la sortie d'une autre commande :

cat fichier.txt | fmt -w 70

4. Formatage sur place

Écrire le résultat dans un nouveau fichier :

fmt -w 80 fichier.txt > fichier-formate.txt

Casser les lignes sans fusionner

L'option -s est utile quand on veut simplement raccourcir les lignes trop longues sans modifier la structure existante :

fmt -s -w 50 fichier.txt

Cela cassera les lignes qui dépassent 50 caractères, mais ne fusionnera pas les lignes courtes entre elles.

Espacement uniforme avec -u

L'option -u applique un espacement standard : une seule espace entre les mots et deux espaces après les phrases (style américain) :

echo "Un texte. Un autre texte.Encore du texte." | fmt -u

Mode crown margin (-c)

Le mode -c préserve l'indentation de la première ligne d'un paragraphe tout en réalignant les lignes suivantes :

fmt -c -w 60 fichier.txt

Cela est particulièrement utile pour formater du texte avec des listes ou du code commenté.

Cas d'utilisation pratiques

1. Nettoyer un fichier texte brut

Si vous recevez un fichier avec des lignes très longues (par exemple depuis une webpage) :

curl -s https://example.com | fmt -w 80

2. Formater des commentaires dans un script

Nettoyer des commentaires trop larges pour l'affichage :

grep "^#" script.sh | fmt -w 70

3. Préparer du texte pour un mail

Formater automatiquement le corps d'un mail pour qu'il soit lisible :

cat mail_brut.txt | fmt -w 72

4. Limiter la largeur d'une sortie

Adapter une longue sortie à la largeur du terminal :

ls -l | fmt -w $(tput cols)

fmt vs autres outils

OutilUsage
fmtFormater les paragraphes (fusion + cassage)
foldSimplement casser les lignes à une largeur fixe
parFormateur de texte plus avancé (non installé par défaut)
columnFormater en colonnes tabulaires

fmt vs fold

fold coupe simplement les lignes à la largeur demandée, sans se soucier des mots :

echo "Linux est un système d'exploitation puissant" | fold -w 20

Résultat avec fold :

Linux est un systè me d'exploitation p uissant

fmt, lui, respecte les mots et reformate intelligemment :

echo "Linux est un système d'exploitation puissant" | fmt -w 20

Combiner fmt avec d'autres commandes

Pipeline complet de nettoyage

Extraire, nettoyer et afficher du texte :

cat document.txt | tr -s ' ' | fmt -w 80

Formatter avant d'envoyer dans un fichier

cat notes.txt | fmt -w 72 > notes_propres.txt

Résume

CommandeRésultat
fmt fichier.txtFormatage standard (75 colonnes)
fmt -w 60 fichier.txtLignes limitées à 60 caractères
fmt -s fichier.txtCasser sans fusionner
fmt -u fichier.txtEspacement uniforme
fmt -c fichier.txtConserver l'indentation

fmt est l'outil idéal quand vous devez rendre du texte brut plus lisible dans le terminal, sans avoir besoin de la puissance d'un véritable traitement de texte. Simple, rapide et efficace.
