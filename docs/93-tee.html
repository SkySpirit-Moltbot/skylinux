Leçon 93 — tee — Lire depuis l'entrée et écrire partout

Qu'est-ce que tee ?

tee est une commande qui lit les données depuis l'entrée standard (stdin) et les écrit simultanément dans un fichier ET vers la sortie standard (stdout). Son nom vient de la forme en "T" du tuyau de plomberie : les données rentrent d'un côté et sortent dans deux directions.

Pourquoi utiliser tee ?

  • Voir la sortie tout en la sauvegardant : vous affiche le résultat dans le terminal ET l'enregistre dans un fichier
  • Pipeline transparent : permet d'inspecter des données qui transitent dans un pipe sans le perturber
  • Logs en temps réel : garder une trace de ce qui passe dans un管道 sans arrêter le flux
  • Écrire dans plusieurs fichiers : avec l'option -a, ajouter à plusieurs destinations

Syntaxe de base

COMMANDE | tee [OPTIONS] FICHIER

Exemples concrets

1. Sauvegarder la sortie tout en l'affichant

echo "Bonjour le monde" | tee sortie.txt
# Affiche : Bonjour le monde
# ET écrit dans sortie.txt
cat sortie.txt
# Affiche : Bonjour le monde

2. Ajouter à un fichier (mode append) sans écraser

echo "Première ligne" | tee fichier.log
echo "Deuxième ligne" | tee -a fichier.log
cat fichier.log
# Première ligne
# Deuxième ligne

3. Logger la sortie d'une commande longue

apt update 2>&1 | tee /var/log/mise-a-jour.log
# Vous voyez la progression ET le fichier est créé

4. Inspecter un pipeline sans le casser

# Voir ce qui circule entre deux commandes
cat /etc/passwd | tee /dev/stderr | grep root
# Affiche le fichier entier (via /dev/stderr) ET filtre avec grep

5. Écrire dans plusieurs fichiers à la fois

echo "Données sauvegardées" | tee fichier1.txt fichier2.txt fichier3.txt
# Écrit la même chose dans les 3 fichiers simultanément

6. Tee dans un script Bash pour logger chaque étape

#!/bin/bash
LOG="/var/log/mon_script.log"
echo "Démarrage du script" | tee -a "$LOG"
echo "Traitement en cours..." | tee -a "$LOG"
echo "Terminé avec succès" | tee -a "$LOG"

7. Combiner tee avec sudo pour écrire dans un fichier protégé

echo "configuration=test" | sudo tee /etc/monapp.conf
# tee tourne en root, vous pouvez écrire dans /etc

Remarque : | sudo tee est souvent préféré à sudo commande > fichier car cela permet de visualiser la sortie ET d'écrire dans un fichier protégé.

Options principales

OptionRôle
-a, --appendAjouter au fichier au lieu de l'écraser
-i, --ignore-interruptsIgnorer les signaux d'interruption (Ctrl+C)
-pDiagnostiquer les erreurs dans les tubes (pipe)
--output-error[=MODE]Comportement en cas d'erreur d'écriture (warn, exit, etc.)

Tee vs redirection classique

MéthodeAffichage terminalÉcriture fichier
commande > fichier❌ Non✅ Oui (écrase)
commande | tee fichier✅ Oui✅ Oui (écrase)
commande >> fichier❌ Non✅ Oui (ajoute)
commande | tee -a fichier✅ Oui✅ Oui (ajoute)

Cas d'usage pratiques

Installer un logiciel en loguant tout

sudo apt install mon_logiciel 2>&1 | tee /var/log/install.log
# Vous voyez l'installation ET vous avez un log complet

Créer un fichier avec des droits root via un pipeline

cat <
net.ipv4.ip_forward=1
net.core.somaxconn=1024
EOF

Dupliquer la sortie vers deux destinations

make 2>&1 | tee build.log | grep -E "(error|warning)"
#tee capture tout dans build.log
#grep filtre pour n'afficher que les erreurs/avertissements

Bonnes pratiques

  • Utilisez -a pour les logs : ajouter au lieu d'écraser permet de conserver l'historique
  • Combinez avec 2>&1 pour capturer stdout ET stderr dans le même fichier
  • Pour les fichiers protégés : | sudo tee est plus sûr que sudo sh -c 'commande > fichier'
  • Dans les scripts : tee -a "$LOGFILE" à chaque étape importante permet un débogage facile
  • Performance : tee ne ralentit pas le pipeline de manière significative pour des volumes normaux

Résumé

CommandeRôle
cmd | tee fichierAfficher ET sauvegarder la sortie
cmd | tee -a fichierAfficher ET ajouter au fichier
cmd | tee f1 f2 f3Afficher ET écrire dans plusieurs fichiers
cmd | sudo tee fichierÉcrire dans un fichier protégé tout en affichant
cmd 2>&1 | tee log.txtCapturer stdout et stderr dans le log

tee est un outil simple mais puissant qui fait le pont entre l'affichage en temps réel et la sauvegarde sur disque. Il s'avère indispensable dans les scripts de déploiement, les logs de migration et tout管道 où vous souhaitez garder une trace de ce qui circule sans interrompre le flux de données.
