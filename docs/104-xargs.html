Leçon 104 : xargs — Construire des commandes à partir de résultats

La commande xargs est l'un des outils les plus polyvalents du terminal Linux. Elle lit des données depuis l'entrée standard (stdin) et les transforme en arguments pour une autre commande. C'est le pont idéal entre les commandes qui produisent du texte et celles qui en ont besoin.

Le problème que xargs résout

Beaucoup de commandes Linux lisent des fichiers ou des données et affichent des résultats. Mais comment faire pour utiliser ces résultats comme arguments d'une autre commande ? C'est là qu'intervient xargs : il récupère la sortie d'une commande et la convertit en paramètres pour une autre.

Par exemple, comment supprimer tous les fichiers trouvés par grep -l ? Ou comment créer un fichier ZIP pour chaque résultat de find ? xargs répond à ces questions.

Syntaxe de base

commande_source | xargs [OPTIONS] commande_destination

Par défaut, xargs exécute echo si aucune commande n'est spécifiée. Cela peut servir à visualiser ce qui serait exécuté.

Exemples fondamentaux

1. Supprimer des fichiers depuis une liste

# Trouver et supprimer les fichiers .tmp
find . -name "*.tmp" | xargs rm
# Équivalent à:
find . -name "*.tmp" -exec rm {} \;

2. Créer des fichiers depuis une liste de noms

# Créer plusieurs fichiers d'un coup
echo -e "rapport.txt\nbudget.ods\nnotes.md" | xargs touch
# Crée : rapport.txt, budget.ods, notes.md

3. Trouver des fichiers et les lister en détail

# Trouver les fichiers .conf et les passer à ls
find /etc -name "*.conf" | xargs ls -la

4. Visualiser sans exécuter (dry-run)

# Voir exactement ce qui serait exécuté
find . -name "*.log" | xargs echo "Suppression de:"
# Affiche: Suppression de: ./sys.log ./app.log ./debug.log

Options essentielles

-n : Limiter le nombre d'arguments par commande

# Passer UN seul argument à la fois
find . -name "*.txt" | xargs -n 1 rm
# Passer DEUX arguments à la fois
echo "a b c d" | xargs -n 2 echo
# Sortie: a b
# c d

-d : Définir un délimiteur personnalisé

# Utiliser la virgule comme séparateur
echo "fichier1,fichier2,fichier3" | xargs -d ',' rm
# Avec find (séparateur = null)
find . -name "*.txt" -print0 | xargs -0 rm

-I : Remplacer une chaîne de remplacement

L'option -I (majuscule i) permet d'insérer les arguments n'importe où dans la commande, pas seulement à la fin.

# Copier chaque fichier vers un répertoire de sauvegarde
ls *.txt | xargs -I {} cp {} /backup/{}.bak
# Créer des archives individuelles
ls *.log | xargs -I {} gzip "{}"

-p : Mode interactif (confirmation)

# Demander confirmation avant chaque exécution
find . -name "*.tmp" | xargs -p rm
# Affiche: rm ./cache.tmp ?... et attend y/n

-t : Mode verbose (afficher la commande)

# Afficher chaque commande avant de l'exécuter
echo "fichier1 fichier2" | xargs -t ls -la
# Affiche: ls -la fichier1 fichier2

Cas d'utilisation courants

1. Rechercher et remplacer du texte dans plusieurs fichiers

# Trouver les fichiers contenant "erreur" et ajouter un log
grep -l "erreur" *.txt | xargs sed -i 's/erreur/[LOG_ERREUR]/g'

2. Supprimer des fichiers avec des noms spéciaux

# Des fichiers avec des espaces ou caractères spéciaux
find . -name "*.mp3" -print0 | xargs -0 -I {} rm "{}"

3. Compter les lignes de plusieurs fichiers

# Additionner le nombre de lignes de tous les fichiers .py
find . -name "*.py" | xargs wc -l
# Pour chaque fichier .log, afficher son nom et son nombre de lignes
ls *.log | xargs -I {} sh -c 'echo "{}: $(wc -l < "{}") lignes"'

4. Envoyer des emails depuis une liste

# Envoyer un email à chaque adresse de la liste
cat emails.txt | xargs -I {} mail -s "Rapport" {} < rapport.txt

5. Créer des répertoires avec numérotation

# Créer projet01, projet02, ..., projet10
seq -f "%02g" 1 10 | xargs -I {} mkdir projet{}

Scripts pratiques

Script : Sauvegarde de fichiers modifiés récemment

#!/bin/bash
# Sauvegarder les fichiers modifiés dans les 7 derniers jours
BACKUP_DIR="/backup/recents"
find ~ -type f -mtime -7 | xargs -I {} cp -v {} "$BACKUP_DIR/"
echo "=== $(find "$BACKUP_DIR" | wc -l) fichiers sauvegardés ==="

Script : Nettoyage sécurisé avec confirmation

#!/bin/bash
# Lister et supprimer les.old après confirmation
echo "Fichiers .old trouvés:"
find . -name "*.old" -print
read -p "Voulez-vous les supprimer ? (o/n) " -n 1 -r
echo
if [[ $REPLY =~ ^[Oo]$ ]]; then
find . -name "*.old" | xargs -p rm -rf
else
echo "Annulé."
fi

Script : Génération de miniature pour chaque image

#!/bin/bash
# Créer une miniature (mini_) pour chaque image
ls *.jpg 2>/dev/null | xargs -I {} convert -resize 200 {} mini_{}
echo "Miniatures créées: $(ls mini_*.jpg | wc -l)"

Options avancées

-0 : Gérer les caractères nuls (recommandé avec find)

# Sécurité : gère les espaces, quotes, retours à la ligne
find . -name "*.txt" -print0 | xargs -0 rm

-L : Nombre maximum de lignes par exécution

# Une ligne = une exécution
cat fichier.txt | xargs -L 1 commande

-s : Limiter la taille totale de la ligne de commande

# Ne pas dépasser 1000 caractères par commande
find . -name "*.txt" | xargs -s 1000 rm

-x : Arrêter si la commande dépasse la limite

# Arrêter si trop d'arguments
find . -name "*.txt" | xargs -x rm

Résumé

xargs est le管道 des管 (le管道, désolé pour le mauvais jeu de mots) qui connecte les commandes entre elles en transformant leur sortie en arguments. C'est un outil indispensable pour automatiser et chaîner les opérations.

  • cat liste | xargs commande — exécuter une commande pour chaque ligne
  • find . | xargs — traité par echo si aucune commande spécifiée
  • find . -print0 | xargs -0 — sécurité avec espaces et caractères spéciaux
  • -n 1 — un argument par exécution
  • -I {} — insérer l'argument à un emplacement personnalisé
  • -p — mode interactif avec confirmation
  • -t — afficher la commande avant de l'exécuter

Associé à find, grep ou ls, xargs devient un outil de manipulation de fichiers extremely puissant.
