systemd-tmpfiles — Gérer les fichiers et répertoires temporaires

Introduction

Sous Linux, de nombreux programmes créent des fichiers et répertoires temporaires dans /tmp, /run ou /var/tmp. Avec le temps, ces fichiers peuvent s'accumuler et consomme inutilement de l'espace disque.

systemd-tmpfiles est l'outil fourni par systemd pour gérer automatiquement le cycle de vie de ces fichiers et répertoires temporaires : création, nettoyage et suppression automatique selon des règles définies.

Pourquoi utiliser systemd-tmpfiles ?

  • Automatisation : le système nettoie automatiquement les fichiers obsolètes au démarrage ou périodiquement
  • Configuration centralisée : un seul fichier de configuration pour tous les fichiers temporaires
  • Fiabilité : gère les droits, propriétaires et permissions des fichiers créés
  • Intégration systemd : fonctionne avec les timers systemd pour des nettoyages réguliers

Emplacements des fichiers de configuration

EmplacementDescription
/usr/lib/tmpfiles.d/*.confFichiers fournis par les paquets système
/etc/tmpfiles.d/*.confFichiers de configuration utilisateur (recommandé)
/run/tmpfiles.d/*.confFichiers temporaires volatiles (effacés au reboot)

Les fichiers dans /etc/tmpfiles.d/ ont la priorité sur ceux de /usr/lib/tmpfiles.d/.

Format d'un fichier de configuration

Chaque ligne d'un fichier .conf suit ce format :

Type Utilisateur Groupe Mode Age Argument

Les types de lignes

TypeDescription
dCréer un répertoire (s'il n'existe pas)
DCréer ou vider un répertoire
fCréer un fichier (s'il n'existe pas)
FCréer ou vider un fichier
LCréer un lien symbolique
cCréer un périphérique (character device)
bCréer un périphérique (block device)
pCréer un tube nommé (pipe)
wÉcrire du contenu dans un fichier
xNe pas nettoyer automatiquement (exclure)
XNettoyer recursively sans supprimer le répertoire parent
rSupprimer uniquement les fichiers (recursive)
RSupprimer récursivement répertoire et sous-répertoires
zDéfinir propriétaire, groupe et permissions récursivement
ZDéfinir propriétaire, groupe et permissions récursivement (avec subvolumes)

Exemples concrets

1. Créer un répertoire temporaire pour une application

# /etc/tmpfiles.d/monapp.conf # Type Utilisateur Groupe Mode Age Chemin d /run/monapp root 0755 1d -

Ce fichier crée le répertoire /run/monapp avec les droits 0755 (rwxr-xr-x) et le supprime automatiquement après 1 jour d'inactivité.

2. Créer un fichier avec du contenu

# /etc/tmpfiles.d/monapp.conf # Type Utilisateur Groupe Mode Age Argument f /run/monapp/pid root 0644 - /run/monapp/daemon.pid
w /run/daemon.pid - - - - 12345

L'option w écrit le contenu spécifié dans le fichier.

3. Créer un lien symbolique

L /etc/monapp/config - - - - /etc/monapp/config.production

4. Nettoyer un répertoire automatiquement

# Nettoyer le cache tous les jours après 7 jours d'inactivité R /var/cache/monapp - - 7d -

5. Définir les permissions d'un répertoire existant

z /var/log/monapp daemon daemon 0755 -

L'option z définit récursivement le propriétaire, le groupe et les permissions.

Syntaxe détaillée des champs

Champ Age (durée de vie)

SyntaxeSignification
-Pas de limite (ne jamais supprimer)
10s10 secondes
5m5 minutes
2h2 heures
1d1 jour
1w1 semaine
1month1 mois
~Au démarrage seulement (supprimer au prochain boot)

Champ Mode (permissions)

Spécifié en notation octale (ex: 0755, 0644).

Commandes de base

Créer les fichiers/répertoires définis

sudo systemd-tmpfiles --create

Cette commande crée tous les fichiers et répertoires définis dans les fichiers de configuration. Elle est automatiquement exécutée au démarrage par systemd via le service systemd-tmpfiles-setup.service.

Nettoyer les fichiers temporaires

sudo systemd-tmpfiles --clean

Supprime les fichiers qui ont dépassé leur durée de vie définie. Cette commande est exécutée périodiquement par systemd-tmpfiles-clean.timer.

Supprimer tous les fichiers temporaires

sudo systemd-tmpfiles --remove

Supprime immédiatement tous les fichiers correspondant aux règles de type R ou r.

Vérifier le statut

sudo systemd-tmpfiles --status

Affiche l'état des services tmpfiles.

Tester une configuration

sudo systemd-tmpfiles --create --dry-run /etc/tmpfiles.d/monapp.conf

L'option --dry-run (ou --purge pour certains) permet de vérifier ce qui serait créé sans le faire.

Exemple complet : fichier de configuration pour une application

# /etc/tmpfiles.d/monapp.conf # Configuration tmpfiles pour MonApp # Répertoire de travail (créer au démarrage, nettoyer après 7 jours) d /run/monapp root 0755 7d -
# Fichier PID (permissions restrictives) f /run/monapp/monapp.pid root root 0644 - -
# Lien symbolique vers la configuration L /etc/monapp/current - - - - /etc/monapp/config.v2
# Définir les permissions du répertoire de logs z /var/log/monapp monapp monapp 0755 -

Services systemd associés

ServiceDescription
systemd-tmpfiles-setup.serviceCrée les fichiers/répertoires temporaires au démarrage
systemd-tmpfiles-setup-dev.serviceCrée les fichiers du pseudo-terminal /dev
systemd-tmpfiles-clean.serviceNettoie les fichiers temporaires
systemd-tmpfiles-clean.timerDéclenche le nettoyage périodiquement

Vérifier le timer

systemctl list-timers systemd-tmpfiles-clean.timer

Nettoyage manuel

Nettoyer maintenant

sudo systemd-tmpfiles --clean

Voir ce qui serait supprimé

sudo systemd-tmpfiles --clean --dry-run

Fichier tmpfiles.d système par défaut

Le système contient déjà des configurations par défaut :

cat /usr/lib/tmpfiles.d/tmp.conf

Exemple typique :

# /usr/lib/tmpfiles.d/tmp.conf # Nettoyer /tmp tous les jours après 30 jours D /tmp 1777 root root 30d
# Nettoyer /var/tmp tous les jours après 30 jours D /var/tmp 1777 root root 30d

Créer son propre fichier de configuration

1. Créer le fichier

sudo nano /etc/tmpfiles.d/monservice.conf

2. Ajouter les règles

# Créer le répertoire au démarrage, nettoyer après 24h d /run/monservice root 0755 1d -

3. Créer les fichiers

sudo systemd-tmpfiles --create /etc/tmpfiles.d/monservice.conf

4. Vérifier

ls -la /run/monservice

Exclure des fichiers du nettoyage

Pour éviter qu'un fichier ou répertoire soit supprimé automatiquement, utilisez le type x :

# Ne jamais nettoyer ce répertoire x /var/log/monservice/important - - -

Bonnes pratiques

  • Placez vos configurations personnalisées dans /etc/tmpfiles.d/ (pas dans /usr/lib/tmpfiles.d/)
  • Utilisez des noms de fichiers descriptifs (monservice.conf)
  • Définissez toujours un âge raisonnable pour éviter l'accumulation
  • Testez vos configurations avec --dry-run avant de les appliquer
  • Surveillez l'espace disque avec df -h /tmp /var/tmp

Dépannage

Le répertoire n'est pas créé

sudo systemd-tmpfiles --create /etc/tmpfiles.d/monapp.conf journalctl -u systemd-tmpfiles-setup

Vérifier les règles actives

systemd-tmpfiles --cat-config

Erreur de permissions

Assurez-vous que le fichier de configuration appartient à root:root et a les permissions 0644.

Résumé des commandes

CommandeAction
systemd-tmpfiles --createCréer les fichiers/répertoires
systemd-tmpfiles --cleanNettoyer les fichiers expirés
systemd-tmpfiles --removeSupprimer tous les fichiers temporaires
systemd-tmpfiles --statusAfficher le statut

systemd-tmpfiles est un outil puissant pour gérer automatiquement le cycle de vie des fichiers et répertoires temporaires sur un système Linux. En définissant des règles claires, vous pouvez éviter l'accumulation de fichiers obsolètes et libérer de l'espace disque automatiquement.
