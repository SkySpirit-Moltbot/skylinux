Leçon 126: man — Les pages de manuel, votre bibliothèque intégré

Dans cette leçon, vous allez découvrir man, la commande qui vous donne accès à la documentation officielle de chaque outil Linux. C'est votre premier réflexe quand vous ne comprenez pas une commande.

1. Qu'est-ce que man ?

man (abréviation de manual) est le système de documentation intégré à Linux. Presque chaque commande, fichier de configuration et fonction système dispose d'une page de manuel que vous pouvez consulter directement dans le terminal.

Pourquoi utiliser les pages man ?

  • Documentation officielle et toujours à jour sur votre système
  • Disponible hors-ligne (pas besoin d'Internet)
  • Couvre les commandes, les fichiers de config, les fonctions C, etc.
  • Structure standardisée : toujours savoir où trouver l'information

2. Installation

Le package man-db est généralement préinstallé sur toutes les distributions Linux modernes.

# Vérifier que man est installé
which man
# Si besoin, installer man et les pages manuel
# Ubuntu/Debian:
sudo apt install man-db man-pages
# Fedora/RHEL:
sudo dnf install man-db
# Arch Linux:
sudo pacman -S man-db man-pages

3. Utilisation basique

Lire la page man d'une commande

# Ouvrir la page man de ls
man ls
# Ouvrir la page man de ssh
man ssh
# Ouvrir la page man de systemd (service)
man systemd

Navigation dans man

Une fois dans man, utilisez ces touches pour naviguer :

ToucheAction
Flèche haut / jLigne précédente
Flèche bas / kLigne suivante
Espace / Page DownPage suivante
b / Page UpPage précédente
gRetour au début
GAller à la fin
/motifRechercher vers le bas (n: suivant, N: précédent)
?motifRechercher vers le haut
qQuitter man
hAide (raccourcis disponibles)

4. Sections des pages man

Les pages man sont organisées en sections numérotées. Chaque section a un but précis :

SectionContenuExemple
1Commandes utilisateurman 1 ls ou man ls
2Appels système (kernel)man 2 open, man 2 fork
3Fonctions des bibliothèques Cman 3 printf
4Fichiers spéciaux (devices)man 4 null, man 4 tty
5Fichiers de configurationman 5 passwd, man 5 fstab
6Jeux et écrans de veilleman 6 fortune
7Conventions, glossaireman 7 utf-8, man 7 regex
8Commandes d'administrationman 8 fdisk, man 8 iptables

Pourquoi plusieurs sections pour un même nom ?

# Par exemple, 'passwd' existe dans plusieurs sections:
man 1 passwd # La commande pour changer son mot de passe
man 5 passwd # Le fichier /etc/passwd
# Préciser la section évite l'ambiguïté
man 3 printf # La fonction C
man 1 printf # La commande shell

5. Options utiles de man

OptionDescription
-k motifRechercher dans les descriptions (équivalent de apropos)
-K motifRechercher dans le texte complet de toutes les pages
-f commandeAfficher une description courte (équivalent de whatis)
-wAfficher l'emplacement du fichier source de la page man
-aAfficher toutes les pages correspondant au nom (toutes sections)
-lFormatage en local (pas de pagination)
-IRecherche insensible à la casse
--no-justificationDésactiver l'alignement du texte

6. Rechercher dans les pages man

Recherche par mot-clé (-k)

# Trouver les pages man qui mentionnent "network"
man -k network
# Équivalent:
apropos network
# Rechercher "socket"
man -k socket
# Rechercher avec expression régulière
man -k "^fdisk"

Recherche dans le texte complet (-K)

# Chercher "fork" dans toutes les pages man (peut être long)
man -K fork
# Rechercher uniquement dans la section 2 (appels système)
man -K -s 2 fork

Description courte (-f / whatis)

# Une ligne de description pour ls
man -f ls
# Équivalent:
whatis ls
# Plusieurs commandes à la fois
whatis ls cp mv rm

7. Trouver le fichier source d'une page man

# Où est stockée la page man de ls ?
man -w ls
# Résultat: /usr/share/man/man1/ls.1.gz
# Pour un fichier de configuration
man -w fstab
# Résultat: /usr/share/man/man5/fstab.5.gz

8. Afficher toutes les sections

# Si 'passwd' existe dans plusieurs sections, toutes les afficher
man -a passwd
# Affiche la section 1, puis 5, enchaînées

9. Exemples pratiques

Trouver comment utiliser une commande inconnue

# 1. D'abord, une description courte
whatis tar
# tar - gnu tar - GNU tar archiver
# 2. Lire la page man complète
man tar

Retrouver les options d'une commande

# Vous savez que ssh existe mais pas les options
man ssh
# Chercher une option spécifique dans la page
# Tapez /-v puis Entrée pour chercher "-v"

Explorer les fichiers de configuration

# Comprendre le format de /etc/passwd
man 5 passwd
# Comprendre le format de /etc/fstab
man 5 fstab
# Comprendre le format de crontab
man 5 crontab

Explorer les appels système Linux

# Comment fonctionne la création de processus ?
man 2 fork
# Comprendre les permissions (chmod utilise open/permissions en interne)
man 2 chmod

Recherche rapide sans ouvrir man

# Vous cherchez une commande pour "compresser"
man -k compress
# Résultat typique:
bzip2 (1) - a block-sorting file compressor
gzip (1) - compression/decompression tool
tar (1) - gnu tar - an archiving utility
unzip (1) - list, test and extract compressed files
zip (1) - package and compress files

10. Outils complémentaires

whatis — Description courte

# Afficher la description d'une commande
whatis ls
# ls (1) - list directory contents

apropos — Recherche par mot-clé

# Trouver les commandes liées à "disk"
apropos disk
# Trouver les commandes liées à "user management"
apropos "user"

which — Localiser une commande

# Où est la commande ls sur le système ?
which ls
# /bin/ls
# Voir toutes les occurrences (si同名 exists dans $PATH)
which -a python

whereis — Localiser les fichiers source et man

# Fichier binaire, source et page man
whereis ls
# ls: /bin/ls /usr/share/man/man1/ls.1.gz

11. Mises à jour et base de données man

Le système man utilise une base de données d'index pour les recherches. Sur certains systèmes, il faut la mettre à jour manuellement :

# Mettre à jour la base de données des pages man (si nécessaire)
sudo mandb
# Sur certaines distributions (Debian/Ubuntu)
sudo update-db

12. Format des pages man

Une page man standard suit toujours cette structure :

NAME — Nom de la commande et description courte
SYNOPSIS — Syntaxe d'utilisation
DESCRIPTION — Explication détaillée
OPTIONS — Liste des options disponibles
EXAMPLES — Exemples d'utilisation
FILES — Fichiers liés (config, etc.)
SEE ALSO — Commandes ou pages liées
BUGS — Problèmes connus
AUTHOR — Auteur(s)

Lire le synopsis (SYNOPSIS)

# Exemple avec ls:
man ls
# Dans SYNOPSIS, vous verrez:
# ls [OPTION]... [FILE]...
# Signification:
# [OPTION] → option(s) entre crochets = facultatif
# ... → peut être répété plusieurs fois
# FILE → argument obligatoire
# [FILE]... → fichier(s) optionnel(s)

13. Tips et bonnes pratiques

  • Premier réflexe : face à une commande inconnue, tapez man commande avant de Googler
  • Recherche rapide : man -k pour trouver une commande par son effet
  • Section 5 : pour comprendre un fichier de config, utilisez man 5 nomfichier
  • Section 2-3 : pour comprendre le fonctionnement interne, les appels système (2) et fonctions C (3)
  • Combiné avec grep : man ls | grep -i recursive pour trouver rapidement une info
  • Mise à jour : après installation d'un nouveau logiciel, lancez sudo mandb si man -k ne trouve rien

Résumé

La commande man est votre encyclopedie Linux. Elle contient la documentation officielle de pratiquement tout — commandes, fichiers de configuration, appels système, fonctions de bibliothèque. Apprendre à naviguer efficacement dans les pages man est une compétence fondamentale pour tout administrateur ou développeur Linux.
