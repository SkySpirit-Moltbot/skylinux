123 - factor : Décomposer les nombres en facteurs premiers

Vous avez un nombre et vous voulez savoir par quels nombres premiers il est divisible ? factor est fait pour ça. Cette commande Unix historique prend n'importe quel entier et le décompose en facteurs premiers — les briques élémentaires de l'arithmétique.

Qu'est-ce qu'un facteur premier ?

Un facteur premier est un nombre premier qui divise exactement un autre nombre. Par exemple, 60 peut être décomposé ainsi :

60 = 2 × 2 × 3 × 5

Cette décomposition est unique (théorème fondamental de l'arithmétique). Connaître les facteurs premiers d'un nombre est utile pour :

  • Simplifier des fractions
  • Calculer le PGCD et le PPCM
  • Comprendre la cryptographie (RSA repose sur la difficulté de factoriser de grands nombres)
  • Trouver tous les diviseurs d'un nombre
  • Résoudre des problèmes de maths ou d'algorithmique

Utilisation de base

1. Factoriser un seul nombre

factor 60
# Résultat :
60: 2 2 3 5
factor 100
# Résultat :
100: 2 2 5 5
factor 17
# Résultat :
17: 17

Quand le résultat n'affiche qu'un seul nombre, c'est que le nombre lui-même est premier.

2. Factoriser plusieurs nombres

factor accepte plusieurs arguments sur la même ligne :

factor 12 18 24 30
# Résultat :
12: 2 2 3
18: 2 3 3
24: 2 2 2 3
30: 2 3 5

3. Entrée depuis un pipeline (stdin)

Quand aucun argument n'est donné, factor lit depuis l'entrée standard. C'est pratique pour traiter de nombreux nombres :

# Envoyer plusieurs nombres via echo
echo 42 56 100 144 | factor
# Résultat :
42: 2 3 7
56: 2 2 2 7
100: 2 2 5 5
144: 2 2 2 2 3 3
# Générer une séquence de nombres à factoriser
seq 1 20 | factor
# Affiche la décomposition de chaque nombre de 1 à 20
# Nombres premiers jusqu'à 50
seq 1 50 | factor | grep ': .[^ ]*$'
# Affiche uniquement les lignes où le nombre n'est分解 qu'en lui-même (donc premier)

Exemples concrets

1. Trouver tous les diviseurs d'un nombre

À partir des facteurs premiers, on peut reconstruire tous les diviseurs. Exemple avec 60 :

# D'abord connaître les facteurs premiers
factor 60
# 60: 2 2 3 5
# Les diviseurs de 60 sont : 1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60

Script pour lister tous les diviseurs d'un nombre :

#!/bin/bash
# Lister tous les diviseurs d'un nombre
n=$1
echo "Diviseurs de $n :"
for i in $(seq 1 "$n"); do
[ $((n % i)) -eq 0 ] && echo "$i"
done

2. Calculer le PGCD de deux nombres

Le PGCD est le produit des facteurs premiers communs avec leur plus petite puissance :

# PGCD de 48 et 180
factor 48 180
# 48: 2 2 2 2 3
# 180: 2 2 3 3 5
# Facteurs communs : 2×2×3 = 12
# PGCD(48, 180) = 12
# Vérification avec la commande dédiée
gcd 48 180
# 12

3. Vérifier si un nombre est premier

# Si factor affiche le même nombre, il est premier
factor 97
# 97: 97
factor 91
# 91: 7 13
# 91 n'est pas premier (7×13)

4. Trouver le PPCM (Plus Petit Commun Multiple)

Le PPCM utilise tous les facteurs premiers avec leur plus grande puissance :

# PPCM de 12 et 18
factor 12 18
# 12: 2 2 3
# 18: 2 3 3
# PPCM = 2² × 3² = 4 × 9 = 36

5. Factoriser de grands nombres

# Nombres plus grands
factor 123456789
# 123456789: 3 3 3607 3803
factor 999999937
# 999999937: 999999937
# C'est un nombre premier de 9 chiffres

6. Utiliser factor dans un script de vérification

#!/bin/bash
# Vérifier si un nombre est premier
is_prime() {
local n=$1
result=$(factor "$n")
# Si factor ne renvoie qu'un seul facteur (le nombre lui-même), c'est premier
if [ "$result" = "$n: $n" ]; then
return 0 # true
else
return 1 # false
fi
}
for num in 2 17 21 29 49 53 97 100; do
if is_prime $num; then
echo "$num est premier"
else
echo "$num n'est pas premier ($(factor $num | cut -d: -f2))"
fi
done

7. Rechercher des nombres ayant des facteurs intéressants

# Nombres dont le plus grand facteur premier est inférieur à 100
for i in $(seq 100 200); do
factors=$(factor $i | cut -d: -f2)
max_factor=$(echo $factors | tr ' ' '\n' | sort -n | tail -1)
if [ "$max_factor" -lt 100 ]; then
echo "$i: factors = $factors (max = $max_factor)"
fi
done

Petite histoire de factor

factor fait partie des utilitaires originaux d'Unix, apparus dans la première版本 d'Unix Research en 1971. Il a été réécrit au fil des décennies mais son fonctionnement reste simple : un algorithme de division par essais successifs, optimisé pour les petits nombres et parallèle pour les grands.

Sur les systèmes Debian/Ubuntu, il fait partie du paquet coreutils :

# Vérifier quelle version de factor est installée
which factor && factor --version

Bonnes pratiques

  • Utilisez seq pour générer des plages de nombres à traiter en lot : seq 1 100 | factor
  • Combinez avec grep ou cut pour extraire des informations spécifiques
  • Dans les scripts, capturez la sortie avec $(factor N | cut -d: -f2) pour ne garder que les facteurs
  • Pour des calculs de PGCD/PPCM fréquents, utilisez gcd et lcm disponibles dans coreutils
