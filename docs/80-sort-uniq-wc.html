sort, uniq et wc — Trier, dédoublonner et compter

Introduction

Trois commandes simples mais extraordinaires pour traiter du texte. sort trie les lignes, uniq supprime les doublons (à condition que les identiques soient adjacents), et wc compte lignes, mots et caractères. Individuellement elles sont utiles, mais combinées elles deviennent un outil de'analyse de données extrêmement puissant.

sort — Trier les lignes

Utilisation de base

# Trier alphabetically (par défaut) sort fichier.txt # Trier numeriquement sort -n nombres.txt # Trier en sens inverse sort -r fichier.txt # Trier par colonne (ici la 3e) sort -k3 fichier.csv

Options principales

OptionDescription
-nTrier numériquement (pas alphabétiquement)
-rOrdre inverse (descendant)
-uSupprimer les doublons (unique)
-kTrier par colonne spécifique
-tSpécifier le séparateur de champs
-fIgnorer la casse (FOLD)
-bIgnorer les espaces au début
-hTrier des tailles humaines (1K, 2M, 3G)
-MTrier par mois (JAN, FEB, etc.)

Exemples pratiques

# Trier les tailles de fichiers (notation humaine) ls -la | sort -h -k5 # Trier par taille de fichier (plus grand en premier) ls -laS | sort -k5 -r # Trier un fichier CSV par la 2e colonne sort -t',' -k2 data.csv # Trier numériquement par la 3e colonne sort -t',' -k3n rapport.csv # Supprimer les doublons en triant sort fichier.txt | uniq # Garder la première occurrence de chaque ligne sort -u fichier.txt

Trier avec ignore-case

# Trier sans distinction majuscules/minuscules sort -f utilisateurs.txt # Combiner plusieurs options sort -ufr fichier.log

Trier par date

# Trier par date (format JJ/MM/AAAA) sort -t'/' -k3n -k2n -k1n dates.txt # Trie d'abord par année, puis mois, puis jour # 25/12/2023 # 01/01/2024 # 15/06/2024 # Avec ls -lt (date de modification) ls -lt | sort -k6 -M # trie par mois

uniq — Supprimer les doublons adjacents

Point crucial : uniq ne fonctionne que sur des lignes adjacentes identiques. Si vous voulez supprimer tous les doublons, vous devez d'abord trier avec sort. C'est une erreur classique.

# Ne supprime que les doublons adjacents (déjà triés requis) uniq fichier.txt # D'abord trier, puis supprimer les doublons sort fichier.txt | uniq # counts only: affiche le nombre d'occurrences sort fichier.txt | uniq -c # Affiche seulement les lignes uniques (apparaissant une seule fois) sort fichier.txt | uniq -u # Affiche seulement les lignes dupliquées sort fichier.txt | uniq -d

Options avancées

OptionDescription
-cCompter les occurrences de chaque ligne
-dAfficher seulement les lignes dupliquées
-uAfficher seulement les lignes uniques
-iIgnorer la casse
-f NIgnorer les N premiers champs
-s NIgnorer les N premiers caractères
-w NComparer seulement les N premiers caractères

Exemples pratiques

# Compter les occurrences (tri obligatoire) sort access.log | uniq -c | sort -rn # Les 10 lignes les plus fréquentes sort access.log | uniq -c | sort -rn | head -10 # Lignes unique uniquement sort data.txt | uniq -u # Lignes dupliquées uniquement sort data.txt | uniq -d # Ignorer les 2 premiers champs sort fichier.txt | uniq -f 2

Cas d'usage courants

# Trouver les IPs les plus fréquentes dans un log cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -5 # Trouver les erreurs uniques grep "ERROR" app.log | sort | uniq # Trouver les utilisateurs connectés (sans doublons) who | awk '{print $1}' | sort | uniq # Comparer deux listes : voir les différences sort liste1.txt liste2.txt | uniq -d # элементы в обоих sort liste1.txt liste2.txt | uniq -u # только в одном из списков

wc — Compter lignes, mots et caractères

# Comptage basique wc fichier.txt # 125 892 5124 fichier.txt # lignes mots caractères # Compter seulement les lignes wc -l fichier.txt # Compter seulement les mots wc -w fichier.txt # Compter seulement les caractères wc -c fichier.txt # Afficher lesBytes (même chose que -c pourASCII) wc --bytes fichier.txt

Options

OptionDescription
-lNombre de lignes
-wNombre de mots
-cNombre d'octets (bytes)
-mNombre de caractères (multi-byte aware)
-LLongueur de la ligne la plus longue

Combiner avec d'autres commandes

# Compter le nombre de fichiers ls | wc -l # Compter le nombre de lignes dans plusieurs fichiers wc -l *.log # Compter le nombre de fonctions dans un script grep -c "^function" script.sh # Utilisation typique : vérifier si un fichier est vide if [ $(wc -l < fichier.txt) -eq 0 ]; then echo "Fichier vide" fi # Compter le nombre de lignes de code (excluant commentaires et vides) grep -v '^\s*#' *.sh | grep -v '^\s*$' | wc -l

Combiner les trois commandes

La vraie puissance apparaît quand on combine ces commandes ensemble. Voici des exemples réels.

Analyser un log Apache

# Top 10 des IPs les plus actives cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -10 # Top 10 des pages les plus consultées cat access.log | awk '{print $7}' | sort | uniq -c | sort -rn | head -10 # Nombre de requêtes par jour cat access.log | awk '{print $4}' | cut -d: -f1 | sort | uniq -c | sort -rn

Analyser des données CSV

# Compter les occurrences par catégorie tail -n +2 data.csv | cut -d',' -f3 | sort | uniq -c | sort -rn # Top 5 des produits vendus tail -n +2 sales.csv | awk -F',' '{print $2}' | sort | uniq -c | sort -rn | head -5 # Trouver les clients uniques cut -d',' -f1 clients.csv | sort | uniq | wc -l

Statistiques système

# Nombre de processus par utilisateur ps aux | awk '{print $1}' | sort | uniq -c | sort -rn # Nombre de fichiers par extension find . -type f | sed 's/.*\.//' | sort | uniq -c | sort -rn # Packages installés par origine dpkg -l | awk '{print $3}' | sed 's/:.*$//' | sort | uniq -c | sort -rn # Nombre de connexions par port netstat -tna | awk '{print $4}' | sed 's/.*://' | sort | uniq -c | sort -rn | head -10

Analyse de code

# Nombre de lignes par fichier (triées) wc -l *.c | sort -n # Top 10 des fichiers les plus volumineux ls -la | sort -k5 -rn | head -10 # Compter les functions par fichier grep "^[[:space:]]*function" *.php | sort | uniq -c | sort -rn # Nombre de commits par utilisateur (version simplifiée) git log --format='%ae' | sort | uniq -c | sort -rn

Trucs et astuces

Trier selon un critère personnalisé

# Trier par longueur de ligne awk '{print length($0) " " $0}' fichier.txt | sort -n | cut -d' ' -f2- # Trier alphanumériquement avec des zéros sort -V versions.txt # 1.2, 1.10, 1.10.1, 2.0 # Trier selon l.random (mélanger) shuf fichier.txt # Garder l'ordre original mais supprimer les doublons sort -u --stable fichier.txt

Cas où uniq ne marche pas comme attendu

# Données NON triées - uniq ne marchera pas correctement echo -e "pomme\nbanane\npomme\ncerise" | uniq # Sortie : pomme, banane, pomme, cerise (pomme apparaît deux fois !) # Toujours trier avant uniq echo -e "pomme\nbanane\npomme\ncerise" | sort | uniq # Sortie : banane, cerise, pomme (correct)

Performance sur de gros fichiers

# Pour les gros fichiers, utiliser --parallel sort --parallel=8 grosfichier.txt > sorted.txt # Compression pendant le tri (économie d'espace) sort -z fichier.txt | uniq -z > resultat.txt # Afficher les différences entre deux fichiers comm -12 <(sort fichier1.txt) <(sort fichier2.txt) # Garder seulement les lignes uniques à fichier1 comm -23 <(sort fichier1.txt) <(sort fichier2.txt)

Tri stable

Par défaut, sort n'est pas stable — si deux lignes sont égales, leur ordre original peut être modifié. Pour un tri stable :

# Tri stable : préserve l'ordre original des lignes équivalentes sort -s -k2,2 fichier.txt # Combiner tri stable et tri par clé secondaire sort -k3n -k2n fichier.csv

Exercice pratique

  1. Créer un fichier de test : Créez un fichier notes.txt avec 20 lignes contenant des mots aléatoires (avec quelques doublons).
  2. Trier le fichier : Triez le fichier alphabétiquement et redirigez le résultat vers notes_trie.txt.
  3. Compter les lignes : Utilisez wc pour afficher le nombre de lignes, mots et caractères du fichier.
  4. Supprimer les doublons : Enchaînez sort et uniq pour créer une version sans doublons.
  5. Compter les occurrences : Utilisez uniq -c pour afficher combien de fois chaque mot apparaît.
  6. Trier par fréquence : Combinez les commandes pour afficher les mots du plus fréquent au moins fréquent.
  7. Analyser un vrai log : Si vous avez accès à un fichier log, affichez les 5 lignes les plus fréquentes.
  8. Défi bonus : Trouvez le nombre de fichiers .sh dans votre répertoire home, triés par nombre de lignes.

Conclusion

sort, uniq et wc sont des outils simples mais indispensables. Ils fonctionnent parfaitement ensemble et avec d'autres commandes Unix. La clé est de comprendre que uniq nécessite un tri préalable pour fonctionner correctement. Quand vous combinez ces trois commandes avec grep, awk et les pipes, vous avez un système d'analyse de texte remarquablement puissant accessible directement depuis votre terminal. Practiquez ces combinaisons — elles vous feront gagner énormément de temps au quotidien.
