121 - shuf : Générer de l'aléatoire en ligne de commande

Quand on pense à Linux, on imagine souvent des commandes précises et déterministes. Pourtant, l'aléatoire est un outil puissant : tirage au sort, mélange de données, sélection aléatoire. La commande shuf est là pour ça.

Qu'est-ce que shuf ?

shuf est une commande GNU coreutils qui génère des permutations aléatoires à partir d'une entrée. Elle permet de trier aléatoirement des lignes, de choisir un élément au hasard, ou encore de produire des nombres dans un ordre imprévisible.

Pas de package à installer : shuf fait partie des utilitaires de base présents sur toutes les distributions Linux.

Utilisation de base

1. Mélanger les lignes d'un fichier

La forme la plus simple : passer un fichier en entrée.

# Mélanger toutes les lignes d'un fichier
shuf noms.txt

Chaque exécution produit un ordre différent. Voici un exemple avec un fichier de villes :

# Contenu de villes.txt :
# Berne
# Zurich
# Genève
# Lausanne
# Bâle
shuf villes.txt
# Résultat possible :
# Lausanne
# Berne
# Bâle
# Genève
# Zurich

2. Mélanger depuis l'entrée standard

Comme beaucoup de commandes Linux, shuf fonctionne aussi avec un pipe :

echo -e "pierre\nfeuille\nciseaux" | shuf
# Résultat possible :
# ciseaux
# pierre
# feuille

Sélectionner un nombre limité d'éléments

L'option -n (pour number) limite la sortie à N lignes. C'est idéal pour un tirage au sort :

# Choisir 1 winner au hasard dans une liste
shuf -n 1 participants.txt
# Résultat : un seul nom tiré au sort

Autre exemple : choisir 3 fichiers aléatoirement dans un répertoire :

ls /var/log/*.log | shuf -n 3

Générer des nombres aléatoires

Avec l'option -i (interval), shuf peut générer des nombres dans un intervalle :

# Générer 5 nombres entre 1 et 49 (comme au loto)
shuf -i 1-49 -n 5
# Résultat possible :
# 7
# 42
# 15
# 33
# 28

L'intervalle fonctionne aussi pour un simple mélange :

# Mélanger les nombres de 1 à 10
shuf -i 1-10

Écrire le résultat dans un fichier

L'option -o (output) redirige la sortie vers un fichier :

# Sauvegarder le mélange dans un nouveau fichier
shuf fruits.txt -o fruits_melangés.txt
# Équivalent à : shuf fruits.txt > fruits_melangés.txt

Répéter les éléments (mode boucle)

Par défaut, shuf ne répète jamais un élément. Mais avec -r (repeat), les éléments peuvent être tirés plusieurs fois :

# Simuler 10 lancers de pièce (pile ou face)
echo -e "pile\nface" | shuf -r -n 10
# Résultat possible :
# pile
# pile
# face
# face
# pile
# face
# pile
# pile
# face
# pile

Sélectionner un élément avec head

Une combinaison classique et très utile pour piocher un élément au hasard :

# Prendre 1 ligne au hasard dans un fichier
shuf -n 1 liste.txt
# Ou avec head, même résultat :
shuf liste.txt | head -n 1

Exemples concrets

Tirage au sort

# Qui fait la vaisselle ce soir ?
echo -e "Alice\nBob\nCharlie\nDiana" | shuf -n 1

Playlist aléatoire

# Jouer 10 chansons au hasard depuis un dossier
ls ~/Musique/*.mp3 | shuf -n 10 | xargs -I {} mpv {}

Mélanger un quiz

# Mélanger les questions d'un QCM
shuf questions.txt -o questions_melangées.txt

Sélectionner des lignes aléatoirement

# Prendre 5 % des lignes au hasard
shuf -n $(($(wc -l < fichier.txt) / 20)) fichier.txt

Crypto random

# Générer un mot de passe aléatoire de 16 caractères
shuf -i 33-126 -n 16 | xargs printf '\\x%x'

Résumé des options principales

OptionDescription
-n NLimiter la sortie à N lignes
-i A-BGénérer des nombres entre A et B
-rAutoriser la répétition des éléments
-o FILEÉcrire la sortie dans FILE
-eLes arguments sont les éléments à mélanger

shuf et l'aléatoire sous Linux

Il est bon de savoir que shuf utilise par défaut /dev/urandom, une source d'aléatoire cryptographiquement sûre pour les opérations normales. Pour des besoins de sécurité extrême (clés cryptographiques), utilisez plutôt /dev/random ou des outils spécialisés comme openssl rand.

# Vérifier la source d'aléatoire du système
cat /proc/sys/kernel/random/entropy_avail

Bonnes pratiques

  • Utilisez -n 1 pour les tirages au sort simples (gagnant, tâche assignée…)
  • Combinez avec xargs pour automatiser des actions sur des éléments aléatoires
  • Avec -i, pensez à -n sinon shuf mélangera tout l'intervalle (peut être très long !)
  • Pour un effet de jeu, -r est indispensable
