Leçon 152 : paste — Fusionner des lignes de fichiers

paste fusionne des lignes de fichiers côte à côte, en les séparant par un délimiteur. Si cut extrait des colonnes, paste fait l'inverse : il recompose des colonnes à partir de fichiers séparés. C'est l'outil idéal pour assembler des données tabulaires, créer des tableaux, ou fusionner deux listes en une seule.

Syntaxe de base

paste [options] fichier1 [fichier2 ...]

Sans options, paste joint chaque ligne des fichiers avec une tabulation (\t) comme séparateur.

Exemple simple

Créez deux fichiers pour tester :

# Fichier 1 : noms echo -e "Alice\nBob\nCharlie" > noms.txt # Fichier 2 : villes echo -e "Genève\nZurich\nBâle" > villes.txt # Fusionner paste noms.txt villes.txt

Résultat :

Alice Genève Bob Zurich Charlie Bâle

Options principales

-d : Changer le délimiteur

Par défaut, paste utilise la tabulation. L'option -d permet de définir un ou plusieurs séparateurs.

# Utiliser un espace comme séparateur paste -d ' ' noms.txt villes.txt # Utiliser une virgule paste -d ',' noms.txt villes.txt # Utiliser plusieurs séparateurs (alternance) paste -d '|' noms.txt villes.txt

-s : Serial mode

Au lieu de fusionner ligne par ligne, -s joint toutes les lignes d'un même fichier.

# Joindre toutes les lignes d'un fichier avec des virgules paste -s -d ',' noms.txt

Résultat :

Alice,Bob,Charlie

-z : Mode delimited par NUL

Utilise le caractère NUL (\0) comme séparateur au lieu de newline. Utile avec find -print0.

Cas d'usage courants

1. Créer un tableau CSV simple

# Fichier noms echo -e "Alice\nBob" > /tmp/noms.txt # Fichier emails echo -e "alice@exemple.com\nbob@exemple.com" > /tmp/emails.txt # Fusionner en CSV (séparateur = virgule) paste -d ',' /tmp/noms.txt /tmp/emails.txt

Résultat :

Alice,alice@exemple.com Bob,bob@exemple.com

2. Combiner plusieurs colonnes

# Trois fichiers : prénom, nom, âge echo -e "Jean\nMarie\nPaul" > /tmp/prenom.txt echo -e "Dupont\nMartin\nDurand" > /tmp/nom.txt echo -e "30\n25\n40" > /tmp/age.txt paste -d ' ' /tmp/prenom.txt /tmp/nom.txt /tmp/age.txt

Résultat :

Jean Dupont 30 Marie Martin 25 Paul Durand 40

3. Joindre deux listes en une ligne

Créer une ligne unique à partir d'un fichier multi-lignes :

# Liste de serveurs echo -e "srv-web-01\nsrv-db-01\nsrv-backup" > /tmp/servers.txt # Une seule ligne séparée par des espaces paste -s -d ' ' /tmp/servers.txt

Résultat :

srv-web-01 srv-db-01 srv-backup

4. Préparer une commande avec xargs

# Créer une liste pour SSH paste -s -d ' ' /tmp/servers.txt | xargs -I {} echo "ssh {}" # Résultat : ssh srv-web-01 srv-db-01 srv-backup

5. Créer des numéros de ligne

Combiner cat -n (numérotation) avec paste :

# Numérotation automatique cat -n /tmp/servers.txt | paste - -

Les deux tirets indiquent deux entrées depuis stdin (le résultat numéroté).

6. Préparer un fichier hosts

# IP et noms echo -e "192.168.1.10\n192.168.1.11" > /tmp/ips.txt echo -e "serveur1\nserveur2" > /tmp/hostnames.txt # Format /etc/hosts paste -d ' ' /tmp/ips.txt /tmp/hostnames.txt

Résultat :

192.168.1.10 serveur1 192.168.1.11 serveur2

7. Générer une ligne de titres pour un tableau

paste -s -d '\t' <(echo "Nom") <(echo "Prénom") <(echo "Âge") # ou avec des fichiers paste -s -d '\t' titres.txt

8. Combiner paste avec d'autres commandes

# Lister des fichiers et leur taille ls -1 | head -5 > /tmp/fichiers.txt du -sh /tmp/* 2>/dev/null | head -5 > /tmp/tailles.txt paste /tmp/fichiers.txt /tmp/tailles.txt

Combiner avec cut

cut extrait des colonnes, paste les recombine. Voici un enchaînement classique :

# Couper deux colonnes d'un CSV, puis les recombiner cut -d',' -f1,3 fichier.csv > /tmp/col1.txt cut -d',' -f2 fichier.csv > /tmp/col2.txt paste -d',' /tmp/col1.txt /tmp/col2.txt

Tableau récapitulatif

OptionDescription
-d 'sep'Délimiteur entre les colonnes (défaut : tabulation)
-sMode série : joint toutes les lignes d'un même fichier
-zSéparateur NUL au lieu de newline
--serialAlias de -s

Résumé

paste est le symétrique de cut : là où cut divise, paste rassemble. C'est l'outil parfait pour fusionner des listes, créer des tableaux simples, ou assembler des colonnes issues de sources différentes.

CommandeUsage
paste f1 f2Fusionner f1 et f2 ligne par ligne (tab)
paste -d',' f1 f2Même chose avec virgule
paste -s f1Joindre toutes les lignes de f1
paste -s -d'|' f1Joindre avec pipe
paste - <(echo "x")Ajouter une colonne constante
