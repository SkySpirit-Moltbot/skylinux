xargs — Construire et exécuter des commandes à partir de résultats

Introduction

La commande xargs est l'un des outils les plus puissants du shell Linux. Elle permet de lire des données depuis l'entrée standard (stdin) et de les utiliser comme arguments pour exécuter une autre commande. C'est le pont idéal entre les commandes qui produisent du texte et celles qui attendent des noms de fichiers ou des arguments.

Imaginez que vous voulez supprimer tous les fichiers d'une liste générée par find, ou compresser tous les fichiers modifiés récemment. xargs est fait pour ça !

Syntaxe de base

commande | xargs autre_commande

xargs prend chaque élément de l'entrée et le passe comme argument à la commande spécifiée.

Exemples concrets

1. Supprimer des fichiers avec confirmation

# Trouver et supprimer les fichiers .tmp find . -name "*.tmp" | xargs rm

Ici, find génère une liste de fichiers, et xargs les transmet à rm pour suppression.

2. Créer des fichiers

# Créer plusieurs fichiers d'un coup echo "rapport1 rapport2 rapport3" | xargs touch

Cela crée les trois fichiers rapport1, rapport2 et rapport3.

3. Compter les lignes de plusieurs fichiers

# Compter les lignes de tous les fichiers .txt ls *.txt | xargs wc -l

4. Parallel execution avec -P

# Compresser 4 fichiers en parallèle ls *.log | xargs -P 4 gzip

L'option -P 4 exécute jusqu'à 4 processus en parallèle, accélérant considérablement le traitement.

Options principales

OptionDescription
-n NPasser N arguments par commande (par défaut : tous)
-P NExécuter N processus en parallèle
-d DELIMUtiliser DELIM comme délimiteur au lieu des espaces
-I {}Remplacer {} par les arguments (style placeholder)
-0Utiliser le caractère nul comme délimiteur (sécurise pour les espaces)
-tAfficher la commande avant de l'exécuter (mode verbose)
-pDemander confirmation avant chaque exécution
-rNe pas exécuter si l'entrée est vide

Cas d'utilisation avancée

Utiliser un placeholder avec -I

# Copier des fichiers vers un répertoire ls *.txt | xargs -I {} cp {} /backup/

Le {} est remplacé par chaque argument individuellement. C'est très utile quand vous devez utiliser l'argument à plusieurs endroits.

Gestion des espaces et caractères spéciaux

# Avec find et -print0 (caractère nul) find . -name "*.txt" -print0 | xargs -0 rm

En combinant find -print0 et xargs -0, vous gérez correctement les noms de fichiers contenant des espaces ou des retours à la ligne.

Limiter les arguments par invocation

# Traiter 10 fichiers par lot ls *.dat | xargs -n 10 traitement

La commande traitement sera appelée avec 10 fichiers à chaque fois jusqu'à épuisement.

Mode interactif avec -p

# Confirmer avant chaque suppression find . -name "*.bak" | xargs -p rm

xargs affichera chaque commande et attendra votre confirmation (y/n) avant d'exécuter.

Combiner avec d'autres outils

Avec grep

# Rechercher dans plusieurs fichiers grep -l "erreur" *.log | xargs grep -l "critique"

Avec rsync

# Synchroniser une liste de répertoires cat liste_reps.txt | xargs rsync -av /source/

Avec tar

# Créer une archive de fichiers listés cat fichiers.txt | xargs tar -czf archive.tar.gz

Bonnes pratiques

  • Utilisez toujours -print0 avec find et -0 avec xargs pour gérer les noms avec des espaces : find . -name "*.txt" -print0 | xargs -0 ...
  • Testez d'abord avec -t pour voir quelles commandes seront exécutées avant de les lancer pour de bon.
  • Limitez le nombre d'arguments avec -n pour éviter les erreurs "Argument list too long".
  • Utilisez -P pour paralléliser les tâches independentessur des machines multicœurs.

Résumé

CommandeUsage
commande | xargs cmdPasser le résultat comme arguments
commande | xargs -n 1 cmdUn argument par exécution
commande | xargs -P 4 cmd4 processus parallèle
commande | xargs -I {} cmd {}Placeholder personnalisé
commande | xargs -0Séparer par caractère nul

La commande xargs est un outil incontournable pour chainer les commandes sous Linux. Elle transforme n'importe quel flux de texte en arguments exploitables, ouvrant la porte à des combinaisons infinies.
