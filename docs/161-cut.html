cut — Extraire des colonnes de texte

Introduction

cut est un outil simple mais puissant pour extraire des colonnes ou des champs spécifiques d'un texte. Que ce soit pour isoler une colonne dans un fichier CSV, extraire des caractères d'une ligne, ou manipuler des données structurées, cut fait le travail efficacement. C'est l'un des outils les plus directs du terminal quand il s'agit de traiter du texte en colonnes.

Syntaxe de base

cut [OPTION]... [FICHIER]...

Si aucun fichier n'est spécifié, cut lit depuis l'entrée standard (stdin), ce qui le rend parfait pour les pipes.

Les trois modes de sélection

cut fonctionne selon trois modes complémentaires :

1. Par octets (-b)

Sélection par position d'octet (byte position). Chaque caractère compte comme un ou plusieurs octets selon l'encodage.

# Extraire les 5 premiers octets de chaque ligne cut -b 1-5 fichier.txt # Extraire les octets 1, 3 et 5 cut -b 1,3,5 fichier.txt # Extraire du début jusqu'à l'octet 10 cut -b -10 fichier.txt # Extraire de l'octet 5 jusqu'à la fin cut -b 5- fichier.txt

2. Par caractères (-c)

Sélection par position de caractère. Plus fiable que -b pour les caractères multi-octets (UTF-8 par exemple).

# Extraire les 10 premiers caractères cut -c 1-10 fichier.txt # Extraire les caractères 5 à 10 cut -c 5-10 fichier.txt # Extraire les caractères 1, 3 et 7 cut -c 1,3,7 fichier.txt

3. Par délimiteur et champs (-d et -f)

Le mode le plus courant. On spécifie un délimiteur (tabulation par défaut) et on sélectionne les champs.

# Extraire le 2ème champ (délimité par tabulation) cut -f 2 fichier.txt # Extraire les champs 1 et 3 cut -f 1,3 fichier.txt # Extraire du champ 2 au champ 5 cut -f 2-5 fichier.txt

Spécifier un délimiteur personnalisé

Par défaut, cut utilise la tabulation comme délimiteur. L'option -d permet de changer cela :

# Utiliser les deux-points comme délimiteur (fichier /etc/passwd) cut -d ':' -f 1,7 /etc/passwd # Utiliser la virgule comme délimiteur (fichier CSV) cut -d ',' -f 1,3,5 donnees.csv # Utiliser le point-virgule cut -d ';' -f 2 fichier.txt # Utiliser un espace cut -d ' ' -f 1 fichier.txt

Combiner avec --complement

L'option --complement inverse la sélection — elle affiche tout SAUF les parties sélectionnées :

# Extraire tout SAUF le 1er champ cut --complement -d ':' -f 1 /etc/passwd # Extraire tout SAUF les 5 premiers caractères cut --complement -c 1-5 fichier.txt

Spécifier un séparateur de sortie

Par défaut, cut préserve le délimiteur dans la sortie. Utilisez -s (supprimer) ou --output-delimiter pour personnaliser :

# Changer le séparateur de sortie cut -d ':' -f 1,5 --output-delimiter=' - ' /etc/passwd # Utiliser un retour à la ligne comme séparateur cut -d ':' -f 1,5 --output-delimiter=$'\n' /etc/passwd

Cas d'utilisation pratiques

Extraire des noms d'utilisateur

# Depuis /etc/passwd : extraire juste les noms d'utilisateur cut -d ':' -f 1 /etc/passwd # Lister les shells utilisés cut -d ':' -f 7 /etc/passwd | sort | uniq

Traiter des fichiers CSV

# Extraire la 1ère et 3ème colonne d'un CSV cut -d ',' -f 1,3 fichier.csv # Extraire toutes les colonnes de la 2ème à la 5ème cut -d ',' -f 2-5 fichier.csv

Extraire des informations système

# Voir seulement les noms des processus (ps) ps aux | tail -n +2 | cut -d ' ' -f 1 # Extraire les permissions de fichiers ls -l | cut -d ' ' -f 1 # Extraire juste les IPs d'un fichier log grep "connect" log.txt | cut -d ' ' -f 8 | sort | uniq

Couper des chaînes de caractères fixes

# Extraire l'extension d'un nom de fichier (caractères après le point) echo "document.pdf" | rev | cut -d '.' -f 1 | rev # Extraire le nom sans extension echo "document.pdf" | cut -d '.' -f 1 # Extraire les 8 premiers caractères d'une date (AAAA-MM-JJ) echo "2024-12-25" | cut -c 1-4 # Résultat : 2024 echo "2024-12-25" | cut -c 6-7 # Résultat : 12

Combiner avec d'autres commandes

cut révèle tout son potentiel en pipeline :

# Lister les utilisateurs avec leur shell, triés cut -d ':' -f 1,7 /etc/passwd | sort # Compter les types de shells utilisés cut -d ':' -f 7 /etc/passwd | sort | uniq -c | sort -rn # Extraire et dédoublonner les IPs d'un log cat access.log | cut -d ' ' -f 1 | sort | uniq -c | sort -rn | head -10 # Lister les montages (sans les en-têtes) df -h | tail -n +2 | cut -d ' ' -f 1,5 # Traiter une sortie JSON simple (extraire une valeur) echo '{"name":"Alice","age":30}' | grep -o '"name":"[^"]*"' | cut -d '"' -f 4

Gestion des délimiteurs consécutifs

Par défaut, si le délimiteur apparaît plusieurs fois de suite, chaque occurrence compte. Pour ignorer les champs vides :

# Exemple avec espaces multiples echo "a b c" | cut -d ' ' -f 2 # Retourne vide (2ème espace) # Solution : d'abord normaliser les espaces echo "a b c" | tr -s ' ' | cut -d ' ' -f 2 # Retourne "b"

Spécifier plusieurs ranges de bytes/caractères

# Caractères 1-5 ET 10-15 cut -c 1-5,10-15 fichier.txt # Mélanger positions et ranges cut -c 1-3,7,12- fichier.txt

Bonnes pratiques

  • Privilégiez -c à -b pour les fichiers UTF-8 — plus fiable avec les caractères accentués
  • Utilisez -d pour les fichiers structurés (CSV, /etc/passwd, logs)
  • Combinez avec tr -s pour normaliser les délimiteurs multiples
  • Spécifiez toujours le délimiteur explicitement si vous n'utilisez pas la tabulation par défaut
  • Pour des manipulations complexes, awk offre plus de flexibilité (voir leçon 47)

cut est un outil ciblé et efficace pour extraire des colonnes. Pour des tâches simples, il surpasse des outils plus complexes comme awk. Combinez-le dans des pipelines pour traiter rapidement des données structurées sans écrire de script complet.
