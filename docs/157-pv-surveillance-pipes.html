pv — Surveiller la progression des données dans un pipe

La commande pv (Pipe Viewer) permet d'insérer dans un pipe UNIX et d'afficher en temps réel la quantité de données transférées, la vitesse de transfert et le temps restant estimé. C'est l'outil idéal pour savoir où en est une copie, une compression ou tout autre traitement de données volumineuses.

Installation

pv n'est pas toujours installé par défaut :

# Ubuntu / Debian
sudo apt install pv
# Fedora / RHEL / CentOS
sudo dnf install pv
# Arch Linux
sudo pacman -S pv

Syntaxe de base

pv [options] [fichier]

Sans argument de fichier, pv lit depuis l'entrée standard.

Options principales

OptionDescription
-pAfficher la barre de progression
-tAfficher le chronomètre (temps écoulé)
-eAfficher le temps restant estimé (ETA)
-rAfficher le débit actuel (bytes/s)
-bAfficher le nombre total d'octets transférés
-nMode numérique : sortie uniquement des entiers pour scripting
-LLimiter la bande passante (ex : -L 1M pour 1 Mo/s)
-sSpécifier la taille totale attendue (pour le calcul de l'ETA)
-WAttendre que la première donnée arrive avant d'afficher

Exemples pratiques

Copie de fichier avec barre de progression

pv fichier_iso.iso > /dev/sdb1

Affiche la progression de la copie avec le débit et le temps restant.

Compression avec visualisation

pv gros_fichier.bin | gzip > gros_fichier.bin.gz

La compression s'effectue normalement, mais pv vous montre le débit et la progression. La taille totale est inconnue, donc pas d'ETA.

Compression avec taille connue pour l'ETA

pv -s $(stat -c%s gros_fichier.bin) gros_fichier.bin | gzip > backup.gz

En spécifiant la taille avec -s, pv peut calculer le temps restant.

Copie dd avec barre de progression

sudo pv -s $(blockdev --getsize64 /dev/sda) /dev/sda | dd of=/dev/sdb bs=4M

Copie complète d'un disque avec barre de progression. L'option -s indique la taille totale du disque source.

Copie via SSH avec limitation de bande passante

pv fichier.tar.gz | ssh user@serveur "cat > /backup/fichier.tar.gz"

Pipeline de traitement multiple

pv -cN source fichier.raw | \
ffmpeg -i - ... | \
pv -cN encodage | \
pv -cN transfert > output.mp4

Avec -cN nom, chaque instance pv affiche un nom distinct, permettant de suivre plusieurs étapes d'un pipeline.

Téléchargement avec barre de progression

curl -s URL | pv | tar xzf -

Télécharge une archive et l'extrait simultanément, en visualisant le débit.

Mode numérique pour scripting

pv -n fichier.bin > /dev/null

En mode -n, pv n'affiche qu'un nombre croissant de 0 à 100 (pourcentage), utile dans un script pour piloter des barres de progression personnalisées.

Cas d'usage concrets

Copie disque à disque

sudo pv /dev/sda -s $(blockdev --getsize64 /dev/sda) | sudo dd of=/dev/sdb bs=4M conv=fsync

Synchronisation rsync avec progression

rsync -av --progress /source/ /dest/

rsync dispose déjà de --progress, mais pv peut s'avérer utile pour les cas où rsync ne donne pas de statistiques satisfaisantes.

Création de backup avec tar et pv

tar czf - /home | pv -s $(du -sb /home | cut -f1) | ssh user@backup "cat > backup_home.tar.gz"

Format d'affichage

Par défaut, pv affiche sur une seule ligne qui se met à jour :

GNU/Linux ISO: 2.45GiB / 4.37GiB 56% [=====> ] 12.5MiB/s ETA: 2m 35s
ÉlémentSignification
2.45GiB / 4.37GiBDonnées transférées / taille totale
56%Pourcentage de progression
[=====> ]Barre de progression visuelle
12.5MiB/sDébit actuel
ETA: 2m 35sTemps restant estimé

Combiner avec d'autres outils

  • pv + gzip/bzip2/xz : voir la progression d'une compression
  • pv + dd : copie de disque avec progression
  • pv + ssh : transfert réseau visualisé
  • pv + tar : archivage et extraction avec barre de progression
  • pv + ffmpeg : suivi de l'encodage vidéo
  • pv + mysqldump : export de base de données avec suivi

Limiter la bande passante

Pour simuler un transfert lent ou limiter l'usage réseau :

pv -L 500k fichier.iso > /dev/null

Limite le transfert à 500 Ko/s.

SuffixeSignification
kKo/s (kilooctets)
mMo/s (mégaoctets)
gGo/s (gigaoctets)

Résumé

CommandeUsage
pv fichier > cibleCopie avec barre de progression
cat f | pv | gzip > f.gzCompression visualisée
pv -s TAILLE fichierAvec ETA (temps restant)
pv -L 1M fichierLimiter à 1 Mo/s
pv -cN etape1 fichierNommer chaque étape dans un pipeline
pv -n fichierMode numérique (0-100) pour scripting

pv est un outil simple mais puissant. Un seul pv inséré dans un pipe peut transformer une opération mystérieuse en transparence totale. Indispensable pour toute copie, compression ou synchronisation de données volumineuses.
