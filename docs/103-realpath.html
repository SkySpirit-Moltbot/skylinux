Leçon 103 : realpath — Résoudre les chemins absolus

La commande realpath (ou readlink -f sur certains systèmes) convertit un chemin relatif ou avec des liens symboliques en chemin absolu canonique. C'est l'outil idéal pour obtenir le chemin "vrai" vers un fichier ou répertoire, en suivant tous les liens symboliques et en éliminant les . et ...

Pourquoi utiliser realpath ?

Quand vous travaillez avec des chemins relatifs ou des liens symboliques, il peut être difficile de savoir exactement où pointe un fichier. realpath résout tout ça :

  • Convertit les chemins relatifs en absolus
  • Suit tous les liens symboliques jusqu'au fichier final
  • Supprime les références . (répertoire courant) et .. (répertoire parent)
  • Normalise les chemins en éliminant les parties redondantes

Syntaxe de base

realpath [OPTIONS] CHEMIN

Exemples fondamentaux

1. Convertir un chemin relatif en absolu

# Depuis /home/david, résoudre ../documents/rapport.txt
realpath ../documents/rapport.txt
# Résultat : /home/david/documents/rapport.txt

2. Obtenir le chemin canonique depuis un lien symbolique

# Si mes_docs est un lien vers /home/david/documents
realpath mes_docs
# Résultat : /home/david/documents

3. Traiter plusieurs fichiers

# Résoudre plusieurs chemins d'un coup
realpath fichier1.txt ../dossier/fichier2.txt ~/documents/fichier3.txt

4. Vérifier l'existence silencieusement

# --quiet n'affiche pas d'erreur si le fichier n'existe pas
realpath --quiet /aucun/fichier/ici
# (pas de sortie, juste un code de retour non nul)

Options principales

OptionDescription
-e, --canonicalize-existingLe fichier DOIT exister (erreur sinon)
-m, --no-symlinksNe pas suivre les liens symboliques (juste normalisation)
-q, --quietNe pas afficher les erreurs
-z, --zeroSéparateur null au lieu de nouvelle ligne
-L, --logicalSuivre les liens symboliques dans le chemin
-P, --physicalNe PAS suivre les liens symboliques (défaut)

Cas d'utilisation pratiques

1. Scripts de déploiement

# Obtenir le chemin absolu du script lui-même
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
echo "Script situé dans: $SCRIPT_DIR"
# Version alternative avec realpath
SCRIPT_DIR="$(realpath "$(dirname "$0")")"

2. Vérifier l'emplacement réel d'un fichier

# Savoir exactement où pointe un lien
realpath /etc/nginx/sites-enabled/default
# Affiche le chemin final après tous les liens

3. Normaliser des chemins utilisateur

# Traiter un chemin saisi par l'utilisateur
# L'utilisateur entre: ~/documents/../documents/rapport.txt
read -p "Chemin du fichier: " chemin
CHEMIN_ABSOLU=$(realpath -m "$chemin")
echo "Chemin normalisé: $CHEMIN_ABSOLU"

4. Comparer deux chemins vers le même fichier

# Vérifier si deux chemins pointent vers le même fichier
if [ "$(realpath fichier1)" = "$(realpath fichier2)" ]; then
echo "Ce sont les mêmes fichiers!"
fi

realpath vs readlink vs dirname/basename

CommandeUsageExemple
realpathChemin absolu completrealpath ./docs/../file.txt → /home/user/file.txt
readlinkCible d'un lien symboliquereadlink mon_lien → /chemin/cible
basenameNom du fichierbasename /a/b/fichier.txt → fichier.txt
dirnameRépertoire parentdirname /a/b/fichier.txt → /a/b

Combinaison avec d'autres outils

Avec ls pour voir les chemins réels

# Lister les fichiers avec leur chemin réel
ls -la | tail -n +2 | awk '{print $NF}' | while read f; do realpath "$f" 2>/dev/null; done

Avec find pour obtenir des chemins absolus

# Trouver des fichiers et afficher leurs chemins absolus
find . -name "*.conf" -exec realpath {} \;

Avec xargs pour traiter des résultats

# Convertir une liste de chemins relatifs
cat liste_chemins.txt | xargs realpath

Scripts pratiques

Script : Trouver le chemin absolu d'un projet

#!/bin/bash
# Trouver le répertoire racine d'un projet
PROJECT_ROOT="$(realpath "$(dirname "$0")")"
echo "Projet: $PROJECT_ROOT"
echo "Config: $PROJECT_ROOT/config/settings.conf"
echo "Logs: $PROJECT_ROOT/var/log/app.log"

Script : Vérifier que deux fichiers sont identiques

#!/bin/bash
# Vérifier si deux chemins pointent vers le même inode
chemin1=$(realpath "$1")
chemin2=$(realpath "$2")
if [ "$chemin1" = "$chemin2" ]; then
echo "✓ '$1' et '$2' pointent vers le même fichier"
echo " Chemin canonique: $chemin1"
else
echo "✗ Fichiers différents"
echo " '$1' → $chemin1"
echo " '$2' → $chemin2"
fi

Résumé

realpath est un outil simple mais puissant pour normaliser et résoudre les chemins sous Linux. Il élimine les ambiguïtés liées aux chemins relatifs et aux liens symboliques.

  • realpath chemin — obtenir le chemin absolu canonique
  • realpath -m chemin — normalisation sans suivre les liens
  • realpath -e fichier — le fichier doit exister
  • $(realpath "$0") — chemin du script en cours

C'est l'outil parfait pour les scripts qui ont besoin de chemins fiables et absolus.
