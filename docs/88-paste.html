Leçon 88 : paste — Fusionner des lignes de fichiers

Introduction

paste est une commande qui fusionne les lignes de plusieurs fichiers, en les plaçant côte à côte et en les séparant par des tabulations. Contrairement à cat qui affiche les fichiers bout à bout, paste les place en colonnes parallèles. C'est l'outil idéal pour combiner des données tabulaires ou créer des tableaux à partir de plusieurs sources.

Utilisation de base

Fusionner deux fichiers

# fichier1.txt contient : # fichier2.txt contient : # Pierre # Paris # Marie # Lyon # Jean # Marseille paste fichier1.txt fichier2.txt # Résultat : # Pierre Paris # Marie Lyon # Jean Marseille

Fusionner un seul fichier

paste fichier1.txt # Affiche chaque ligne suivie d'une tabulation # Pierre # Marie # Jean

Modifier le séparateur

Utiliser un délimiteur personnalisé

# Séparer par des deux-points paste -d':' fichier1.txt fichier2.txt # Pierre:Paris # Marie:Lyon # Jean:Marseille # Séparer par un espace et une barre paste -d' | ' fichier1.txt fichier2.txt # Pierre | Paris # Marie | Lyon # Jean | Marseille

Utiliser plusieurs séparateurs

# Les séparateurs sont utilisés轮流 paste -d':,' fichier1.txt fichier2.txt fichier3.txt # Pierre:Paris,Lyon # Marie:Lyon,Marseille # Jean:Marseille,Bordeaux

Créer des tableaux CSV

Assembler des colonnes en CSV

# noms.txt # ages.txt # villes.txt # Pierre # 28 # Paris # Marie # 34 # Lyon # Jean # 45 # Marseille paste -d',' noms.txt ages.txt villes.txt > tableau.csv cat tableau.csv # Pierre,28,Paris # Marie,34,Lyon # Jean,45,Marseille

Ajouter un en-tête

# Créer un fichier avec en-tête echo -e "Nom,Age,Ville" > header.txt # Combiner avec paste cat header.txt <(paste -d',' noms.txt ages.txt villes.txt) # Résultat : # Nom,Age,Ville # Pierre,28,Paris # Marie,34,Lyon # Jean,45,Marseille

Sérialiser des lignes

Placer toutes les lignes sur une seule ligne

# Convertir un fichier multiligne en une seule ligne paste -s fichier.txt # Pierre Marie Jean (sur une seule ligne, séparé par des tabs) # Avec un séparateur personnalisé paste -s -d',' fichier.txt # Pierre,Marie,Jean

Combiner avec d'autres commandes

# Liste des fichiers sur une ligne ls | paste -s -d' | ' # fichier1.txt | fichier2.txt | fichier3.txt # Liste des processus sur une ligne ps aux | awk 'NR>1 {print $11}' | paste -s -d', ' # bash,rsynecd,nginx,...

Numérotation automatique

Utiliser paste avec seq

# Numérotation des lignes d'un fichier seq 1 5 > nums.txt echo -e "Un\nDeux\nTrois\nQuatre\nCinq" > mots.txt paste nums.txt mots.txt # 1 Un # 2 Deux # 3 Trois # 4 Quatre # 5 Cinq

Combiner paste avec d'autres outils

Avec cut pour créer des tableaux

# Extraire des colonnes puis les combiner cut -d':' -f1 /etc/passwd > utilisateurs.txt cut -d':' -f6 /etc/passwd > repertoires.txt paste utilisateurs.txt repertoires.txt | head -5 # root /root # daemon /usr/sbin # bin /bin # sys /usr/src # ...

Avec awk

# Créer un rapport formaté paste <(seq 1 3) <(echo -e "Alice\nBob\nCharlie") <(echo -e "Vendeur\nDev\nDesigner") # 1 Alice Vendeur # 2 Bob Dev # 3 Charlie Designer

Avec sort

# Fusionner puis trier paste fichier1.txt fichier2.txt | sort # Si fichier1.txt contient : Charlotte, Antoine, Marie # Résultat trié : # Antoine Paris # Charlotte Lyon # Marie Marseille

Exercices pratiques

Exercice 1 — Créer un annuaire

# noms.txt # telephones.txt # Alice # 079-123-45-67 # Bob # 079-234-56-78 # Claire # 079-345-67-89 paste -d'\t' noms.txt telephones.txt # Alice 079-123-45-67 # Bob 079-234-56-78 # Claire 079-345-67-89

Exercice 2 — Créer un fichier de configuration

# clés.txt # valeurs.txt # hostname # mon-serveur # domain # example.com # port # 8080 paste -d'=' clés.txt valeurs.txt # hostname=mon-serveur # domain=example.com # port=8080

Exercice 3 — Générer une liste de tâches numérotées

# tareas.txt # Acheter des courses # Réviser le rapport # Appeler le client paste <(seq -f "%d." 1 3) taches.txt # 1. Acheter des courses # 2. Réviser le rapport # 3. Appeler le client

Exercice 4 — Préparer des données pour Excel

# fichier1.txt # fichier2.txt # fichier3.txt # Prénom # Nom # Email # Jean # Dupont # jean@mail.com # Marie # Martin # marie@mail.com paste -d';' fichier1.txt fichier2.txt fichier3.txt > contacts.csv cat contacts.csv # Jean;Dupont;jean@mail.com # Marie;Martin;marie@mail.com

Différence entre paste et join

CommandeUsageExemple
pasteFusionne lignes côte à côte (toujours)Ligne 1 de A + Tab + Ligne 1 de B
joinFusionne sur un champ communLigne où champ A = champ B
# paste — fusion simple paste fichier1.txt fichier2.txt # a 1 # b 2 # c 3 # join — fusion sur champ commun join fichier1.txt fichier2.txt # Nécessite une clé commune dans les deux fichiers

Points clés à retenir

  • paste fichier1 fichier2 → fusionne ligne par ligne avec tabulation
  • -d'séparateur' → change le délimiteur entre les colonnes
  • -s → place toutes les lignes sur une seule ligne
  • Idéal pour créer des tableaux CSV ou TSV
  • Combinez avec cut, awk, seq pour des usages avancés
  • paste = colonnes parallèles, join = fusion sur clé commune
