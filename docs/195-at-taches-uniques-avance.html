at — Planifier une tâche unique (avancé)

📖 Introduction

La commande at permet de planifier l'exécution d'une commande ou d'un script à un moment précis et précis. Contrairement à cron qui répète des tâches périodiquement, at exécute une tâche une seule fois.

C'est l'outil idéal pour différer une action sans créer une entrée cron permanente.

🔧 Prérequis

Le démon atd doit être actif pour que at fonctionne :

# Vérifier l'état du service sudo systemctl status atd # Le démarrer s'il ne l'est pas sudo systemctl enable --now atd

🚀 Utilisation de base

Syntaxe générale

at [options] HEURE echo "commande" | at [options] HEURE

Planifier pour une heure précise

# Exécuter à 14h30 aujourd'hui echo "tar -czf /backup/home.tar.gz /home" | at 14:30 # Exécuter à 23h00 aujourd'hui echo "systemctl restart nginx" | at 23:00

Planifier pour une date précise

# Demain à 8h at 8:00 tomorrow # Mercredi prochain à 10h at 10:00 wednesday # 15 janvier à 9h at 9:00am January 15 # 25 décembre 2026 à midi at noon December 25 2026

💡 Exemples pratiques

Planifier avec un script interactif

# Entrer en mode interactif at 15:00 # Puis taper les commandes : tar -czf /backup/donnees.tar.gz /home mail -s "Backup terminé" root@localhost # Terminer avec Ctrl+D

Redirection et sortie

Par défaut, la sortie de la commande planifiée est envoyée par e-mail à l'utilisateur. Vous pouvez rediriger cette sortie :

# Exécuter et enregistrer la sortie dans un fichier echo "/opt/monscript.sh > /var/log/script.log 2>&1" | at 6:00 tomorrow # Ignorer la sortie echo "/opt/monscript.sh > /dev/null 2>&1" | at 6:00 tomorrow

Spécifier une file d'attente

Les tâches at sont placées dans des files (queues) nommées avec des lettres :

# File 'a' (par défaut) echo "commande" | at -q a 10:00 # File 'b' (pour les tâches moins urgentes) echo "commande" | at -q b 10:00

📋 Gérer les tâches planifiées

Lister les tâches en attente

atq

Ou équivalent :

at -l

Voir le contenu d'une tâche

at -c NUMERO_TACHE

Cela affiche le script shell complet qui sera exécuté, y compris l'environnement.

Supprimer une tâche

atrm NUMERO_TACHE

Ou équivalent :

at -d NUMERO_TACHE

Exemple complet

# Planifier une tâche $ echo "df -h >> /var/log/disk.log" | at 23:00 job 15 at Wed Nov 4 23:00:00 2026 # Lister les tâches $ atq 15 Wed Nov 4 23:00:00 2026 a root # Voir le contenu $ at -c 15 #!/bin/sh # ... df -h >> /var/log/disk.log # Supprimer si besoin $ atrm 15

⚙️ Fichiers de configuration

/etc/at.allow et /etc/at.deny

Ces fichiers contrôlent qui peut utiliser at :

  • Si /etc/at.allow existe, seuls les utilisateurs listés peuvent utiliser at
  • Si seul /etc/at.deny existe, tous les utilisateurs SAUF ceux listés peuvent l'utiliser
  • Si aucun des deux n'existe, seul root peut l'utiliser
# Interdire l'utilisation de at à un utilisateur echo "toto" | sudo tee /etc/at.deny # Autoriser uniquement root (supprimer at.deny, créer at.allow) sudo rm /etc/at.deny echo "root" | sudo tee /etc/at.allow

🔒 Sécurité et bonnes pratiques

  • Restreindre l'accès — Utilisez /etc/at.deny pour interdire aux utilisateurs non autorisés
  • Vérifier les tâches — Utilisez at -c avant de supprimer une tâche pour vérifier son contenu
  • Logs — Les exécutions sont enregistrées dans /var/log/cron ou via journalctl
  • Environnement — Les tâches at s'exécutent avec un environnement minimal. Précisez les chemins complets.

⚡ Astuces avancées

Combiner avec des conditions

# Planifier uniquement si un fichier existe echo "[ -f /tmp/pret ] && /opt/monscript.sh" | at 14:00 # Planifier avec un timeout echo "timeout 300 /opt/monscript.sh" | at 14:00

Planifier dans un répertoire précis

# Exécuter depuis un répertoire précis cd /projet && tar -czf backup.tar.gz data | at 2:00 tomorrow

Script complet comme tâche

# Lire les commandes depuis un fichier at 3:00 tomorrow -f /opt/scripts/sauvegarde.sh

⚠️ Notes importantes

  • Les tâches at qui ne peuvent pas être exécutées (système éteint) sont perdues. Pour les systèmes间歇, utilisez anacron.
  • L'environnement d'exécution est minimal. Utilisez toujours des chemins absolus.
  • La sortie est envoyée par e-mail local. Vérifiez votre boîte ou redirigez vers un fichier.
