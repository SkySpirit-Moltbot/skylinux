systemd-tmpfiles — Gérer les fichiers et répertoires temporaires

Le système génère constamment des fichiers temporaires : logs, caches, sockets, PID files. systemd-tmpfiles est l'outil qui centralise leur création, nettoyage et gestion automatique via des fichiers de configuration simples.

Pourquoi systemd-tmpfiles ?

Sans gestion centralisée, les fichiers temporaires s'accumulent : le disque se remplit, les services perdent leurs fichiers de verrouillage, les permissions se dégradent. systemd-tmpfiles résout ce problème en définissant des règles déclaratives pour chaque répertoire temporaire du système.

Les répertoires temporaires standards

RépertoireContenuVariable
/tmpFichiers temporaires utilisateur/tmp
/var/tmpFichiers temporaires persistants/var/tmp
/runDonnees volatiles (sockets, PID)/run
/var/runAlias historique de /run/run

Fichiers de configuration

Les règles se trouvent dans deux emplacements :

  • /usr/lib/tmpfiles.d/*.conf — règles des paquets (ne pas modifier)
  • /etc/tmpfiles.d/*.conf — règles personnalisées (prioritaires)
  • /run/tmpfiles.d/*.conf — règles temporaires

Format d'une règle tmpfiles

# Type Chemin Mode UID GID Age Argument d /run/myapp 0755 root root - - d /var/tmp/myapp 0755 myapp myapp 7d - f /run/app.pid 0644 root root - - f /etc/myapp.conf 0640 root root - - L /run/app.sock - root root - /dev/null r /tmp/crash-*.log - - - 7d -

Les colonnes expliquées

ColonneDescription
TypeAction a realiser (voir tableau ci-dessous)
CheminChemin du fichier ou repertoire
ModePermissions (octal)
UIDProprietaire (nom ou numerique)
GIDGroupe proprietaire
AgeDelai avant nettoyage automatique (ex: 7d, 24h)
ArgumentContenu (pour 'f'/'w') ou cible (pour 'L')

Les types de directives

TypeAction
dCreer un repertoire (s'il n'existe pas)
DCreer un repertoire et nettoyer son contenu au demarrage
fCreer un fichier (avec contenu optionnel)
FCreer un fichier et nettoyer son contenu au demarrage
LCreer un lien symbolique
rSupprimer les fichiers correspondant au motif (Age)
RSupprimer recursively un repertoire au demarrage
wEcrire du texte dans un fichier (utile pour templates)
cCreer un peripherique (character)
bCreer un peripherique (block)
pCreer un named pipe (FIFO)
zDefinir proprietaire/permissions et verifier automatiquement

Exemples concrets

1. Creer un repertoire de travail pour une application

# /etc/tmpfiles.d/myapp.conf d /run/myapp 0755 myapp myapp -

2. Nettoyer automatiquement les fichiers temporaires de plus de 7 jours

# /etc/tmpfiles.d/temp-cleanup.conf # Nettoyer /tmp tous les jours pour les fichiers de plus de 7 jours r /tmp/*-*-*-*-* - - - 7d -

3. Definir un fichier de configuration avec contenu par defaut

# /etc/tmpfiles.d/myapp.conf # Creer le fichier de config s'il n'existe pas f /etc/myapp.conf 0640 root root - PORT=8080\nPIDFILE=/run/myapp.pid\n

4. Creer un lien symbolique

# Creer un lien vers un socket L /run/myapp.sock - root root - /dev/null

Commandes de gestion

Appliquer les regles manuellement

# Executer toutes les regles (creer/Mettre a jour) sudo systemd-tmpfiles --create
# Nettoyer les fichiers temporaires selon l'age sudo systemd-tmpfiles --clean
# Les deux a la fois sudo systemd-tmpfiles --create --clean

Verifier l'etat

# Lister les regles chargees et leur statut systemd-tmpfiles --cat-config
# Simuler sans executer (dry-run) sudo systemd-tmpfiles --create --dry-run
# Afficher les fichiers qui seraient supprimes par --clean sudo systemd-tmpfiles --clean --dry-run

Supprimer manuellement un repertoire defini par tmpfiles

# Supprimer immediatement /run/myapp (le recreer au prochain demarrage) sudo rm -rf /run/myapp # Ou via tmpfiles sudo systemd-tmpfiles --remove /run/myapp

Integration avec systemd

Le service systemd-tmpfiles-setup.service s'execute au demarrage pour appliquer les regles. Trois services gerent le cycle de vie :

ServiceRôleOrdre
systemd-tmpfiles-setup.serviceCree les fichiers/repertoires au demarrageLocal fs target
systemd-tmpfiles-clean.timerDeclenche le nettoyage periodiqueChaque jour
systemd-tmpfiles-clean.serviceExecute le nettoyage selon l'agePar le timer

Modifier la frequence de nettoyage

# Voir la configuration du timer systemctl cat systemd-tmpfiles-clean.timer
# Exemple de sortie : # [Timer] # OnBootSec=15min # OnUnitActiveSec=daily
# Overrider le timer pour nettoyer toutes les heures sudo systemctl edit systemd-tmpfiles-clean.timer
# Contenu a ajouter dans l'override : # [Timer] # OnBootSec=15min # OnUnitActiveSec=1h

Exemple reel : rule pour PostgreSQL

# /usr/lib/tmpfiles.d/postgresql.conf # (fourni par le paquet PostgreSQL) d /var/run/postgresql 0755 postgres postgres -

Ce fichier garantit que le repertoire /var/run/postgresql existe avant le demarrage de PostgreSQL. Si le repertoire est supprime en cours d'execution, il est recree au prochain demarrage ou via systemd-tmpfiles --create.

Exemple : nettoyage automatique des logs anciens

# /etc/tmpfiles.d/log-cleanup.conf # Supprimer les vieux fichiers dans /var/log/myapp tous les jours r /var/log/myapp/*.log - - - 30d -

Bonnes pratiques

  • Toujours placer les regles personnelles dans /etc/tmpfiles.d/, jamais dans /usr/lib/tmpfiles.d/
  • Utiliser l'age (7d, 24h) pour que le nettoyage automatique fonctionne
  • Specifier UID/GID par nom quand c'est possible (plus lisible)
  • Tester avec --dry-run avant d'appliquer
  • Verifier les regles existantes avant d'en creer de nouvelles : systemd-tmpfiles --cat-config
  • Pour /tmp, ne pas specifier d'age trop court : certains programmes expectant que les fichiers y persistent entre sessions

Depannage courant

Un repertoire n'est pas cree au demarrage

# Verifier que le service tmpfiles est actif systemctl status systemd-tmpfiles-setup.service
# Verifier les erreurs dans les logs journalctl -u systemd-tmpfiles-setup.service
# Forcer la creation maintenant sudo systemd-tmpfiles --create

Les fichiers ne sont pas supprimes automatiquement

# Verifier que le timer est actif systemctl status systemd-tmpfiles-clean.timer
# Lister les prochaines executions systemctl list-timers systemd-tmpfiles-clean.timer
# Forcer le nettoyage maintenant sudo systemd-tmpfiles --clean

Resume

CommandeRôle
systemd-tmpfiles --createCreer fichiers/repertoires selon les regles
systemd-tmpfiles --cleanSupprimer les fichiers selon l'age
systemd-tmpfiles --cat-configAfficher toutes les regles chargees
systemd-tmpfiles --removeSupprimer les fichiers d'une regle
systemctl status ...tmpfiles-*Verifier les services associes

systemd-tmpfiles est un outil essentiel pour tout administrateur Linux. Il centralise la gestion des fichiers temporaires, previent l'accumulation et garantit que les repertoires indispensables existent au demarrage. Un seul fichier de regles peut remplacer plusieurs lignes de scripts shell dans les unit files.
