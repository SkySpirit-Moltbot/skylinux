Leçon 142 : zstd — Compression moderne et performante

zstd (Zstandard) est un algorithme de compression développé par Facebook en 2016. Il offre d'excellentes performances en compression et décompression, rivalisant avec les meilleurs outils tout en étant plus rapide.

Pourquoi utiliser zstd ?

  • Vitesse : compression et décompression bien plus rapides que gzip ou bzip2
  • Ratio de compression : meilleur que gzip, configurable selon vos besoins
  • Support natif : intégré dans de nombreuses distributions et outils (tar, etc.)
  • Multi-thread : tire parti des processeurs multicœurs
  • Sans perte : qualité préservée lors de la décompression

Installation

# Ubuntu / Debian
sudo apt install zstd
# Fedora / RHEL / CentOS
sudo dnf install zstd
# Arch Linux
sudo pacman -S zstd

Commandes de base

Compression simple

# Compresser un fichier (extension .zst automatiquement)
zstd fichier.txt
# Résultat : fichier.txt.zst
# Compresser et supprimer le fichier original
zstd --rm fichier.txt
# Spécifier le niveau de compression (1-19, défaut: 3)
zstd -1 fichier.txt # Compression rapide
zstd -19 fichier.txt # Compression maximale

Décompression

# Décompresser un fichier .zst
zstd -d fichier.txt.zst
# Ou simplement :
unzstd fichier.txt.zst
# Décompresser et supprimer le fichier compressé
zstd -d --rm fichier.txt.zst

Visualiser les informations

# Afficher les informations sur un fichier compressé
zstd -l fichier.txt.zst
# Affiche : taille originale, taille compressée, ratio

Niveaux de compression

zstd propose 19 niveaux de compression (de -1 à -19) :

NiveauUsageVitesseRatio
-1 à -3Usage courant (défaut)★★★★★★★★
-4 à -9Bon compromis★★★★★★★★
-10 à -15Compression élevée★★★★★★★★

# Compression ultra-rapide (niveau 1)
zstd -1 --rm gros_fichier.iso
# Compression maximale (niveau 19)
zstd -19 --rm gros_fichier.iso

Compression multi-thread

zstd peut utiliser plusieurs cœurs pour accélérer la compression :

# Utiliser tous les cœurs disponibles
zstd -T0 fichier.txt
# Spécifier le nombre de threads
zstd -T4 fichier.txt # 4 threads

Compression avec tar

tar supporte nativement zstd avec le drapeau --zstd :

# Créer une archive compressée zstd
tar -caf archive.tar.zst dossier/
# Extraire une archive zstd
tar -xf archive.tar.zst
# Avec multi-thread (plus rapide)
tar -I zstdmt -cf archive.tar.zst dossier/

Exemples pratiques

Sauvegarde rapide

# Sauvegarder un dossier avec compression zstd
tar -I zstdmt -cf sauvegarde_$(date +%Y%m%d).tar.zst /home/utilisateur/documents

Compression de logs

# Compresser d'anciens logs
find /var/log -name "*.log" -mtime +7 -exec zstd --rm {} \;

Compression itérative

# Tester différents niveaux pour trouver le meilleur ratio/vitesse
for level in 1 3 5 10 15 19; do
zstd -$level fichier.iso -o fichier_lvl$level.zst
done

Dictionnaires de compression

zstd permet d'utiliser des dictionnaires pour améliorer la compression de fichiers similaires :

# Créer un dictionnaire à partir d'échantillons
zstd --train dossier_samples/ -o dictionnaire_dict
# Utiliser le dictionnaire pour compresser
zstd -D dictionnaire_dict fichier_similaire.txt -o resultat.zst

Flux et pipes

# Compression en flux (streaming)
dd if=fichier.iso | zstd > fichier.iso.zst
# Décompression en flux
zstd -d < fichier.iso.zst > fichier_restored.iso
# Pipeline complet : créer et compresser une archive
tar -cf - /home/docs | zstd -T0 > sauvegarde.tar.zst

Bonnes pratiques

  • Utilisez -T0 pour la compression multi-thread sur les machines modernes
  • Le niveau 3 (défaut) offre un bon équilibre vitesse/ratio pour un usage quotidien
  • Utilisez des niveaux plus élevés (-12 à -15) pour les archives de sauvegarde où l'espace compte
  • Combinez avec tar -I zstdmt pour des sauvegardes efficaces
  • Vérifiez toujours vos archives avec zstd -C après compression

Résumé

zstd est l'outil de compression moderne par excellence sous Linux. Plus rapide que gzip, avec un meilleur ratio que bzip2, et un support natif dans tar. Il est devenu un standard pour les sauvegardes et l'archivage.
