Leçon 162 : parallel — Exécuter des commandes en parallèle

Quand vous devez traiter beaucoup de fichiers ou exécuter de nombreuses tâches, le faire séquentiellement prend un temps précieux. GNU parallel est un outil qui permet d'exécuter plusieurs commandes simultanément, en utilisant pleinement les cœurs de votre processeur.

1. Installation

Parallel est généralement disponible dans les dépôts de votre distribution :

# Ubuntu / Debian
1sudo apt install parallel
# Fedora / RHEL / CentOS
1sudo dnf install parallel
# Arch Linux
1sudo pacman -S parallel

2. Syntaxe de base

La syntaxe générale de parallel est simple :

parallel commande ::: argument1 argument2 argument3

Les arguments après ::: sont passés à la commande. Par défaut, parallel utilise autant de jobs (tâches) que vous avez de cœurs CPU.

3. Exemples concrets

3.1 Compression de plusieurs fichiers

Compresser 10 fichiers en parallèle (au lieu de les compresser un par un) :

parallel gzip ::: fichier1.txt fichier2.txt fichier3.txt fichier4.txt fichier5.txt

3.2 Traitement d'images avec ImageMagick

Redimensionner 100 photos en parallèle en utilisant 4 jobs simultanés :

parallel -j 4 convert -resize 800x600 {} {} ::: *.jpg
Note : Ici {} représente le nom du fichier en cours de traitement. Vous pouvez utiliser {.} pour le nom sans l'extension.

3.3 Téléchargements parallèles avec curl

parallel curl -O ::: https://exemple.com/fichier1.zip https://exemple.com/fichier2.zip https://exemple.com/fichier3.zip

3.4 Compter les lignes de plusieurs fichiers

parallel wc -l ::: fichier1.txt fichier2.txt fichier3.txt

4. Lire les arguments depuis un fichier ou stdin

4.1 Depuis un fichier avec :::

parallel commande ::: "$(cat liste.txt)"

4.2 pipe et :::

cat urls.txt | parallel curl -O

4.3 Avec --pipe pour stdin

Distribuer les lignes d'un fichier vers plusieurs processus :

cat large_fichier.txt | parallel --pipe --block 10k commande
--pipe divise stdin en blocs et exécute la commande sur chaque bloc.
--block définit la taille de chaque bloc (ici 10 Ko).

5. Contrôler le nombre de jobs simultanés

OptionDescription
-j NExécuter N jobs en parallèle (par défaut = nombre de CPU)
-j 0Exécuter autant de jobs que de cœurs CPU
-j 1Exécution séquentielle (1 seul job à la fois)
--jobs NForme longue de -j
parallel -j 2 commande ::: a b c d e f

6. Placeholders utiles

PlaceholderSignificationExemple
{}Argument completfichier.jpg
{.}Sans extensionfichier
{/}Juste le nom du fichierfichier.jpg
{//}Répertoire parent/home/user/photos
{/.}Nom sans extensionfichier

Exemple avec placeholders

parallel convert {} {.}_small.jpg ::: *.jpg

Cela convertit chaque photo.jpg en photo_small.jpg.

7. Garder l'ordre des résultats

Par défaut, les résultats peuvent arriver dans un ordre différent de celui des entrées (selon le temps d'exécution). Pour forcer l'ordre :

parallel --keep-order commande ::: a b c

8. Journal et progression

parallel --bar commande ::: $(seq 1 100)

Affiche une barre de progression pendant l'exécution.

parallel --joblog mon_log.txt commande ::: args

Enregistre les détails de chaque job dans un fichier log.

9. Arrêter sur erreur

parallel --halt now,fail=1 commande ::: args
OptionComportement
--halt now,fail=1Arrête dès qu'un job échoue
--halt now, fail=2Arrête quand 2 jobs ont échoué
--halt neverNe s'arrête jamais (par défaut)

10. Chaînage de commandes avec :::

Vous pouvez passer des arguments à plusieurs commandes :

parallel echo fichier {} "&&" gzip {} ::: txt log csv

11. Scripts complexes avec --pipepart

Pour distribuer efficacement de gros fichiers sur plusieurs cœurs :

parallel --pipepart --block 100M -a gros_fichier.bin wc -l
--pipepart est plus rapide que --pipe car il lit directement le fichier sans passer par un pipe.

12. Exemple complet : redimensionner des images

Redimensionner toutes les photos d'un dossier en 800x600 avec 4 processus simultanés

mkdir -p petite_images && cd petite_images && parallel --bar -j 4 convert -resize 800x600 ../images/{} {} ::: *.jpg

13. Résumé des options principales

OptionDescription
-j NNombre de jobs parallèles
--barAfficher une barre de progression
--joblogLog des jobs exécutés
--haltArrêt sur erreur
--pipeTraiter stdin en parallèle
--pipepartVersion rapide de --pipe
{}Placeholder pour l'argument
--dry-runAfficher sans exécuter

Exercices

  1. Installez parallel sur votre système.
  2. Créez 10 fichiers texte et compressez-les en parallèle avec gzip.
  3. Utilisez parallel avec wc -l pour compter les lignes de plusieurs fichiers simultanément.
  4. Comparez le temps d'exécution entre un traitement séquentiel et parallèle avec time.
  5. Générez une liste de 20 URLs bidon et utilisez parallel curl pour les traiter.
