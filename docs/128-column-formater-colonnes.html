Leçon 128 : column — Formater du texte en colonnes

Introduction

La commande column est un outil puissant pour formater du texte en colonnes nettes et lisibles. Elle transforme un texte brut, souvent issu d'une commande ou d'un fichier, en un affichage tabulaire aligné automatiquement.

Utile pour visualiser des données tabulaires, des listes de fichiers, des tableaux de configuration ou des sorties de commandes — sans avoir à écrire de script complexe.

Syntaxe de base

column [options] [fichier...]

Utilisation simple

Formater un fichier texte délimité

Créons d'abord un fichier d'exemple avec des données séparées par des deux-points (:) :

cat > utilisateurs.txt << 'EOF' Pierre:Administrateur:1001:Linux Marie:Développeur:1002:Python Jean:Designer:1003:GIMP Sophie:Technicien:1004:Réseau EOF

Puis affichons-le en colonnes avec le délimiteur : :

column -t -s ':' utilisateurs.txt

Résultat :

Pierre Administrateur 1001 Linux Marie Développeur 1002 Python Jean Designer 1003 GIMP Sophie Technicien 1004 Réseau

Sans délimiteur (espace)

Par défaut, column détecte les espaces comme séparateurs :

cat mots.txt un deux trois alpha beta gamma foo bar baz column mots.txt

Options principales

OptionDescription
-tCrée un tableau en détectant automatiquement le nombre de colonnes
-s SEPSpécifie le ou les caractères séparateurs (par exemple :,;)
-c LARGEURLimite la largeur totale de sortie à LARGEUR colonnes
-o CHAÎNEUtilise CHAÎNE comme séparateur de colonnes (par défaut : deux espaces)
-xRemplit les colonnes par lignes d'abord (par défaut : par colonnes)

Exemples pratiques

Liste de fichiers avec ls

# Lister les fichiers et afficher en colonnes ls -l /usr/bin | awk '{print $9}' | grep -v '^$' | column # Ou plus simplement ls -1 /usr/share/man/man1 | head -20 | column

Afficher /etc/passwd de manière lisible

sudo cut -d: -f1,5,6 /etc/passwd | column -t -s ':'

Tableau de configuration réseau

cat > reseau.txt << 'EOF' eth0:192.168.1.10:255.255.255.0:actif wlan0:10.0.0.5:255.0.0.0:actif docker0:172.17.0.1:255.255.0.0:inactif EOF column -t -s ':' reseau.txt

Utiliser un séparateur personnalisé

# Avec un CSV (virgule) echo "Nom,Pays,Ville" > data.csv echo "Pierre,Suisse,Berne" >> data.csv echo "Marie,France,Paris" >> data.csv column -t -s ',' data.csv

Limiter la largeur avec -c

# Forcer un affichage sur 80 colonnes maximum column -t -c 80 fichier.txt

Remplissage par lignes avec -x

Par défaut, column remplit colonne par colonne. L'option -x remplit ligne par ligne :

# Sans -x (par défaut : colonne par colonne) seq 1 12 | column # Avec -x (ligne par ligne) seq 1 12 | column -x

Combiner avec d'autres commandes

Avec ps pour afficher les processus

ps aux | awk '{print $2, $11}' | head -15 | column -t

Avec df pour les espaces disque

df -h | tail -n +2 | awk '{print $1, $2, $5}' | column -t

Avec find

find . -maxdepth 1 -type f -printf '%f\n' | sort | column

Avec grep pour filtrer et formater

grep -E '^[^#]*=' /etc/sysctl.conf | column -t -s '='

Format de sortie personnalisé

Changer le séparateur de colonnes

# Utiliser des barres verticales comme séparateur column -t -s ':' -o ' | ' fichier.txt

Sans tableau (-t désactivé)

Sans -t, le texte est simplement réorganisé en colonnes :

seq 1 20 | column

Cas d'utilisation courants

Préparer des données pour un rapport

# Transformer un CSV en tableau lisible cat rapport.csv | column -t -s ',' > rapport-formate.txt

Afficher les variables d'environnement

env | sort | column -t -s '='

Visualiser les services systemd actifs

systemctl list-units --type=service --state=active --no-pager | awk '{print $1, $2, $4}' | column -t

Comparer des paquets installés

dpkg -l | awk '{print $2, $3}' | head -20 | column -t

Limites de column

  • column ne gère pas lesCellules multilignes — chaque ligne doit être indépendante.
  • Si une cellule contient elle-même le séparateur, le résultat peut être décalé.
  • Sur des fichiers très volumineux, le traitement peut être lent.
  • La largeur de sortie dépend du terminal — -c peut être nécessaire sur des terminaux étroits.

Bonnes pratiques

  • Utilisez toujours -t pour un affichage tabulaire clair.
  • Combinez -s avec le bon délimiteur selon le format de votre fichier.
  • Pour des données complexes, envisagez awk ou pandas pour plus de contrôle.
  • Testez d'abord sans -t pour voir comment column interprète vos données.
  • Utilisez -x pour un rendu plus naturel sur des listes courtes.

column est l'outil idéal pour transformer rapidement des données brutes en tableaux lisibles. Que ce soit pour visualiser des fichiers de configuration, des sorties de commandes ou des données tabulaires, il fait gagner du temps sans nécessiter de programmation.
