Leçon 134 - mktemp — Créer des fichiers et répertoires temporaires sécurisés

La commande mktemp crée des fichiers et répertoires temporaires avec des noms uniques et sécurisés. Contrairement à créer un fichier /tmp/test.txt manuellement (risque de collision), mktemp génère des noms aléatoires impossibles à deviner. C'est indispensable pour les scripts qui necesitan un espace de travail temporaire, le traitement de données intermédiaires, ou toute situation où vous ne voulez pas polluer le système avec des fichiers temporaires mal nommés.

Pourquoi utiliser mktemp ?

Le répertoire /tmp est un espace partagé. Si vous créez un fichier appelé temp.txt, vous risquez :

  • Une collision avec un autre processus qui utilise le même nom
  • Un conflit de sécurité si un attaquant prédit le nom du fichier
  • Des résidus de fichiers si votre script crash avant le nettoyage

mktemp résout ces problèmes en générant des noms aléatoires et en vous garantissant que le fichier n'existe pas encore.

Syntaxe de base

mktemp [OPTIONS] [TEMPLATE]

Options principales

OptionDescription
-d, --directoryCréer un répertoire temporaire au lieu d'un fichier
-p REP, --tmpdir=REPCréer dans le répertoire spécifié (par défaut /tmp)
-u, --dry-runNe pas créer, juste retourner le nom (peu sécurisé)
-q, --quietNe pas afficher d'erreur si la création échoue

Créer un fichier temporaire

Sans template (comportement par défaut)

Par défaut, mktemp crée un fichier dans /tmp avec le préfixe tmp. et ajoute 10 caractères aléatoires :

mktemp
# /tmp/tmp.xKj9mNpL2q

Chaque appel génère un nom différent :

mktemp && mktemp && mktemp
# /tmp/tmp.aB3cD7eF9h
# /tmp/tmp.iJ1kL4mN6p
# /tmp/tmp.qR7sT0uV3x

Avec un template personnalisé

Vous pouvez définir votre propre format avec des X qui seront remplacés par des caractères aléatoires. Le template doit contenir au moins 3 X à la fin :

mktemp /tmp/monfichier-XXXX.txt
# /tmp/monfichier-Kj9m.txt

Utiliser un préfixe plus descriptif :

mktemp /tmp/backup-XXXXXX
# /tmp/backup-aB3cD7

Créer un répertoire temporaire

L'option -d crée un répertoire au lieu d'un fichier :

mktemp -d
# /tmp/tmp.MnPqR5sT8u

Ou avec un template personnalisé :

mktemp -d /tmp/monprojet-XXXXXX
# /tmp/monprojet-eF9gH1

Définir le répertoire parent

Avec -p

Spécifier un répertoire différent de /tmp :

mktemp -p ~/Documents/
# /home/utilisateur/Documents/tmp.jK8LmN

Avec la variable TMPDIR

Vous pouvez aussi définir TMPDIR pour changer le comportement par défaut :

TMPDIR=/var/tmp mktemp
# /var/tmp/tmp.pQ0rS2tU5v

Cas d'usage courants

1. Capturer la sortie d'une commande temporairement

Très utile quand une commande écrit dans un fichier et que vous voulez un nom temporaire :

# Stocker le résultat dans un fichier temporaire
tmpfile=$(mktemp)
commande_lourde > "$tmpfile"
# Traiter le résultat
cat "$tmpfile" | grep "motif"
# Nettoyer
rm "$tmpfile"

2. Travailler sur des fichiers dangereux en sécurité

Avant de modifier un fichier important, faire une copie temporaire pour tester :

tmpfile=$(mktemp)
cp document_important.txt "$tmpfile"
# Tester les modifications sur la copie
sed -i 's/ancien/nouveau/g' "$tmpfile"
# Vérifier le résultat
diff document_important.txt "$tmpfile"
# Si tout est bon, remplacer le fichier original
# mv "$tmpfile" document_important.txt

3. Créer un espace de travail pour un script

Utiliser un répertoire temporaire pour ranger les fichiers intermédiaires d'un script :

#!/bin/bash
# Créer un répertoire de travail temporaire
workdir=$(mktemp -d)
echo "Travail dans: $workdir"
# Trap pour nettoyer en cas d'erreur ou de Ctrl+C
trap "rm -rf '$workdir'" EXIT
# ... faire quelque chose avec $workdir ...
# Le nettoyage se fait automatiquement à la fin

4. Télécharger et extraire temporairement

Télécharger une archive dans un répertoire temporaire pour l'examiner :

tmpdir=$(mktemp -d)
cd "$tmpdir"
wget -q https://example.com/archive.tar.gz
tar -xzf archive.tar.gz
# Explorer le contenu...
cd - > /dev/null
rm -rf "$tmpdir"

5. Stocker un PID ou un état

Créer un fichier pour stocker un état temporaire :

pidfile=$(mktemp /tmp/monapp-pid-XXXX)
echo $$ > "$pidfile"
# ... l'application tourne ...
rm "$pidfile"

Nettoyage automatique avec trap

Le piège classique des fichiers temporaires : si votre script crash ou est interrompu, les fichiers restent. La commande trap permet de nettoyer automatiquement :

#!/bin/bash
# Créer le fichier temporaire
tmpfile=$(mktemp)
# Nettoyer sur sortie normale, erreur, ou interruption
trap 'rm -f "$tmpfile"' EXIT
trap 'rm -f "$tmpfile"; exit 1' INT TERM
# ... votre code ici ...
# Le fichier est automatiquement supprimé à la fin

Pour un répertoire temporaire avec sous-fichiers :

#!/bin/bash
workdir=$(mktemp -d)
trap "rm -rf '$workdir'" EXIT
trap "rm -rf '$workdir'; exit 1" INT TERM HUP
# ... travail ...

Attention : le mode dry-run (-u)

L'option -u génère juste le nom sans créer le fichier. C'est rapide mais peu sécurisé — un autre processus pourrait créer le fichier entre le moment où mktemp génère le nom et celui où vous le créez :

# DANGEREUX - ne faites pas ça
tmp=$(mktemp -u)
commande > "$tmp" # Un autre processus pourrait créer "$tmp" avant

Utilisez toujours -u uniquement quand vous allez créer le fichier immédiatement après :

# Plus sûr si fait immédiatement
tmp=$(mktemp -u)
touch "$tmp" && echo "contenu" > "$tmp" && rm "$tmp"

Vérifier que le fichier existe

Après création, vérifiez que le fichier a bien été créé (et que vous avez les permissions) :

tmpfile=$(mktemp)
if [ -f "$tmpfile" ]; then
echo "Fichier créé: $tmpfile"
else
echo "Erreur: impossible de créer le fichier temporaire"
exit 1
fi

Permissions par défaut

Les fichiers et répertoires créés par mktemp ont des permissions restrictives :

  • Fichiers : 0600 (rw-------) — seul le propriétaire peut lire/écrire
  • Répertoires : 0700 (rwx------) — seul le propriétaire peut lire/écrire/exécuter

C'est sécurisé par défaut. Vous pouvez les modifier si nécessaire :

tmpfile=$(mktemp)
chmod 0644 "$tmpfile" # Lecture pour tous, écriture pour owner

Exemple : script de backup temporaire

Un exemple complet qui utilise mktemp pour un backup sûr :

#!/bin/bash
# Backup temporaire sécurisé
SOURCE="${1:-fichier.txt}"
# Créer un répertoire temporaire pour le backup
backupdir=$(mktemp -d /tmp/backup-XXXXXX)
# Nettoyer automatiquement
trap "rm -rf '$backupdir'" EXIT
# Copier le fichier avec horodatage
timestamp=$(date +%Y%m%d-%H%M%S)
cp "$SOURCE" "$backupdir/backup-$timestamp"
# Compresser le backup
tar -czf "$HOME/backup-$timestamp.tar.gz" -C "$backupdir" .
echo "Backup créé: $HOME/backup-$timestamp.tar.gz"

Bonnes pratiques

  • Utilisez toujours les quotes autour de la variable pour gérer les espaces dans les chemins
  • Combinez avec trap pour nettoyer automatiquement en cas d'interruption
  • Évitez -u sauf si vous créez le fichier immédiatement après
  • Nommez vos templates de manière descriptive pour faciliter le débogage
  • Vérifiez toujours que le fichier/répertoire a été créé avant de l'utiliser
  • Utilisez des répertoires temporaires (-d) pour les opérations multi-fichiers

mktemp est un outil essentiel pour tout script qui nécessite des fichiers ou répertoires temporaires. Sa capacité à générer des noms uniques et sécurisés, combinée avec trap pour le nettoyage automatique, en fait une commande indispensable pour écrire des scripts robustes et sûrs.
